你好！作为你的技术面试官，我非常乐意为你梳理前端面试的全貌。

除了我们刚才聊过的 Vue 3（指令、生命周期）、JavaScript 核心（原型链、深浅拷贝）以及工程化（Git）之外，一个完整的中高级前端面试通常还会围绕以下几个核心维度展开。

为了让你有针对性地复习，我将这些高频考点分门别类地列举出来（只列问题，不附答案，方便你作为自测清单）：

### 一、 JavaScript 进阶与底层机制
1. **闭包（Closure）**：闭包的本质是什么？它在实际开发中有哪些应用场景？如何避免闭包导致的内存泄漏？
2. **事件循环（Event Loop）**：浏览器的宏任务（Macrotask）和微任务（Microtask）是如何调度的？Node.js 的事件循环和浏览器有什么区别？
3. **Promise 与异步编程**：能否手写一个符合 Promises/A+ 规范的 `Promise`（或 `Promise.all` / `Promise.retry`）？`async/await` 的底层实现原理（Generator）是什么？
4. **作用域与 `this` 指向**：词法作用域是什么？`this` 的绑定规则有哪几种？箭头函数的 `this` 有何特殊之处？
5. **V8 引擎与内存管理**：浏览器的垃圾回收机制（GC）是怎样的（标记清除、分代回收）？常见的内存泄漏场景有哪些？

### 二、 前端框架深度探究（以 Vue / React 为主）
1. **响应式原理**：Vue 3 的 `Proxy` 相比 Vue 2 的 `Object.defineProperty` 优势在哪里？它是如何收集依赖和触发更新的？
2. **虚拟 DOM 与 Diff 算法**：Vue 和 React 的 Diff 算法有什么异同？为什么说虚拟 DOM 不一定比原生 DOM 快？
3. **状态管理**：Pinia 相比 Vuex 有哪些架构上的改进？在 React 中，Redux、Zustand 或 Context API 各自的适用场景是什么？
4. **服务端渲染（SSR）**：SPA（单页应用）的 SEO 和首屏痛点是什么？Nuxt.js 或 Next.js 是如何解决这些问题的？同构渲染的原理是什么？
5. **React 专属（若你是双修）**：React Fiber 架构解决了什么问题？Hooks 的闭包陷阱是怎么产生的？`useMemo` 和 `useCallback` 的正确使用时机？

### 三、 计算机网络与浏览器原理
1. **HTTP 协议演进**：HTTP/1.1、HTTP/2、HTTP/3 各自的核心特性和解决了什么性能痛点（如队头阻塞）？
2. **跨域机制（CORS）**：为什么会有同源策略？CORS 的简单请求和复杂请求（Preflight 预检请求）有什么区别？除了 CORS 还有哪些跨域方案？
3. **浏览器渲染全流程**：从在浏览器地址栏输入 URL 到页面展现，经历了哪些完整步骤？
4. **重绘（Repaint）与回流/重排（Reflow）**：它们的区别是什么？在 CSS 和 JS 层面如何尽最大可能避免触发回流？
5. **前端安全**：XSS（跨站脚本攻击）和 CSRF（跨站请求伪造）的攻击原理分别是什么？在实际项目中如何防御？

### 四、 前端工程化与基建
1. **构建工具（Webpack vs Vite）**：Webpack 的 Loader 和 Plugin 有什么区别？Vite 为什么在开发环境下那么快（ESM 机制）？
2. **性能优化（Tree Shaking）**：Tree Shaking 的工作原理是什么？为什么它强依赖于 ES Modules？如何避免代码产生副作用（Side Effects）导致 Tree Shaking 失效？
3. **模块化规范**：CommonJS 和 ES Modules 的核心差异是什么（动态引用 vs 静态分析、值拷贝 vs 引用绑定）？
4. **前端自动化与 CI/CD**：你们团队的部署流程是怎样的？用过 Jenkins、GitLab CI 或 GitHub Actions 吗？
5. **包管理**：npm、yarn、pnpm 的依赖嵌套和幽灵依赖问题是什么？pnpm 是如何通过硬链接和软链接解决这些问题的？

### 五、 性能优化与体验（Web Vitals）
1. **核心性能指标**：你了解 Google 提出的 Core Web Vitals 吗（如 LCP、FID、CLS）？如何测量和优化这些指标？
2. **资源加载优化**：图片懒加载、路由懒加载的实现原理？什么是 `preload` 和 `prefetch`？
3. **大数据量渲染**：如果后端一次性返回 10 万条数据，前端如何保证页面不卡顿（虚拟列表/长列表优化、时间分片、`requestAnimationFrame`）？
4. **缓存策略**：浏览器的强缓存（Cache-Control、Expires）和协商缓存（ETag、Last-Modified）的流转逻辑是怎样的？

### 六、 架构设计与项目经验（定级为高级前端的核心）
1. **微前端架构**：了解过 qiankun 或 single-spa 吗？微前端的核心痛点（沙箱隔离、样式冲突、主子应用通信）是如何解决的？
2. **Monorepo（单体仓库）**：为什么要用 Monorepo（如 Turborepo、Lerna）？它解决了多包管理的哪些痛点？
3. **设计模式**：在前端开发中（或源码中）用到过哪些设计模式？（如观察者模式、发布订阅模式、单例模式、策略模式等）。
4. **复杂问题解决能力（STAR 面试法）**：你在过去的项目中遇到过最难的技术挑战是什么？你是如何排查、定位并最终解决它的？最终产出了什么业务价值？
