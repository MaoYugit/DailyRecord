### 一、 条件与列表渲染指令（最高频考点）

**1. `v-show` 与 `v-if` / `v-else-if` / `v-else`**
*   **作用**：两者都用于控制元素的显示与隐藏。
*   **面试官核心考点（区别）**：
    *   `v-show` 是通过修改 CSS 的 `display` 属性来切换，DOM 元素始终保留；适合**频繁切换**的场景。
    *   `v-if` 是真正的条件渲染，会触发 DOM 元素的销毁和重建，带有完整的组件生命周期；适合**条件不常改变**的场景。

**2. `v-for`**
*   **作用**：基于源数据多次渲染元素或模板块。
*   **面试官核心考点**：
    *   **必须绑定 `key`**：解释清楚 `key` 在 Diff 算法中的作用（复用节点，提高更新效率，避免状态错乱）。
    *   **Vue 3 破坏性更新**：在 Vue 2 中，`v-for` 的优先级高于 `v-if`（同级使用会导致性能浪费）；**在 Vue 3 中，`v-if` 的优先级高于 `v-for`**。如果同级使用，`v-if` 将无法访问到 `v-for` 作用域内的变量，会报错。面试时一定要强调**强烈不建议在同一元素上同时使用这两个指令**。

### 二、 数据绑定与事件指令

**3. `v-bind` (简写为 `:`)**
*   **作用**：动态绑定一个或多个 attribute，或一个组件 prop。
*   **Vue 3 亮点**：Vue 3 中 `v-bind` 的绑定顺序会影响最终结果（同名属性后面覆盖前面）。另外在 `<style>` 中可以使用 `v-bind()` 绑定响应式变量（CSS in JS 的官方实现）。

**4. `v-on` (简写为 `@`)**
*   **作用**：绑定事件监听器。
*   **面试官核心考点**：熟知常用的事件修饰符，如 `.stop` (阻止冒泡)、`.prevent` (阻止默认行为)、`.once` 等。

**5. `v-model`**
*   **作用**：在表单控件或组件上创建双向绑定。
*   **Vue 3 破坏性更新（重点）**：
    *   默认绑定的 prop 名称从 `value` 变成了 `modelValue`，事件名从 `input` 变成了 `update:modelValue`。
    *   **废弃了 `.sync` 修饰符**，现在可以直接在一个组件上使用多个 `v-model`（例如 `v-model:title="title" v-model:content="content"`）。
    *   支持自定义 `v-model` 修饰符。

### 三、 内容渲染指令

**6. `v-text`**
*   **作用**：更新元素的文本内容（等同于原生 `textContent`）。相比于插值表达式 `{{}}`，它会替换元素内部所有的内容。

**7. `v-html`**
*   **作用**：更新元素的 `innerHTML`。
*   **面试官核心考点**：必须主动提到 **XSS 攻击风险**。绝不能将用户输入的内容直接用 `v-html` 渲染，通常需要配合 `DOMPurify` 等库进行转义清洗。

### 四、 组件与插槽指令

**8. `v-slot` (简写为 `#`)**
*   **作用**：提供具名插槽或需要接收 prop 的作用域插槽。
*   **注意**：只能用于 `<template>` 标签或组件上。

### 五、 性能优化与编译指令（区分高级/初级前端的试金石）

**9. `v-once`**
*   **作用**：仅渲染元素和组件**一次**。后续重新渲染时，元素/组件及其所有的子节点将被视为静态内容并跳过。
*   **场景**：用于优化包含大量静态内容的组件。

**10. `v-memo` (Vue 3.2+ 新增，高级考点)**
*   **作用**：缓存一个模板的子树。接受一个依赖数组，只有数组里的值发生变化时，才会重新渲染该部分，否则复用之前的 VNode。
*   **面试官核心考点**：它和 `v-once` 有什么区别？(`v-once` 是永远不更新，`v-memo` 是根据依赖项有条件地更新)。常用于配合 `v-for` 渲染超长列表，做细粒度的性能优化。

**11. `v-pre`**
*   **作用**：跳过该元素及其所有子元素的编译。最常见的用法是显示原始双大括号标签及内容。
*   **场景**：跳过没有指令的巨大静态节点可以加快编译速度。

**12. `v-cloak`**
*   **作用**：这个指令保持在元素上直到关联组件实例结束编译。结合 CSS (`[v-cloak] { display: none }`) 使用，可以隐藏未编译的 Mustache 标签直到组件准备完毕。
*   **注意**：在如今主流的 Vue CLI / Vite 构建的单文件组件 (SFC) 项目中，因为模板都是预编译的，所以基本用不到了。
