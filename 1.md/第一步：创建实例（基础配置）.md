在前端面试中，如果一个候选人说他只会调接口，却不清楚 `request.ts` 是怎么写的，那他的薪资很难突破 5k。

**拿 7k 的核心能力之一，就是能从零搭建一个业务通用的 Axios 封装。** 你不需要背代码，但你必须理解这个“流水线”是怎么跑的。

我把 Axios 的封装拆解为 **“三道工序”**，你对照着看你公司那个 `request.ts` 就能秒懂。

---

### 第一步：创建实例（基础配置）

为什么要封装？因为每个接口都要写 `http://api.xxx.com` 太麻烦了。我们要统一配置。

```javascript
import axios from 'axios'

const service = axios.create({
  baseURL: import.meta.env.VITE_API_URL, // 刚才说的环境切换变量
  timeout: 5000, // 5秒超时就报错，防止页面死等
})
```

---

### 第二步：请求拦截器（发货前的检查）

**面试官：** “你怎么在请求里带上 Token？”
**你的回答：** “在**请求拦截器**里统一处理。”

请求拦截器就像是快递发货前的检查员，给每个包裹贴上“通行证”。

```javascript
service.interceptors.request.use(
  config => {
    // 1. 从 Pinia 或 LocalStorage 获取 Token
    const token = localStorage.getItem('token')
    
    // 2. 如果有 Token，就塞进 Header 头里
    if (token) {
      config.headers['Authorization'] = `Bearer ${token}`
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)
```

---

### 第三步：响应拦截器（收货后的拆箱）

这是最关键的一步。后端返回的数据通常长这样：
```json
{
  "code": 200,
  "data": { "name": "张三" },
  "message": "成功"
}
```
**如果不封装：** 你每次都要写 `res.data.data.name`，多写一个 `.data` 很烦。
**如果封装：** 我们在拦截器里直接把 `data` 给取出来。

```javascript
service.interceptors.response.use(
  response => {
    const res = response.data // 这是后端返回的整个大对象
    
    // 如果 code 不是 200，说明业务上有错（比如密码错了）
    if (res.code !== 200) {
      // 弹出错误提示（用 Element Plus 的消息组件）
      ElMessage.error(res.message || '系统出错了')
      return Promise.reject(new Error(res.message))
    }
    
    // 如果是 200，直接返回 data 里面的核心内容
    return res.data
  },
  error => {
    // 这里处理 HTTP 状态码错误（比如 401 Token 过期，404 找不到）
    if (error.response.status === 401) {
      // 清除 Token，跳回登录页
    }
    return Promise.reject(error)
  }
)
```

### 四、 接口模块化（你应该怎么写业务）

不要在页面里直接写 `axios.get`。要按照功能模块写 API 文件，比如 `api/user.js`：

```javascript
import request from '@/utils/request' // 引入你封装好的 request.ts

// 登录接口
export function login(data) {
  return request({
    url: '/user/login',
    method: 'post',
    data
  })
}

// 获取用户信息
export function getInfo() {
  return request({
    url: '/user/info',
    method: 'get'
  })
}
```

### 五、 面试常问问题

#### 1. 为什么要做 Axios 拦截器？
*   **统一处理 Token：** 不用每个接口手动传。
*   **统一处理错误：** 比如 401 跳转登录、500 报错提示，写一次，全项目生效。
*   **简化数据结构：** 在响应拦截器里直接返回 `res.data`，页面代码更简洁。

#### 2. 怎么处理 Token 过期？
*   **回答：** “在**响应拦截器**里捕获 `401` 状态码。一旦发现 401，就清除本地 Token 和 Pinia 里的状态，然后利用 `router.push('/login')` 强制用户跳转到登录页。”

#### 3. 你在项目中遇到过跨域吗？怎么解？
*   **回答：** “遇到过。开发环境我配置了 **Vite 的 Proxy 代理**；生产环境我们公司一般是运维配置 **Nginx 反向代理**。”（这个回答价值 7k）。

### 给你的实战建议：

1.  **去翻项目代码：** 找到你公司项目里的 `utils/request.ts` 或 `api/index.ts`，你会发现结构跟我上面写的一模一样。
2.  **手写一遍封装：** 自己开个练习项目，试着不看参考，自己把 Axios 的三步走（实例、请求拦截、响应拦截）写出来。
3.  **理解 Promise：** Axios 返回的是 Promise。你要搞清楚 `.then().catch()` 和 `async/await` 的用法。

**总结：**
对于 7k 岗位，面试官不指望你会用 Axios 写出多么花哨的黑科技，但你一定要表现出：**“我知道数据是怎么流转的，我知道 Token 是怎么带上的，我知道报错了该在哪里统一处理。”** 

把这个流程讲顺了，你就不再是一个只会切图的，而是一个合格的初级前端开发。加油！
