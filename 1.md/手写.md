## 手写

### 一、 JavaScript 基础（核心原理）
1.  **手写 `call`、`apply`、`bind`**（考察 `this` 指向及闭包）
2.  **手写 `new` 操作符**（考察构造函数原理）
3.  **手写 `instanceof` 关键字**（考察原型链查找）
4.  **手写 Object.create()**（考察原型继承）
5.  **手写 深拷贝 (Deep Clone)**（考察递归及循环引用处理）
6.  **手写 类型检测函数**（能够准确判断 Array, Object, Null 等）

### 二、 常用工具函数（高频实用）
7.  **手写 防抖 (Debounce) 与 节流 (Throttle)**（最常考，需理解应用场景）
8.  **手写 数组扁平化 (Flat)**（考察递归、reduce 或扩展运算符）
9.  **手写 数组去重**（考察 Set、Map 或 filter）
10. **手写 函数柯里化 (Currying)**（考察闭包与参数收集）
11. **手写 解析 URL 参数为对象**（考察字符串处理或正则）
12. **手写 模板引擎字符串替换**（如将 `{{name}}` 替换为实际数据）

### 三、 异步编程（进阶重难点）
13. **手写 Promise 核心逻辑**（包含状态切换、then 方法，这是大厂终极挑战）
14. **手写 Promise.all / Promise.race / Promise.allSettled**
15. **手写 基于 Promise 的 AJAX 请求封装**
16. **手写 异步并发限制 (Concurrency Limit)**（控制同一时间只有 N 个请求在执行）
17. **手写 sleep 函数**（利用 Promise 和 setTimeout）

### 四、 设计模式
18. **手写 发布-订阅模式 (EventEmitter)**（包含 on, emit, off, once 方法）
19. **手写 观察者模式**
20. **手写 单例模式**（JavaScript 实现方式）

### 五、 DOM 与 浏览器相关
21. **手写 事件委托 (Event Delegation)**
22. **手写 将虚拟 DOM 转换为真实 DOM**（简单的渲染函数）
23. **手写 循环加载图片**（处理异步加载与回调）

### 六、 基础算法（前端版）
24. **手写 快速排序 (Quick Sort) 或 冒泡排序**
25. **手写 二分查找 (Binary Search)**
26. **手写 斐波那契数列**（递归 vs 动态规划）
27. **手写 LRU 缓存淘汰算法**（大厂高频）

---

**建议练习方法：**
*   **第一步**：先理解该题目对应的 **理论原理**（如：`new` 到底做了哪四件事？）。
*   **第二步**：手写出基础版本（满足核心功能）。
*   **第三步**：考虑 **边缘情况**（如：参数为空怎么办？遇到循环引用怎么办？）。
*   **第四步**：在白纸或无代码提示的编辑器中独立完成。
