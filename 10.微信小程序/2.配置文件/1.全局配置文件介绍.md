### `app.json`

```json
{
  "entryPagePath": "pages/index/index",
  "pages": [
    "pages/index/index",
    "pages/list/list",
    "pages/cate/cate",
    "pages/profile/profile",
    "pages/cart/cart"
  ],
  "window": {
    "navigationBarTitleText": "Normal Strule",  // 标题文字
    "navigationBarBackgroundColor": "#f3514f",	// 状态栏和导航栏背景颜色
    "enablePullDownRefresh": true,				// 是否开启下拉刷新
    "backgroundColor": "#efefef",				// 下拉窗口背景色
    "backgroundTextStyle": "light"				// 下拉窗口文字亮还是暗 dark
  },
  "style": "v2",
  "sitemapLocation": "sitemap.json",
  "lazyCodeLoading": "requiredComponents"
}
```

`pages`：小程序由哪些页面组成，每一项对应一个页面的路径信息

- 页面路由不需要写文件后缀
- 新增/减少页面，都需要对`pages`数组进行修改
- 未指定e`ntryPagePath`时，数组的第一项代表小程序的初始页面（首页）

`window`：用于设置小程序的状态栏、导航条、标题、窗口背景色

- 状态栏：电量那一行
- 导航条：微信胶囊那一行，标题也在这
- 窗口：下拉刷新时显示的那一个灰色页面，一般不显示

`tabBar`：定义小程序顶部 / 底部 tab 栏，tab 按照数组的顺序排序，list 配置最少2个，最多5个

- `borderStyle`：导航栏靠近页面那边的边框颜色

- `backgroundColor`：导航栏背景颜色

- `color`：文字颜色

- `selectedColor`：文字被选中时的颜色

- `list`：tab 的一些配置

  - `pagePath`：tab 对应页面的路径
  - `iconPath`：tab 图标对应的路径
  - `SelectedIconPath`：tab 被选中之后页面对应的路径
  - `text`：tab 文字
