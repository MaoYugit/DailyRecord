### **第九章：与 TypeScript 结合**

到目前为止，我们一直在使用纯 JavaScript。它灵活、易上手，非常适合快速原型开发。但当项目变得庞大、团队成员增多时，JavaScript 的动态类型特性（一个变量可以随时改变类型）就可能成为 bug 的温床。

**TypeScript (TS)** 是 JavaScript 的一个**超集**，它为 JavaScript 添加了**静态类型系统**。你可以把它想象成给你的代码装上了一套“**智能导航和防撞系统**”。

**为什么要在 Vue 中使用 TypeScript？(面试核心)**

*   **代码更安全、更健壮：** TS 会在**编译时**（你写代码的时候）就检查出潜在的类型错误（比如把一个数字传给了期望字符串的函数），而不是等到**运行时**（用户在使用时）才报错。这能消灭一整类的 bug。
*   **无与伦-比的开发体验：** 拥有类型信息后，你的代码编辑器（如 VS Code）能提供极其精准的**自动补全、智能提示和重构**功能。你不再需要频繁地去查阅其他文件的代码来确定一个对象的结构。
*   **更好的代码可读性和可维护性：** 类型本身就是一种**文档**。当你看到一个函数签名 `function greet(name: string)`，你立刻就知道它需要一个字符串参数，这让代码更容易理解和维护。

**我们的目标：**

1.  快速掌握在 Vue 开发中最常用到的 TypeScript 核心概念。
2.  学习如何为一个全新的 Vue 项目启用 TypeScript。
3.  将我们现有的组件（Props, Emits, ref）和 Store 改造为类型安全的代码。

#### **9.1 TypeScript 基础快速入门**

我们不会深入讲解 TS 的所有语法，只关注在 Vue 中最实用的部分。

**1. 基本类型**

```typescript
let name: string = 'Vue Master';
let version: number = 3;
let isAwesome: boolean = true;
let features: string[] = ['Composition API', 'Pinia']; // 字符串数组
```

**2. `interface`: 定义对象的“形状”**

这是 TS 中最强大的功能之一。`interface` 用来描述一个对象应该包含哪些属性，以及这些属性的类型。

**实践：** 为我们的课程对象创建一个接口。

1.  在 `src` 目录下，创建一个 `types` 或 `interfaces` 文件夹。
2.  在里面创建一个 `course.ts` 文件。

```typescript
// src/types/course.ts
export interface Course {
  name: string;
  price: number;
  stock: number;
  onSale: boolean;
  description: string;
  image: string;
  features: string[];
}

export interface User {
  name: string;
  email: string;
}
```
现在，我们有了一个可复用的、描述课程和用户数据结构的“蓝图”。

**3. `type`: 类型别名**

`type` 与 `interface` 非常相似，都可以用来描述对象或函数的形状。

> **大师兄提示 (面试常考): `interface` vs `type` 的区别？**
> *   **扩展性：** `interface` 可以通过 `extends` 关键字进行扩展，更适合面向对象的设计。`type` 可以通过交叉类型 `&` 来实现类似效果。
> *   **声明合并：** `interface` 支持声明合并（多次定义同名接口，属性会合并），`type` 不支持。
> *   **选择建议：** 当你定义一个**对象的结构**时，优先使用 `interface`。当你需要定义**联合类型** (`string | number`)、**元组**或更复杂的类型组合时，使用 `type`。

**4. 泛型 (Generics)**

泛型允许我们创建可复用的、支持多种类型的组件或函数，可以把它看作是类型的“参数”。

```typescript
// 一个接收任意类型并返回该类型的函数
function identity<T>(arg: T): T {
  return arg;
}

let output = identity<string>("myString"); // T 被指定为 string
let output2 = identity<number>(123);      // T 被指定为 number
```
你马上就会看到，Vue 的 `ref` 和 `defineProps` 大量使用了泛型。

#### **9.2 在 Vue 中使用 TypeScript**

**步骤一：创建一个支持 TS 的 Vue 项目**

如果你从零开始，在创建项目时选择 `Yes` 即可：

```bash
npm create vue@latest
✔ Add TypeScript? … Yes
```
Vite 会自动为你配置好所有需要的东西。

**步骤二：为 Props 和 Emits 添加类型**

这是 TS 在 Vue 中最直观、最有效的应用场景。

1.  **为组件开启 TS：** 确保你的 `<script>` 标签有 `lang="ts"` 属性。
2.  **使用 `defineProps` 的泛型：**

让我们来改造 `CourseInfo.vue`。

```vue
<!-- src/components/CourseInfo.vue -->
<script lang="ts" setup> // ✨ 1. 添加 lang="ts"
import type { Course } from '../types/course'; // ✨ 2. 导入我们的接口

// ✨ 3. 使用泛型参数来定义 props 的类型
// 这比之前的对象形式更简洁、类型更安全！
defineProps<{
  course: Course
}>();
</script>
````defineProps` 是一个编译器宏，它能神奇地利用泛型信息，而无需你手动导入 `PropType`。现在，如果你在父组件传递的 `course` 对象缺少了某个属性，或者类型不对，TS 会立刻报错！

**3. 为 `defineEmits` 添加类型**

改造 `CourseActions.vue`。

```vue
<!-- src/components/CourseActions.vue -->
<script lang="ts" setup>
// ✨ 使用类型字面量来定义 emits
// 语法：(e: '事件名', 参数1: 类型, 参数2: 类型, ...): void
const emit = defineEmits<{
  (e: 'addToCart', quantity: number): void
}>();

// ...
function handleAddToCart() {
  // 如果你尝试 emit('addToCart', 'a string')，TS会报错！
  emit('addToCart', quantity.value);
}
</script>
```

**步骤三：为响应式数据和 `ref` 添加类型**

`ref` 和 `reactive` 也是泛型函数。

```typescript
import { ref, reactive } from 'vue';
import type { Course, User } from '../types/course';

// TS 可以根据初始值推断出类型
const count = ref(0); // count 的类型被推断为 Ref<number>

// 但对于复杂的或初始值为 null 的情况，最好显式指定类型
const user = ref<User | null>(null); // user 可以是 User 类型，也可以是 null

// reactive 也可以使用泛型
const course = reactive<Course>({
  name: '...',
  price: 89.9,
  // ... 其他属性
});
```

**步骤四：在 Pinia 和 Vue Router 中使用 TS**

**1. Pinia Store**

在 Pinia 中使用 TS 非常愉快，因为它的设计本身就是类型优先的。

改造 `userStore`：

```typescript
// src/stores/user.ts (注意文件后缀变为 .ts)
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';
import type { User } from '../types/course'; // 导入 User 接口

export const useUserStore = defineStore('user', () => {
  // ✨ 为 state 添加类型
  const user = ref<User | null>(null);
  const token = ref<string | null>(null);

  // ✨ Getters 的返回类型会被自动推断！
  const isLoggedIn = computed(() => !!token.value);
  const userName = computed(() => user.value?.name || '游客');

  // ✨ Actions 的参数类型应该被明确指定
  async function login(username: string, password: string) {
    // ...
    // TS 会确保你在这里赋值的 user 对象符合 User 接口的形状
    user.value = { name: username, email: `${username}@example.com` };
    // ...
  }
  
  // ...
  return { user, token, isLoggedIn, userName, login, logout };
});
```

**2. Vue Router**

我们可以为路由定义数组添加类型，以获得更好的类型提示。

```typescript
// src/router/index.ts
import { createRouter, createWebHistory, type RouteRecordRaw } from 'vue-router';
import Home from '../views/Home.vue';

// ✨ 为 routes 数组指定类型
const routes: Array<RouteRecordRaw> = [
  { 
    path: '/',
    name: 'Home',
    component: Home
  },
  { 
    path: '/course/:id', 
    name: 'CourseDetail',
    component: () => import('../views/CourseDetail.vue')
  },
];

const router = createRouter({ /* ... */ });
export default router;
```
现在，如果你在定义路由对象时写错了属性名（比如把 `path` 写成了 `paths`），TS 就会立即提醒你。
