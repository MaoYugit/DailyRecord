### **第六章：逻辑复用与组合式函数 (Composables)**

在第五章，我们领会了 Composition API 的核心思想：**按逻辑功能组织代码**。这让我们的组件内部变得前所未有的清晰。现在，我们要问一个更进一步的问题：如果多个组件都需要“追踪鼠标位置”或者“从 API 获取数据”这个逻辑，我们该怎么办？难道要在每个组件里都复制粘贴一遍代码吗？

当然不。Composition API 为我们提供了一种极其优雅的逻辑复用方案——**组合式函数 (Composable Functions)**。

**我们的目标：**

1.  理解什么是组合式函数，以及为什么它是 Vue 3 中逻辑复用的最佳方式。
2.  亲手创建两个实用的组合式函数：一个用于追踪鼠标位置，另一个用于封装数据请求。
3.  认识并学会使用社区最强大的组合式函数库 —— VueUse。

---

#### **6.1 什么是组合式函数？**

*   **定义：** 一个组合式函数 (Composable) 是一个利用 Vue 的 Composition API (`ref`, `onMounted` 等) 来**封装和复用有状态逻辑**的函数。

我们来拆解这个定义：
*   **它是一个函数：** 本质上，它就是一个普通的 JavaScript 函数。
*   **封装逻辑：** 它的职责是把某个特定功能的响应式状态 (`ref`, `reactive`)、相关方法和生命周期钩子都包裹起来。
*   **复用有状态逻辑：** 这是关键。“状态”指的是会随时间变化的数据（比如鼠标的 x, y 坐标）。Composable 让我们可以在任何组件中，轻松地创建和管理这些可变的状态。

**命名约定**
按照社区约定，组合式函数的名字通常以 `use` 开头，例如 `useMouse`，`useFetch`。这是一种风格提示，表明“这个函数将会使用 Composition API”。

> **大师兄提示 (面试必考点): Composables vs. Mixins (Vue 2)**
> 面试官很可能会问：“Vue 3 的 Composables 和 Vue 2 的 Mixins 都是为了逻辑复用，它们有什么区别？”
>
> **Mixins (混入)** 是 Vue 2 中复用逻辑的主要方式，但它有几个难以解决的痛点：
> 1.  **来源不清晰：** 当一个组件混入多个 Mixin 时，你很难知道模板中某个属性（如 `data` 里的 `user`）到底是由哪个 Mixin 注入的。
> 2.  **命名冲突：** 不同的 Mixin 可能会有相同的选项名（比如都有一个叫 `getData` 的方法），导致互相覆盖，引发难以调试的 bug。
> 3.  **可配置性差：** Mixin 很难向其传递参数来改变其内部逻辑。
>
> **Composables (组合式函数)** 完美地解决了这些问题：
> 1.  **来源清晰：** 你需要显式地从一个文件中导入 Composable，并且它返回的值需要你手动解构出来。数据的来源一目了然：`const { x, y } = useMouse()`。
> 2.  **没有命名冲突：** 即使两个 Composable 都返回了一个叫 `data` 的 ref，你也可以在解构时重命名它：`const { data: userData } = useUser()`，`const { data: postData } = usePost()`。
> 3.  **高度灵活：** 它就是一个函数，你可以向它传递任何参数，包括 `ref`，来定制它的行为。

#### **6.2 创建你的第一个 Composable**

理论说完了，我们来点真格的。

**案例一：`useMousePosition` (追踪鼠标位置)**

这是一个学习 Composable 的“Hello, World!”案例。它简单、直观，并且完美地展示了 Composable 的所有要素。

**步骤一：创建 `composables` 目录**

在 `src` 目录下，创建一个新的文件夹，命名为 `composables`。所有可复用的组合式函数都将存放在这里。

**步骤二：创建 `useMouse.js` 文件**

在 `src/composables` 目录下，创建一个 `useMouse.js` 文件。

```javascript
// src/composables/useMouse.js
import { ref, onMounted, onUnmounted } from 'vue';

// 按照约定，组合式函数以“use”开头
export function useMouse() {
  // 被组合式函数封装和管理的状态
  const x = ref(0);
  const y = ref(0);

  // 组合式函数可以随时更改其状态。
  function update(event) {
    x.value = event.pageX;
    y.value = event.pageY;
  }

  // 一个组合式函数也可以挂靠在所属组件的生命周期上
  // 来启动和卸载副作用
  onMounted(() => window.addEventListener('mousemove', update));
  onUnmounted(() => window.removeEventListener('mousemove', update));

  // 通过返回值暴露所管理的状态
  return { x, y };
}
```

看，这个文件本身就是一个高内聚的模块。所有与“鼠标追踪”相关的状态、方法、生命周期钩子都被封装在了一起。

**步骤三：在组件中使用它**

现在，我们可以在任何组件中轻松地使用这个逻辑。

```vue
<!-- src/App.vue -->
<script setup>
// 1. 导入你的组合式函数
import { useMouse } from './composables/useMouse.js';

// 2. 在 setup 作用域中执行函数，解构出需要的数据
const { x, y } = useMouse();

// ... 其他代码 ...
</script>

<template>
  <!-- ... -->
  <hr>
  <!-- 3. 像使用本地 state 一样在模板中使用 -->
  <h2>鼠标位置: {{ x }}, {{ y }}</h2>
</template>
```

**这就是组合式函数的魔力！** `App.vue` 组件完全不需要关心如何监听鼠标事件、如何更新坐标、如何在组件销毁时清理事件。它只管调用 `useMouse()`，然后拿到响应式的 `x` 和 `y` 坐标来使用。代码变得极其干净！

**案例二：`useFetch` (封装数据请求)**

这是一个更贴近真实业务场景的例子。几乎每个项目都需要从服务器获取数据，并处理加载中和错误状态。

**步骤一：创建 `useFetch.js` 文件**

```javascript
// src/composables/useFetch.js
import { ref, toValue } from 'vue';

export function useFetch(url) {
  const data = ref(null);
  const error = ref(null);
  const isLoading = ref(false);

  const fetchData = async () => {
    isLoading.value = true;
    try {
      // toValue 是 Vue 3.3+ 的新 API，可以智能地处理 ref 或普通值
      // 如果 url 是一个 ref，它会返回 url.value，否则直接返回 url
      const res = await fetch(toValue(url));
      if (!res.ok) {
        throw new Error(`HTTP error! status: ${res.status}`);
      }
      data.value = await res.json();
    } catch (e) {
      error.value = e;
    } finally {
      isLoading.value = false;
    }
  };
  
  // 立即执行数据获取
  fetchData();

  return { data, error, isLoading };
}
```

**步骤二：在组件中使用 `useFetch`**

让我们用它来获取一个模拟的课程列表。

```vue
<!-- 在 components 目录下创建一个 CourseList.vue -->
<script setup>
import { useFetch } from '../composables/useFetch.js';

const { data: courses, error, isLoading } = useFetch('https://jsonplaceholder.typicode.com/posts?_limit=5'); // 一个公共的测试 API
</script>

<template>
  <div>
    <h2>课程列表</h2>
    <div v-if="isLoading">正在加载中...</div>
    <div v-else-if="error" class="error">加载失败: {{ error.message }}</div>
    <ul v-else-if="courses">
      <li v-for="course in courses" :key="course.id">
        {{ course.title }}
      </li>
    </ul>
  </div>
</template>

<style scoped>
.error { color: red; }
</style>
```

这个模式非常强大！`CourseList.vue` 组件的职责变得非常纯粹：只负责展示 UI。所有关于数据获取、加载状态管理、错误处理的复杂逻辑，都被 `useFetch` 这个可复用的 Composable 完美封装了。

#### **6.3 社区优秀的 Composables 库：VueUse**

我们不可能、也没必要为所有事情都“重新发明轮子”。Vue 社区有一个神级项目，它为你提供了海量的、高质量的、即插即用的组合式函数——**VueUse**。

**VueUse 是什么？**
它是一个包含超过 200 个实用组合式函数的集合库，可以把它想象成 **Vue Composition API 的 Lodash**。它涵盖了浏览器 API、状态、传感器、动画、网络等方方面面。

**如何使用？**

1.  **安装：**

    ```bash
    npm install @vueuse/core
    ```

2.  **使用：**

**案例一：用 VueUse 重写 `useMouse`**

```vue
<script setup>
// 直接从 VueUse 导入 useMouse
import { useMouse } from '@vueuse/core';

const { x, y } = useMouse();
</script>
```

是的，就是这么简单。我们自己花十几行代码写的 `useMouse`，VueUse 已经为我们提供了优化得更好的版本。

**案例二：`useLocalStorage` - 优雅地持久化数据**

我们经常需要将一些用户偏好（比如主题色）或未提交的表单数据保存在浏览器的 `localStorage` 中。手动操作会很繁琐，但用 VueUse 只需一行代码。

```vue
<script setup>
import { useLocalStorage } from '@vueuse/core';

// 创建一个响应式 ref，它会自动与 localStorage 中 'my-app-name' 这个键同步
// '游客' 是初始/默认值
const name = useLocalStorage('my-app-name', '游客');
</script>

<template>
  <hr>
  <h2>本地存储示例:</h2>
  <input v-model="name" type="text">
  <p>你好, {{ name }}!</p>
</template>
```

现在，你在输入框里输入的任何内容都会被**实时**保存到 `localStorage` 中。即使你关闭或刷新页面，输入的内容依然存在！`useLocalStorage` 已经为你处理了所有序列化、反序列化和监听变化的复杂工作。

**探索 VueUse**

VueUse 的能力远不止于此。从 `useDraggable` (让元素可拖拽) 到 `useDebounceFn` (函数防抖) 再到 `useShare` (调用 Web Share API)，它就像一个宝库。强烈建议你去它的官网 [vueuse.org](https://vueuse.org/) 探索一番，它会极大地提升你的开发效率。
