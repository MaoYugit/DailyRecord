# [204. 计数质数](https://leetcode.cn/problems/count-primes/)

**中等**

提示

给定整数 `n` ，返回 *所有小于非负整数 `n` 的质数的数量* 。

**示例 1：**

```
输入：n = 10
输出：4
解释：小于 10 的质数一共有 4 个, 它们是 2, 3, 5, 7 。
```

**示例 2：**

```
输入：n = 0
输出：0
```

**示例 3：**

```
输入：n = 1
输出：0
```

**提示：**

- `0 <= n <= 5 * 106`



---



解决这道题最高效、最经典的方法是 **埃氏筛法**（Sieve of Eratosthenes）。

下面我为你详细讲解一下**埃氏筛法**的原理和如何用它来解决这道题。

---

### 什么是埃氏筛法？

想象一下，你要从一把沙子中筛出小石子。埃氏筛法就像这个过程，它不是一个个地去判断每个数是不是素数，而是一轮一轮地“筛掉”所有已知的素数的倍数，剩下的就都是素数了。

**核心思想：**
如果一个数是合数（非素数），那么它一定可以被某个更小的素数整除。

**算法步骤：**

1.  **创建一个标记列表**：创建一个长度为 `n` 的布尔列表（比如叫做 `isPrime`），并假设所有数**都是**素数，所以将它们全部初始化为 `True`。
2.  **处理已知非素数**：我们知道 0 和 1 不是素数，所以先把 `isPrime[0]` 和 `isPrime[1]` 标记为 `False`。
3.  **开始筛选**：从第一个素数 `2` 开始遍历：
    *   如果 `isPrime[i]` 是 `True`（说明数字 `i` 还没有被筛掉，它是一个素数），那么就把 `i` 的所有倍数（`2*i`, `3*i`, `4*i`, ...）都标记为 `False`，因为它们肯定不是素数。
4.  **循环优化**：
    *   外层循环只需要遍历到 `sqrt(n)` 即可。因为如果一个数 `x` 是合数，它必然有一个小于或等于 `sqrt(x)` 的因子。因此，任何小于 `n` 的合数，都一定能被一个小于 `sqrt(n)` 的素数筛掉。
    *   内层循环标记倍数时，可以从 `i * i` 开始。因为像 `2 * i`, `3 * i` 这些更小的倍数，在之前遍历 `2` 和 `3` 的时候就已经被筛掉了。
5.  **统计结果**：最后，遍历 `isPrime` 列表，统计其中值为 `True` 的个数，就是 `n` 以内素数的总数。

---

#### Python 代码实现

下面是用埃氏筛法解决 LeetCode 204 题的 Python 代码：

```python
class Solution:
    def countPrimes(self, n: int) -> int:
        # 题目要求是小于 n 的素数，所以列表大小为 n
        # 0 和 1 不是素数，小于2的数没有素数
        if n < 2:
            return 0
        
        # 1. 创建一个标记列表，初始假设所有数都是素数
        # isPrime[i] 为 True 表示 i 是素数
        isPrime = [True] * n
        
        # 2. 标记已知的非素数
        isPrime[0] = isPrime[1] = False
        
        # 3. 从 2 开始筛选，外层循环只需要到 sqrt(n)
        # 这里的 i*i < n 等价于 i < sqrt(n)
        for i in range(2, int(n**0.5) + 1):
            # 如果 i 是一个素数（没有被前面的数筛掉）
            if isPrime[i]:
                # 4. 把 i 的所有倍数都筛掉（标记为非素数）
                # 优化：从 i*i 开始，因为小于 i*i 的倍数已经被处理过了
                # 例如，i=5时，2*5, 3*5, 4*5 已经被 2 和 3 筛过了
                # isPrime[i*i : n : i] 是一个切片操作，表示从 i*i 开始，到 n 结束，步长为 i
                # 将这些位置的所有元素都设为 False
                isPrime[i*i : n : i] = [False] * len(isPrime[i*i : n : i])
                
        # 5. 统计结果
        return sum(isPrime)

```

#### 为什么埃氏筛法更优？

对于这道题，最朴素的暴力解法是遍历从 2 到 `n-1` 的每一个数，并对每一个数再进行一次判断，看它是否为素数。这种方法的时间复杂度接近 O(n²)，当 `n` 很大时（题目中 `n` 可达 5 * 10^6），会严重超时。

而埃氏筛法通过空间换时间，预先计算出所有素数，其时间复杂度大约是 O(n log log n)，效率非常高，是解决此类问题的标准方案。

---

### 暴力算法：逐个检查

**核心思想：**
要找出 `n` 以内有多少个素数，最笨的办法是什么？

1.  我们从 2 开始，一个一个地检查每个数字，一直检查到 `n-1`。
2.  对于每一个数字，我们都来判断一下它**是不是素数**。
3.  我们用一个计数器，如果判断出一个数是素数，就把计数器加一。
4.  检查完所有数字后，计数器的值就是最终答案。

**关键问题：如何判断一个数 `x` 是不是素数？**

根据素数的定义：一个大于 1 的自然数，除了 1 和它自身外，不能被其他自然数整除。

那么，要判断 `x` 是不是素数，我们就可以用**试除法**：
我们用从 2 开始到 `x-1` 的所有整数去尝试除 `x`。

*   如果**有任何一个数**能整除 `x`（余数为0），那就说明 `x` 有了除了1和它自己之外的因子，所以它**不是素数**。
*   如果这个范围内的**所有数都不能**整除 `x`，那它就**是素数**。

---

#### Python 代码实现

我们可以把“判断是否为素数”这个功能写成一个单独的辅助函数，这样代码会更清晰。

```python
class Solution:
    def isPrime(self, x: int) -> bool:
        """
        一个辅助函数，用来判断数字 x 是否为素数。
        """
        # 素数定义是大于1的整数，所以小于2的都不是素数
        if x < 2:
            return False
        
        # 试除法：用从 2 到 x-1 的所有数去试
        for i in range(2, x):
            # 如果能被整除，说明不是素数
            if x % i == 0:
                return False
        
        # 如果循环结束都没有找到能整除的数，说明是素数
        return True

    def countPrimes(self, n: int) -> int:
        # 如果 n 小于等于 2，没有素数
        if n <= 2:
            return 0
        
        count = 0
        # 遍历从 2 到 n-1 的每一个数
        for i in range(2, n):
            # 对每一个数，调用 isPrime 函数来判断
            if self.isPrime(i):
                # 如果是素数，计数器加一
                count += 1
        
        return count

# 示例
# solver = Solution()
# print(solver.countPrimes(10)) # 输出应该是 4 (2, 3, 5, 7)
```
#### 暴力算法的优化

上面的 `isPrime` 函数其实可以优化。我们不需要检查到 `x-1`，只需要检查到 `sqrt(x)`（x的平方根）就可以了。

**为什么？**
因为如果一个数 `x` 是合数，那么它一定可以分解成两个因数 `a * b = x`。在这两个因数中，必然有一个是小于或等于 `sqrt(x)` 的。
*   例如，判断 36 是不是素数。`sqrt(36) = 6`。
    *   `2 * 18` (2 <= 6)
    *   `3 * 12` (3 <= 6)
    *   `4 * 9`  (4 <= 6)
    *   `6 * 6`  (6 <= 6)
*   我们只要找到那个较小的因子（比如2, 3, 4, 6），就能确定 36 不是素数了，没必要再去检查 9, 12, 18。

**优化后的 `isPrime` 函数：**

```python
def isPrime_optimized(self, x: int) -> bool:
    if x < 2:
        return False
    # 只需要检查到 sqrt(x)
    for i in range(2, int(x**0.5) + 1):
        if x % i == 0:
            return False
    return True
```

把这个优化后的函数代入到主函数中，虽然效率会提升很多，但对于 LeetCode `n` 的最大值（5 * 10^6）来说，时间复杂度依然太高，还是会超时。

### 总结

| 算法           | `isPrime` 检查范围 | 时间复杂度     | LeetCode结果 |
| :------------- | :----------------- | :------------- | :----------- |
| **基础暴力法** | `2` 到 `x-1`       | 约 O(n²)       | 严重超时     |
| **优化暴力法** | `2` 到 `sqrt(x)`   | 约 O(n√n)      | 超时         |
| **埃氏筛法**   | (不适用此逻辑)     | O(n log log n) | **通过**     |

这个暴力解法是学习算法的很好起点，它能让你明白问题是什么，然后你才能更好地理解为什么像“埃氏筛法”这样的高效算法是必要的。
