# 第一课：公理化概率体系——从感性到理性的断裂

在 AI 开发中，你经常会看到“概率分布”、“Softmax 输出”或“似然函数”。如果你只把它们当成“0 到 1 之间的数字”，你永远只能写出低端的代码。我们要从**概率三元组 $(\Omega, \mathcal{F}, P)$** 开始。

### 1. 样本空间 (Sample Space) $\Omega$
**定义：** 随机试验所有可能结果的集合。

*   **严厉提醒：** 在 AI 中，$\Omega$ 往往是极其复杂的。
*   **例子：** 
    *   掷一枚硬币，$\Omega = \{H, T\}$。
    *   **AI 视角：** 一个分类模型识别手写数字图片（MNIST），其样本空间 $\Omega$ 实际上是所有可能的 $28 \times 28$ 像素矩阵的集合。

### 2. $\sigma$-代数（事件域） $\mathcal{F}$
这是最令初学者痛苦的地方，也是区分平庸与精通的分水岭。为什么我们不能直接说“$\Omega$ 的任何子集都是事件”？
*   **定义：** $\mathcal{F}$ 是 $\Omega$ 的子集簇（一堆子集组成的集合），它必须满足：
    1.  包含空集 $\emptyset$。
    2.  **对补集封闭：** 如果事件 $A$ 发生了，那么“$A$ 不发生”也是一个可讨论的事件。
    3.  **对可列并封闭：** 如果有一系列事件 $A_1, A_2, \dots$ 都在 $\mathcal{F}$ 中，那么它们中“至少有一个发生”这个复合事件也必须在 $\mathcal{F}$ 中。
*   **为什么在 AI 中重要？**
    在处理连续变量（如神经网络的权重或预测的房价）时，如果不对子集进行限制，会遇到数学上的“非可测集”悖论。**没有 $\mathcal{F}$，概率计算将失去一致性。**

### 3. 概率测度 (Probability Measure) $P$
概率不是一种感觉，而是一个**函数**。它将 $\mathcal{F}$ 中的每一个事件 $A$ 映射到一个实数 $P(A)$。
它必须满足柯尔莫哥洛夫三公理：
1.  **非负性：** $P(A) \ge 0$。
2.  **规范性：** $P(\Omega) = 1$（必然发生的事件概率为 1）。
3.  **可列可加性：** 如果一堆事件 $A_1, A_2, \dots$ 两两互不相容，那么它们并集的概率等于各自概率的和。

---

### 🚀 面向开发的深度思考：为什么三元组能救你的命？

当你编写一个 Softmax 函数时：
$$ \text{Softmax}(x_i) = \frac{e^{x_i}}{\sum e^{x_j}} $$
你本质上是在**人工构造一个概率测度 $P$**。
*   分母的求和保证了**规范性**（总和为 1）。
*   指数函数保证了**非负性**。
*   如果你的模型输出不满足规范性（例如总和不为 1），那么你的损失函数（Cross Entropy）就会崩溃，因为它的数学前提——**概率公理体系**被你破坏了。

# 任务 1：数学推导

## 1. 证明 $P(\emptyset) = 0$

**证明：**

1. 考虑全集 $\Omega$，由概率公理2（规范性）知：
   $$P(\Omega) = 1 \quad \text{(规范性)}$$

2. 注意到 $\Omega = \Omega \cup \emptyset \cup \emptyset \cup \cdots$，且 $\emptyset$ 与 $\Omega$ 互斥，所有 $\emptyset$ 之间也互斥

3. 由于 $\emptyset \cap \Omega = \emptyset$，且 $\emptyset \cap \emptyset = \emptyset$，满足两两互斥条件

4. 应用概率公理3（可列可加性）：
   $$P(\Omega) = P(\Omega) + \sum_{n=1}^{\infty} P(\emptyset)$$
   $$1 = 1 + \sum_{n=1}^{\infty} P(\emptyset) \quad \text{(代入 } P(\Omega)=1\text{)}$$

5. 因此：
   $$\sum_{n=1}^{\infty} P(\emptyset) = 0$$

6. 由概率公理1（非负性）知：
   $$P(\emptyset) \ge 0 \quad \text{(非负性)}$$

7. 对于非负实数的无穷求和，若和为0，则每一项必须为0：
   $$P(\emptyset) = 0$$

**证毕**

## 2. 证明 $P(A^c) = 1 - P(A)$

**证明：**

1. 对于任意事件 $A \subset \Omega$，有：
   $$\Omega = A \cup A^c$$
   其中 $A \cap A^c = \emptyset$（互斥）

2. 由概率公理3（可列可加性，特殊情况有限可加性）：
   $$P(\Omega) = P(A \cup A^c) = P(A) + P(A^c)$$

3. 由概率公理2（规范性）：
   $$P(\Omega) = 1$$

4. 因此：
   $$1 = P(A) + P(A^c)$$

5. 整理得：
   $$P(A^c) = 1 - P(A)$$

**证毕**

## 3. 证明：如果 $A \subset B$，则 $P(A) \le P(B)$

**证明：**

1. 已知 $A \subset B$，可构造：
   $$B = A \cup (B \setminus A)$$
   其中 $A \cap (B \setminus A) = \emptyset$（互斥）

2. 由概率公理3（可列可加性，特殊情况有限可加性）：
   $$P(B) = P(A \cup (B \setminus A)) = P(A) + P(B \setminus A)$$

3. 由概率公理1（非负性）：
   $$P(B \setminus A) \ge 0$$

4. 因此：
   $$P(B) = P(A) + P(B \setminus A) \ge P(A)$$
   即：
   $$P(A) \le P(B)$$

**证毕**

# 任务 2：编程思考

## 1. Softmax计算代码

```python
import numpy as np

def softmax(logits):
    """
    计算Softmax概率分布
    
    参数:
    logits: 原始得分数组，如 [2.0, 1.0, 0.1]
    
    返回:
    probabilities: Softmax概率分布
    """
    # 数值稳定性处理：减去最大值避免指数运算溢出
    exp_logits = np.exp(logits - np.max(logits))
    probabilities = exp_logits / np.sum(exp_logits)
    return probabilities

# 测试代码
logits = np.array([2.0, 1.0, 0.1])
probs = softmax(logits)
print("Logits:", logits)
print("Softmax概率分布:", probs)
print("概率和:", np.sum(probs))
```

输出示例：
```
Logits: [2.  1.  0.1]
Softmax概率分布: [0.65900114 0.24243297 0.09856589]
概率和: 1.0
```

## 2. 证明Softmax输出符合概率定义

**证明：**

设输入向量为 $\mathbf{z} = [z_1, z_2, \dots, z_n]$，Softmax定义为：
$$P(i) = \frac{e^{z_i}}{\sum_{j=1}^n e^{z_j}}$$

**验证概率公理：**

1. **非负性**：
   - 指数函数性质：对于任意实数 $z_i$，$e^{z_i} > 0$
   - 分母：$\sum_{j=1}^n e^{z_j} > 0$（正数之和为正）
   - 因此：$P(i) = \frac{\text{正数}}{\text{正数}} > 0$
   - 故 $P(i) \ge 0$ 成立

2. **规范性**：
   $$\sum_{i=1}^n P(i) = \sum_{i=1}^n \frac{e^{z_i}}{\sum_{j=1}^n e^{z_j}} = \frac{\sum_{i=1}^n e^{z_i}}{\sum_{j=1}^n e^{z_j}} = 1$$
   因此 $\sum_{i=1}^n P(i) = 1$ 成立

3. **可列可加性**（对于互斥事件）：
   - 对于互斥事件集合 $\{E_1, E_2, \dots\}$，其对应的Softmax概率分别为 $P(E_1), P(E_2), \dots$
   - 由于Softmax输出的是概率质量函数，满足：
     $$P\left(\bigcup_{k=1}^{\infty} E_k\right) = \sum_{k=1}^{\infty} P(E_k)$$
     其中并集对应索引的并集，求和对应相应概率之和
   - 具体地，如果 $E_k$ 对应索引集合 $I_k$，且所有 $I_k$ 互不相交，则：
     $$P\left(\bigcup_{k=1}^{\infty} E_k\right) = \frac{\sum_{k=1}^{\infty} \sum_{i \in I_k} e^{z_i}}{\sum_{j=1}^n e^{z_j}} = \sum_{k=1}^{\infty} \frac{\sum_{i \in I_k} e^{z_i}}{\sum_{j=1}^n e^{z_j}} = \sum_{k=1}^{\infty} P(E_k)$$

**因此，Softmax输出的概率分布满足概率三元组的所有公理要求。**

**数值验证：**
对于输入 `[2.0, 1.0, 0.1]`：
- 所有输出值：`[0.6590, 0.2424, 0.0986]` 均为正数 ✓
- 概率和：`0.6590 + 0.2424 + 0.0986 = 1.0000` ✓
