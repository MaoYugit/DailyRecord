### 1. 条件概率：样本空间的坍缩
**定义：** 在事件 $B$ 发生的条件下，事件 $A$ 发生的概率为：
$$P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad \text{其中 } P(B) > 0$$

**导师的深度解析：**
不要只看公式。你要把 $P(A|B)$ 理解为**样本空间的强制重新缩放**。原本我们的宇宙是 $\Omega$，现在，$B$ 发生了，这意味着 $\Omega$ 中所有不在 $B$ 里的点都“死”了。现在的宇宙缩减到了 $B$。
*   $P(A \cap B)$ 是在旧宇宙里的度量。
*   除以 $P(B)$ 是为了**归一化**，使得在新宇宙 $B$ 里的总概率重新回到 1（满足规范性公理）。

**AI 开发关联：**
在训练分类器时，Softmax 输出的就是 $P(y|x)$。这里 $x$（输入特征）就是你的已知条件 $B$。你的模型本质上是在 $x$ 给定的微观宇宙里，寻找最可能的标签 $y$。

---

### 2. 全概率公式：分而治之的权杖
**定义：** 设 $B_1, B_2, \dots, B_n$ 是样本空间 $\Omega$ 的一个**划分**（互不相容且并集为 $\Omega$），则对任一事件 $A$：
$$P(A) = \sum_{i=1}^n P(A|B_i)P(B_i)$$

**导师的深度解析：**
这是典型的“工程建模思维”。有些事情直接求 $P(A)$ 极难，但如果我知道在不同背景（$B_i$）下 $A$ 发生的概率，我就能通过加权平均得到真相。
*   **在 AI 中的变体：** 混合高斯模型（GMM）。你想求一个复杂分布的概率 $P(x)$，你把它拆成多个高斯组件 $B_i$。$P(B_i)$ 是组件权重，$P(x|B_i)$ 是每个高斯的密度。

---

### 3. 贝叶斯定理：认知的转置
这是本课的灵魂。
$$P(B_i|A) = \frac{P(A|B_i)P(B_i)}{P(A)} = \frac{P(A|B_i)P(B_i)}{\sum_j P(A|B_j)P(B_j)}$$

**术语标准化（必须刻在脑子里）：**
*   $P(B_i)$：**先验概率 (Prior)**。在看到数据前，你对世界的认知。
*   $P(A|B_i)$：**似然 (Likelihood)**。如果假设 $B_i$ 成立，看到数据 $A$ 的概率有多大？
*   $P(B_i|A)$：**后验概率 (Posterior)**。看到数据 $A$ 后，你修正后的认知。

**导师的严厉批判：**
平庸的开发者只会套公式，精通者看到的是**“因果倒置”**。$P(A|B)$ 是“因导果”（生成数据），而 $P(B|A)$ 是“果导因”（模型推理）。AI 的本质就是通过观察“结果”（数据），去反推“原因”（模型参数）。

---

### 🚀 进阶：为什么在 AI 开发中我们要用 Log-Space？

在处理贝叶斯推断时，我们会遇到大量概率连乘。在计算机中，这会导致**浮点数下溢 (Underflow)**。
$$P(B|A_1, A_2, \dots, A_n) \propto P(B) \prod_{i=1}^n P(A_i|B)$$
**精通者的做法：** 取对数。
$$\ln P(B|A) \propto \ln P(B) + \sum \ln P(A_i|B)$$
这不仅解决了数值稳定性问题，还将**乘法运算转化成了加法运算**，极大地提升了计算效率。这也是为什么深度学习的损失函数通常带有 `Log`。

# 任务 1：数学推导

**已知条件：**
- 二分类问题：$y \in \{0, 1\}$
- 类条件概率服从方差相等的高斯分布：
  $$P(x|y=1) \sim N(\mu_1, \Sigma)$$
  $$P(x|y=0) \sim N(\mu_0, \Sigma)$$
- 协方差矩阵 $\Sigma$ 相同（方差相等）

**证明：**

1. **贝叶斯定理二分类形式：**
   $$P(y=1|x) = \frac{P(x|y=1)P(y=1)}{P(x|y=1)P(y=1) + P(x|y=0)P(y=0)}$$

2. **代入高斯分布概率密度函数：**
   $$P(x|y=1) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(x-\mu_1)^T\Sigma^{-1}(x-\mu_1)\right)$$
   $$P(x|y=0) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(x-\mu_0)^T\Sigma^{-1}(x-\mu_0)\right)$$

3. **设先验概率：**
   $$\pi_1 = P(y=1), \quad \pi_0 = P(y=0) = 1 - \pi_1$$

4. **代入贝叶斯公式：**
   $$P(y=1|x) = \frac{\pi_1 \exp\left(-\frac{1}{2}(x-\mu_1)^T\Sigma^{-1}(x-\mu_1)\right)}{\pi_1 \exp\left(-\frac{1}{2}(x-\mu_1)^T\Sigma^{-1}(x-\mu_1)\right) + \pi_0 \exp\left(-\frac{1}{2}(x-\mu_0)^T\Sigma^{-1}(x-\mu_0)\right)}$$

5. **分子分母同除以分子：**
   $$P(y=1|x) = \frac{1}{1 + \frac{\pi_0}{\pi_1} \exp\left(-\frac{1}{2}[(x-\mu_0)^T\Sigma^{-1}(x-\mu_0) - (x-\mu_1)^T\Sigma^{-1}(x-\mu_1)]\right)}$$

6. **展开二次型：**
   \begin{align*}
   &(x-\mu_0)^T\Sigma^{-1}(x-\mu_0) - (x-\mu_1)^T\Sigma^{-1}(x-\mu_1) \\
   &= x^T\Sigma^{-1}x - 2\mu_0^T\Sigma^{-1}x + \mu_0^T\Sigma^{-1}\mu_0 - [x^T\Sigma^{-1}x - 2\mu_1^T\Sigma^{-1}x + \mu_1^T\Sigma^{-1}\mu_1] \\
   &= 2(\mu_1 - \mu_0)^T\Sigma^{-1}x + (\mu_0^T\Sigma^{-1}\mu_0 - \mu_1^T\Sigma^{-1}\mu_1)
   \end{align*}

7. **代入并整理：**
   $$P(y=1|x) = \frac{1}{1 + \exp\left(-[(\mu_1 - \mu_0)^T\Sigma^{-1}x + \frac{1}{2}(\mu_0^T\Sigma^{-1}\mu_0 - \mu_1^T\Sigma^{-1}\mu_1) - \ln(\pi_1/\pi_0)]\right)}$$

8. **令：**
   $$w = \Sigma^{-1}(\mu_1 - \mu_0)$$
   $$b = \frac{1}{2}(\mu_0^T\Sigma^{-1}\mu_0 - \mu_1^T\Sigma^{-1}\mu_1) + \ln\left(\frac{\pi_1}{\pi_0}\right)$$

9. **得到Sigmoid函数形式：**
   $$P(y=1|x) = \frac{1}{1 + \exp(-(w^Tx + b))} = \sigma(w^Tx + b)$$

**证毕：** 当类条件概率服从方差相等的高斯分布时，后验概率 $P(y=1|x)$ 必然是Sigmoid函数形式。

import numpy as np

class NaiveBayesSpamFilter:
    def __init__(self):
        # 先验概率
        self.prior_spam = 0.4      # P(S)
        self.prior_ham = 0.6       # P(H)
        
        # 似然概率
        self.likelihood_win_spam = 0.8    # P("win"|S)
        self.likelihood_win_ham = 0.05    # P("win"|H)
    
    def calculate_posterior_single_word(self):
        """
        计算单个"win"单词时的后验概率
        """
        # 使用贝叶斯定理和全概率公式
        # P(S|"win") = P("win"|S)P(S) / [P("win"|S)P(S) + P("win"|H)P(H)]
        
        # 计算分子
        numerator = self.likelihood_win_spam * self.prior_spam
        
        # 计算分母（全概率公式）
        denominator = (self.likelihood_win_spam * self.prior_spam + 
                      self.likelihood_win_ham * self.prior_ham)
        
        # 计算后验概率
        posterior_spam = numerator / denominator
        
        return posterior_spam
    
    def calculate_posterior_multiple_words(self, n_words):
        """
        计算包含n个独立"win"单词时的后验概率
        
        为什么需要Log？
        1. 防止数值下溢：多个小数连乘会变得非常小，可能超出浮点数精度范围
        2. 提高计算稳定性：将连乘转换为连加
        3. 优化计算效率：加法比乘法快
        """
        # 方法1：直接计算（会有数值问题）
        # P(S|{"win"}^n) ∝ P({"win"}^n|S)P(S) = P("win"|S)^n * P(S)
        
        # 分子
        numerator = (self.likelihood_win_spam ** n_words) * self.prior_spam
        
        # 分母（全概率公式）
        denominator = ((self.likelihood_win_spam ** n_words) * self.prior_spam + 
                      (self.likelihood_win_ham ** n_words) * self.prior_ham)
        
        # 直接计算结果
        posterior_direct = numerator / denominator
        
        # 方法2：使用Log计算（数值稳定）
        # log(P(S|{"win"}^n)) = log(P({"win"}^n|S)) + log(P(S)) - log(P({"win"}^n))
        
        log_numerator = (n_words * np.log(self.likelihood_win_spam) + 
                        np.log(self.prior_spam))
        
        # 计算log分母需要log-sum-exp技巧
        log_prob_win_given_spam = np.log(self.likelihood_win_spam)
        log_prob_win_given_ham = np.log(self.likelihood_win_ham)
        
        log_evidence_spam = (n_words * log_prob_win_given_spam + 
                           np.log(self.prior_spam))
        log_evidence_ham = (n_words * log_prob_win_given_ham + 
                          np.log(self.prior_ham))
        
        # log-sum-exp技巧：log(exp(a) + exp(b)) = max(a,b) + log(1 + exp(-|a-b|))
        max_log = max(log_evidence_spam, log_evidence_ham)
        log_denominator = max_log + np.log(np.exp(log_evidence_spam - max_log) + 
                                          np.exp(log_evidence_ham - max_log))
        
        # 计算log后验概率
        log_posterior = log_evidence_spam - log_denominator
        posterior_log = np.exp(log_posterior)
        
        return posterior_direct, posterior_log

# 创建实例
