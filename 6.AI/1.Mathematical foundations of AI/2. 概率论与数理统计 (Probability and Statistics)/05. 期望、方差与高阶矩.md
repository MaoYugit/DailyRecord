# 第五课：期望、方差与高阶矩——数据的“统计基因”

在 AI 训练中，我们不仅观察模型预测的对不对，还要观察预测的**稳定性**和**分布形状**。如果你只会算均值，你永远无法理解为什么大模型训练时会发生“损失爆炸（Loss Spike）”。

### 1. 期望 (Expectation)：加权平均的极限
对于连续随机变量：
$$E[X] = \int_{-\infty}^{+\infty} x f(x) dx$$

**导师的深度解析：**
期望是概率分布的“重心”。在深度学习中，损失函数 $L$ 的期望就是我们努力最小化的**风险（Risk）**。但注意，期望对异常值（Outliers）极其敏感。如果你的数据分布是长尾的，期望可能会把你带进坑里。

### 2. 方差 (Variance) 与标准差：波动的度量
$$Var(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$

**AI 开发关联：**
*   **权重初始化：** 为什么 Kaiming 初始化或 Xavier 初始化那么重要？因为我们要保证信号在通过每一层神经网络后，其**方差保持不变**。如果方差变大，梯度会爆炸；如果方差变小，梯度会消失。
*   **Batch Normalization：** 它的核心任务就是强制控制每一层输出的均值为 0，方差为 1。

### 3. 高阶矩：偏度 (Skewness) 与 峰度 (Kurtosis)
这是区分“高手”与“小白”的分水岭。
*   **三阶矩（偏度）：** 描述分布是对称的（如高斯），还是往一边歪的。
    *   **AI 应用：** 如果你的训练数据标签严重偏斜，模型会产生偏差。
*   **四阶矩（峰度）：** 描述分布的边缘（Tails）有多厚。
    *   **AI 应用：** 高峰度意味着存在大量的“极端样本”。如果你的模型处理的是金融风控或自动驾驶，**厚尾分布**（Heavy-tailed distribution）是你最大的噩梦，因为“黑天鹅”事件发生的概率远高于高斯假设。

---

### 4. 变量和的性质（极其重要）
假设 $X$ 和 $Y$ 是独立的：
1.  $E[aX + bY] = aE[X] + bE[Y]$（期望具有线性性质，无论是否独立都成立）。
2.  $Var(aX + bY) = a^2Var(X) + b^2Var(Y)$（方差的独立叠加性）。

**为什么这在 AI 中救命？**
当你把 100 个神经元的输出加在一起时，如果它们是独立的，总输出的方差是各自方差的和。如果你不控制好每个神经元的方差，加法运算会让输出数值迅速超出硬件的浮点数表示范围。

# 任务 1：手动计算高阶矩

## 1. 三阶矩 \(E[Z^3]\)

对于标准正态分布 \(Z \sim N(0, 1)\)，其概率密度函数为：
\[
f(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}
\]

**利用对称性分析：**
- 函数 \(z^3\) 是奇函数（\((-z)^3 = -z^3\)）
- 概率密度函数 \(f(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}\) 是偶函数（\(f(-z) = f(z)\)）
- 奇函数 × 偶函数 = 奇函数
- 奇函数在对称区间 \((-\infty, \infty)\) 上的积分为 0

因此：
\[
E[Z^3] = \int_{-\infty}^{\infty} z^3 f(z) dz = 0
\]

**结论：** \(E[Z^3] = 0\)

## 2. 四阶矩 \(E[Z^4] = 3\) 的推导

### 方法1：利用分部积分法

四阶矩的定义：
\[
E[Z^4] = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} z^4 e^{-z^2/2} dz
\]

令：
\[
I_n = \int_{-\infty}^{\infty} z^n e^{-z^2/2} dz
\]
我们需要计算 \(I_4\)。

**已知标准正态分布的基本结果：**
\[
I_0 = \int_{-\infty}^{\infty} e^{-z^2/2} dz = \sqrt{2\pi}
\]
\[
I_2 = \int_{-\infty}^{\infty} z^2 e^{-z^2/2} dz = \sqrt{2\pi} \quad (\text{因为 } E[Z^2] = \text{Var}(Z) = 1)
\]

**使用分部积分法：**
令：
\[
u = z^3, \quad dv = z e^{-z^2/2} dz
\]
则：
\[
du = 3z^2 dz, \quad v = -e^{-z^2/2}
\]

分部积分公式：
\[
\int u dv = uv - \int v du
\]
\[
\int z^4 e^{-z^2/2} dz = -z^3 e^{-z^2/2} + 3\int z^2 e^{-z^2/2} dz
\]

计算定积分：
\[
I_4 = \int_{-\infty}^{\infty} z^4 e^{-z^2/2} dz = \left[-z^3 e^{-z^2/2}\right]_{-\infty}^{\infty} + 3\int_{-\infty}^{\infty} z^2 e^{-z^2/2} dz
\]

第一项极限：
\[
\lim_{z \to \pm\infty} z^3 e^{-z^2/2} = 0 \quad (\text{指数衰减比多项式增长快})
\]
所以：
\[
I_4 = 0 + 3I_2 = 3\sqrt{2\pi}
\]

因此：
\[
E[Z^4] = \frac{1}{\sqrt{2\pi}} \cdot I_4 = \frac{1}{\sqrt{2\pi}} \cdot 3\sqrt{2\pi} = 3
\]

**得证：** \(E[Z^4] = 3\)

# 任务 2：编程实战——检测数据漂移

```python
import numpy as np
import scipy.stats as stats

# 1. 生成两组数据
np.random.seed(42)  # 设置随机种子保证可重复性

# Data_A: N(0, 1)
Data_A = np.random.normal(loc=0, scale=1, size=1000)

# Data_B: N(0.5, 1.5^2) = N(0.5, 2.25)
Data_B = np.random.normal(loc=0.5, scale=1.5, size=1000)

# 2. 计算统计量
def calculate_statistics(data, name):
    """计算并打印数据的统计特征"""
    mean_val = np.mean(data)
    var_val = np.var(data, ddof=1)  # 样本方差
    skew_val = stats.skew(data)     # 偏度
    kurt_val = stats.kurtosis(data, fisher=False)  # 峰度（Pearson定义，正态分布为3）
    
    print(f"\n{name} 统计特征:")
    print(f"均值 (Mean): {mean_val:.4f}")
    print(f"方差 (Variance): {var_val:.4f}")
    print(f"偏度 (Skewness): {skew_val:.4f}")
    print(f"峰度 (Kurtosis): {kurt_val:.4f}")
    
    return mean_val, var_val, skew_val, kurt_val

# 计算两组数据的统计量
stats_A = calculate_statistics(Data_A, "Data_A (N(0,1))")
stats_B = calculate_statistics(Data_B, "Data_B (N(0.5,1.5))")

# 3. 思考分析
print("\n" + "="*60)
print("思考分析:")
print("="*60)

# 均值差异分析
print("\n1. 均值差异分析:")
mean_diff = abs(stats_B[0] - stats_A[0])
print(f"  均值差异: {mean_diff:.4f}")
print("  在现实场景中，仅凭均值差异判定数据变化风险不足，因为：")
print("  a) 均值变化可能很小但分布形状变化很大")
print("  b) 均值相同但方差/峰度变化也会影响模型性能")

# 峰度变化影响分析
print("\n2. 峰度变化对模型的影响:")
print(f"  Data_A峰度: {stats_A[3]:.4f} (理论值3)")
print(f"  Data_B峰度: {stats_B[3]:.4f}")
print("\n  如果均值一样但峰度变了：")
print("  a) 峰度增加 (厚尾): 异常值更多，模型对极端值更敏感")
print("  b) 峰度减少 (薄尾): 数据更集中在均值附近，可能欠拟合")
print("  c) 深度学习模型: 激活函数敏感度变化，梯度分布改变")
print("  d) 统计模型: 假设检验失效，置信区间不准确")

# 假设检验示例
print("\n3. 统计检验示例:")
# t检验检查均值差异
t_stat, p_val = stats.ttest_ind(Data_A, Data_B)
print(f"  t检验p值: {p_val:.6f} {'(显著差异)' if p_val < 0.05 else '(无显著差异)'}")

# KS检验检查分布差异
ks_stat, ks_pval = stats.ks_2samp(Data_A, Data_B)
print(f"  KS检验p值: {ks_pval:.6f} {'(分布不同)' if ks_pval < 0.05 else '(分布相似)'}")

print("\n结论: 需要综合多个统计量和假设检验来判断数据漂移的危险程度。")
```

# 任务 3：Batch Norm 的数学直觉推导

## 已知条件：
- 输入 \(x\) 的均值：\(E[x] = \mu\)
- 输入 \(x\) 的方差：\(\text{Var}(x) = \sigma^2\)
- Batch Normalization 变换：\(\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}\)
- \(\epsilon > 0\) 是一个小常数（防止除零）

## 证明：

### 1. 证明 \(E[\hat{x}] = 0\)

**推导过程：**
\[
E[\hat{x}] = E\left[\frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}\right]
\]

利用期望的线性性质：
\[
E[\hat{x}] = \frac{1}{\sqrt{\sigma^2 + \epsilon}} \cdot E[x - \mu]
\]
\[
= \frac{1}{\sqrt{\sigma^2 + \epsilon}} \cdot (E[x] - \mu)
\]
\[
= \frac{1}{\sqrt{\sigma^2 + \epsilon}} \cdot (\mu - \mu)
\]
\[
= \frac{1}{\sqrt{\sigma^2 + \epsilon}} \cdot 0 = 0
\]

**结论1：** \(E[\hat{x}] = 0\)

### 2. 证明 \(\text{Var}(\hat{x}) = 1\)

**推导过程：**
方差定义：
\[
\text{Var}(\hat{x}) = E[(\hat{x} - E[\hat{x}])^2] = E[\hat{x}^2] \quad (\text{因为 } E[\hat{x}] = 0)
\]

计算 \(E[\hat{x}^2]\)：
\[
E[\hat{x}^2] = E\left[\left(\frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}\right)^2\right]
\]
\[
= \frac{1}{\sigma^2 + \epsilon} \cdot E[(x - \mu)^2]
\]

根据方差定义，\(E[(x - \mu)^2] = \text{Var}(x) = \sigma^2\)，所以：
\[
E[\hat{x}^2] = \frac{1}{\sigma^2 + \epsilon} \cdot \sigma^2
\]
\[
= \frac{\sigma^2}{\sigma^2 + \epsilon}
\]

当 \(\epsilon \to 0^+\) 时，\(\frac{\sigma^2}{\sigma^2 + \epsilon} \to 1\)。

在实际的 Batch Normalization 中：
1. 通常使用样本统计量：\(\hat{\mu} = \frac{1}{m}\sum_{i=1}^m x_i\)，\(\hat{\sigma}^2 = \frac{1}{m}\sum_{i=1}^m (x_i - \hat{\mu})^2\)
2. 对于样本方差的无偏估计，分母应为 \(m-1\)，但 BN 中常用 \(m\)
3. \(\epsilon\) 通常很小（如 \(10^{-5}\)），所以 \(\hat{\sigma}^2 \gg \epsilon\)

因此，在近似意义上：
\[
\text{Var}(\hat{x}) = \frac{\sigma^2}{\sigma^2 + \epsilon} \approx 1
\]

**严谨证明补充：**
如果考虑总体参数（非样本估计），且令 \(\epsilon = 0\)，则：
\[
\text{Var}(\hat{x}) = \frac{1}{\sigma^2} \cdot \sigma^2 = 1
\]
但实际实现中 \(\epsilon > 0\) 是为了数值稳定性，因此：
\[
\text{Var}(\hat{x}) = \frac{\sigma^2}{\sigma^2 + \epsilon} \approx 1 \quad (\text{当 } \sigma^2 \gg \epsilon)
\]

**结论2：** \(\text{Var}(\hat{x}) \approx 1\)，当 \(\epsilon\) 很小时非常接近 1。

## Batch Norm 的直观理解：
1. **中心化**：减去均值使分布以 0 为中心
2. **标准化**：除以标准差使分布具有单位方差
3. **数值稳定**：\(\epsilon\) 防止除零和数值下溢
4. **学习效果**：稳定梯度分布，加速训练，有一定正则化效果
