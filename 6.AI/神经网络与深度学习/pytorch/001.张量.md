## 一、 张量是什么 (What is a Tensor?)

在数学中：
*   **标量 (Scalar)**：一个数（如 `5`），0维。
*   **向量 (Vector)**：一排数（如 `[1, 2, 3]`），1维。
*   **矩阵 (Matrix)**：方阵（如 Excel 表格），2维。
*   **张量 (Tensor)**：上述所有东西的统称。在深度学习中，我们处理的数据往往是高维的（比如彩色图片是 3 维：长、宽、颜色通道），张量就是存储这些数据的**多维数组**。

**重点：** 它和 NumPy 的 `ndarray` 非常像，但它有两个杀手锏：
1.  **支持 GPU 加速**。
2.  **支持自动求导**（这是神经网络训练的核心）。

## 二、 张量的创建

### 1. 掌握张量创建的基本方法

最常用的是从现有的 Python 列表或 NumPy 数组转换。

```python
import torch
import numpy as np

# (1) 从列表创建
t1 = torch.tensor([1, 2, 3]) 

# (2) 从 NumPy 数组创建 (共享内存，效率高)
arr = np.array([4, 5, 6])
t2 = torch.from_numpy(arr)

# (3) 直接创建指定形状的张量 (注意 Tensor 是大写，通常传入形状)
t3 = torch.Tensor(2, 3) # 创建一个 2行3列 的张量，数值是内存里的随机值
```

### 2. 线性张量和随机张量的创建方法

在初始化模型参数（比如权重）时，经常用到这些。

```python
# (1) 线性张量
# arange: [开始, 结束), 步长
t_seq = torch.arange(0, 10, 2)  # tensor([0, 2, 4, 6, 8])

# linspace: [开始, 结束], 步数 (等差数列)
t_line = torch.linspace(0, 10, 5) # tensor([ 0.0, 2.5, 5.0, 7.5, 10.0])

# (2) 随机张量
# rand: [0, 1) 之间的均匀分布
t_rand = torch.rand(2, 3) 

# randn: 标准正态分布 (均值为0, 方差为1)，最常用！
t_randn = torch.randn(2, 3)

# randint: 指定范围内的随机整数
t_ints = torch.randint(0, 10, (2, 2)) # 0到10之间，2x2矩阵
```

### 3. 0-1 张量的创建方法

常用于初始化偏置项或掩码（Mask）。

```python
# 全 0
t_zeros = torch.zeros(3, 3)

# 全 1
t_ones = torch.ones(3, 3)

# 单位矩阵 (对角线为1)
t_eye = torch.eye(3)

# 像某个张量一样 (形状一致)
t_like = torch.zeros_like(t_rand) 
```

## 三、 张量的类型转换

PyTorch 常见的类型有：`float32` (默认), `float64`, `int64` (Long), `int32`。

### 1. 转换方法

```python
t = torch.tensor([1.2, 2.3])

# (1) 使用 .to() 方法 (最推荐，不仅能改类型，还能改设备)
t_int = t.to(torch.int32)

# (2) 使用快捷方法
t_float = t.float()  # 转为 float32
t_long = t.long()    # 转为 int64 (常用于分类标签)

# (3) 查看类型
print(t.dtype)
```

## 四、 张量数值计算与运算函数

### 1. 基础运算
```python
a = torch.tensor([1, 2])
b = torch.tensor([3, 4])

print(a + b)  # 加法
print(a * b)  # 对应元素相乘 (Hadamard product)
print(a.pow(2)) # 平方
```

### 2. 矩阵运算 (面试常考)
```python
m1 = torch.randn(2, 3)
m2 = torch.randn(3, 4)

# 矩阵乘法 (2x3 乘以 3x4 得到 2x4)
res1 = torch.mm(m1, m2)
res2 = m1 @ m2  # 这种写法更简洁
```

### 3. 常用函数
```python
t = torch.randn(2, 3)

print(t.sum())    # 求和
print(t.mean())   # 求平均
print(t.max())    # 最大值
print(t.abs())    # 绝对值

# 沿着维度计算 (dim=0 是列，dim=1 是行)
print(t.sum(dim=1)) 
```

## 五、 张量索引与形状操作 (重难点)

### 1. 索引操作 (类似 NumPy)
```python
t = torch.randn(3, 4)

print(t[0, :])    # 第 0 行所有元素
print(t[:, 1])    # 第 1 列所有元素
print(t[t > 0])   # 布尔索引：只取出大于0的数
```

### 2. 形状操作 (最常用)
```python
t = torch.arange(12) # 0到11，长度12

# (1) reshape/view: 改变形状
t_23 = t.view(3, 4)  # 变成 3行4列 (view 效率更高)

# (2) unsqueeze: 增加维度 (比如把 [3, 4] 变成 [1, 3, 4]，常用于增加 batch 维度)
t_add = t_23.unsqueeze(0) 

# (3) squeeze: 压缩维度 (去掉长度为 1 的维度)
t_sq = t_add.squeeze()

# (4) transpose: 交换两个维度 (转置)
t_trans = t_23.t() # 针对2维的简写
```

## 六、 张量拼接操作

将多个张量合并成一个。

```python
t1 = torch.zeros(2, 3)
t2 = torch.ones(2, 3)

# cat: 拼接 (不会增加维度)
res_cat = torch.cat([t1, t2], dim=0) # 变成 4x3

# stack: 堆叠 (会增加一个新维度)
res_stack = torch.stack([t1, t2], dim=0) # 变成 2x2x3
```

## 七、 自动微分模块 (Autograd) —— 深度学习的灵魂

神经网络能学习，全靠计算梯度（导数）。

```python
# 1. 创建张量并指定需要求导
x = torch.tensor([2.0], requires_grad=True)

# 2. 定义运算过程 y = x^2 + 3
y = x**2 + 3

# 3. 反向传播
y.backward()

# 4. 查看梯度 (dy/dx = 2x, 当 x=2 时，梯度应为 4)
print(x.grad) # 输出 tensor([4.])
```

## 八、 线性回归案例 (实战)

我们用上面学到的所有知识，手动实现一个简单的线性回归。
**目标：** 寻找 $y = wx + b$ 中的 $w$ 和 $b$。

```python
import torch

# 1. 准备数据 (假设 y = 3x + 0.8)
x = torch.linspace(0, 1, 100).reshape(-1, 1)
y_true = 3 * x + 0.8 + torch.randn(100, 1) * 0.1 # 加点噪声

# 2. 初始化参数 (随机初始化)
w = torch.randn(1, requires_grad=True)
b = torch.zeros(1, requires_grad=True)

learning_rate = 0.1

# 3. 训练循环
for i in range(500):
    # 前向传播：预测值
    y_pred = x * w + b
    
    # 计算损失 (均方误差 MSE)
    loss = torch.mean((y_pred - y_true)**2)
    
    # 反向传播：计算梯度
    loss.backward()
    
    # 更新参数 (不需要求导的过程放在 no_grad 里)
    with torch.no_grad():
        w -= learning_rate * w.grad
        b -= learning_rate * b.grad
        
        # 梯度清零 (PyTorch 默认会累加梯度，必须手动清零)
        w.grad.zero_()
        b.grad.zero_()
    
    if i % 50 == 0:
        print(f"Epoch {i}, Loss: {loss.item():.4f}, w: {w.item():.2f}, b: {b.item():.2f}")

print(f"\n训练结束！最终结果：w={w.item():.2f}, b={b.item():.2f}")
```

### 给你的学习建议：
1.  **别死记硬背**：这些函数很多，先有个印象，用到的时候去查。
2.  **形状最重要**：在写 PyTorch 代码时，如果你报错了，90% 都是因为张量的 **Shape（形状）** 不匹配。随时用 `print(tensor.shape)` 来检查。
3.  **动手操作**：把上面的线性回归案例跑通，尝试修改 `learning_rate`（学习率）看看结果有什么变化。
