### MongoDB & Mongoose

#### 第一阶段：MongoDB 核心基础

**学习目标：** 掌握 MongoDB 的基本概念、安装配置以及核心操作，为后续学习打下坚实基础。

*   **1. NoSQL 和 MongoDB 入门**
    *   理解 NoSQL 数据库的概念、分类（文档型、键值型、列式、图形）及优势。
    *   MongoDB 简介：了解其作为文档数据库的特点、应用场景和优势。
    *   核心术语：数据库（Database）、集合（Collection）、文档（Document）、字段（Field）、BSON（Binary JSON）等。

*   **2. 安装与环境配置**
    *   在不同操作系统（Windows, macOS, Linux）上安装 MongoDB。
    *   安装和配置 MongoDB Compass（官方 GUI 工具）。
    *   了解并使用 `mongo` shell 进行数据库交互。

*   **3. 数据库和集合的基本操作**
    *   创建和删除数据库。
    *   创建和删除集合。

*   **4. CRUD 操作：核心中的核心**
    *   **创建 (Create):**
        *   `insertOne()`：插入单个文档。
        *   `insertMany()`：插入多个文档。
    *   **读取 (Read):**
        *   `find()` 和 `findOne()`：查询文档。
        *   查询条件：相等、比较操作符（`$gt`, `$lt`, `$gte`, `$lte`）、逻辑操作符（`$and`, `$or`, `$not`）。
        *   `$in` 和 `$nin` 操作符。
        *   投影（Projection）：选择性返回字段。
    *   **更新 (Update):**
        *   `updateOne()` 和 `updateMany()`：更新文档。
        *   更新操作符：`$set`, `$unset`, `$inc`, `$push`, `$pull` 等。
        *   `findOneAndUpdate()`：查找并更新。
    *   **删除 (Delete):**
        *   `deleteOne()` 和 `deleteMany()`：删除文档。

#### 第二阶段：Mongoose ODM 基础与进阶

**学习目标：** 掌握 Mongoose 作为 MongoDB 的对象数据模型（ODM）库，学习如何通过它来简化 Node.js 应用中的数据库操作。

*   **1. Mongoose 入门**
    *   什么是 Mongoose 及其优势（Schema 验证、中间件等）。
    *   在 Node.js 项目中安装和引入 Mongoose。
    *   连接到 MongoDB 数据库。

*   **2. Schema 和 Model**
    *   **Schema（模式）：**
        *   定义文档的结构和数据类型（String, Number, Date, Boolean, Buffer, ObjectId, Array 等）。
        *   Schema 选项：`timestamps`, `collection` 等。
        *   **数据验证（Validation）：**
            *   内置验证器：`required`, `unique`, `min`, `max`, `enum`, `match`。
            *   自定义验证器。
    *   **Model（模型）：**
        *   基于 Schema 创建 Model，作为与数据库集合交互的接口。

*   **3. 使用 Mongoose 进行 CRUD 操作**
    *   `Model.create()` / `new Model().save()`：创建文档。
    *   `Model.find()`, `Model.findOne()`, `Model.findById()`：查询文档。
    *   `Model.updateOne()`, `Model.updateMany()`, `Model.findOneAndUpdate()`：更新文档。
    *   `Model.deleteOne()`, `Model.deleteMany()`, `Model.findByIdAndDelete()`：删除文档。

#### 第三阶段：数据建模与高级查询

**学习目标：** 学习如何在 MongoDB 中设计高效的数据模型，并掌握高级查询技巧以应对复杂场景。

*   **1. 数据建模（Schema Design）**
    *   理解嵌入（Embedding）和引用（Referencing/Normalization）的区别与权衡。
    *   一对一（One-to-One）、一对多（One-to-Many）和多对多（Many-to-Many）关系的建模策略。
    *   数据建模的最佳实践。

*   **2. Mongoose 的 Population**
    *   使用 `populate()` 实现引用文档的关联查询，类似于 SQL 中的 `JOIN`。

*   **3. 索引（Indexing）与性能优化**
    *   索引的重要性：加速查询。
    *   创建不同类型的索引：单字段索引、复合索引、文本索引。
    *   使用 `explain()` 方法分析查询性能。
    *   查询性能优化技巧：
        *   使用 `lean()` 方法提高查询速度。
        *   选择性返回字段 (`select()`)。

*   **4. Mongoose 高级特性**
    *   **中间件（Middleware / Hooks）：** 在 `save`, `remove`, `find` 等操作前后执行自定义逻辑（例如，密码加密）。
    *   **虚拟属性（Virtuals）：** 定义不存储在数据库中的计算属性。
    *   **查询助手（Query Helpers）：** 自定义可链式调用的查询方法。
    *   **静态方法和实例方法（Statics and Methods）：** 在 Model 和 Document 层面添加自定义方法。

#### 第四阶段：数据聚合与高级 MongoDB

**学习目标：** 精通 MongoDB 的聚合框架，并了解 MongoDB 的高级管理和架构概念。

*   **1. 聚合框架（Aggregation Framework）**
    *   理解聚合管道（Aggregation Pipeline）的概念。
    *   常用的聚合阶段（Stages）：
        *   `$match`：过滤文档。
        *   `$group`：按指定字段分组。
        *   `$project`：重塑文档结构。
        *   `$sort`：排序。
        *   `$limit` 和 `$skip`：分页。
        *   `$lookup`：实现跨集合的关联查询（类似于 `LEFT JOIN`）。
        *   `$unwind`：展开数组字段。
    *   在 Mongoose 中使用聚合：`Model.aggregate()`。

*   **2. 事务（Transactions）**
    *   了解 ACID 事务在 MongoDB 中的实现。
    *   何时以及如何使用多文档事务。

*   **3. 复制（Replication）**
    *   理解副本集（Replica Set）的概念，以实现高可用性。
    *   主节点（Primary）和次要节点（Secondary）的角色。

*   **4. 分片（Sharding）**
    *   了解分片的概念，以实现水平扩展。
    *   分片键（Shard Key）的选择策略。

*   **5. 安全性（Security）**
    *   启用访问控制和认证。
    *   配置基于角色的访问控制（RBAC）。

#### 第五阶段：实战项目与面试准备

**学习目标：** 将所学知识应用于实际项目中，并针对常见的面试问题进行准备。

*   **1. 实战项目**
    *   **构建一个完整的 RESTful API：**
        *   使用 Express.js, MongoDB 和 Mongoose。
        *   实现用户认证（注册、登录、JWT）。
        *   实现对某个资源（如博客文章、产品等）的完整 CRUD 操作。
        *   实现高级功能，如分页、排序、搜索和过滤。
        *   应用数据验证和错误处理。
        *   编写单元测试和集成测试。
    *   **实践项目创意：**
        *   博客平台
        *   电商网站后端
        *   任务管理应用

*   **2. 面向面试的核心问题**

        *   什么是文档和集合？

    *   **数据建模：**
        *   何时使用嵌入，何时使用引用？
        *   如何设计一对多关系？
    *   **性能与优化：**
        *   索引的作用是什么？什么是复合索引？
        *   如何诊断和优化慢查询？
        *   `lean()` 查询有什么好处？
    *   **高级主题：**
        *   解释一下 MongoDB 的聚合管道。
        *   `$lookup` 是做什么用的？
        *   什么是副本集和分片？
        *   MongoDB 如何保证数据一致性？
    *   **Mongoose 相关：**
        *   什么是 Mongoose 中间件（Hooks）？举例说明。
        *   `populate` 是如何工作的？有什么潜在的性能问题？
    *   **编码题：**
        *   使用 Mongoose 编写一个查询，找出符合特定条件的文档。
        *   实现一个简单的聚合查询，例如计算每个分类下的平均分。
        *   设计一个包含用户和文章的 Schema。
