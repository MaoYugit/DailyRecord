### **一、NoSQL 和 MongoDB 入门**

#### **1. 什么是 NoSQL 数据库？**

想象一下，你以前存放数据的方式是使用 Excel 表格。每张表格（Table）都有固定的列（Columns），每一行（Row）都必须遵守这个结构。这就是传统 **关系型数据库 (SQL)** 的核心思想，比如我们常见的 MySQL、PostgreSQL 等。它们结构严谨，非常适合存储结构化数据。

但是，随着互联网的发展，数据变得越来越复杂、多样化，而且数量巨大。比如社交媒体的帖子、物联网设备的数据流、用户的操作日志等，这些数据的结构可能随时会变，或者根本就没有固定结构。用死板的 Excel 表格来存储这些数据，就显得力不从心了。

于是，**NoSQL** (通常指 "Not Only SQL"，不仅仅是 SQL) 数据库应运而生。它的核心特点就是 **灵活**。

**NoSQL 的主要优势：**

*   **灵活的数据模型：** 你可以随时添加或删除字段，而不需要像 SQL 那样先去修改整个表的结构。
*   **高可扩展性：** NoSQL 数据库通常被设计为可以轻松地通过增加更多服务器（水平扩展）来处理更大的数据量，而传统 SQL 数据库则更依赖于提升单个服务器的性能（垂直扩展），成本更高。
*   **高性能：** 针对特定的数据模型和访问模式，NoSQL 数据库可以提供非常高的读写性能。

#### **2. NoSQL 数据库的四大家族**

NoSQL 不是一种特定的数据库，而是一类数据库的统称。它们主要分为四种类型：

| 类型                     | 描述                                                         | 例子              | 形象的比喻                                                   |
| :----------------------- | :----------------------------------------------------------- | :---------------- | :----------------------------------------------------------- |
| **文档型 (Document)**    | 将数据存储在类似 JSON 的文档中。每个文档都可以有不同的结构。**这是 MongoDB 所属的类型。** | MongoDB, CouchDB  | 一个文件夹，里面存放着各种格式和内容的 Word 文档。           |
| **键值型 (Key-Value)**   | 数据以简单的键值对形式存储，非常快速。                       | Redis, DynamoDB   | 一本巨大的字典，通过单词（Key）快速找到释义（Value）。       |
| **列式 (Column-family)** | 数据按列而不是按行存储，适合大规模数据聚合分析。             | Cassandra, HBase  | 一张巨大的表格，但你可以非常快地单独拿出某一列数据进行分析。 |
| **图形 (Graph)**         | 专门用于存储实体及其之间的关系，非常适合社交网络、推荐系统等。 | Neo4j, JanusGraph | 一张复杂的人物关系图，能快速找出两个人之间的关系路径。       |

#### **3. 主角登场：MongoDB 简介**

在 NoSQL 的世界里，MongoDB 是最受欢迎的 **文档型数据库** 之一。

*   **特点和优势：**
    *   **面向文档的存储：** 数据被组织成类似 JSON (在 MongoDB 中称为 BSON) 的文档，非常直观，易于开发者理解和使用。
    *   **灵活的模式 (Schema)：** 一个集合（下面会讲）里的文档不需要有相同的结构。
    *   **强大的查询语言：** 提供了丰富的查询操作符，可以实现复杂的查询需求。
    *   **高性能：** 支持创建索引以提高查询速度，并且具有高可用性（通过副本集）和高扩展性（通过分片）的架构。
    *   **活跃的社区和丰富的生态：** 有大量的学习资源和第三方工具支持。

*   **应用场景：**
    *   内容管理系统（博客、CMS）
    *   物联网 (IoT) 数据存储
    *   移动应用后端
    *   实时分析和日志记录
    *   社交网络和游戏

#### **4. MongoDB 核心术语（与 SQL 对比）**

为了方便你理解，我们将其与你可能熟悉的关系型数据库术语进行对比：

| MongoDB 术语          | 关系型数据库 (SQL) 术语 | 解释                                                         |
| :-------------------- | :---------------------- | :----------------------------------------------------------- |
| **Database (数据库)** | Database (数据库)       | 数据库的容器，一个 MongoDB 服务器可以有多个数据库。          |
| **Collection (集合)** | Table (表)              | 数据库中的一个集合，用于存放一组文档。                       |
| **Document (文档)**   | Row (行)                | 集合中的一个基本单元，由键值对组成，是数据的实际载体。       |
| **Field (字段)**      | Column (列)             | 文档中的一个键值对的键，代表数据的某个属性。                 |
| **_id**               | Primary Key (主键)      | 每个文档中必须有的一个唯一标识符，MongoDB 会自动生成。       |
| **BSON**              | (无直接对应)            | Binary JSON 的缩写，一种二进制序列化格式，用于在 MongoDB 中存储文档。它比 JSON 支持更多的数据类型（如日期、二进制数据等）。 |

**一个简单的例子：**

假设我们要存储一个用户信息，在 MongoDB 中它会是这样的一个 **Document**：

```json
{
  "_id": ObjectId("63d8a7a5a8e4b1e3f8a4f8b2"),
  "name": "张三",
  "age": 25,
  "email": "zhangsan@example.com",
  "skills": ["JavaScript", "MongoDB", "Node.js"],
  "address": {
    "city": "北京",
    "street": "中关村大街"
  }
}
```

这个文档存放在一个名为 `users` 的 **Collection** 里。

### **二、安装与环境配置**

理论知识有了，现在我们来动手实践。

#### **1. 安装 MongoDB Community Server**

MongoDB 服务器是存储数据的地方。你需要根据你的操作系统进行安装。

*   **官方渠道：** 始终建议从 [MongoDB 官方下载中心](https://www.mongodb.com/try/download/community) 下载。
*   **选择版本：** 选择 Community Server (社区版)，这是免费的。然后根据你的操作系统选择对应的版本和包（通常 Windows 用 MSI，macOS 用 DMG 或 Homebrew，Linux 用 DEB/RPM）。

**各平台安装简介：**

*   **Windows:**
    1.  下载 `.msi` 安装包。
    2.  双击运行，按照向导提示进行。推荐选择 "Complete" (完整) 安装。
    3.  一个重要的步骤是，请务必勾选 "Install MongoDB as a Service" (将 MongoDB 安装为服务)。 这样 MongoDB 就会在后台自动运行，不需要每次都手动开启。
    4.  安装程序会自动帮你设置好数据存储目录和日志目录。
    5.  安装完成后，需要将 MongoDB 的 `bin` 目录（例如 `C:\Program Files\MongoDB\Server\7.0\bin`）添加到系统的环境变量 `Path` 中，这样你才能在任何路径下使用 mongo 命令(新版本需要单独下载mongosh,然后把mongosh.exe所在目录加到环境变量)。

*   **macOS (推荐使用 Homebrew):**
    
    1.  如果没有安装 Homebrew，先安装它。
    2.  在终端中运行命令来安装 MongoDB：
        ```bash
        brew tap mongodb/brew
        brew install mongodb-community
        ```
    3.  安装完成后，可以通过以下命令来启动 MongoDB 服务：
        ```bash
        brew services start mongodb-community
        ```
    
*   **Linux (以 Ubuntu 为例):**
    1.  通常使用 `apt` 包管理器进行安装。
    2.  首先，需要导入 MongoDB 的公共 GPG 密钥：
        ```bash
        sudo apt-get install gnupg
        curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | \
           sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg \
           --dearmor
        ```
    3.  为 MongoDB 创建一个列表文件：
        ```bash
        echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu $(lsb_release -cs)/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
        ```
    4.  更新本地包数据库并安装 MongoDB：
        ```bash
        sudo apt-get update
        sudo apt-get install -y mongodb-org
        ```
    5.  启动 MongoDB 服务：
        ```bash
        sudo systemctl start mongod
        ```
    6.  验证服务是否正在运行：
        ```bash
        sudo systemctl status mongod
        ```

#### **2. 安装 MongoDB Compass (GUI 工具)**

Compass 是 MongoDB 官方推出的图形化界面工具，它能让你更直观地查看和操作数据，非常适合初学者。

1.  访问 [MongoDB Compass 的下载页面](https://www.mongodb.com/try/download/compass)。
2.  下载对应你操作系统的版本并安装。
3.  安装完成后打开 Compass，它会显示一个连接窗口。默认的连接字符串 `mongodb://localhost:27017` 通常可以直接使用，这是连接到你本地刚安装好的 MongoDB 服务器。
4.  点击 "Connect"，如果一切顺利，你就能看到你的数据库了。

#### **3. 使用 `mongo` Shell 进行交互**

`mongo` shell (新版本中叫 `mongosh`) 是一个命令行的交互式 JavaScript 接口，是与 MongoDB 交互最直接的方式。

1.  **打开 Shell:**
    *   确保你的 MongoDB 服务已经启动。
    *   打开你的终端 (Terminal / Command Prompt)。
    *   因为你已经配置了环境变量，所以直接输入 `mongosh` 然后回车。

2.  **看到如下界面，就表示成功连接：**
    ```
    Current Mongosh Log ID: ...
    Connecting to:          mongodb://127.0.0.1:27017/?directConnection=true&serverSelectionTimeoutMS=2000
    ...
    test>
    ```
    `test>` 表示你当前正在 `test` 数据库中。

3.  **尝试几个基本命令：**
    *   `show dbs`: 显示所有的数据库。
    *   `use myNewDB`: 切换到（或创建一个新的）名为 `myNewDB` 的数据库。注意，这个数据库只有在插入第一条数据后才会被真正创建。
    *   `show collections`: 显示当前数据库中的所有集合。

### **三、数据库和集合的基本操作**

**准备工作：进入我们的“学习乐园”**

首先，让我们创建一个专门用于学习的数据库。

在 `mongosh` 命令行中，输入：

```javascript
use my_school_db
```

*   **`use <数据库名>`** 这个命令有两个作用：
    1.  如果名为 `my_school_db` 的数据库存在，就切换过去。
    2.  如果不存在，就在内存中“准备”创建它。**注意：** 此时数据库只是被选中了，它只有在插入第一条数据后才会被真正物理创建。

#### **1. 创建和删除数据库**

*   **创建数据库:**
    *   我们已经通过 `use my_school_db` 命令选中了数据库。现在，只要我们向里面插入任意数据，它就会被自动创建。我们稍后在讲 `insertOne` 时会完成这一步。

*   **查看所有数据库:**
    ```javascript
    show dbs
    ```
    你可能会发现，列表中并没有我们刚刚创建的 `my_school_db`。这就是上面说的“懒创建”机制。

*   **删除数据库:**
    *   **警告：这是一个毁灭性操作，会删除数据库内的所有数据且无法恢复！**
    *   要删除数据库，你必须**先位于**那个数据库中。我们现在就在 `my_school_db` 里。
    ```javascript
    db.dropDatabase()
    ```
    执行后，这个数据库就被彻底删除了。为了继续学习，请再次执行 `use my_school_db`。

#### **2. 创建和删除集合**

*   **创建集合:**
    *   **显式创建：** 我们可以明确地创建一个集合。
    ```javascript
    db.createCollection("students")
    ```
    *   **隐式创建：** 更常见的方式是，当你第一次向一个不存在的集合插入数据时，MongoDB 会自动为你创建它。

*   **查看当前数据库中的集合:**
    ```javascript
    show collections
    ```
    你会看到我们刚刚创建的 `students` 集合。

*   **删除集合:**
    *   同样，这也是一个危险操作。
    ```javascript
    db.students.drop()
    ```
    执行后，`students` 集合就被删除了。

### **四、CRUD 操作：核心中的核心**

现在，我们来学习数据的 **增 (Create)、删 (Delete)、改 (Update)、查 (Read)**。为了方便，我们接下来的所有操作都将在一个名为 `students` 的集合中进行。你不需要手动创建它，我们在插入数据时它会自动出现。

#### **1. 创建 (Create)**

*   **`insertOne()`：插入单个文档**
    *   我们来插入第一个学生“张三”的信息。
    ```javascript
    db.students.insertOne({
      name: "张三",
      age: 20,
      gpa: 3.8,
      courses: ["Math", "Physics"],
      address: { city: "北京", district: "海淀区" }
    })
    ```
    *   执行后，你会看到一个返回结果，告诉你操作成功 (`"acknowledged": true`)，并显示了插入文档的 `_id`。
    *   **恭喜！** 就在这一刻，`my_school_db` 数据库和 `students` 集合被真正地物理创建了！现在你再执行 `show dbs` 就能看到它了。

*   **`insertMany()`：插入多个文档**
    
    *   一次性插入李四和王五的信息。注意，它接收的是一个由多个文档组成的**数组 `[...]`**。
    ```javascript
    db.students.insertMany([
      { name: "李四", age: 21, gpa: 3.5, courses: ["Chemistry", "English"], address: { city: "上海", district: "浦东新区" } },
      { name: "王五", age: 20, gpa: 4.0, courses: ["Math", "Computer Science"], address: { city: "北京", district: "朝阳区" } }
    ])
    ```

#### **2. 读取 (Read)**

这是最常用、最重要的操作。

*   **`find()` 和 `findOne()`**
    
    *   **查询所有文档：** `find({})` 中的 `{}` 表示一个空的查询条件，即匹配所有。
    ```javascript
    db.students.find({})
    ```
    *   **查询单个文档：** `findOne()` 只返回符合条件的第一个文档。
    ```javascript
    db.students.findOne({ name: "张三" })
    ```
    
*   **查询条件**
    *   **相等查询：** 查找所有年龄为 20 的学生。
    ```javascript
    db.students.find({ age: 20 })
    ```
    *   **比较操作符：**
        *   `$gt` (大于), `$lt` (小于), `$gte` (大于等于), `$lte` (小于等于)
        *   查找 GPA **大于 3.6** 的学生：
        ```javascript
        db.students.find({ gpa: { $gt: 3.6 } })
        ```
    *   **逻辑操作符：**
        
        *   `$and` (与，通常是隐式的), `$or` (或)
        *   查找所有年龄为 20 **且** GPA 大于 3.9 的学生 (隐式 AND)：
        ```javascript
        db.students.find({ age: 20, gpa: { $gt: 3.9 } })
        ```
        *   查找所在城市是“北京” **或** GPA 大于 3.9 的学生 (显式 OR)：
        ```javascript
        db.students.find({
          $or: [
            { "address.city": "北京" },
            { gpa: { $gt: 3.9 } }
          ]
        })
        ```
        > 注意：查询嵌套文档的字段时，要用 `.` 连接，如 `"address.city"`。
        
    *   **`$in` 和 `$nin` 操作符**
        *   `$in` (存在于数组中), `$nin` (不存在于数组中)
        *   查找名字是“张三”或“王五”的学生：
        ```javascript
        db.students.find({ name: { $in: ["张三", "王五"] } })
        ```
        *   查找选了 "Math" 这门课的学生：
        ```javascript
        db.students.find({ courses: "Math" }) // 当数组中包含该元素时，可以直接查询
        ```

---

*   **投影 (Projection)：只看我们想看的数据**
    *   有时候我们不希望返回文档的所有字段，只想看学生的姓名和 GPA。投影就是用来指定返回哪些字段的。
    *   `find` 命令的第二个参数 `{}` 就是投影操作符。`字段: 1` 表示**包含**该字段，`字段: 0` 表示**排除**该字段。
    *   **规则：** `_id` 字段默认总是返回。你可以在投影中明确地排除它 (`_id: 0`)。通常，你不能在一次投影中混合使用 `1` 和 `0`（唯一的例外是排除 `_id`）。

    *   **示例：只显示姓名和 GPA，同时排除 _id**
        ```javascript
        db.students.find(
          { age: { $gte: 20 } }, // 查询条件：年龄大于等于20
          { name: 1, gpa: 1, _id: 0 } // 投影：只显示 name 和 gpa，不显示 _id
        )
        ```
        执行后，你会看到返回的结果非常干净，只包含你指定的字段。

#### **3. 更新 (Update)**

更新操作稍微复杂一些，因为它包含两个部分：**“你要更新哪个/哪些文档”** (查询条件) 和 **“你要怎么更新”** (更新操作符)。

*   **`updateOne()` 和 `updateMany()`**
    *   `updateOne()`: 只更新符合条件的**第一个**文档。
    *   `updateMany()`: 更新符合条件的**所有**文档。

*   **核心更新操作符**
    *   **`$set`：修改或添加字段的值**
        *   这是最常用的操作符。如果字段存在，就更新其值；如果不存在，就创建该字段。
        *   **示例：** 将“张三”的年龄修改为 22，并给他添加一个 `major` (专业) 字段。
        ```javascript
        db.students.updateOne(
          { name: "张三" }, // 查询条件：找到名字叫张三的
          { $set: { age: 22, major: "Computer Science" } } // 更新操作：修改 age，添加 major
        )
        ```
        你可以用 `db.students.findOne({ name: "张三" })` 来检查更新是否成功。

    *   **`$unset`：删除一个字段**
        
        *   **示例：** 我们决定不再记录“李四”的 GPA。
        ```javascript
        db.students.updateOne(
          { name: "李四" }, // 查询条件
          { $unset: { gpa: "" } } // 更新操作：删除 gpa 字段，后面的值可以是任意的，通常给个空字符串
        )
        ```
        
    *   **`$inc`：增加或减少数值**
        *   只能用于数值类型的字段。
        *   **示例：** 所有学生的年龄都增加一岁。这里要用 `updateMany`！
        ```javascript
        db.students.updateMany(
          {}, // 查询条件为空，表示匹配所有学生
          { $inc: { age: 1 } } // 更新操作：将 age 字段的值增加 1
        )
        ```
    
    *   **`$push`：向数组中添加一个元素**
        *   **示例：** “王五”又选了一门新课 "Data Structures"。
        ```javascript
        db.students.updateOne(
          { name: "王五" }, // 查询条件
          { $push: { courses: "Data Structures" } } // 更新操作：向 courses 数组末尾添加一个元素
        )
        ```
    
    *   **`$pull`：从数组中删除一个符合条件的元素**
        *   **示例：** “张三”退选了 "Physics" 这门课。
        ```javascript
        db.students.updateOne(
          { name: "张三" }, // 查询条件
          { $pull: { courses: "Physics" } } // 更新操作：从 courses 数组中移除 "Physics"
        )
        ```
    
*   **`findOneAndUpdate()`：查找并更新**
    *   这是一个原子操作，它会查找一个文档，更新它，然后返回**更新前**或**更新后**的文档。这在很多编程场景中非常有用。
    *   **示例：** 找到 GPA 最高的学生，将他的 GPA 标记为 `status: "honored"`，并返回他**更新前**的信息。
    ```javascript
    db.students.findOneAndUpdate(
       { gpa: 4.0 }, // 查询条件
       { $set: { status: "honored" } } // 更新操作
    )
    ```

#### **4. 删除 (Delete)**

删除操作与查询类似，你只需要提供查询条件来告诉 MongoDB 要删除哪些文档。

*   **`deleteOne()`：删除符合条件的第一个文档**
    *   **示例：** 删除名为“李四”的学生。
    ```javascript
    db.students.deleteOne({ name: "李四" })
    ```
    即使有多个“李四”，也只会删除找到的第一个。

*   **`deleteMany()`：删除符合条件的所有文档**
    *   **示例：** 删除所有来自“北京”的学生。
    ```javascript
    db.students.deleteMany({ "address.city": "北京" })
    ```
    执行后，“张三”和“王五”都会被删除。

*   **删除集合中的所有文档**
    *   **极度危险！** 提供一个空的查询条件 `{}` 会匹配并删除集合中的所有文档，但集合本身还会保留。
    ```javascript
    // 再次警告：这将清空整个 students 集合！
    db.students.deleteMany({})
    ```

### **第一阶段核心基础小结**

太棒了！您已经完成了 MongoDB 最核心的基石部分。让我们快速回顾一下：

1.  **数据库和集合管理：**
    *   `use <db_name>`: 切换/创建数据库。
    *   `db.dropDatabase()`: 删除当前数据库。
    *   `db.createCollection("coll_name")`: 创建集合。
    *   `db.collection_name.drop()`: 删除集合。

2.  **CRUD 四大操作：**
    *   **创建 (C):** `insertOne()`, `insertMany()`
    *   **读取 (R):** `find()`, `findOne()`
    *   **更新 (U):** `updateOne()`, `updateMany()`
    *   **删除 (D):** `deleteOne()`, `deleteMany()`

3.  **核心理念：**
    *   所有“读、改、删”操作都依赖于**查询条件**来定位文档。
    *   我们学会了使用比较符 (`$gt`, `$lte`)、逻辑符 (`$or`) 和数组成员符 (`$in`) 来构建查询。
    *   我们学会了使用**投影**来定制返回的数据。
    *   我们学会了使用**更新操作符** (`$set`, `$inc`, `$push`, `$pull`等) 来精确地修改文档。
