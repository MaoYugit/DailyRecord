#### **创建第一个 Express 应用**

这是你进入 Express 世界的第一步。我们将从零开始，搭建并运行一个最基础的 Web 服务器。

##### **1. 安装与设置 (Installation & Setup)**

首先，我们需要为项目创建一个工作目录，并初始化一个 Node.js 项目。

*   **步骤 1：创建项目文件夹**
    打开你的终端（在 Windows 上是 PowerShell 或 CMD，在 macOS/Linux 上是 Terminal），创建一个新的文件夹并进入该目录。

    ```bash
    # 创建一个名为 "my-first-app" 的文件夹
    mkdir my-first-app
    
    # 进入这个文件夹
    cd my-first-app
    ```

*   **步骤 2：初始化 Node.js 项目**
    每个 Node.js 项目都需要一个 `package.json` 文件。这个文件用于管理项目的元数据（如项目名称、版本）和依赖项（项目所需的第三方库）。使用 `npm init` 命令可以快速生成这个文件。

    ```bash
    # 使用 -y 标志可以跳过所有提问，并使用默认值快速生成 package.json 文件
    npm init -y
    ```
    执行后，你的文件夹中会出现一个 `package.json` 文件。

*   **步骤 3：安装 Express 框架**
    现在，我们来安装 Express。Express 本身也是一个 npm 包，是项目的核心依赖。

    ```bash
    # install 是安装命令，express 是我们要安装的包名
    npm install express
    ```
    这个命令会做几件事：
    1.  从 npm 仓库下载 Express 框架的代码。
    2.  在你的项目根目录下创建一个 `node_modules` 文件夹，并将 Express 的代码存放在里面。
    3.  自动更新 `package.json` 文件，在 `dependencies` 字段中添加 `express` 及其版本号，记录下你的项目依赖它。
    4.  生成或更新 `package-lock.json` 文件，用于锁定依赖的具体版本，保证团队协作时环境的一致性。

至此，你的项目环境已经搭建完毕！你的文件夹结构现在看起来是这样的：

```
my-first-app/
├── node_modules/
├── package-lock.json
└── package.json
```

##### **2. "Hello World" 服务 (A "Hello World" Server)**

现在，让我们编写代码来创建一个能够响应 "Hello World!" 的服务器。

*   **步骤 1：创建服务器文件**
    在项目根目录 (`my-first-app/`) 下，创建一个新的 JavaScript 文件，通常我们将其命名为 `app.js` 或 `index.js`。

*   **步骤 2：编写服务器代码**
    打开 `app.js` 文件，并输入以下代码：

    ```javascript
    // 1. 引入 express 模块
    // 这行代码会从 node_modules 文件夹中加载 Express 框架
    const express = require('express');
    
    // 2. 创建一个 Express 应用实例
    // app 对象是 Express 功能的核心，我们后续的所有操作都将基于它
    const app = express();
    
    // 3. 定义服务器的端口号
    // Web 服务器需要监听一个网络端口来接收请求。3000 是一个常用的开发端口
    const port = 3000;
    
    // 4. 定义一个路由 (Route)
    // 当用户访问我们网站的根路径 ('/') 时，这个函数就会被触发
    // req 代表收到的 HTTP 请求，res 代表要发出的 HTTP 响应
    app.get('/', (req, res) => {
      // 使用 res.send() 方法向客户端发送响应
      res.send('Hello World!');
    });
    
    // 5. 启动服务器并监听指定端口
    // 这行代码让我们的应用开始在 3000 端口上等待请求
    // 第二个参数是一个回调函数，当服务器成功启动时会执行
    app.listen(port, () => {
      console.log(`示例应用正在监听 http://localhost:${port}`);
    });
    ```

*   **步骤 3：运行你的应用**
    回到你的终端，确保你仍然在 `my-first-app` 目录下，然后执行以下命令：

    ```bash
    node app.js
    ```
    如果一切顺利，你会在终端看到输出：
    `示例应用正在监听 http://localhost:3000`

*   **步骤 4：查看结果**
    打开你的网络浏览器（如 Chrome、Firefox），在地址栏输入 `http://localhost:3000` 并按回车。

    你会看到页面上显示出 **"Hello World!"**。

    恭喜！你已经成功创建并运行了你的第一个 Express 应用。

##### **3. 请求 (req) 与响应 (res) 对象 (Request & Response Objects)**

在上面的 "Hello World" 示例中，你已经接触到了 `req` 和 `res`。这两个对象是 Express 的核心，理解它们至关重要。

*   **请求对象 `req` (Request)**
    `req` 对象代表了客户端发来的 HTTP 请求。它包含了关于这个请求的所有信息，比如请求的 URL、HTTP 头部、查询参数、请求体等等。你可以通过访问 `req` 对象的属性来获取这些信息。

    **举例来说**：
    *   `req.url`：获取请求的 URL 路径 (例如 `/about`, `/users?id=123`)。
    *   `req.method`：获取请求的方法 (例如 `GET`, `POST`)。
    *   `req.headers`：获取一个包含所有 HTTP 请求头的对象。

    我们可以修改一下 `app.js` 来看看 `req` 对象：

    ```javascript
    // ... 其他代码保持不变 ...
    
    app.get('/', (req, res) => {
      // 在服务器的终端上打印出请求方法和 URL
      console.log(`收到一个 ${req.method} 请求，访问的 URL 是 ${req.url}`);
      res.send('Hello World!');
    });
    
    // ... 其他代码保持不变 ...
    ```
    现在，重启你的服务器（在终端按 `Ctrl + C` 停止，然后再次运行 `node app.js`），刷新浏览器页面。你会在终端看到类似 `收到一个 GET 请求，访问的 URL 是 /` 的输出。

*   **响应对象 `res` (Response)**
    `res` 对象代表了服务器要发送给客户端的 HTTP 响应。Express 提供了许多便捷的方法，挂载在 `res` 对象上，让你能够轻松地构建和发送响应。

    **常用方法举例**：
    *   `res.send()`: 发送各种类型的响应，比如字符串、HTML、Buffer 或 JSON 对象。这是最常用的方法之一。
    *   `res.json()`: 专门用于发送 JSON 格式的响应。它会自动设置正确的 `Content-Type` 响应头 (`application/json`)。
    *   `res.status(code)`: 设置响应的 HTTP 状态码（如 `200` 代表成功，`404` 代表未找到）。

    让我们再修改一下代码，尝试发送一个 JSON 响应：

    ```javascript
    // ... 其他代码保持不变 ...
    
    // 当用户访问 /api/user 时
    app.get('/api/user', (req, res) => {
      // 发送一个 JSON 对象作为响应
      res.json({
        id: 1,
        name: '小明',
        email: 'xiaoming@example.com'
      });
    });
    
    // ... 其他代码保持不变 ...
    ```
    重启服务器后，在浏览器中访问 `http://localhost:3000/api/user`，你将看到一个格式化的 JSON 对象。

这两个对象是你与客户端进行交互的桥梁，在后续的所有开发中，你都会持续不断地使用它们。
