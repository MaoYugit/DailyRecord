### **四、 视图与模板引擎 (Views & Template Engines)**

#### **核心理念：动态生成 HTML**

想象一下，你有一个 HTML 文件模板，里面有一些“占位符”或“空白处”。模板引擎的工作就是用你的**动态数据**（比如从数据库查询出来的用户信息）去**填充**这些空白处，然后生成一个最终的、完整的 HTML 文件发送给用户。

这就像一个邮件合并工具：你有一个信件模板（视图），和一个收件人列表（数据），工具会为每个收件人生成一封个性化的信件（最终的 HTML）。

---

#### **1. 模板引擎集成**

Express 本身不包含模板引擎，但它提供了一个统一的接口，可以轻松集成各种流行的模板引擎。最常见的三种是：

*   **EJS (Embedded JavaScript Templating)**
    *   **特点**：语法最接近原生 HTML。你可以在 HTML 中使用 `<% ... %>` 标签来嵌入 JavaScript 逻辑。
    *   **优点**：学习曲线非常平缓，如果你熟悉 HTML 和 JS，几乎可以立即上手。
    *   **看起来像这样**：`<h1><%= title %></h1>`

*   **Pug (以前叫 Jade)**
    *   **特点**：使用缩进而不是标签来定义 HTML 结构。语法非常简洁，没有闭合标签。
    *   **优点**：代码量少，非常干净。
    *   **缺点**：对缩进要求严格，初学者可能会不习惯。你写的不是标准 HTML。
    *   **看起来像这样**：`h1= title`

*   **Handlebars.js**
    *   **特点**：使用 `{{...}}` 作为占位符，语法逻辑清晰。
    *   **优点**：功能强大，语义明确，生态系统丰富。
    *   **看起来像这样**：`<h1>{{title}}</h1>`

**我们将以 EJS 作为主要示例**，因为它最容易入门。

---

#### **实战：使用 EJS 创建一个动态用户列表页面**

##### **第 1 步：安装 Express 和 EJS**

```bash
# 确保你在你的项目文件夹中
npm install express ejs
```

##### **第 2 步：创建项目结构**

Express 有一个默认的约定：所有的模板文件（视图）都应该放在一个名为 `views` 的文件夹中。

```
my-webapp/
├── views/                  // 存放模板文件的文件夹
│   └── users.ejs           // 我们的用户列表模板
├── node_modules/
├── app.js                  // 主应用文件
└── package.json
```

##### **第 3 步：创建 EJS 模板 (`views/users.ejs`)**

这是一个 HTML 文件，但嵌入了一些特殊的 EJS 标签。

*   `<%= ... %>`：用于**输出变量的值**到 HTML 中（它会自动转义特殊字符，防止 XSS 攻击）。
*   `<% ... %>`：用于**执行 JavaScript 逻辑**，如 `if` 语句或 `for` 循环，它不会直接输出任何内容。

```html
<!-- 文件: views/users.ejs -->
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title><%= pageTitle %></title>
  <style>
    body { font-family: sans-serif; }
    li { margin-bottom: 5px; }
    .active { color: green; font-weight: bold; }
    .inactive { color: grey; }
  </style>
</head>
<body>
  <h1><%= pageTitle %></h1>

  <% if (users.length > 0) { %>
    <ul>
      <% users.forEach(user => { %>
        <li class="<%= user.isActive ? 'active' : 'inactive' %>">
          <%= user.name %> - (Email: <%= user.email %>)
        </li>
      <% }); %>
    </ul>
  <% } else { %>
    <p>没有找到任何用户。</p>
  <% } %>
</body>
</html>
```

##### **第 4 步：在 Express 中配置和使用模板引擎 (`app.js`)**

现在我们需要告诉 Express：
1.  我们要使用 EJS 作为我们的模板引擎。
2.  去哪里找我们的模板文件。

```javascript
// 文件: app.js
const express = require('express');
const path = require('path'); // 引入 path 模块
const app = express();
const port = 3000;

// 1. 设置模板引擎 (View Engine)
// 这行代码告诉 Express，当调用 res.render 时，默认使用 ejs 引擎
app.set('view engine', 'ejs');

// 2. 设置视图文件的存放目录
// 这行代码告诉 Express，去 'views' 文件夹中寻找模板文件
// 使用 path.join(__dirname, 'views') 是一个好习惯，可以避免跨平台路径问题
app.set('views', path.join(__dirname, 'views'));

// 模拟一些用户数据
const usersData = [
  { id: 1, name: 'Alice', email: 'alice@example.com', isActive: true },
  { id: 2, name: 'Bob', email: 'bob@example.com', isActive: false },
  { id: 3, name: 'Charlie', email: 'charlie@example.com', isActive: true }
];

// 3. 创建路由并传递数据
app.get('/users', (req, res) => {
  // 定义要传递给模板的数据对象
  const data = {
    pageTitle: '用户列表',
    users: usersData
  };

  // 使用 res.render() 来渲染视图
  // 第一个参数是视图文件的名字（不需要加 .ejs 后缀）
  // 第二个参数是一个对象，包含了要传递给视图的数据
  res.render('users', data);
});

app.listen(port, () => {
  console.log(`服务器正在 http://localhost:${port} 上运行`);
});
```

##### **第 5 步：运行和测试**

1.  在终端运行你的应用：`node app.js`
2.  打开浏览器，访问 `http://localhost:3000/users`

你将会看到一个由 `users.ejs` 模板和 `usersData` 数据动态生成的 HTML 页面。

---

#### **总结：数据传递流程**

1.  **客户端请求** `GET /users`。
2.  **Express 路由**匹配到 `app.get('/users', ...)` 处理器。
3.  **处理器内部**：
    *   准备一个包含动态数据的 `data` 对象。
    *   调用 `res.render('users', data)`。
4.  **Express 内部**：
    *   根据 `app.set('views', ...)` 的设置，找到 `views/users.ejs` 文件。
    *   根据 `app.set('view engine', 'ejs')` 的设置，调用 EJS 引擎。
    *   EJS 引擎接收 `users.ejs` 模板和 `data` 对象。
    *   EJS 执行模板中的所有 JS 代码（循环、判断），并将 `data` 对象中的值（`pageTitle`, `users`）填充到 `<%= ... %>` 占位符中。
5.  **生成最终 HTML**，并将其作为 HTTP 响应发送回客户端。
