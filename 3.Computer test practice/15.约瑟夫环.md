约瑟夫环（Josephus Problem）是算法面试和 LeetCode 中的经典问题。它的基本形式是：**$n$ 个人围成一圈，从第一个人开始报数，报到 $m$ 的人出列，剩下的人继续从 1 开始报数，直到最后只剩一个人。**

在 LeetCode 中，最典型的题目是 **1823. 找出游戏获胜者** 和 **剑指 Offer 62. 圆圈中最后剩下的数字**。

学习约瑟夫环，通常有三种境界：**模拟法**、**队列法**、和**数学递归法**。

---

### 1. 模拟法（初级：List + 索引取模）
这是最符合直觉的方法。我们用一个列表模拟圆圈，每次计算出要删除的那个人的索引。

**核心技巧：**
如果当前起跳点的索引是 `cur`，要报 $k$ 个数，那么下一个删除的位置索引是：
$$(cur + k - 1) \pmod{\text{当前人数}}$$
*注：这里是 $k-1$ 是因为报数包含当前这个人。*

```python
def solve_josephus_list(n, k):
    people = list(range(1, n + 1))
    idx = 0
    while len(people) > 1:
        # 计算删除位置
        idx = (idx + k - 1) % len(people)
        people.pop(idx)
    return people[0]
```
*   **复杂度**：时间 $O(n^2)$（因为 `pop` 在列表中是 $O(n)$），空间 $O(n)$。
*   **适用**：$n$ 较小（如 $n < 10000$）的情况。

---

### 2. 队列法（中级：双端队列轮转）
利用 Python 的 `collections.deque`，我们可以模拟“报数”的过程：报数的人从队头移到队尾，数到 $k$ 的人直接弹出，不再入队。

```python
from collections import deque

def solve_josephus_deque(n, k):
    q = deque(range(1, n + 1))
    while len(q) > 1:
        # 将前 k-1 个人移到队尾
        q.rotate(-(k - 1))
        # 弹出第 k 个人
        q.popleft()
    return q[0]
```
*   **技巧**：`rotate(-x)` 表示向左旋转，等价于把前 $x$ 个元素依次接到末尾。
*   **复杂度**：时间 $O(n \cdot k)$。

---

### 3. 数学递推法（高级：动态规划）
这是 LeetCode 进阶要求的解法。如果我们不需要知道中间出列的顺序，只需要知道**最后剩下的那个人**，可以通过数学公式直接算出来。

**逻辑推导：**
1. 假设 $f(n, k)$ 表示 $n$ 个人报数 $k$ 最后剩下的人的索引。
2. 当一个人出列后，剩下的问题变成了 $f(n-1, k)$。
3. 我们可以得到递推公式：
   $$f(n, k) = (f(n-1, k) + k) \pmod n$$
   基础情况：$f(1, k) = 0$（当只有 1 个人时，索引为 0 的人获胜）。

**迭代代码实现：**
这是最优雅且最快的方法。

```python
def solve_josephus_math(n, k):
    res = 0  # f(1, k) = 0
    # 从 2 个人开始往上推直到 n 个人
    for i in range(2, n + 1):
        res = (res + k) % i
    return res + 1  # 结果加 1 是因为题目编号通常从 1 开始
```
*   **复杂度**：时间 **$O(n)$**，空间 **$O(1)$**。
*   **优点**：可以处理 $n$ 非常大的情况（例如 $n=10^7$）。
