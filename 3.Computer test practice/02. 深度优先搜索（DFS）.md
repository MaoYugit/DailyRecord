## 🚀 第一阶段：心法与二叉树

#### 1. 什么是 DFS？（直觉理解）

想象你在走一个迷宫，DFS 的策略是：**“一条道走到黑，不撞南墙不回头”。**

*   你选定一条路，一直往前走。
*   如果前面没路了（撞南墙了），你就退回到上一个路口（回溯）。
*   换一条没走过的路继续走。
*   直到走完所有路。

在编程里，实现这个逻辑的神器就是 **递归（Recursion）**。

#### 2. 递归的核心模板（背下来！）

很多初学者写不出 DFS，是因为不知道怎么写递归。递归只有 **三个要素**，任何 DFS 代码都逃不出这个框架：

```python
def dfs(当前节点):
    # 1. 截止条件（撞南墙）
    # 如果当前节点是空的，或者是无效的，赶紧停下来返回
    if not 当前节点:
        return 

    # 2. 做点什么（处理当前层）
    # 比如打印节点值，或者把它加到结果里
    print(当前节点.val)

    # 3. 这里的风景看完了，去下一层（分身术）
    dfs(当前节点.左边)
    dfs(当前节点.右边)
```

**关键点：** 你要把 `dfs` 函数看作是一个**哪怕死也会完成任务的“包工头”**。你只要告诉他“去做”，不要去想他到底怎么一层层做的，**相信他能做完**。

#### 3. 实战演练：LeetCode 104. 二叉树的最大深度

这是最经典的入门题。
**题目：** 给你一个二叉树，求它最深有多少层？

**思考逻辑（DFS版）：**
假设你现在站在根节点（Root），你想知道这棵树有多深。
如果你比较“懒”，你会怎么做？
你会对你的两个手下（左子节点、右子节点）说：
*   “左边那位，你去量量你那边有多深？”
*   “右边那位，你也去量量你那边有多深？”
*   等他们汇报回来，你选一个更大的，然后 **+1**（加上你自己这一层），就是答案。

**代码实现（Python）：**

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        # 1. 截止条件（撞南墙）
        # 如果当前节点是 None（空的），那深度肯定是 0
        if not root:
            return 0
        
        # 2. & 3. 递归调用（分身去干活）
        # 这里的 maxDepth 就是那个“包工头”
        left_depth = self.maxDepth(root.left)   # 左边有多深？
        right_depth = self.maxDepth(root.right) # 右边有多深？
        
        # 汇报总结
        # 我这一层的深度 = 左边和右边较大的那个 + 1 (我自己)
        return max(left_depth, right_depth) + 1
```

**为什么这段代码能工作？**
你不需要人肉模拟每一层（那样脑子会炸）。你只需要相信：`self.maxDepth(root.left)` 既然叫这个名字，它就一定能返回左边的深度。这就是**递归的“信任”**。

#### 4. 实战演练：LeetCode 144. 二叉树的前序遍历

**题目：** 给你一个二叉树，返回它的节点值列表。顺序是：中 -> 左 -> 右。

**套用我们的模板：**

```python
class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = [] # 这是一个小本本，用来记数字
        
        def dfs(node):
            # 1. 截止条件
            if not node:
                return
            
            # 2. 做点什么（题目要求：中 -> 左 -> 右）
            # 所以我们先记录当前节点（中）
            res.append(node.val) 
            
            # 3. 去下一层
            dfs(node.left)  # 接着去左边
            dfs(node.right) # 最后去右边
        
        # 启动引擎
        dfs(root)
        return res
```

**如果是中序遍历（LeetCode 94）怎么办？**
只要改一下顺序！
*   前序：中 -> `dfs(左)` -> `dfs(右)`
*   中序：`dfs(左)` -> 中 -> `dfs(右)`
*   后序：`dfs(左)` -> `dfs(右)` -> 中

你看，这就是 DFS 的魅力，**结构永远不变，只变处理数据的位置**。

⚠️ **高能预警**：这一阶段是面试中 **出现频率最高、性价比最高** 的部分。如果你能把这块吃透，至少能应付 50% 的中等难度面试题。

### 🗺️ 从“二叉树”到“二维网格”的进化

在二叉树里（第一阶段），我们的选择很少：只有 **左** 和 **右** 两条路。
但在二维网格里（比如一个棋盘），如果你站在一个格子上，你有 **4 个方向** 可以走：**上、下、左、右**。

**最大的区别是：**
*   **二叉树**：只能往下走，不会走回头路。
*   **网格**：可以绕圈圈！如果你不加限制，DFS 就会在两个格子之间无限循环（左 -> 右 -> 左 -> 右...），直到报错。

所以，网格 DFS 多了一个核心逻辑：**标记你去过的地方（Mark Visited）**。

### 🏝️ 经典案例：LeetCode 200. 岛屿数量 (Number of Islands)

这是网格 DFS 的**鼻祖**。学会这一道题，后面几十道题都是换汤不换药。

**题目**：给你一个由 `'1'`（陆地）和 `'0'`（水）组成的二维网格，请计算网格中岛屿的数量。（连在一起的 1 算一个岛）。

**思路：生化危机（病毒感染法）**
想象你是上帝，你在遍历这个地图。
1.  当你第一次发现一块陆地（`'1'`）时，**岛屿数量 +1**。
2.  但是！为了防止之后重复数这块地，你要立刻对这块地投放“病毒”（启动 DFS）。
3.  **DFS 的作用**：这个病毒会把当前这块陆地传染变成水（`'0'`），并且向四周扩散。凡是和它连着的陆地，统统变成水。
4.  **结果**：整块岛屿直接就在地图上“消失”了（被炸沉了）。
5.  这样当你继续遍历地图时，再遇到刚才那块岛屿的任何部分，看到的都是水，就不会重复计数了。

---

### 📝 核心模板（背下来！）

这是处理网格问题的**万能公式**。任何网格 DFS 都要先写这几行 **“保命代码”**（Base Case）。

**坐标系小知识**：
*   `grid` 是一个二维数组。
*   `r` (row) 代表行号（上下）。
*   `c` (col) 代表列号（左右）。
*   向上走：`(r-1, c)`，向下走：`(r+1, c)`
*   向左走：`(r, c-1)`，向右走：`(r, c+1)`

**代码实现：**

```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        if not grid:
            return 0
            
        # 1. 这种题目，先算出地图长宽，方便后面用
        rows = len(grid)
        cols = len(grid[0])
        count = 0  # 记录岛屿数量
        
        # 2. 定义我们的“病毒” DFS 函数
        def dfs(r, c):
            # --- 核心保命 4 连击 (Base Case) ---
            # 如果坐标越界（跑出地图了），赶紧停！
            if r < 0 or r >= rows or c < 0 or c >= cols:
                return
            
            # 如果这里已经是水（'0'）了，或者是已经炸过的岛，赶紧停！
            if grid[r][c] == '0':
                return
            
            # --- 做点什么 ---
            # 走到这里，说明 grid[r][c] 肯定是 '1' (陆地)
            # 把它变成 '0' (淹没它/标记为已访问)，防止回头
            grid[r][c] = '0' 
            
            # --- 分身术（向 4 个方向扩散） ---
            dfs(r - 1, c) # 上
            dfs(r + 1, c) # 下
            dfs(r, c - 1) # 左
            dfs(r, c + 1) # 右

        # 3. 上帝视角：遍历地图的每一个格子
        for r in range(rows):
            for c in range(cols):
                # 只有发现新大陆（'1'）的时候，才触发逻辑
                if grid[r][c] == '1':
                    count += 1  # 发现一个岛！记下来
                    dfs(r, c)   # 派病毒去把这个岛彻底铲平（避免重复数）
                    
        return count
```

---

### 🧐 详细拆解“保命 4 连击”

新手写网格 DFS，最容易报 `IndexError`（数组越界）。
你必须在 dfs 函数的第一行，像念咒语一样写下这判断：

```python
if r < 0 or r >= rows or c < 0 or c >= cols:
    return
```
*   `r < 0`: 太靠上了，出界了。
*   `r >= rows`: 太靠下了，出界了。
*   `c < 0`: 太靠左了，出界了。
*   `c >= cols`: 太靠右了，出界了。

只要满足任何一条，说明你跑出地图了，必须立刻 `return`。

### ⚔️ 实战演练：LeetCode 695. 岛屿的最大面积

这道题和上面那道题（200）几乎一模一样，只是要求变了。
*   200 题：求岛屿的**个数**（dfs 只负责炸岛，不返回值）。
*   695 题：求最大的那个岛有**多大**（dfs 需要返回面积）。

**修改思路：**
DFS 函数现在变成了“测量员”。
1.  如果出界或者是水，面积是 0。
2.  如果是陆地，先把地淹了（标记），然后面积 = 1（自己）+ 上面的面积 + 下面的面积 + 左 + 右。

**代码（尝试看懂区别）：**

```python
class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        max_area = 0 # 记录目前为止见过的最大面积
        
        def dfs(r, c):
            # 1. 保命连击 + 遇到水就停
            # 注意：这题里的水是 0，陆地是 1 (数字)
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == 0:
                return 0 # 没地，面积是 0
            
            # 2. 标记已访问 (淹没它)
            grid[r][c] = 0 
            
            # 3. 算面积：我自己(1) + 四个方向汇报上来的面积
            return 1 + dfs(r-1, c) + dfs(r+1, c) + dfs(r, c-1) + dfs(r, c+1)

        # 4. 遍历全图
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1:
                    # 这次我们需要 DFS 给我们返回一个面积数字
                    current_area = dfs(r, c)
                    # 更新最大值
                    max_area = max(max_area, current_area)
                    
        return max_area
```

## **第三阶段：回溯法（Backtracking）**。

这是 DFS 的**完全体**，也是面试官最爱用来考“逻辑思维”的题型。

---

### 🔙 什么是“回溯”？

回溯法 = **DFS + 后悔药**。

在之前的“岛屿问题”里，我们走过的地方就直接“炸沉”或者标记为“已访问”，永远不再回头。
但在回溯法里，我们的逻辑是：
1.  **尝试：** 选一条路走。
2.  **发现不对（或走到了终点）：** **撤销**刚才的决定（把脚收回来）。
3.  **换路：** 尝试另一条路。

**生活中的例子：**
你在玩游戏（比如《黑神话·悟空》）。
*   你走到一个岔路口，存档（Save）。
*   你走左边，结果遇到 Boss 被打死了。
*   你读档（Load），回到岔路口（这就是**回溯**）。
*   你这次改走右边。

---

### 📦 核心模型：填空箱子

我们用最经典的 **LeetCode 46. 全排列 (Permutations)** 来讲。
**题目：** 给定一个不含重复数字的数组 `[1, 2, 3]` ，返回所有可能的排列。

**思考逻辑：**
想象你有 3 个空的箱子 `[ ] [ ] [ ]`，你手里有 3 张牌 `1, 2, 3`。

1.  **站在第 1 个箱子前：**
    *   你把 `1` 放进去。现在是 `[1] [ ] [ ]`。
    *   手里剩 `2, 3`。

2.  **站在第 2 个箱子前：**
    *   你把 `2` 放进去。现在是 `[1] [2] [ ]`。
    *   手里剩 `3`。

3.  **站在第 3 个箱子前：**
    *   你把 `3` 放进去。现在是 `[1] [2] [3]`。
    *   **咔嚓！拍照！**（找到一个结果）。

4.  **关键时刻（回溯）：**
    *   刚才第 3 个箱子放的是 `3`。现在我要**把 `3` 拿出来**（恢复原状）。
    *   退回到第 2 个箱子，把 `2` 拿出来。
    *   换一张牌！把 `3` 放到第 2 个箱子里试试……

---

### 📝 回溯法万能模板（背诵全文！）

几乎所有的回溯题（全排列、组合、N皇后）都长这样：

```python
result = []
def backtrack(路径, 选择列表):
    # 1. 结束条件
    if 满足结束条件:
        result.append(路径)
        return

    # 2. 核心循环（遍历当前所有的选择）
    for 选择 in 选择列表:
        # --- A. 做选择 ---
        if 选择 已经选过了:
            continue
        路径.add(选择)  # 把这个数字放进箱子
        
        # --- B. 进入下一层决策 ---
        backtrack(路径, 选择列表)
        
        # --- C. 撤销选择 (后悔药) ---
        路径.remove(选择) # 【关键】把这个数字从箱子里拿出来！
```

### 💻 实战：LeetCode 46. 全排列

请仔细看代码里的“做选择”和“撤销选择”。

```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        res = []  # 存所有结果的大本本
        
        # path: 当前已经填好的数字列表，比如 [1, 2]
        def dfs(path):
            # 1. 结束条件：如果 path 里的数字数量够了（比如填满了3个）
            if len(path) == len(nums):
                # 【超级大坑预警】
                # 必须写 path[:] 或者 path.copy()
                # 否则你存进去的是一个“活的”列表，后面回溯修改它，这里存的也会变！
                res.append(path[:]) 
                return

            # 2. 遍历所有的数字，看看哪个能放
            for num in nums:
                # 如果这个数字已经在 path 里了，就不能再用了（题目说不重复）
                if num in path:
                    continue
                
                # --- A. 做选择 ---
                path.append(num) # 把数字放进箱子
                
                # --- B. 下一层 ---
                dfs(path)        # 继续去填下一个箱子
                
                # --- C. 撤销选择 (回溯) ---
                # 这一步是回溯的灵魂！
                # 递归回来后，我们要把刚才放进去的数字拿出来，
                # 这样才能腾出位置，给下一次循环尝试别的数字。
                path.pop() 

        dfs([])
        return res
```

### 🧠 这里的“坑”在哪里？

**1. 为什么要 `path.pop()`？**
如果你不 pop，你的 `path` 就会变成 `[1, 2, 3, 2...]` 越加越长。
你必须保证：在尝试 `[1, 3]` 之前，`path` 必须干干净净地回到 `[1]` 的状态。
`pop()` 就是把最后放进去的那个东西拿走，**恢复现场**。

**2. 为什么要 `res.append(path[:])`？**
这是 Python 特有的坑。
`path` 是一个对象。如果你直接 `res.append(path)`，你存的是这个**对象的引用**（门牌号）。
等你后面执行 `path.pop()` 把列表清空了，你 `res` 里存的那个东西也就变成空的了。
`path[:]` 的意思是：“给我**复印**一份当前的列表，存复印件”。

### ⚔️ 第三阶段作业

回溯法起步稍微有点难，但一旦通了就极其舒爽。

2.  **LeetCode 78 (子集)**：

### 🗺️ 第四阶段：图（Graph）的深度遍历

#### 1. 什么是“图”？（破除恐惧）

别被名字吓到了。
*   **二叉树**：是“等级森严”的组织结构。CEO -> 经理 -> 员工。只能往下管，不能越级，也没有回头路。
*   **网格**：是“方方正正”的棋盘。只能走上下左右。
*   **图**：就是**“微信朋友圈”**。

在“图”的世界里：
1.  **节点 (Node)**：就是**人**（你可以把它看作 0, 1, 2, 3... 号人）。
2.  **边 (Edge)**：就是**好友关系**。
    *   A 认识 B，B 认识 C，C 可能认识 A（这就形成了**环**）。
    *   有的关系是单向的（我关注了马斯克，马斯克没关注我），这叫**有向图**。
    *   有的关系是双向的（互为好友），这叫**无向图**。

---

#### 2. 最难的一步：怎么用代码表示“图”？

在二叉树里，你有 `node.left` 和 `node.right`，这很直观。
在图里，一个人可能有 100 个朋友，不可能写 `node.friend1`, `node.friend2`...

我们用**“邻接表” (Adjacency List)** 来存。
**重点来了**，请一定盯着下面这个例子看懂：

**输入数据：** `graph = [[1, 2], [3], [3], []]`

这其实是一个**数组**（列表），**索引（下标）代表“那个人”**，**内容代表“他的朋友”**。

*   `graph[0]` 是 `[1, 2]`：意思就是，**0号** 认识 **1号** 和 **2号**。
*   `graph[1]` 是 `[3]`：意思就是，**1号** 认识 **3号**。
*   `graph[2]` 是 `[3]`：意思就是，**2号** 认识 **3号**。
*   `graph[3]` 是 `[]`：意思就是，**3号** 谁都不认识（或者他是终点，没下文了）。

**画成图就是：**
```text
      0
     / \
    v   v
    1   2
     \ /
      v
      3
```

---

#### 3. DFS 在图里怎么走？

在二叉树里，代码是这样的：
```python
dfs(root.left)
dfs(root.right)
```

在图里，因为朋友数量不确定，所以我们不能写死。我们要用 **`for` 循环** 来遍历所有的朋友。

**图 DFS 的核心逻辑（伪代码）：**
```python
def dfs(当前的人):
    # 拿出这个人的通讯录 (graph[当前的人])
    # 挨个给朋友打电话
    for 朋友 in graph[当前的人]:
        dfs(朋友)
```

你看，这就是**图**和**树**唯一的区别：**把“左右两行”变成了“一个循环”**。

#### 4. 实战拆解：LeetCode 797. 所有可能的路径

**题目**：给你刚才那个 `graph`，请你找出从 **0号** 到 **最后那个人（n-1号）** 的所有路径。

**分析**：
这道题就是典型的**“回溯法”**在图上的应用。
我们要记录路径 `path`。
1.  出发点：0。
2.  终点：3（也就是 `len(graph) - 1`）。
3.  规则：一条道走到黑，记录下来；然后回头，换条路走。

**详细代码（请像阅读文章一样阅读注释）：**

```python
class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:
        # 1. 确定终点是谁
        # graph 的长度是 4，说明有 0,1,2,3 四个人。
        # 所以终点是 3 (也就是 len-1)
        target = len(graph) - 1
        
        results = [] # 存最终的所有路线
        
        # 2. 定义 DFS 函数
        # node: 我现在走到谁这里了？
        # path: 我这一路走来都经过了谁？(比如 [0, 1])
        def dfs(node, path):
            # --- 截止条件 (Base Case) ---
            # 如果我现在站的地方就是终点，那太好了！
            if node == target:
                # 记录这条路线 (记得要复印一份 path[:])
                results.append(path[:])
                return

            # --- 遍历邻居 (核心逻辑) ---
            # graph[node] 就是当前这个 node 的好友列表
            # 比如 node是0，neighbors就是 [1, 2]
            for neighbor in graph[node]:
                
                # A. 做选择 (决定去这个朋友家)
                path.append(neighbor)
                
                # B. 下一层 (从这个朋友家继续往下走)
                dfs(neighbor, path)
                
                # C. 撤销选择 (回溯)
                # 从朋友家退出来，准备去访问下一个朋友
                path.pop()

        # 3. 启动引擎
        # 从 0 开始走，当前的路径里只有 [0]
        dfs(0, [0])
        
        return results
```

#### 5. 进阶：图的致命陷阱 —— “环” (Cycle)

LeetCode 797 是一个比较“仁慈”的图，它保证了**没有环**（它是单向的，而且不会绕回来）。

但是，绝大多数现实中的图是有环的。
**场景：** A 认识 B，B 认识 A。
1.  你访问 A。
2.  A 说去找 B -> `dfs(B)`
3.  B 说去找 A -> `dfs(A)`
4.  A 说去找 B...
5.  **报错：RecursionError (死循环)**

**解决方案：Visited 数组 (记账本)**
就像我们在“岛屿问题”里把陆地改成水一样，在图里，我们需要随身带一个小本本 `visited`。
*   每访问一个人，就把名字记在本子上。
*   每次想找下一个人之前，先查查本子：“这人我找过没？”
*   找过就不去了。

**通用图 DFS 模板（应对有环的图）：**

```python
# 假设我们要遍历整个图，不走回头路
visited = set() # 这是一个集合，用来查重，速度很快

def dfs(node):
    # 1. 先查户口：如果来过了，直接停
    if node in visited:
        return

    # 2. 标记：把名字记下来
    visited.add(node)
    print(f"我访问了 {node}")

    # 3. 遍历邻居
    for neighbor in graph[node]:
        dfs(neighbor)
```
