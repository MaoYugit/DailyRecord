### 🟢 第一阶段：标准二分查找（寻找具体的一个数）

#### 1. 核心逻辑

在一个**有序**数组中，我们要找一个 `target`。
我们不从头挨个找，而是从**中间**劈一刀：
*   如果 `中间值 == target`：找到了！
*   如果 `中间值 < target`：说明目标在右半边，把左边界移到中间右边。
*   如果 `中间值 > target`：说明目标在左半边，把右边界移到中间左边。

#### 2. 万能闭区间模版（请死记硬背这一套）

网上有很多写法（左闭右开、左开右闭...），为了防止面试脑抽，建议**只记“左闭右闭”这一种**。

*   **区间**：`[left, right]`
*   **循环条件**：`left <= right` （因为 `left == right` 时，区间里还有一个元素，必须检查）
*   **转移**：`left = mid + 1`, `right = mid - 1`

#### 3. 题目：二分查找 (LeetCode 704)

**题目**：
给定一个 `n` 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target`  ，写一个函数搜索 `nums` 中的 `target`，如果目标值存在返回下标，否则返回 `-1`。

**Python 代码详解**：

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        # 1. 定义左右边界（闭区间）
        left = 0
        right = len(nums) - 1
        
        # 2. 循环条件：只要区间还有效（left <= right）
        while left <= right:
            # 3. 计算中间点
            # 为什么不用 (left + right) // 2？
            # 在 Python 里其实没所谓（会自动转大数），但在 C++/Java 里可能会溢出
            # 写成 left + (right - left) // 2 是最安全的装X写法
            mid = left + (right - left) // 2
            
            if nums[mid] == target:
                return mid # 找到了，直接返回
            elif nums[mid] < target:
                # 中间值比目标小，说明目标在右边
                # [mid+1, right]
                left = mid + 1
            else:
                # 中间值比目标大，说明目标在左边
                # [left, mid-1]
                right = mid - 1
                
        # 4. 循环结束都没找到
        return -1
```

#### 4. 题目：搜索插入位置 (LeetCode 35)

这题是 LC 704 的变种，也是面试常客。
**题目**：
给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

**分析**：
这题其实就是找：**第一个 >= target 的数的下标**。
如果循环结束还没找到，`left` 指针所在的位置就是目标应该插入的位置。

**Python 代码**：

```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        
        # 循环结束时，left 指向第一个 > right 的位置
        # 也就是 target 应该插入的位置
        return left
```

### 🟡 第二阶段：重复元素与 `bisect`

#### 1. `bisect` 模块详解

这是 Python 标准库，**不用安装，直接导入**。它专门用于维护有序列表。

*   **`bisect.bisect_left(nums, target)`**：
    *   查找 `target` 应插入的位置。
    *   如果 `nums` 里有重复的 `target`，它返回 **第一个** `target` 的下标（左边界）。
    *   **口诀：找 $\ge$ target 的第一个位置。**

*   **`bisect.bisect_right(nums, target)`**：
    *   查找 `target` 应插入的位置。
    *   如果 `nums` 里有重复的 `target`，它返回 **最后一个** `target` **之后** 的下标（右边界 + 1）。
    *   **口诀：找 $>$ target 的第一个位置。**

**图解对比**：
`nums = [1, 2, 2, 2, 3]`，`target = 2`
*   `bisect_left` 返回 `1` （指向第一个 2）。
*   `bisect_right` 返回 `4` （指向 3，即最后一个 2 的屁股后面）。

#### 2. 实战题目：在排序数组中查找元素的第一个和最后一个位置 (LeetCode 34)

**题目**：
给定 `nums = [5,7,7,8,8,10]`, `target = 8`。
要求返回开始位置和结束位置 `[3, 4]`。如果不存返回 `[-1, -1]`。

**解法 A：使用 `bisect` 神器（推荐机考用）**

```python
import bisect

class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        if not nums: return [-1, -1]
        
        # 1. 找左边界（第一个 >= target 的位置）
        left_idx = bisect.bisect_left(nums, target)
        
        # 检查 left_idx 是否越界，以及对应的值是不是真的 target
        if left_idx >= len(nums) or nums[left_idx] != target:
            return [-1, -1] # 没找到
            
        # 2. 找右边界（第一个 > target 的位置）
        # bisect_right 返回的是插入位置，是在最后一个 target 的后面
        # 所以真实的右边界下标是 bisect_right - 1
        right_idx = bisect.bisect_right(nums, target) - 1
        
        return [left_idx, right_idx]
```

**解法 B：手写二分（面试官不让用库时用）**

逻辑：当 `nums[mid] == target` 时，别停！
*   找左边界：记录一下位置，然后**往左收缩** `right = mid - 1`，试图找更左边的。
*   找右边界：记录一下位置，然后**往右收缩** `left = mid + 1`，试图找更右边的。

```python
class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        def findLeft(nums, target):
            left, right = 0, len(nums) - 1
            res = -1
            while left <= right:
                mid = left + (right - left) // 2
                if nums[mid] == target:
                    res = mid     # 记录一下
                    right = mid - 1 # 继续向左找
                elif nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
            return res

        def findRight(nums, target):
            left, right = 0, len(nums) - 1
            res = -1
            while left <= right:
                mid = left + (right - left) // 2
                if nums[mid] == target:
                    res = mid     # 记录一下
                    left = mid + 1  # 继续向右找
                elif nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
            return res
            
        return [findLeft(nums, target), findRight(nums, target)]
```

#### 3. 实战题目：搜索旋转排序数组 (LeetCode 33) - ⭐️ OD 高频难点

**题目**：
数组 `[0,1,2,4,5,6,7]` 在下标 3 处旋转变成 `[4,5,6,7,0,1,2]`。
请你在旋转后的数组中找 `target`。

**分析**：
这题不能直接用 `bisect`，因为数组不是整体有序的，而是**两段有序**。
这就需要我们在 `if` 判断里加逻辑。
核心思想：**将数组一分为二，其中一半一定是有序的！**

**Python 代码**：

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] == target:
                return mid
            
            # 关键判断：哪一部分是有序的？
            # 如果左边有序 (例如 [4,5,6,7, ...])
            if nums[0] <= nums[mid]:
                # 如果 target 在左边的有序范围内
                if nums[0] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            # 否则右边一定有序 (例如 [..., 0,1,2])
            else:
                # 如果 target 在右边的有序范围内
                if nums[mid] < target <= nums[len(nums)-1]:
                    left = mid + 1
                else:
                    right = mid - 1
                    
        return -1
```

### 🔴 第三阶段：二分答案（猜答案）

#### 1. 核心思维：逆向思维

通常题目问：“求结果 X”。
*   **普通思维**：根据条件一步步算 X。
*   **二分答案思维**：我先 **猜** 一个 X，然后验证这个 X 行不行？
    *   如果行，我试试能不能更小/更大？
    *   如果不行，我调整范围。

**什么时候用？**
当你看到题目里有：
*   “求最小的...最大值”
*   “求最大的...最小值”
*   “满足条件的最少时间/最小能力/最小容量”
*   答案具有 **单调性**（即：如果 X 行，那么比 X 大的肯定也都行）。

#### 2. 通用解题模版

这类题目的难点不在二分本身，而在于 **写一个 `check(mid)` 函数**。

```python
def binary_search_answer(nums, target):
    # 1. 确定答案可能的范围 [left, right]
    # 比如速度最小是 1，最大是 10^9
    left, right = min_possible, max_possible
    ans = -1
    
    while left <= right:
        mid = left + (right - left) // 2
        
        # 2. 核心：check 函数
        # 验证：如果答案是 mid，能满足条件吗？
        if check(mid):
            ans = mid      # 记录这个可行解
            right = mid - 1 # 试图找更小的（根据题目要求调整）
        else:
            left = mid + 1  # mid 不行，需要更大的
            
    return ans
```

#### 3. 题目：爱吃香蕉的珂珂 (LeetCode 875) - ⭐️ 教科书级入门

**题目**：
珂珂想吃掉 `piles` 堆香蕉，必须在 `h` 小时内吃完。
她每小时吃 `k` 根。如果一堆少于 `k`，她吃完这堆就休息（也就是一堆至少花 1 小时）。
**求最小的吃香蕉速度 `k`**。

**分析**：
1.  **确定范围**：
    *   速度最慢：1 根/小时。
    *   速度最快：最大的那一堆香蕉（一小时吃完最大的一堆，再快也没意义了）。
    *   范围：`[1, max(piles)]`。
2.  **单调性**：
    *   如果速度 `k` 能吃完，那 `k+1` 肯定更能吃完。
    *   我们要找 **能吃完的最小 k**。
3.  **Check 函数**：
    *   给定速度 `speed`，算算一共需要几小时？
    *   `hours = sum(math.ceil(pile / speed))`。
    *   如果 `hours <= h`，说明这个速度可行。

**Python 代码**：

```python
import math

class Solution:
    def minEatingSpeed(self, piles: List[int], h: int) -> int:
        # 1. 确定搜索范围
        left = 1
        right = max(piles)
        ans = right
        
        # 定义 check 函数：以 speed 的速度，h 小时内能吃完吗？
        def check(speed):
            hours = 0
            for p in piles:
                # 向上取整：比如 pile=7, speed=3 -> 需要 3 小时
                # 写法技巧：(p + speed - 1) // speed 等价于 ceil(p/speed)
                hours += (p + speed - 1) // speed
            return hours <= h

        # 2. 二分查找
        while left <= right:
            mid = left + (right - left) // 2
            
            if check(mid):
                # 如果 mid 速度能吃完，我们试试能不能再慢点（贪心）
                ans = mid
                right = mid - 1
            else:
                # 这里的速度太慢了，超时了，必须快点
                left = mid + 1
                
        return ans
```

#### 4. 题目：分割数组的最大值 (LeetCode 410) - ⭐️ 华为 OD 超高频

**题目**：
给定一个数组 `nums`，把它切成 `k` 个连续子数组。
要求：这 `k` 个子数组中，**和最大** 的那个子数组，它的和要 **尽可能小**。

**翻译一下**：
假设我在分配工作给 `k` 个人，不能打乱顺序。我们要让工作最重的那个人，工作量尽可能少。

**分析**：
1.  **确定范围（答案是子数组的和）**：
    *   最小值：`max(nums)` （因为一个子数组至少包含一个元素，那最大的那个元素单独成组，和就是它自己。如果比它还小，这个元素就没地放了）。
    *   最大值：`sum(nums)` （k=1，一个人干所有活）。
    *   范围：`[max(nums), sum(nums)]`。
2.  **Check 函数**：
    *   **给定一个上限 `limit`**（假设任何子数组的和都不能超过 `limit`）。
    *   **问**：在这个限制下，我最少需要分成几组？
    *   **贪心策略**：我就往死里塞，直到塞不下（超过 limit）了，就新开一组。
    *   如果最终分出的组数 `cnt <= k`，说明这个 limit 是可行的（甚至太宽松了）。

**Python 代码**：

```python
class Solution:
    def splitArray(self, nums: List[int], k: int) -> int:
        left = max(nums)
        right = sum(nums)
        ans = right
        
        # check: 当子数组最大和限制为 limit 时，能不能分成 <= k 组？
        def check(limit):
            count = 1 # 当前组数
            current_sum = 0
            
            for num in nums:
                # 贪心：如果加上这个数没超标，就加进去
                if current_sum + num <= limit:
                    current_sum += num
                else:
                    # 超标了，这个数必须放到下一组去
                    count += 1
                    current_sum = num
            
            # 如果需要的组数 <= k，说明 limit 够大，是可行的
            return count <= k
            
        while left <= right:
            mid = left + (right - left) // 2
            if check(mid):
                ans = mid
                right = mid - 1 # 试图让最大和更小一点
            else:
                left = mid + 1 # limit 太小了，塞不下，调大点
                
        return ans
```
