### 1. 栈 (Stack)：后进先出 (LIFO)

**生活例子：薯片桶 (或洗碗堆的一叠盘子)**
*   你往桶里放薯片，最后放进去的那一片，肯定在最上面。
*   你想吃薯片，必须先拿掉最上面那片（即最后放进去的那片）。
*   **口诀：** “后来居上”。专业术语叫 **LIFO (Last In, First Out)**。

#### Python 实现：
在 Python 里，直接用最普通的 **列表 (List)** 就能完美实现栈。
*   **放薯片 (入栈)：** `stack.append(x)`
*   **拿薯片 (出栈)：** `stack.pop()`
*   **看一眼最上面的薯片 (查看栈顶)：** `stack[-1]`

```python
stack = []
stack.append("底层薯片")
stack.append("中间薯片")
stack.append("顶层薯片")

print(stack.pop())  # 输出: "顶层薯片" (最后进的，最先出)
```

### 2. 队列 (Queue)：先进先出 (FIFO)

**生活例子：排队买奶茶**
*   谁先排队，谁就先拿到奶茶走人。
*   新来的人只能排在队伍的最后面。
*   **口诀：** “先来后到”。专业术语叫 **FIFO (First In, First Out)**。

#### Python 实现：
**注意：** 虽然列表 `list` 也能实现队列（用 `list.pop(0)`），但效率很低（因为后面所有人都要往前挪一位）。
在 Python 里，我们永远用 **`collections.deque`** (双端队列) 来当队列用。

*   **排队 (入队)：** `queue.append(x)`
*   **领奶茶走人 (出队)：** `queue.popleft()` (注意是 pop**left**)
*   **看一眼排在第一位的人：** `queue[0]`

```python
from collections import deque

queue = deque([])
queue.append("张三")
queue.append("李四")
queue.append("王五")

print(queue.popleft())  # 输出: "张三" (先来的，先走)
```

### 3. 栈与队列的“变身” (重点考点)

在华为 OD 或 LeetCode 中，纯粹考入队出队的题很少，它们通常以这两种进阶形式出现：

#### A. 单调栈 (Monotonic Stack) —— 华为 OD 常客
*   **核心：** 栈里的元素是严格递增或递减的。
*   **用途：** 找“下一个更大/更小”的数。
*   **例子：** “找后面哪天的气温比今天高”。

#### B. 优先队列 (Priority Queue / Heap)
*   **核心：** 不是按时间排队，而是按“优先级”排队。比如 VIP 客户可以插队先办业务。
*   **Python 实现：** `heapq` 模块。

### 给“理解力较差”同学的避坑总结：

*   **什么时候用栈？**
    当题目有 **“匹配”、“抵消”、“回溯”、“撤销 (Undo)”** 或者 **“寻找附近更大的数”** 这种含义时，先想栈。
*   **什么时候用队列？**
    当题目有 **“排队”、“层级遍历”、“按顺序处理”** 或者 **“寻找最短路径 (BFS)”** 这种含义时，先想队列。

**特别提醒：**
在 Python 中写代码，看到“队列”字样，一定要在开头写：
`from collections import deque`
然后用 `append()` 和 `popleft()`。千万别在 `list` 上用 `pop(0)`，否则面试官会觉得你基础不扎实！
