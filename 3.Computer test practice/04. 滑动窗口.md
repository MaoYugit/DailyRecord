**滑动窗口（Sliding Window）** 其实是**双指针**的一种特例。相比于回溯和 DFS 的“暴力穷举”，滑动窗口通常用于解决**数组或字符串**中的**子数组/子串**问题，它的核心优势是将嵌套循环的 $O(N^2)$ 复杂度降低到 $O(N)$。

# 第一讲：滑动窗口的核心与“不定长”模板

## 1. 什么是滑动窗口？

想象你在看一个长长的胶卷，手里拿了一个框（窗口）。
*   **左边界（Left）**：窗口的屁股。
*   **右边界（Right）**：窗口的头。
*   **窗口**：`[Left, Right]` 中间的内容。

**核心动作只有两个：**
1.  **进（Expand）：** `right` 主动向右走，把新元素加进来。
2.  **出（Shrink）：** 当窗口内的条件**不满足**（或者满足了特定条件）时，`left` 被动向右走，把旧元素扔出去。

这就像一只毛毛虫，先伸头（Right++），吃饱了或者太长了，再缩尾巴（Left++）。

## 3. 实战教学

我们通过两道最经典的题目，分别演示**求最小**和**求最大**的逻辑。

### 案例 A：求最小长度 (LeetCode 209. 长度最小的子数组)
**题目：** 给定一个数组 `nums` 和一个目标值 `target`，找出和 `>= target` 的**最小**连续子数组长度。

**思路：**
1.  `right` 拼命吃（累加 sum），直到 `sum >= target`。
2.  一旦满足，说明窗口可能太大了，`left` 开始吐（减去 nums[left]），看能不能在保持 `>= target` 的前提下让窗口变小。
3.  记录最小长度。

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        n = len(nums)
        left = 0
        current_sum = 0
        min_len = float('inf') # 初始化为无穷大
        
        # 1. 右指针滑动
        for right in range(n): # 使用 for 循环也是一样的，对应模板的 while right < n
            # 【入窗】
            current_sum += nums[right]
            
            # 2. 满足条件了（sum >= target），尝试收缩窗口找更小的
            while current_sum >= target:
                # 【更新结果】当前窗口满足条件，记下长度
                current_len = right - left + 1
                min_len = min(min_len, current_len)
                
                # 【出窗】
                current_sum -= nums[left]
                left += 1
                
        return 0 if min_len == float('inf') else min_len
```

### 案例 B：求最大长度 (LeetCode 3. 无重复字符的最长子串)
**题目：** 给定一个字符串，找出不含有重复字符的**最长**子串。

**思路：**
1.  `right` 进窗。
2.  如果发现 `right` 指向的字符已经在窗口里了（重复了！），窗口就不合法了。
3.  `left` 必须一直吐，直到把重复的那个字符吐出去为止。
4.  在每次窗口合法的时候，更新最大长度。

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        n = len(s)
        left = 0
        window = set() # 用集合记录窗口里有哪些字符
        max_len = 0
        
        for right in range(n):
            char = s[right]
            
            # 【收缩条件】：如果新来的字符已经在窗口里了，必须缩到没有它为止
            while char in window:
                # 【出窗】
                window.remove(s[left])
                left += 1
            
            # 【入窗】(现在窗口干净了，可以加进去了)
            window.add(char)
            
            # 【更新结果】(求最大通常在收缩之后)
            max_len = max(max_len, right - left + 1)
            
        return max_len
```

## 4. 第一阶段总结与练习

### 核心区别点：
1.  **求最小 (Min)**：往往在 `while` **循环内部**更新结果。（因为满足条件时，我们要看能不能更小）。
2.  **求最大 (Max)**：往往在 `while` **循环外部**更新结果。（因为经过 `while` 清理后，窗口才是合法的，此时可以计算最大值）。
