### 🟢 第一阶段：固定窗口 (Fixed Window)

#### 1. 核心概念

**什么是固定窗口？**
假设窗口大小为 `k`，窗口在数组上从左向右滑动。

*   每次滑动，右边进来一个新元素（入队）。
*   左边出去一个旧元素（出队）。
*   **关键点**：窗口长度永远固定为 `k`。

**为什么要用它？**
如果你每次都重新计算窗口里的和（或者其他属性），时间复杂度是 $O(N \cdot k)$。
如果不重新计算，而是利用**上一步的结果**进行增量更新，时间复杂度就是 $O(N)$。

#### 2. 核心逻辑图解

假设数组 `nums = [1, 2, 3, 4, 5]`，窗口大小 `k = 3`。

1.  **初始状态** (前3个)：`[1, 2, 3]` -> Sum = 6
2.  **向右移动一格**：
    *   **进来** (Right)：`4`
    *   **出去** (Left)：`1`
    *   **新 Sum** = 旧 Sum + 4 - 1 = 9
    *   窗口变为 `[2, 3, 4]`

你看，我们不需要重新算 `2+3+4`，只需要做简单的加减法。

---

#### 3. Python 通用模板 (背诵版)

对于固定窗口，我推荐**“先初始化，后滑动”**的写法，这样不容易写错边界。

```python
def fixed_sliding_window(nums, k):
    # 1. 统计第一个窗口（前 k 个元素）的状态
    # 比如求和：
    current_sum = sum(nums[:k])
    max_sum = current_sum
    
    # 2. 开始滑动
    # 从第 k 个元素开始，一直到数组末尾
    # i 代表当前窗口最右侧的元素下标
    for i in range(k, len(nums)):
        # 核心逻辑：进一个，出一个
        # nums[i] 是刚进来的
        # nums[i-k] 是刚出去的
        current_sum += nums[i] - nums[i-k]
        
        # 更新答案
        max_sum = max(max_sum, current_sum)
        
    return max_sum
```

##### 题目 1：LeetCode 643. 子数组最大平均数 I (简单)

> 给定一个整数数组 `nums` 和一个整数 `k`，请找出平均数最大的长度为 `k` 的连续子数组，并返回这个最大平均数。

**思路**：
平均数最大 = 和最大（因为分母 `k` 是常数）。我们只需要求出**长度为 k 的子数组的最大和**，最后除以 `k` 即可。

**代码实现**：

```python
class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        # 1. 初始化第一个窗口的和
        # 注意：不要在循环里用 sum()，否则会超时
        curr_sum = sum(nums[:k])
        max_sum = curr_sum
        
        # 2. 从下标 k 开始滑动
        for i in range(k, len(nums)):
            # 进一个 nums[i]，出一个 nums[i-k]
            curr_sum += nums[i] - nums[i-k]
            
            # 更新最大值
            if curr_sum > max_sum:
                max_sum = curr_sum
                
        # 3. 返回平均数
        return max_sum / k
```

##### 题目 2：LeetCode 1456. 定长子串中元音的最大数目 (中等)

> 给你字符串 `s` 和整数 `k` 。请返回字符串 `s` 中长度为 `k` 的单个子字符串中可能包含的最大元音字母数。
> 元音字母为 'a', 'e', 'i', 'o', 'u'。

**思路**：
这次维护的不是“数字和”，而是“元音的个数”。
*   进来的字符是元音 -> 计数 +1
*   出去的字符是元音 -> 计数 -1

**代码技巧**：
使用 `set` 来判断是否为元音，速度最快。

**代码实现**：

```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set("aeiou") # 使用集合查找更快
        
        # 1. 初始化第一个窗口
        curr_count = 0
        for i in range(k):
            if s[i] in vowels:
                curr_count += 1
        
        max_count = curr_count
        
        # 2. 开始滑动
        for i in range(k, len(s)):
            # 处理进来的字符 (右边)
            if s[i] in vowels:
                curr_count += 1
            
            # 处理出去的字符 (左边，下标是 i-k)
            if s[i-k] in vowels:
                curr_count -= 1
                
            # 更新最大值
            # 这一步可以优化：如果已经达到 k 了，直接返回 k (因为不可能更大了)
            max_count = max(max_count, curr_count)
            if max_count == k:
                return k
                
        return max_count
```

#### 5. ⚠️ 机试常见坑点 (必看)

1.  **超时陷阱**：千万不要在 `for` 循环里写 `sum(nums[i-k:i])`。切片求和的复杂度是 $O(k)$，配合外层循环就变成了 $O(N \cdot k)$。必须使用增量更新（加一个减一个）。
2.  **下标越界**：注意循环是从 `range(k, len(nums))` 开始。
    *   `i` 是当前窗口的**右**边界。
    *   `i-k` 是上一个窗口的**左**边界（即被移除的那个元素）。

### 🟠 第二阶段：可变窗口求最大/最长 (Variable Window - Max)

#### 1. 核心概念

**与固定窗口的区别：**
*   **固定窗口**：窗口大小 `k` 是已知的，我们找窗口内的最大值/最大和。
*   **可变窗口**：窗口大小**未知**，我们需要找到**满足特定条件**的**最长**窗口。

**形象比喻 —— “贪吃蛇”：**
1.  **进食 (Expand)**：右指针 `right` 拼命往右吃（扩大窗口），直到吃到不该吃的东西（条件不满足了）。
2.  **呕吐 (Shrink)**：左指针 `left` 只能被迫往右移（缩小窗口），把刚才吃坏肚子的东西吐出来，直到身体恢复正常（条件再次满足）。
3.  **记录**：在每次“身体正常”的时候，记录一下当前的长度。

#### 2. 万能模板 (背诵版)

这是滑动窗口最通用的骨架，请务必刻在脑子里：

```python
def variable_sliding_window(nums):
    left = 0
    ans = 0  # 记录最大长度
    
    # current_state: 用来记录窗口内数据的变量
    # 比如：当前的和、当前的字符计数、当前0的个数等
    current_state = 0 

    # right 主动向右移动
    for right in range(len(nums)):
        # 1. 【进】元素进入窗口，更新状态
        x = nums[right]
        # current_state += x (伪代码)
        
        # 2. 【出】如果不满足条件，左指针收缩 (while 循环)
        while 窗口状态不满足条件:
            # remove_element = nums[left]
            # current_state -= remove_element (伪代码)
            left += 1
        
        # 3. 【算】现在窗口是合法的，更新最大长度
        # 窗口长度 = right - left + 1
        ans = max(ans, right - left + 1)
        
    return ans
```

**口诀**：**右边猛进，不爽左移，也就是合法时，更新答案。**

##### 题目 1：LeetCode 3. 无重复字符的最长子串 (中等 - 必考题)

> 给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

**分析**：
*   **条件**：窗口内不能有重复字符。
*   **状态维护**：用一个集合 `window_set` 记录窗口里的字符。
*   **滑动逻辑**：
    *   右边进来一个字符 `c`。
    *   如果 `c` 已经在 `window_set` 里了（出问题了！），左指针 `left` 就要一直往右移，一边移一边从集合里删元素，**直到**把那个重复的字符删掉为止。
    *   更新最大长度。

**代码实现**：

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        left = 0
        ans = 0
        window_set = set()
        
        for right in range(len(s)):
            # 1. 【进】尝试把 s[right] 加入窗口
            # 如果 s[right] 已经在窗口里，说明重复了，需要收缩
            while s[right] in window_set:
                # 2. 【出】移除左边的元素，直到不再重复
                window_set.remove(s[left])
                left += 1
            
            # 现在窗口干净了，加入新元素
            window_set.add(s[right])
            
            # 3. 【算】更新最大长度
            ans = max(ans, right - left + 1)
            
        return ans
```

##### 题目 2：LeetCode 1004. 最大连续1的个数 III (中等)

> 给定一个二进制数组 `nums` 和一个整数 `k`，如果可以翻转最多 `k` 个 `0` 变成 `1`，求数组中连续 `1` 的最大个数。

**分析**：
这题属于“脑筋急转弯”。

*   **翻译题意**：我们要找一个最长的子数组，这个子数组里 **`0` 的个数不超过 `k`**。
*   **状态维护**：维护窗口内 `0` 的数量 `zeros`。
*   **滑动逻辑**：
    *   右边进来如果是 `0`，`zeros += 1`。
    *   如果 `zeros > k`（爆了），左指针 `left` 右移。如果左边移出去的是 `0`，那么 `zeros -= 1`。
    *   更新答案。

**代码实现**：

```python
class Solution:
    def longestOnes(self, nums: List[int], k: int) -> int:
        left = 0
        ans = 0
        zeros_count = 0 # 记录当前窗口内 0 的个数
        
        for right in range(len(nums)):
            # 1. 【进】
            if nums[right] == 0:
                zeros_count += 1
            
            # 2. 【出】当 0 的个数超过 k，窗口不合法，左边收缩
            while zeros_count > k:
                if nums[left] == 0:
                    zeros_count -= 1
                left += 1
            
            # 3. 【算】窗口现在合法 (0的个数 <= k)，更新长度
            ans = max(ans, right - left + 1)
            
        return ans
```

#### 4. 核心细节总结

1.  **While 循环**：这是可变窗口的标志。固定窗口用 `if`，可变窗口用 `while`，因为左指针可能需要连续移动好几步才能让窗口重新合法。
2.  **更新答案的位置**：在 `while` 循环结束后。因为跳出 `while` 循环意味着窗口**恢复了合法状态**，这时候算的长度才是有效的。
3.  **计算长度**：永远是 `right - left + 1`。

### 🟡 第三阶段：可变窗口求最小/最短 (Variable Window - Min)

#### 1. 核心思维：逆向操作

**对比一下：**
*   **求最长（第二阶段）**：窗口**合法**时，右指针猛进（Expand），尝试让窗口变大。只有**不合法**时，左指针才收缩。
*   **求最短（第三阶段）**：窗口**不合法**（还没满足条件）时，右指针猛进。一旦**合法**了（满足条件了），我们就要尝试**收缩左指针**，看看能不能在保持合法的前提下，把窗口变小（Optimize）。

**口诀**：**“缺了就补（右移），够了就缩（左移）”。**

#### 2. 通用模板 (背诵版)

注意看 `while` 的条件，跟第二阶段完全相反！

```python
def min_sliding_window(nums, target):
    left = 0
    min_len = float('inf') # 初始化为无穷大
    current_state = 0
    
    for right in range(len(nums)):
        # 1. 【进】不断加入元素，直到满足条件
        current_state += nums[right]
        
        # 2. 【缩】只要条件满足，就尝试收缩左边，寻找更短的解
        while 窗口满足条件(current_state >= target):
            # 记录当前的可行解（因为现在是合法的）
            min_len = min(min_len, right - left + 1)
            
            # 【出】移除左边元素，尝试更小的窗口
            current_state -= nums[left]
            left += 1
            
    return 0 if min_len == float('inf') else min_len
```

##### 题目 1：LeetCode 209. 长度最小的子数组 (中等 - 基础必会)

> 给定一个含有 `n` 个正整数的数组和一个正整数 `target` 。
> 找出该数组中满足其和 `≥ target` 的长度最小的 连续子数组。

**思路**：
1.  右指针向右走，累加数值。
2.  一旦 `sum >= target`，说明当前窗口合法了。
3.  **开始循环收缩**：
    *   更新最小长度 `min_len`。
    *   减去左边的值，左指针右移。
    *   检查：减去后还 `≥ target` 吗？如果是，继续缩！如果不是，跳出循环，继续让右指针去加新数字。

**代码实现**：

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        left = 0
        total = 0
        ans = float('inf') # 使用无穷大初始化
        
        for right in range(len(nums)):
            # 1. 【进】
            total += nums[right]
            
            # 2. 【缩】只要和足够大，就尝试缩小窗口
            while total >= target:
                # 记录当前的长度
                ans = min(ans, right - left + 1)
                
                # 移除左边，尝试更小
                total -= nums[left]
                left += 1
                
        # 如果 ans 没变过，说明整个数组加起来都不够 target
        return 0 if ans == float('inf') else ans
```

##### 题目 2：LeetCode 76. 最小覆盖子串 (困难 - 滑动窗口的大 Boss)

> 给你一个字符串 `s` 、一个字符串 `t` 。返回 `s` 中涵盖 `t` 所有字符的最小子串。
> 如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""` 。
> *注意：t 中可能有重复字符，比如 t = "AA"*

**这是机试中的高频难题，请仔细看。**

**难点**：如何快速判断窗口是否“涵盖”了 `t`？
**技巧**：

1.  用一个哈希表 (或 `Counter`) 记录 `t` 需要的字符和数量，记为 `need`。
2.  用一个变量 `need_cnt` 记录**还需要凑够多少个字符**。
    *   比如 `t = "ABC"`, `need_cnt = 3`。
    *   窗口里进了一个 'A'，`need['A']` 减 1，`need_cnt` 减 1。
    *   当 `need_cnt == 0` 时，说明窗口合法（全覆盖了）。

**代码逻辑**：
1.  右指针移动，如果遇到的字符是 `t` 需要的，`need_cnt` 减少。
2.  当 `need_cnt == 0`（都凑齐了）：
    *   记录当前子串。
    *   左指针尝试收缩：
        *   如果移出去的字符是 `t` 需要的（且窗口里这个字符刚好够用，不多余），那么 `need_cnt` 必须增加（因为不够了）。
        *   继续右移寻找。

**代码实现 (教科书级写法)**：

```python
import collections

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        # 统计 t 中每个字符需要的数量
        need = collections.Counter(t)
        need_cnt = len(t) # 还需要凑够的总字符数
        
        left = 0
        min_len = float('inf')
        start_index = 0 # 记录最短子串的起始位置
        
        for right, char in enumerate(s):
            # 1. 【进】
            if need[char] > 0:
                # 如果这个字符是我们需要凑的，need_cnt 减 1
                need_cnt -= 1
            
            # 无论是不是需要的，都要在 need 字典里减 1
            # 这一步很巧妙：
            # 如果 char 在 t 里，need[char] 从正数变 0 或负数
            # 如果 char 不在 t 里，need[char] 从 0 变负数 (表示多余的)
            need[char] -= 1
            
            # 2. 【缩】当所有字符都凑齐了 (need_cnt == 0)
            if need_cnt == 0:
                # 尝试收缩左边界
                # 只要左边的字符是“多余的” (need[s[left]] < 0)，就可以扔掉
                while True:
                    c = s[left]
                    if need[c] == 0:
                        # 这是一个关键字符，刚好够用，不能扔！
                        # 扔了就不满足条件了，停止收缩
                        break
                    
                    # 这是一个多余字符 (need[c] < 0)，扔掉！
                    need[c] += 1
                    left += 1
                
                # 3. 【算】此时是一个合法的最小窗口（对于当前的 right 来说）
                curr_len = right - left + 1
                if curr_len < min_len:
                    min_len = curr_len
                    start_index = left
                
                # 4. 【破坏】为了让窗口继续向右滑动寻找新解，
                # 我们不得不忍痛移除最左边的那个关键字符
                need[s[left]] += 1
                need_cnt += 1 # 因为移除关键字符，所以还需要凑 1 个
                left += 1
                
        return "" if min_len == float('inf') else s[start_index : start_index + min_len]
```

*(注：LeetCode 76 有多种写法，上面这种“先缩多余字符，再破坏平衡”的逻辑在机试中最容易写对。)*

### 🔵 第四阶段：哈希表与计数 —— 异位词与排列

#### 1. 核心概念：什么是“异位词” (Anagram)？

*   **定义**：两个字符串，如果它们包含的**字符种类**和**每种字符的数量**完全相同，只是顺序不同，就互为“异位词”。
    *   例如：`"abc"` 和 `"cba"` 是异位词；`"aab"` 和 `"baa"` 是异位词。
*   **数学本质**：它们的**字符计数（Counter）**完全一致。
    *   `Counter("aab")` -> `{'a': 2, 'b': 1}`
    *   `Counter("baa")` -> `{'a': 2, 'b': 1}`

#### 2. 解题核心：固定窗口 + 计数数组

这类题目通常会给你一个长字符串 `s` 和一个目标字符串 `p`，让你在 `s` 里找 `p` 的异位词。

**技巧点**：
1.  **窗口大小固定**：因为异位词长度肯定和原词一样长，所以窗口大小 `k = len(p)`。
2.  **优化比较**：
    *   暴力法：每次切片 `s[i:i+k]` 然后 `Counter()` 比较，复杂度 $O(N \cdot K)$，太慢。
    *   **进阶法**：用两个长度为 26 的数组（因为只有小写字母）分别记录 `p` 和 `当前窗口` 的字符频次。每次滑动时，只更新进出两个字符的计数，然后比较两个数组是否相同。比较长度为 26 的数组是 $O(1)$ 的常数操作！

#### 3. 实战演练

##### 题目 1：LeetCode 438. 找到字符串中所有字母异位词 (中等 - 高频)

> 给定两个字符串 `s` 和 `p`，找到 `s` 中所有是 `p` 的异位词的子串，返回这些子串的起始索引。

**思路**：
1.  维护一个大小为 `len(p)` 的窗口。
2.  统计 `p` 的字符计数（目标）。
3.  统计窗口内的字符计数。
4.  滑动：
    *   **进**：右边字符计数 +1。
    *   **出**：左边字符计数 -1。
    *   **查**：如果两个计数数组一样，说明找到了。

**代码实现 (标准数组法)**：
这种写法比 `collections.Counter` 更快，是 C++/Java 转 Python 选手的最爱，也是面试官觉得“你懂底层”的写法。

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        n, k = len(s), len(p)
        if n < k: return []
        
        # 用数组代替哈希表（因为只有26个字母）
        # p_count: 目标计数, window_count: 当前窗口计数
        p_count = [0] * 26
        window_count = [0] * 26
        
        # 1. 预处理：统计 p 和 s 中第一个窗口的数据
        for i in range(k):
            p_count[ord(p[i]) - ord('a')] += 1
            window_count[ord(s[i]) - ord('a')] += 1
            
        ans = []
        
        # 检查第一个窗口 (下标 0)
        if p_count == window_count:
            ans.append(0)
            
        # 2. 开始滑动
        # i 是当前窗口即将移出去的那个左边界的下标
        # j 是即将进来的右边界的下标 (j = i + k)
        for i in range(n - k):
            left_char_idx = ord(s[i]) - ord('a')
            right_char_idx = ord(s[i + k]) - ord('a')
            
            # 【出】左边出
            window_count[left_char_idx] -= 1
            # 【进】右边进
            window_count[right_char_idx] += 1
            
            # 【查】数组比较是 O(1) 的 (因为长度固定26)
            if window_count == p_count:
                ans.append(i + 1)
                
        return ans
```

##### 题目 2：LeetCode 567. 字符串的排列 (中等)

> 给你两个字符串 `s1` 和 `s2` ，写一个函数来判断 `s2` 是否包含 `s1` 的排列。

**分析**：
这题跟上面那题**一模一样**！
*   `s1` 就是上面的 `p` (目标)。
*   `s2` 就是上面的 `s` (大字符串)。
*   只要找到**一个**匹配的，立马返回 `True`。

**偷懒写法 (使用 Counter)**：
既然已经学会了数组法，这里展示一个利用 Python `Counter` 的写法，虽然稍微慢一点点，但代码极短，适合机试抢时间。

```python
from collections import Counter

class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        k = len(s1)
        target = Counter(s1)
        window = Counter(s2[:k]) # 初始化第一个窗口
        
        if window == target:
            return True
            
        for i in range(k, len(s2)):
            # 进一个
            window[s2[i]] += 1
            # 出一个
            window[s2[i-k]] -= 1
            
            # 这一步很重要：Counter 不会自动删除计数为 0 的键
            # 如果不删，比较时 {'a':1, 'b':0} != {'a':1}
            if window[s2[i-k]] == 0:
                del window[s2[i-k]]
            
            if window == target:
                return True
                
        return False
```

#### 4. 阶段总结

处理异位词/排列问题的**万能公式**：
1.  **Target**：先统计目标字符串的字符数。
2.  **Window**：用一个固定大小的窗口在长字符串上滑。
3.  **Check**：比较两个统计结果是否相等。
4.  **注意**：用数组 `[0]*26` 效率最高；用 `Counter` 写起来最快但要注意 `del` 掉 0 值。

### ⚫ 第五阶段：高阶技巧 —— “恰好 K 个” 与 单调队列

#### 1. 必杀技：“恰好 K 个” = “最多 K 个” - “最多 K-1 个”

**难点在哪？**
直接求“恰好 K 个”很难，因为滑动窗口通常具有单调性（越宽包含的越多），但“恰好”不具备单调性。

**数学转化：**
如果我们能写出一个函数 `atMost(k)`，用来计算“**最多**包含 k 个不同整数的子数组数量”，那么：
> **恰好 K 个的数量 = `atMost(k)` - `atMost(k-1)`**

**为什么 `atMost` 好算？**
因为“最多 K 个”是一个标准的**Phase 2（可变窗口求最长）**问题！

##### 实战：LeetCode 992. K 个不同整数的子数组 (困难)

> 给定一个正整数数组 `nums` 和一个整数 `k`，返回 `nums` 中 **恰好** 具有 `k` 个不同整数的子数组的数目。

**代码模板 (背诵这个转换逻辑)**：

```python
import collections

class Solution:
    def subarraysWithKDistinct(self, nums: List[int], k: int) -> int:
        # 核心转换公式
        return self.atMost(nums, k) - self.atMost(nums, k - 1)
    
    # 这是一个标准的“最多包含 k 个”的滑动窗口
    def atMost(self, nums, k):
        counter = collections.defaultdict(int)
        left = 0
        ans = 0
        distinct_count = 0 # 记录当前有多少个不同的数
        
        for right, x in enumerate(nums):
            # 1. 【进】
            if counter[x] == 0:
                distinct_count += 1
            counter[x] += 1
            
            # 2. 【出】如果不满足条件 (不同整数 > k)，左收缩
            while distinct_count > k:
                counter[nums[left]] -= 1
                if counter[nums[left]] == 0:
                    distinct_count -= 1
                left += 1
            
            # 3. 【算】关键点！
            # 对于以 right 结尾的子数组，满足条件的个数是 right - left + 1
            # 比如 [1, 2, 1]，k=2
            # 窗口 [1, 2, 1] 合法，那么 [1, 2, 1], [2, 1], [1] 都合法（但题目只看种类数）
            # 这里累加的是数量
            ans += right - left + 1
            
        return ans
```

#### 2. 必杀技：单调队列 (Monotonic Queue)

这是解决 **LeetCode 239** 的专用武器。

**场景**：
我们需要一个滑动窗口，每次移动都要知道窗口里的**最大值**。
*   如果用 `max(window)`，复杂度是 $O(k)$，总复杂度 $O(N \cdot k)$ -> **超时**。
*   我们需要一个 $O(1)$ 获取最大值的方法。

**核心逻辑 —— “职场残酷法则”**：
维护一个双端队列 `deque`，里面存元素的**下标**。
规则：
1.  **优胜劣汰**：如果新来的员工（当前元素）比老员工（队列尾部的元素）能力强（数值大），老员工就没用了，直接被踢走（`pop`）。因为新员工不仅数值大，而且存活时间更长。
2.  **退休机制**：如果老员工（队列头部元素）的工号（下标）已经滑出了窗口范围，他必须退休（`popleft`）。
3.  **结果**：队列的**头部**永远是当前窗口的老大（最大值）。

##### 实战：LeetCode 239. 滑动窗口最大值 (困难 - 必考)

> 给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。
> 返回滑动窗口中的最大值。

**代码实现 (标准单调队列)**：

```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        q = deque() # 存下标
        ans = []
        
        for i, x in enumerate(nums):
            # 1. 【进】入队前的清理（保持单调递减）
            # 如果新来的 x 比队尾的大，队尾的就永远不可能是最大值了，删掉
            while q and nums[q[-1]] <= x:
                q.pop()
            
            # 入队当前元素的下标
            q.append(i)
            
            # 2. 【出】检查队头是否过期
            # 队头下标是 q[0]，当前下标是 i
            # 窗口大小是 k，如果 q[0] <= i - k，说明已经滑出去了
            if q[0] <= i - k:
                q.popleft()
            
            # 3. 【算】记录答案
            # 只有当窗口形成后 (i >= k - 1) 才开始记录
            if i >= k - 1:
                ans.append(nums[q[0]])
                
        return ans
```

恭喜你！你已经掌握了滑动窗口的完整知识体系。我们在机试中遇到题目，只需要按以下流程思考：

1.  **判断题型**：是子数组/子串问题吗？是连续的吗？-> **滑动窗口**。
2.  **选择模板**：

        *   否 -> **继续判断**。
    *   **求最长/最大？**
        *   -> **Phase 2** (不合法才缩左边，`while` 不满足条件)。
    *   **求最短/最小？**
        *   -> **Phase 3** (合法就缩左边，`while` 满足条件)。
    *   **涉及异位词/排列？**
        *   -> **Phase 4** (固定窗口 + 数组/哈希表计数)。
    *   **求“恰好 K 个”？**
        *   -> **Phase 5** (转化法：最多 K - 最多 K-1)。
    *   **滑动中求 Max 值？**
        *   -> **Phase 5** (单调队列 `deque`)。
