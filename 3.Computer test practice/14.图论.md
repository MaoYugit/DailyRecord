## 第一章 **图的基石**

在深入学习 DFS 或 BFS 之前，你必须先学会如何**在代码中描述一个图**。

在 LeetCode 的题目中，图通常不会直接以对象的形式给你，而是给你一个数组，例如 `edges = [[0,1], [1,2], [2,0]]`。你需要先把它转化成你的程序能高效读取的结构。

---

### 1.1 图的两种基本表示法

图由 **节点 (Vertex/Node)** 和 **边 (Edge)** 组成。

#### 1. 邻接矩阵 (Adjacency Matrix)
使用一个二维数组 `matrix[i][j]` 表示从节点 `i` 到节点 `j` 是否有边。
*   **优点**：查询 `i` 和 `j` 是否连通只需 $O(1)$ 时间。
*   **缺点**：浪费空间。如果节点有 10,000 个，矩阵就有 1 亿个元素，即使只有几条边。
*   **适用**：稠密图（边非常多）或节点数很少的情况。

#### 2. 邻接表 (Adjacency List) —— **面试最常用！**
为每个节点保存一个列表，记录它指向的所有邻居。
*   **优点**：节省空间，遍历一个节点的邻居非常快。
*   **适用**：稀疏图（面试中 90% 的情况）。

---

### 1.2 Python 中的邻接表实现

在 Python 中，实现邻接表最优雅、最实用的方式是使用 `collections.defaultdict`。

#### 核心代码模板：
假设题目给出的输入是：`n = 3` (3个节点), `edges = [[0, 1], [1, 2], [0, 2]]`

```python
from collections import defaultdict

# 1. 初始化邻接表
# 使用 list 作为默认值，如果访问不存在的键，会自动创建一个空列表 []
graph = defaultdict(list)

# 2. 构建图 (以无向图为例)
edges = [[0, 1], [1, 2], [0, 2]]
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)  # 如果是有向图，删掉这一行

# 3. 打印查看
# graph 会看起来像: {0: [1, 2], 1: [0, 2], 2: [1, 0]}
print(dict(graph))
```

---

### 1.3 核心对比：什么时候用哪种？

| 特性                    | 邻接矩阵                             | 邻接表 (推荐)       |
| :---------------------- | :----------------------------------- | :------------------ |
| **存储空间**            | $O(V^2)$                             | $O(V + E)$          |
| **判断 i, j 是否相连**  | $O(1)$                               | $O(degree(i))$      |
| **找节点 i 的所有邻居** | $O(V)$                               | $O(degree(i))$      |
| **Python 实现**         | 二维列表 `[[0]*n for _ in range(n)]` | `defaultdict(list)` |

> $V$ = 节点数, $E$ = 边数, $degree(i)$ = 节点 $i$ 的邻居数量。

### 1.2 深度优先搜索 (DFS)

#### 1. 核心思想：一路走到底，不撞南墙不回头
DFS 就像走迷宫：你选择一条路一直往前走，直到走不通了（遇到死胡同或已经走过的节点），才退回到上一个路口，选另一条路继续试探。

#### 2. DFS 的三个关键点
1.  **访问邻居**：从当前节点出发，访问一个尚未访问过的邻居。
2.  **标记已访问 (`visited`)**：**极其重要！** 如果不标记，在有环的图中（比如 A->B, B->A），程序会陷入死循环。
3.  **递归与回溯**：利用递归栈自动保存状态，走不通时自动返回。

---

### 3. DFS 通用模板 (Python 版)

这是你在面试中写 DFS 最稳妥的结构：

```python
from collections import defaultdict

def solve():
    # 1. 建图
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)
    
    # 2. 标记数组/集合 (记录访问过的节点)
    visited = set()

    # 3. 定义 DFS 函数
    def dfs(node):
        # 如果当前节点已经访问过，直接返回
        if node in visited:
            return
        
        # 标记当前节点
        visited.add(node)
        print(f"正在访问节点: {node}") # 处理逻辑的地方
        
        # 遍历所有邻居，递归访问
        for neighbor in graph[node]:
            if neighbor not in visited:
                dfs(neighbor)

    # 4. 外部调用 (处理非连通图的情况)
    # 遍历所有节点，确保每一个孤岛都被访问到
    for i in range(n):
        if i not in visited:
            dfs(i)
```

*   **路径搜索**：寻找从 A 到 B 的路径（不一定是最短路径）。
*   **图的遍历**：访问图中的所有节点。
*   **岛屿问题**：在网格图中计算连通区域的数量。

如果说 DFS 是“不撞南墙不回头”的孤勇者，那么 **BFS（Breadth-First Search）** 就是“稳扎稳打、层层推进”的统帅。

### 1.3 广度优先搜索 (BFS)

#### 1. 核心思想：层层扩散
BFS 从起点开始，先访问所有距离为 1 的邻居，再访问所有距离为 2 的邻居，以此类推。就像往水池里丢了一块石头，波纹一圈一圈向外扩散。

#### 2. BFS 的灵魂：队列 (Queue)
为了实现“先进先出”，我们必须使用队列。在 Python 中，**绝对不要**用普通的 `list` 当队列（`pop(0)` 的时间复杂度是 $O(n)$），一定要用 `collections.deque`（双端队列），它的 `popleft()` 是 $O(1)$。

#### 3. BFS 最重要的特性
**在不带权重的图中（每条边长度都为 1），BFS 第一次搜到目标节点时，所经过的路径一定是最短路径。** 这一点是面试中区分 DFS 和 BFS 的关键。

---

### 4. BFS 通用模板 (Python 版)

这个模板包含了“层级遍历”的思想，这是面试中最常考的形式（比如求最短步数）：

```python
from collections import deque, defaultdict

def bfs(start_node, target_node, n):
    # 1. 建图 (假设已建好为 graph)
    # 2. 初始化队列，并将起点放入
    queue = deque([start_node])
    
    # 3. 标记访问 (防止死循环)
    visited = set([start_node])
    
    # 记录步数/距离
    step = 0
    
    # 4. 开始循环
    while queue:
        # 核心：当前层级的节点数
        # 这一步能让你知道哪些节点属于同一“层”
        level_size = len(queue)
        
        for _ in range(level_size):
            curr = queue.popleft()
            
            # 判断是否到达目标
            if curr == target_node:
                return step
            
            # 遍历邻居
            for neighbor in graph[curr]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        
        # 遍历完一层，步数 +1
        step += 1
        
    return -1 # 无法到达目标
```

### 5. DFS vs BFS：怎么选？

| 特性           | DFS (深度优先)                     | BFS (广度优先)         |
| :------------- | :--------------------------------- | :--------------------- |
| **数据结构**   | 递归 / 栈 (Stack)                  | 队列 (Queue)           |
| **主要用途**   | 连通性、路径搜索、所有解、拓扑排序 | **最短路径**、层级遍历 |
| **空间复杂度** | $O(树的高度)$                      | $O(每一层最大节点数)$  |
| **直观理解**   | 迷宫探索                           | 扩散、雷达扫描         |

### 2.1 什么是拓扑排序？

拓扑排序是针对 **有向无环图 (DAG, Directed Acyclic Graph)** 的。

*   **形象理解**：想象你要学完一系列课程，有些课（如《数据结构》）必须先学完前置课程（如《编程基础》）。拓扑排序就是给你排出一个合理的学习顺序。
*   **入度 (In-degree)**：指向该节点的边的数量。在课程安排中，入度表示这门课有多少门前置课程。
*   **出度 (Out-degree)**：从该节点出发的边的数量。

---

### 2.2 Kahn 算法（入度表法 —— 面试最推荐）

这是最直观、面试中最常用的 BFS 实现方式。它的核心思想是：**每次都找那些没有前置依赖（入度为 0）的任务去执行。**

#### 算法步骤：
1.  **统计入度**：统计每个节点的入度，并建立邻接表。
2.  **找起点**：将所有**入度为 0** 的节点放入队列（这些节点不需要前置条件）。
3.  **删减依赖**：从队列中取出一个节点：
    *   将其加入结果列表。
    *   遍历它的邻居，将邻居的入度减 1。
    *   **关键点**：如果减 1 后邻居的入度变成了 0，说明它的前置条件已满足，将其放入队列。
4.  **判断环**：如果最后结果列表中的节点数量少于图中节点总数，说明图中**存在环**（有些任务永远无法开始）。

---

### 2.3 拓扑排序 Python 模板

这是解决 LeetCode 课程表类题目的标准写法：

```python
from collections import deque, defaultdict

def topological_sort(n, edges):
    # 1. 初始化邻接表和入度数组
    graph = defaultdict(list)
    in_degree = [0] * n
    
    # 2. 建图并统计入度
    for dest, src in edges:
        graph[src].append(dest)
        in_degree[dest] += 1
    
    # 3. 将所有入度为 0 的节点加入队列
    queue = deque([i for i in range(n) if in_degree[i] == 0])
    
    res = []
    
    # 4. 经典的 BFS 过程
    while queue:
        u = queue.popleft()
        res.append(u)
        
        for v in graph[u]:
            in_degree[v] -= 1
            # 如果入度减为 0，入队
            if in_degree[v] == 0:
                queue.append(v)
    
    # 5. 判断是否有环 (结果长度是否等于节点数)
    if len(res) == n:
        return res
    else:
        return [] # 存在环，无法完成拓扑排序
```

### 2.4 核心考点：如何检测“环”？

这是面试官非常喜欢追问的点：
*   **无向图**：通过 DFS 访问状态或并查集来检测。
*   **有向图**：通过拓扑排序。如果算法结束以后，**处理过的节点数 < 总节点数**，则说明图中一定存在环（Cycle）。

---

### 3.1 什么是并查集？

并查集主要解决“帮派问题”。
*   **Find (查询)**：查一下 $X$ 属于哪个帮派（找老大的过程）。
*   **Union (合并)**：把 $X$ 所在的帮派和 $Y$ 所在的帮派合并成一个（两个帮派联姻）。

### 3.2 两个核心优化（面试必考点）

如果只是简单的合并，树可能会退化成一条链，查询效率会变低。我们要掌握两个优化：

1.  **路径压缩 (Path Compression)**：在 `find` 的过程中，直接把沿途的所有节点都挂在根节点下面。这样下次查的时候就是 $O(1)$ 了。
2.  **按秩合并 (Union by Rank/Size)**：合并时，总是把“小树”挂在“大树”下面，防止树长得太高。

---

### 3.3 并查集 Python 工业级模板

在面试中，我建议你直接写一个类 `UnionFind`，这会显得你的代码极其规范：

```python
class UnionFind:
    def __init__(self, n):
        # parent[i] 表示 i 的父亲，初始化时指向自己（每个点都是一个独立集合）
        self.parent = list(range(n))
        # rank 用来记录树的高度，优化合并
        self.rank = [1] * n
        # 记录连通分量的数量（可选）
        self.count = n

    def find(self, x):
        # 路径压缩：递归寻找根节点，并把沿途节点的父亲直接指向根
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        rootX = self.find(x)
        rootY = self.find(y)
        
        if rootX != rootY:
            # 按秩合并：小树接到大树下
            if self.rank[rootX] > self.rank[rootY]:
                self.parent[rootY] = rootX
            elif self.rank[rootX] < self.rank[rootY]:
                self.parent[rootX] = rootY
            else:
                self.parent[rootY] = rootX
                self.rank[rootX] += 1
            
            self.count -= 1 # 每合并成功一次，集合总数减 1
            return True
        return False # 说明本来就在同一个集合，这次合并没意义（发现了环）

    def is_connected(self, x, y):
        return self.find(x) == self.find(y)
```

---

### 3.4 什么时候用并查集 vs DFS/BFS？

*   **DFS/BFS**：适合**静态图**。如果图已经给定了，求岛屿数量，DFS 很香。
*   **并查集**：
    1.  适合**动态增加边**的情况。
    2.  适合**判断无向图是否有环**（在 `union` 前如果发现 `find(x) == find(y)`，说明再加这条边就成环了）。
    3.  代码实现通常比 BFS 更短。

### 4.2 Dijkstra 算法：单源最短路径 (必杀技)

Dijkstra 的本质是**贪心**：每次从未访问的节点中，找一个距离起点最近的节点，然后用它去“松弛”（更新）它的邻居。

#### Python 工业级模板 (使用 `heapq`)：
这是面试时最标准、最高效的写法。

```python
import heapq

def dijkstra(n, edges, start_node):
    # 1. 建图 (邻接表)
    graph = [[] for _ in range(n + 1)]
    for u, v, w in edges:
        graph[u].append((v, w))
    
    # 2. 初始化距离数组，初始为无穷大
    distances = {i: float('inf') for i in range(1, n + 1)}
    distances[start_node] = 0
    
    # 3. 优先级队列 (小顶堆)：存储 (当前总距离, 当前节点)
    pq = [(0, start_node)]
    
    while pq:
        curr_dist, u = heapq.heappop(pq)
        
        # 4. 重要优化：如果弹出的距离已经大于已记录的距离，跳过
        if curr_dist > distances[u]:
            continue
            
        # 5. 遍历邻居，尝试松弛
        for v, weight in graph[u]:
            dist = curr_dist + weight
            if dist < distances[v]:
                distances[v] = dist
                heapq.heappush(pq, (dist, v))
                
    return distances
```

### 4.3 Floyd-Warshall 算法：多源最短路径

如果你需要计算**任意两个点**之间的距离，且节点数 $V$ 较小（通常 $V \le 300$），Floyd 是最简单的选择。它的核心是三层循环的动态规划。

```python
def floyd_warshall(n, edges):
    # 初始化矩阵，自己到自己为0，其他无穷大
    dist = [[float('inf')] * n for _ in range(n)]
    for i in range(n): dist[i][i] = 0
    
    for u, v, w in edges:
        dist[u][v] = w # 有向图
        
    # 三层循环：k 是中间转折点
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][j] > dist[i][k] + dist[k][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist
```

### 5.1 最小生成树 (MST - Minimum Spanning Tree)

**场景**：你有 $N$ 个城市，想建一些路把它们**全部连通**起来，怎样建路总成本最低？
**核心特征**：
1.  **连通**所有节点。
2.  形成的结构是一棵**树**（即：$N$ 个点，$N-1$ 条边，且无环）。
3.  **权重总和最小**。

#### 1. Kruskal 算法（贪心 + 并查集 —— 面试首选）
Kruskal 的思想极其简单：
1.  把图中所有的边按**权重从小到大排序**。
2.  按顺序挑选边。如果这条边的两个端点**尚未连通**（用并查集 `find` 判断），就把它加入树中，并合并它们（用 `union`）。
3.  如果已经连通，就跳过（防止成环）。

**Python 核心逻辑：**
```python
def kruskal(n, edges):
    # edges: [[u, v, weight], ...]
    edges.sort(key=lambda x: x[2]) # 按权重排序
    uf = UnionFind(n) # 使用第三阶段学的并查集模板
    
    mst_weight = 0
    edges_count = 0
    
    for u, v, w in edges:
        if uf.union(u, v): # 如果合并成功，说明没成环
            mst_weight += w
            edges_count += 1
            if edges_count == n - 1: break # 树已经建好
            
    return mst_weight if edges_count == n - 1 else -1
```

### 5.2 二分图判定 (Bipartite Graph)

**场景**：能不能把所有节点分成 A、B 两组，使得所有的边都只存在于 A 组和 B 组之间（同组内没有边直接相连）？

**核心算法：染色法 (Coloring)**
*   遍历节点，给它涂颜色 1。
*   把它所有的邻居涂成颜色 -1。
*   如果发现某个邻居已经被涂了颜色，且颜色竟然和当前节点一样，说明**不是二分图**。
*   通常使用 **DFS** 或 **BFS** 实现。

### 一、 无向图 (Undirected Graph) 中的环检测

在无向图中，环的定义很简单：通过边走一圈能回到原点，且不走回头路。

#### 1. 武器一：并查集 (Union-Find) —— **最推荐**
这是检测无向图是否有环最直观的方法。
*   **逻辑**：遍历每一条边 `(u, v)`。在合并之前，先查 `find(u)` 和 `find(v)`。如果它们已经属于同一个集合，说明 `u` 和 `v` 之间已经有一条路径相连了，现在再加这条边，必然成环。
*   **适用场景**：动态加边、判断整张图是否有环。
*   **对应题目**：LeetCode 684. 冗余连接。

#### 2. 武器二：DFS
*   **逻辑**：在 DFS 遍历邻居时，如果遇到了一个**已访问过**的节点，且该节点**不是当前节点的父节点**（即不是刚从那里走过来的），说明有环。
*   **代码要点**：`dfs(curr, parent)`。

---

### 二、 有向图 (Directed Graph) 中的环检测

有向图的环检测比无向图复杂，因为 A -> B 和 B -> A 是两条不同的边。

#### 1. 武器一：拓扑排序 (Kahn 算法) —— **最推荐**
这是我们在第二阶段学的知识。
*   **逻辑**：如果图中没有环，所有节点都能进入拓扑序列。如果环存在，环内的节点入度永远不会减到 0，因此无法进入序列。
*   **结论**：`如果 拓扑序列长度 < 总节点数，则有环`。
*   **适用场景**：课程表问题、依赖关系检测。

#### 2. 武器二：DFS 三色标记法 (State Array)
如果你不想用拓扑排序，可以用 DFS。我们需要给节点标记三种状态：
*   **状态 0 (未访问)**：还没走到这个点。
*   **状态 1 (正在访问)**：正在以这个点为起点进行递归（即在递归栈中）。
*   **状态 2 (已完成访问)**：这个点的所有子孙节点都探查完了，没有环。

**核心逻辑**：在递归过程中，如果你遇到了一个**状态为 1** 的邻居，说明你转了一圈又撞上了递归栈里的自己 —— **发现环！**

```python
def has_cycle(n, graph):
    state = [0] * n  # 0:未访, 1:访问中, 2:完成
    
    def dfs(u):
        state[u] = 1 # 标记为正在访问
        for v in graph[u]:
            if state[v] == 1: # 撞上了递归栈里的点，有环！
                return True
            if state[v] == 0: # 继续探查未访问的点
                if dfs(v): return True
        state[u] = 2 # 探查完毕，标记为完成
        return False

    for i in range(n):
        if state[i] == 0:
            if dfs(i): return True
    return False
```

### 三、 进阶：负权环 (Negative Cycle)

这是第四阶段“最短路径”的高阶变体。
*   **定义**：一个环的所有边权加起来是**负数**。
*   **影响**：如果你在负权环里绕圈，路径长度会无限减小（变成负无穷），导致 Dijkstra 算法失效。
*   **检测武器**：**Bellman-Ford 算法** 或 **SPFA 算法**。
*   **逻辑**：如果对图进行了 $N-1$ 次松弛操作后，依然能继续松弛（路径变短），则说明存在负权环。
*   **考频**：校招机试中极少考代码实现，通常只需知道其原理。

| **有权图** | 检查是否有导致最短路失效的环 | **Bellman-Ford**                      |
