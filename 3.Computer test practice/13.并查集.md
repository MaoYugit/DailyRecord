# 并查集（Union-Find）

---

### 1. 核心思想：江湖门派

想象一下，江湖上有许多小弟，最初每个人都是自成一派，自己是自己的老大。

*   **并（Union）：** 两个门派合并。比如 A 派的老大投降了 B 派的老大，从此 A 派所有人都归 B 派管。
*   **查（Find）：** 查某人的“最高领导”是谁。如果两个人的最高领导是同一个人，说明他们在同一个门派。

---

### 2. 并查集的三个关键动作

我们要用一个数组 `parent` 来记录每个人的上级。`parent[i]` 表示 $i$ 的上级是谁。

#### 动作一：初始化（每个人都是老大）
最开始，每个人都是独立的，他们的上级就是自己。
```python
parent = [i for i in range(n)] 
# 比如 parent[3] = 3，意思就是 3 号的上级是 3 自己。
```

#### 动作二：查询（Find）—— 找最高领导
我们要一直往上找，直到找到那个“上级是自己”的人，他就是掌门。
**超级优化（路径压缩）：** 为了以后找得快，我们在找掌门的过程中，顺便让路上的所有人都直接认掌门当上级。

```python
def find(i):
    if parent[i] == i:
        return i
    # 路径压缩：直接把我的上级改成最终的掌门
    parent[i] = find(parent[i]) 
    return parent[i]
```

#### 动作三：合并（Union）—— 吞并门派
如果要合并 $i$ 和 $j$ 所属的门派，先找到他们的掌门。如果掌门不同，就把其中一个掌门变成另一个掌门的下级。

```python
def union(i, j):
    root_i = find(i)
    root_j = find(j)
    if root_i != root_j:
        parent[root_i] = root_j # i 门派投降 j 门派
```

### 3. 完整的 Python 模板（背下这个，面试直接写）

在 LeetCode 刷题时，建议写成一个类，这样代码很整洁：

```python
class UnionFind:
    def __init__(self, n):
        # 初始化，每个人都是自己的老大
        self.parent = list(range(n))
        self.count = n  # 记录当前有多少个独立的门派（连通分量）

    def find(self, i):
        if self.parent[i] == i:
            return i
        # 路径压缩：递归寻找时，把路径上的节点都指向根节点
        self.parent[i] = self.find(self.parent[i])
        return self.parent[i]

    def union(self, i, j):
        root_i = self.find(i)
        root_j = self.find(j)
        if root_i != root_j:
            self.parent[root_i] = root_j
            self.count -= 1 # 每合并一次，门派数量减 1
            return True
        return False # 已经在同一个门派了
```

---

### 4. 为什么要用并查集？（和 BFS/DFS 比）

*   **BFS/DFS：** 像“静态”扫地。图已经画好了，我去数有多少块。
*   **并查集：** 像“动态”组队。连接是一对一对给你的，你需要**随时**知道某两个人是不是队友，或者随时知道现在有多少个队伍。
*   **效率：** 并查集的查询和合并几乎是**瞬间（接近 $O(1)$）**完成的。

### 学习小贴士：

1.  **遇到“动态连接”、“朋友圈”、“连通性”** 这种关键词，优先想并查集。
2.  **一定要写“路径压缩”：** 即 `parent[i] = find(parent[i])`。如果不写这一行，并查集会退化成一条长长的链，速度变慢，可能会超时。
3.  **理解 `count`：** 在初始化时 `count = n`，每次**成功**合并（即两个掌门不同）时，`count -= 1`。最后 `count` 就是图中独立块的数量。
