## 第一阶段：傻瓜式入门与万能模版

#### 1. 什么是回溯？
不要被名字吓到。回溯算法的本质就是：**“一条路走到黑，撞了南墙回过头，换条路接着走”。**

想象你在走一个迷宫：
1.  你面前有A、B、C三条路。
2.  你先选A路，一直走，发现是死胡同。
3.  你**退回**（这就是回溯）到路口。
4.  撤销刚才选A的决定，改选B路……

在代码里，由两个动作组成：
*   **前进（递归）：** 尝试下一个数字/选项。
*   **撤销（回溯）：** 把刚才加进去的数字拿出来，恢复现场，准备试下一个。

#### 2. Python 万能模版（请死记硬背）
这是回溯算法的“八股文”，90%的题目都是这个结构。请把这段代码刻在脑子里：

```python
result = []  # 存放最终结果的篮子

def backtrack(路径, 选择列表):
    # 1. 结束条件：如果满足条件（比如路径长度够了），就记录结果
    if 满足结束条件:
        result.append(路径[:]) # 注意这里要由切片[:]，后面会讲为什么
        return

    # 2. 核心循环：遍历所有选择
    for i in range(len(选择列表)):
        choice = 选择列表[i]
        
        # 3. 做选择
        路径.append(choice)
        
        # 4. 递归：进入下一层决策树
        # (通常这里会把选择列表缩小，或者改变参数)
        backtrack(路径, 剩下的选择列表)
        
        # 5. 撤销选择（回溯的核心！）
        路径.pop() 
```

**口诀：** 做选择 -> 递归 -> 撤销选择。

#### 3. 实战演练：全排列（LeetCode 46）
这是最经典的第一题。
**题目：** 给定 `[1, 2, 3]`，求出所有可能的排列。
比如：`[1,2,3], [1,3,2], [2,1,3]...`

**思路模拟（脑子里要有这个画面）：**
*   **手拿一个空盒子（路径）**。
*   面对 `1, 2, 3`。
*   **尝试 1：** 把 1 放入盒子。盒子现在是 `[1]`。
    *   还剩 `2, 3`。
    *   **尝试 2：** 把 2 放入盒子。盒子现在是 `[1, 2]`。
        *   还剩 `3`。
        *   **尝试 3：** 把 3 放入盒子。盒子现在是 `[1, 2, 3]`。
        *   **没得选了，满了！** -> **记录 `[1, 2, 3]`**。
        *   **回溯（撤销）：** 把 3 拿出来。盒子变回 `[1, 2]`。
    *   **尝试 3（换个路）：** 刚才试过 2 了，现在试 3。把 3 放入盒子。盒子是 `[1, 3]`。
        *   还剩 `2`。
        *   **尝试 2：** 把 2 放入盒子。盒子是 `[1, 3, 2]`。
        *   **记录 `[1, 3, 2]`**。
        *   **回溯：** 把 2 拿出来...
*   （以此类推）

**代码实现（直接套模版）：**

```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        res = []  # 存所有结果
        path = [] # 存当前路径（盒子）
        
        # 定义回溯函数
        # 这里的 used 是一个技巧，用来标记哪个数字已经被用过了
        # 因为全排列里，用过的数字不能再用
        def backtrack(path, used):
            # 1. 结束条件：盒子里的数字个数等于题目给的数字个数
            if len(path) == len(nums):
                res.append(path[:]) # 必须用[:]拷贝一份！
                return
            
            # 2. 遍历选择
            for i in range(len(nums)):
                # 如果这个数字已经被用在当前路径里了，就跳过
                if used[i]:
                    continue
                
                # 3. 做选择
                path.append(nums[i])
                used[i] = True # 标记为已使用
                
                # 4. 递归
                backtrack(path, used)
                
                # 5. 撤销选择 (核心！怎么过去的，怎么回来)
                path.pop()     # 把数字拿出来
                used[i] = False # 标记为未使用
        
        # 初始化 used 数组，全是 False
        used = [False] * len(nums)
        backtrack([], used)
        return res
```

#### 4. 给初学者的大坑（必须注意！）

**为什么上面代码里要写 `res.append(path[:])` 而不是 `res.append(path)`？**

这是 Python 的一个特性（引用传递）。
*   `path` 就像是一个唯一的盒子。
*   如果你直接把盒子放进结果列表里，然后你在后面继续操作这个盒子（比如 `pop`），结果列表里的那个盒子内容也会变！
*   等到最后，你会发现结果全是空的 `[[], [], []]`，因为所有的数字都被你 `pop` 出去了。
*   **解决办法：** `path[:]` 相当于给当前的盒子拍了一张**照片**（拷贝），把照片存进去。以后盒子怎么变，照片不会变。

---

### 难点一：为什么要写 `path[:]` ？（引用传递详解）

你在代码里看到的 `res.append(path[:])`，那个 `[:]` 到底在干嘛？

#### 1. 现实生活中的比喻：黑板与照片

想象你在教室里，墙上挂着**唯一的一块小黑板**（这就是 `path` 列表）。你的任务是把每次写好的数字组合交给老师（存进 `res` 结果列表）。

*   **错误的做饭 (`res.append(path)`)：**
    1.  你在黑板上写了 `[1, 2, 3]`。
    2.  你喊老师：“老师，你看我的黑板！”
    3.  老师并没有把黑板上的字抄下来，而是拿了一根绳子，**一头拴在黑板上，一头拴在老师的本子上**。老师说：“行，我记住了，你的答案就是这块黑板上的内容。”
    4.  你继续做题，你**把黑板擦了**，准备写下一题。
    5.  **灾难发生了：** 老师本子上拴着的那块黑板，现在变成空的了！
    6.  等你把所有题做完，黑板被擦得干干净净。老师回头看本子，发现所有答案都指向那块空黑板。结果就是：`[[], [], [], ...]`。

*   **正确的做法 (`res.append(path[:])`)：**
    1.  你在黑板上写了 `[1, 2, 3]`。
    2.  你拿出手机，**对着黑板拍了一张照片**（这就是 `[:]` 的作用，它创造了一个副本）。
    3.  你把**照片**交给老师。
    4.  你回头把黑板擦了 (`pop`)。
    5.  **结果：** 黑板虽然空了，但老师手里的**照片**上依然清晰地写着 `[1, 2, 3]`。

#### 2. 代码验证
你可以打开你的 Python 编辑器跑一下这段代码，一眼就懂：

```python
# 错误示范
path = [1, 2]
res = []
res.append(path)   # 放进去的是“黑板本身”
print(f"刚放进去: {res}") 

path.pop()         # 修改黑板
print(f"修改path后，res也变了: {res}") 
# 输出: [[1]] -> 你看，res 里的东西莫名其妙变了！

# ---------------------------

# 正确示范
path = [1, 2]
res = []
res.append(path[:]) # 放进去的是“照片”
print(f"刚放进去: {res}")

path.pop()          # 修改黑板
print(f"修改path后，res不受影响: {res}") 
# 输出: [[1, 2]] -> res 里的东西还是原来的样子！
```

### 总结关键动作

你会发现，程序的运行轨迹像一个**呼吸的过程**：
1.  **吸气（递归）：** 往列表里加数字，标记为 True，越陷越深。
2.  **到底（Base Case）：** 拍照留念。
3.  **呼气（回溯）：** 往外拿数字 (`pop`)，标记回 False，回到上一层。

**每一次 `pop` 都是为了给后面的数字腾位置！**
如果不 `pop`，盒子满了你就没法玩下一轮了。

## **第二阶段：**组合（Combinations）** 和 **子集（Subsets）** 问题**

这一阶段非常重要，因为面试中**80%**的回溯题都在这一类。

---

### 1. 核心区别：为什么要换个写法？

在第一阶段的“全排列”中，`[1, 2]` 和 `[2, 1]` 是两个不同的结果，所以我们要回头去找刚才没用的数字。

但在今天的题目里（比如找子集），`[1, 2]` 和 `[2, 1]` 是一家人，**算重复的**！
如果我们还用之前的写法，就会出现重复结果。

**怎么解决？**
我们要引入一个极其重要的概念：**“不走回头路”**。

> **想象一下：**
> 你在排队打饭，面前有一排菜：`A, B, C, D`。
> 规则是：你只能往右边走，选过的菜或者左边的菜，不能回头再选。
>
> *   如果你选了 B，接下来你只能看 C 和 D。
> *   你绝对不能回头去看 A。

在代码里，我们需要给回溯函数多加一个参数，通常叫 **`startIndex`**（起始位置）。

---

### 2. 题目一：子集 (LeetCode 78)

**题目：** 给你一个数组 `[1, 2, 3]`，找出它所有的子集。
**结果应该是：** `[], [1], [2], [3], [1,2], [1,3], [2,3], [1,2,3]`（顺序无所谓）。

**超详细代码逻辑：**

我们直接修改之前的模版。
1.  **不需要 `used` 数组了**（因为我们不回头）。
2.  **需要 `startIndex`**（告诉下一层递归从哪里开始选）。
3.  **结果收集的时机变了**：全排列是“走到头”才收集，找子集是“每走一步”都要收集（因为 `[1]` 也是子集，`[1, 2]` 也是）。

#### 代码实现（请逐行阅读注释）：

```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        res = []
        path = []
        
        # 多加一个参数：startIndex
        # 含义：这一层递归，只能从 nums[startIndex] 往后选
        def backtrack(startIndex):
            # 1. 收集结果
            # 注意：这里不需要 if 结束条件，因为每一个 path 都是一个子集！
            # 只要进来了，先把当前的 path 拍个照存下来
            res.append(path[:])
            
            # 2. 遍历选择
            # 关键点：从 startIndex 开始遍历，而不是从 0 开始！
            # 这样就杜绝了“往回看”的可能
            for i in range(startIndex, len(nums)):
                
                # 3. 做选择
                path.append(nums[i])
                
                # 4. 递归
                # 关键点：传进去的是 i + 1
                # 意思是：下一层只能从我当前选的这个数字的“后面”开始选
                backtrack(i + 1)
                
                # 5. 撤销选择 (老规矩)
                path.pop()
        
        # 最开始从索引 0 开始选
        backtrack(0)
        return res
```

#### 此时你的脑海里应该有这张图：
假设 `nums = [1, 2, 3]`

*   **当前 `startIndex` = 0**
    *   选 `1` (`i=0`) -> `path=[1]` -> 递归 `backtrack(1)`
        *   **当前 `startIndex` = 1** (只能选 2, 3)
            *   选 `2` -> `path=[1,2]` -> 递归 `backtrack(2)`
                *   **当前 `startIndex` = 2** (只能选 3)
                    *   选 `3` -> `path=[1,2,3]` -> 递归 `backtrack(3)`...
            *   撤销 2
            *   选 `3` -> `path=[1,3]`...
    *   撤销 1
    *   选 `2` (`i=1`) -> `path=[2]` -> **注意！这里递归 `backtrack(2)`**
        *   **当前 `startIndex` = 2** (只能选 3，**绝不回头看 1**)
            *   选 `3` -> `path=[2,3]`...

### 3. 题目二：组合 (LeetCode 77)

**题目：** 给定两个整数 `n` 和 `k`，返回 1 ... `n` 中所有可能的 `k` 个数的组合。
比如 `n=4, k=2`，就是要你从 `1,2,3,4` 里挑两个数。
结果：`[1,2], [1,3], [1,4], [2,3], [2,4], [3,4]`。

**思路：**
这题和上面的“子集”几乎一模一样！
唯一的区别是：**子集是都要，组合是只要长度为 k 的。**

所以，我们只需要在模版里加一个 `if` 判断长度。

#### 代码实现：

```python
class Solution:
    def combine(self, n: int, k: int) -> List[List[int]]:
        res = []
        path = []
        
        # startIndex 这里的含义是：当前可选的数字从几开始
        # 比如 n=4，数字就是 1, 2, 3, 4
        def backtrack(startIndex):
            # 1. 结束条件
            # 只有当 path 里的球凑够 k 个了，才收网
            if len(path) == k:
                res.append(path[:])
                return # 既然够了，就不用往深处找了，直接返回
            
            # 2. 遍历选择
            # 数字是从 1 到 n，所以 range 要写 (startIndex, n + 1)
            for i in range(startIndex, n + 1):
                path.append(i)
                
                # 递归：下一层从 i + 1 开始
                backtrack(i + 1)
                
                path.pop()
        
        # 题目是从 1 开始数的，所以我们传 1
        backtrack(1)
        return res
```

### 1. 核心逻辑变化：从“选数字”变成“走格子”

在前两个阶段，我们的选择列表是 `[1, 2, 3, ...]`。
在二维矩阵里，我们的选择列表变成了**方向**：**上、下、左、右**。

**想象你在玩一个走迷宫的游戏：**

1.  你站在格子 `(row, col)` 上。
2.  你可以往四个方向走。
3.  **限制条件（撞墙）：**
    *   不能走出边界（比如 `row < 0` 或者 `row >= 总行数`）。
    *   不能走进墙壁（如果不满足题目条件）。
    *   **不能走回头路**（这就需要我们标记“已访问”）。

### 2. 经典题目：单词搜索 (LeetCode 79)

**题目：** 给一个字母棋盘 `board` 和一个单词 `word`。问这个单词是否在棋盘上？（字母必须相邻，不能重复使用同一个格子的字母）。

例子：
```text
棋盘：
[
  ['A','B','C','E'],
  ['S','F','C','S'],
  ['A','D','E','E']
]
单词："ABCCED" -> 返回 True
```

---

### 3. 解题思路：机器人的试探

我们派出一个机器人从棋盘的每一个格子开始尝试：

1.  **检查当前格子：**
    *   越界了吗？ -> 越界了就死路（Return False）。
    *   是我要找的字母吗？（比如我要找 "A"，但这格是 "S"） -> 不是就死路（Return False）。
    *   这个格子我刚才走过了吗？ -> 走过就不能走了（Return False）。

2.  **如果是对的字母：**
    *   **核心技巧（标记）：** 为了防止一会儿兜圈子又走回来，我先把这个格子涂黑（比如改成特殊字符 `'#'`）。
    *   **递归（走下一步）：** 尝试往 **上、下、左、右** 四个方向找单词的下一个字母。
    *   **回溯（还原）：** 如果四个方向都走不通，说明这条路是错的。**最重要的步骤来了：** 把刚才涂黑的格子擦干净（改回原来的字母），方便别的路径以后能用它。

### 4. 代码实现（死记硬背版）

这道题的代码结构非常经典，请仔细看每一个注释。

```python
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        rows = len(board)
        cols = len(board[0])
        
        # 参数定义：
        # r, c: 当前机器人的坐标 (row, col)
        # i: 当前我们要找 word 里的第几个字母
        def backtrack(r, c, i):
            # 1. 结束条件（成功）：
            # 如果 i 已经指到了单词的最后，说明全找到了！
            if i == len(word):
                return True
            
            # 2. 结束条件（失败/越界/不对）：
            # r, c 超出边界 OR 当前格子不是我们要找的字母 word[i]
            if (r < 0 or r >= rows or 
                c < 0 or c >= cols or 
                board[r][c] != word[i]):
                return False
            
            # 3. 做选择（标记）：
            # 既然到了这一步，说明 board[r][c] 是对的字母。
            # 先把它存起来，然后临时改成 '#'，防止回头走。
            temp = board[r][c]
            board[r][c] = '#' 
            
            # 4. 递归（向四个方向尝试）：
            # 只要有一个方向能走通（返回True），那我就成功了
            # 这里的 i + 1 意思是找单词的下一个字母
            found = (backtrack(r + 1, c, i + 1) or  # 下
                     backtrack(r - 1, c, i + 1) or  # 上
                     backtrack(r, c + 1, i + 1) or  # 右
                     backtrack(r, c - 1, i + 1))    # 左
            
            # 5. 撤销选择（回溯）：
            # 无论刚才找没找到，我要退出了，必须把格子恢复原状！
            board[r][c] = temp 
            
            return found

        # 主程序：
        # 因为单词可以从棋盘的任意一个位置开始
        # 所以我们要遍历棋盘的每一个格子作为起点
        for r in range(rows):
            for c in range(cols):
                # 如果从 (r, c) 出发能找到，就直接返回 True
                if backtrack(r, c, 0):
                    return True
                    
        # 跑遍了所有格子都没找到
        return False
```

3.  **必须正好 4 段：** 切完必须正好用光所有字符。

```python
class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        res = []
        path = [] # 存放切好的每一段，比如 ['255', '255', '11', '135']
        
        # 判断切出来的这段字符串是否合法
        def isValid(segment):
            # 1. 如果长度为0（空串），不行
            if len(segment) == 0: 
                return False
            # 2. 如果第一位是0，且长度大于1（比如 "01"），不行！
            if len(segment) > 1 and segment[0] == '0':
                return False
            # 3. 如果数字大于 255，不行！
            if int(segment) > 255:
                return False
            return True

        def backtrack(startIndex):
            # 1. 结束条件：
            # 如果 path 里已经有 4 段了
            if len(path) == 4:
                # 关键：必须正好把字符串用完（startIndex 走到了末尾）
                if startIndex == len(s):
                    # 把 ['255', '255', ...] 拼成 "255.255..."
                    res.append(".".join(path))
                return # 无论有没有用完，既然凑够4段了，就必须返回
            
            # 2. 遍历选择：每一刀可以切 1个、2个 或 3个 字符
            # 这里的 i 是这一刀切到的位置
            # range 的范围：从 startIndex+1 开始，到 startIndex+4 结束（不包含+4）
            # 也就是长度 1, 2, 3
            for i in range(startIndex + 1, startIndex + 4):
                # 剪枝：如果切的位置超过了字符串长度，直接 break
                if i > len(s):
                    break
                
                # 截取字符串：左闭右开
                segment = s[startIndex : i]
                
                # 3. 核心：如果这段不合法，就不用递归了，直接看下一种切法
                if not isValid(segment):
                    continue
                
                # 4. 做选择
                path.append(segment)
                
                # 5. 递归（下一刀从 i 开始切）
                backtrack(i)
                
                # 6. 撤销选择
                path.pop()

        # 剪枝：如果字符串太长（超过12位）或太短（少于4位），直接返回空
        # 因为 IP 最长 3*4=12，最短 1*4=4
        if len(s) > 12 or len(s) < 4:
            return []
            
        backtrack(0)
        return res
```

```python
class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        result = []
        
        # 1. 顶级剪枝（Pruning）
        # IP地址最长 12 位 (255.255.255.255)，最短 4 位 (0.0.0.0)
        # 如果不满足，根本不用费劲切了，直接返回空。
        if len(s) > 12 or len(s) < 4:
            return []

        # path: 已经切下来的几段香肠，比如 ['255', '255']
        def backtrack(startIndex, path):
            
            # 2. 结束条件：切够 4 段了
            if len(path) == 4:
                # 只有当正好把字符串切完 (startIndex 到了末尾)，才算成功
                if startIndex == len(s):
                    result.append(".".join(path))
                return # 切够4段了，不管成没成功，都得退回去了
            
            # 3. 核心循环：尝试切不同长度 (1, 2, 3)
            # i 代表切下来的片段长度
            for i in range(1, 4):
                
                # 边界检查：如果切的长度超过了剩下的字符串长度，就别切了
                if startIndex + i > len(s):
                    break
                
                # 动手切！从 startIndex 开始，切 i 个字符
                segment = s[startIndex : startIndex + i]

                # --- 合法性检查 (剪枝) ---
                
                # 规则1：如果长度 > 1，第一位不能是 '0' (比如 "05" 不行)
                if len(segment) > 1 and segment.startswith("0"):
                    continue # 换个长度试试
                
                # 规则2：不能超过 255
                if int(segment) > 255:
                    continue # 太大了，换个长度肯定更大，其实这里可以直接 break
                
                # -----------------------

                # 4. 做选择
                path.append(segment)
                
                # 5. 递归 (注意：下一刀从 startIndex + i 开始切)
                backtrack(startIndex + i, path)
                
                # 6. 撤销选择 (回溯)
                path.pop()

        backtrack(0, [])
        return result
```

### 第一题：分割回文串 (LeetCode 131)

**难度：** 中等
**理由：** 这道题和“复原 IP 地址”简直是**亲兄弟**。
*   **IP地址**是：切下来的必须是合法数字（0-255）。
*   **这道题**是：切下来的必须是**回文串**（比如 "aba", "aa"）。

**逻辑复用：**
你完全可以用你刚才写的 IP 地址代码框架！
1.  还是 `startIndex` 控制切割位置。
2.  还是 `for` 循环决定这一刀切多长（只不过这里没有长度 3 的限制，可以切到底）。
3.  判断函数 `isValid` 变成判断字符串是否回文（Python里就是 `s == s[::-1]`，超简单）。

**代码结构提示（自己填空）：**

```python
# 模版和 IP 地址几乎一模一样
def backtrack(startIndex, path):
    # 1. 结束条件：切到了字符串末尾
    if startIndex == len(s):
        res.append(path[:])
        return

    # 2. 循环：从 startIndex 切到末尾
    for i in range(startIndex, len(s)):
        # 切下来一段
        temp = s[startIndex : i+1]
        
        # 判断：如果是回文，就收下；不是回文，就 continue
        if temp == temp[::-1]:
            path.append(temp)
            backtrack(i + 1, path) # 递归
            path.pop()             # 回溯
```

### 第二题：子集 II (LeetCode 90)

**难度：** 中等
**理由：** 之前的题目，输入都是 `[1, 2, 3]`（不重复）。如果输入是 `[1, 2, 2]` 怎么办？
我们要找子集，结果里不能有重复的集合（`[1, 2]` 和 `[1, 2]` 算重复）。

**核心新知识点：去重（剪枝）**

这就好比你去买苹果，摊位上有三个苹果，标号是 A, B, C。其中 B 和 C 长得一模一样（都是 2）。
*   你选了 `[A, B]` (1, 2)。
*   回溯后，你又选 `[A, C]` (1, 2)。
*   这就算重复了！

**解决方案（死记硬背）：**
1.  **必须先排序！** `nums.sort()`。
2.  **在 for 循环里加一句话：**
    ```python
    # i > startIndex 意味着这不是每一层的第一个选择（是回头草或者后面的兄弟）
    # nums[i] == nums[i-1] 意味着当前这个数和前面那个数长得一样
    if i > startIndex and nums[i] == nums[i-1]:
        continue
    ```
    这句话的意思是：**“同一个树层，前面那个一样的数字如果没被选（其实是刚被撤销），那我也不能选，否则就重复了。”**

这道题直接套用你第二阶段“子集”的代码，加上这两行，就能过。

### 模版一：组合/子集（最常用）
**适用场景：**
*   `[1, 2]` 和 `[2, 1]` 是一样的（顺序不重要）。
*   比如：找子集、找组合、切分字符串（复原IP）、分割回文串。
*   **关键字：** `startIndex`，`i + 1`。

```python
result = []
path = []

def backtrack(startIndex):
    # 1. 结束条件/收集结果
    # 如果是找子集，每次进来都收集；如果是找固定长度组合，判断 len(path)==k
    result.append(path[:]) 
    
    # 2. 遍历选择
    for i in range(startIndex, len(nums)):
        
        # --- 剪枝（可选） ---
        # if i > startIndex and nums[i] == nums[i-1]: continue (去重专用)
        # ------------------
        
        # 3. 做选择
        path.append(nums[i])
        
        # 4. 递归
        # 关键点：传入 i + 1，表示“当前这个数选完了，以后不能再选它”
        backtrack(i + 1)
        
        # 5. 撤销选择
        path.pop()
```

### 模版二：允许重复选择（针对 LeetCode 39）
**适用场景：**
*   同一个数字可以被无限次选择。
*   比如：组合总和。
*   **关键字：** `startIndex`，`i`（递归参数不变）。

```python
result = []
path = []

def backtrack(startIndex, current_sum):
    # 1. 结束条件
    if current_sum == target:
        result.append(path[:])
        return
    if current_sum > target:
        return

    # 2. 遍历选择
    for i in range(startIndex, len(candidates)):
        
        # 3. 做选择
        path.append(candidates[i])
        
        # 4. 递归
        # 关键点：传入 i，表示“当前这个数刚选过，但我下一层还可以接着选它”
        # 只有这里和模版一不一样！！！
        backtrack(i, current_sum + candidates[i])
        
        # 5. 撤销选择
        path.pop()
```

### 模版三：全排列（顺序重要）
**适用场景：**
*   `[1, 2]` 和 `[2, 1]` 不一样。
*   比如：全排列、N皇后。
*   **关键字：** `used` 数组，每次循环从 0 开始。

```python
result = []
path = []
used = [False] * len(nums) # 标记谁被用过了

def backtrack():
    # 1. 结束条件
    if len(path) == len(nums):
        result.append(path[:])
        return

    # 2. 遍历选择
    # 关键点：这里永远从 0 开始遍历！
    for i in range(len(nums)):
        # 如果这个数用过了，就跳过
        if used[i]:
            continue
            
        # 3. 做选择
        path.append(nums[i])
        used[i] = True # 标记为已占用
        
        # 4. 递归
        backtrack()
        
        # 5. 撤销选择
        path.pop()
        used[i] = False # 释放标记
```

### 模版四：二维棋盘/网格
**适用场景：**
*   走迷宫、单词搜索、岛屿问题。
*   **关键字：** `board[r][c] = '#'`（原地标记）。

```python
def backtrack(r, c, index):
    # 1. 结束条件
    if 满足成功条件: return True
    if 越界 or 不满足条件 or 已访问过: return False

    # 2. 做选择（标记当前格子，防止回头走）
    temp = board[r][c]
    board[r][c] = '#'

    # 3. 递归（尝试上下左右）
    found = (backtrack(r+1, c, index+1) or 
             backtrack(r-1, c, index+1) or ...)

    # 4. 撤销选择（还原格子）
    board[r][c] = temp
    
    return found
```
