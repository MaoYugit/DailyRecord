某公司有一笔资金(m万元)计划进行投资，前期调研分析了多种(n种)产品，分析得出了每种产品的预期收益率(e%)和风险等级(记为r,用1~10表示。数值越大表示风险越高)，公司风控部门要求投资产品的风险等级不能超过x且单个产品的投资金额不能超过y元，请规划一个满足公司风控要求的最大预期收益的投资方案并输出方案的预期收益。

**输入描述**

输入的第一行为可用于投资的金额m(万元)，调研的投资产品种类数n(种)，风险部门要求的最高可以投资风险等级x。单个产品的最大投资金额y(万元)，用空格分割;
第二行开始为每个产品的预期收益率e(%)和每个产品的风险等级r，用空格分割。
不考虑非法输入，所有输入都是正整数，输出结果四舍五入取整，输入输出口均小于2^31

**输出描述**

输出计算的最大预期收益
示例1：

输入：

100 7 5 10
10 3
15 5
14 3
20 7
18 6
17 4
30 9

输出：
6

这道题的核心是一个**贪心算法**问题。

### 1. 题目逻辑分析

我们的目标是让收益最大化，同时需要满足三个约束条件：
1.  **风险约束**：产品的风险等级 $r \le x$。
2.  **单个产品投资限额**：每个产品最多只能投 $y$ 万元。
3.  **总预算约束**：所有投资金额之和不能超过 $m$ 万元。

**贪心策略：**
为了获得最大收益，我们应该优先把钱投在**预期收益率（e%）最高**的产品上。
*   首先，过滤掉所有风险等级超过 $x$ 的产品。
*   然后，将剩余产品按收益率从高到低排序。
*   接着，依次遍历这些产品，每个产品尽可能多投（投 $y$ 万元），直到总预算 $m$ 用完为止。

---

### 2. 示例模拟
**输入：**
总资金 $m=100$，种类 $n=7$，最高风险 $x=5$，单项限额 $y=10$。
产品列表（收益率, 风险）：
1. (10, 3) - OK
2. (15, 5) - OK
3. (14, 3) - OK
4. (20, 7) - 风险太高，丢弃
5. (18, 6) - 风险太高，丢弃
6. (17, 4) - OK
7. (30, 9) - 风险太高，丢弃

**符合条件的产品排序（按收益率降序）：**
1. 收益率 17%，投 10万，收益 $10 \times 0.17 = 1.7$
2. 收益率 15%，投 10万，收益 $10 \times 0.15 = 1.5$
3. 收益率 14%，投 10万，收益 $10 \times 0.14 = 1.4$
4. 收益率 10%，投 10万，收益 $10 \times 0.10 = 1.0$

**累计投资：** $10+10+10+10 = 40$ 万元（未超过总预算 100）。
**总收益：** $1.7 + 1.5 + 1.4 + 1.0 = 5.6$。
**四舍五入取整：** 6。

### 3. 代码实现 (Python)

```python
import sys

def solve():
    # 1. 读取第一行参数
    try:
        line1 = sys.stdin.readline().split()
        if not line1:
            return
        m, n, x, y = map(int, line1)
        
        # 2. 读取所有产品并过滤风险
        valid_products = []
        for _ in range(n):
            e, r = map(int, sys.stdin.readline().split())
            if r <= x:
                valid_products.append(e)
    except EOFError:
        pass

    # 3. 按收益率从高到低排序
    valid_products.sort(reverse=True)

    total_profit = 0.0
    remaining_budget = m

    # 4. 贪心分配资金
    for e in valid_products:
        if remaining_budget <= 0:
            break
        
        # 每个产品投资额取 (剩余总预算) 和 (单项限额) 的最小值
        invest_amount = min(y, remaining_budget)
        
        # 累加收益: 投资额 * 收益率%
        total_profit += invest_amount * (e / 100.0)
        
        # 扣除预算
        remaining_budget -= invest_amount

    # 5. 四舍五入取整输出
    # 在Python中，int(x + 0.5) 是标准的四舍五入取整方法
    print(int(total_profit + 0.5))

if __name__ == "__main__":
    solve()
```

### 4. 知识点总结

1.  **贪心算法 (Greedy Algorithm)**：
    *   这道题不需要动态规划（背包问题），因为每个产品投资的金额是连续的（或者说可以任意分配，只要不超过 $y$），所以我们直接选收益率最高的即可。
  
2.  **数据过滤与排序**：
    *   利用 `if r <= x` 进行初步筛选。
    *   利用 `sort(reverse=True)` 进行优先级排序。

3.  **浮点数处理与精度**：
    *   收益计算涉及 `e / 100.0`，会产生浮点数。
    *   **四舍五入技巧**：在编程中，由于 `round()` 函数在某些语言（如 Python）中采用“奇入偶舍”，最稳妥的四舍五入到整数的方法是 `int(x + 0.5)`。

4.  **边界处理**：
    *   如果符合条件的产品很少，总投资金额可能达不到 $m$。
    *   如果符合条件的产品很多，总投资金额会受限于 $m$。代码中的 `min(y, remaining_budget)` 完美处理了这两种情况。
