给定一个正整数 n，如果能够分解为 m (m > 1) 个连续正整数之和，请输出所有分解中，m最小的分解。
如果给定整数无法分解为连续正整数，则输出字符串"N"。

**输入描述**
输入数据为一整数，范围为 (1,2^30]
**输出描述**
比如输入为:
21
输出:
21=10+11

示例1：
输入

21
输出
21=10+11
21可以分解的连续正整数组合的形式有多种
说明
21=1+2+3+4+5+6

21=6+7+8

21=10+11
其中 21=10+11，是最短的分解序列。

---

这道题的核心是数学中的**等差数列求和**。

### 1. 数学原理
假设正整数 $n$ 可以分解为 $m$ 个连续正整数之和，设起始数字为 $a$（$a \ge 1$），则这 $m$ 个数为 $a, a+1, \dots, a+m-1$。
它们的和为：
$$n = \frac{m}{2} \times (a + (a + m - 1)) = \frac{m(2a + m - 1)}{2}$$
整理得：
$$2n = m(2a + m - 1)$$

令 $f_1 = 2a + m - 1$，$f_2 = m$，则有：
1. $f_1 \times f_2 = 2n$（即 $f_1$ 和 $f_2$ 是 $2n$ 的一对因子）。
2. $f_1 - f_2 = (2a + m - 1) - m = 2a - 1$。由于 $a \ge 1$，所以 $2a - 1$ 是一个**正奇数**。
3. 由 $2a - 1 \ge 1$ 可知 $f_1 > f_2$。

**结论：**
要找到 $n$ 的分解，只需要找到 $2n$ 的一对因子 $(f_1, f_2)$，满足 $f_1 > f_2$ 且两者的**奇偶性不同**（这样它们的差才是奇数）。
在这种情况下，分解的长度就是 $m = f_2$，起始数字 $a = \frac{f_1 - f_2 + 1}{2}$。

**最小的 $m$：**
我们要使 $m$ 最小且 $m > 1$，只需从 $m = 2$ 开始从小到大遍历 $2n$ 的因子，找到第一对满足“奇偶性不同”且“起始数字 $a \ge 1$”的因子即可。

### 2. 算法步骤
1. 计算 $2n$。
2. 遍历 $m$ 从 2 到 $\sqrt{2n}$（更精确的上限是使 $a=1$ 时的 $m$ 值，即 $m < \sqrt{2n}$）：
   - 如果 $2n$ 能被 $m$ 整除，设 $f_2 = m, f_1 = 2n/m$。
   - 检查 $f_1$ 和 $f_2$ 是否奇偶性不同（即 $f_1 - f_2$ 是奇数）。
   - 如果满足，则找到了最小的 $m$。
   - 计算 $a = (f_1 - f_2 + 1) / 2$。
   - 输出结果并退出。
3. 如果遍历结束仍未找到，输出 "N"。

### 3. Python 代码实现
由于 $n \le 2^{30}$，$\sqrt{2n} \approx 46340$，循环次数很少，执行效率非常高。

```python
import sys

def solve():
    # 读取输入
    line = sys.stdin.readline().strip()
    if not line:
        return
    n = int(line)

    # 2n = m * (2a + m - 1)
    # 令 f2 = m, f1 = 2a + m - 1
    target = 2 * n
    
    # 因为 a >= 1, 所以 f1 >= m + 1，即 m < sqrt(2n)
    # 最大的 m 出现在 a=1 时：m^2 + m - 2n = 0
    max_m = int(((1 + 8 * n)**0.5 - 1) / 2)
    
    found_m = -1
    found_a = -1
    
    # 寻找最小的 m (m > 1)
    for m in range(2, max_m + 1):
        if target % m == 0:
            f2 = m
            f1 = target // m
            # f1 和 f2 必须一奇一偶
            if (f1 - f2) % 2 == 1:
                found_m = m
                found_a = (f1 - f2 + 1) // 2
                break # 找到最小的 m 立即退出
                
    if found_m == -1:
        print("N")
    else:
        # 构造连续正整数序列
        result = [str(found_a + i) for i in range(found_m)]
        print(f"{n}=" + "+".join(result))

if __name__ == "__main__":
    solve()
```

### 4. 示例说明
*   **输入 `21`：**
    - $2n = 42$。
    - $m=2$：$42 \div 2 = 21$。$21$ 与 $2$ 奇偶性不同，满足。
    - $a = (21 - 2 + 1) / 2 = 10$。
    - 输出 `21=10+11`。
*   **输入 `8`：**
    - $2n = 16$。
    - $m=2$：$16 \div 2 = 8$。同为偶数，不满足。
    - $m=3$：不能整除。
    - $m=4$：$16 \div 4 = 4$。同为偶数，不满足。
    - 遍历结束，输出 `N`。（注：2的幂次方无法分解为连续正整数和）

如果有数学推导比较少的解法，我们可以用**“平均分配”**的直观逻辑来思考。

### 1. 直观思路：平均分派
假设我们要把数字 `n` 拆分成 `m` 个连续的正整数。我们可以想象有 `m` 个抽屉，我们想往里面放连续的数字。

1. **基础分：** 既然是 `m` 个连续正整数，那么最基础的连续序列就是 `1, 2, 3, ..., m`。
2. **计算基础和：** 这 `m` 个基础数字的和是 `base_sum = (1 + m) * m / 2`。
3. **计算多出来的量：** 如果 `n` 比这个 `base_sum` 大，说明我们可以把多出来的部分平均分配到这 `m` 个数字上。
   - 比如 `n = 21`, `m = 2`。
   - 基础序列：`1, 2`，和为 `3`。
   - 多了多少？`21 - 3 = 18`。
   - 能不能平分给这 2 个数字？`18 / 2 = 9`，可以整除！
   - 所以每个数字加 9：`1+9, 2+9` -> `10, 11`。得到 `21 = 10 + 11`。

### 2. 算法规则（极其简单）
1. 我们要找**最小**的 `m`（且 `m > 1`），所以我们让 `m` 从 2 开始往后数。
2. 对于每一个 `m`：
   - 先算前 `m` 个正整数的和：`base_sum = m * (m + 1) / 2`。
   - 如果这个 `base_sum` 已经超过了 `n`，说明 `m` 太大了，以后都不可能找到了，直接退出循环输出 "N"。
   - 看看 `n - base_sum` 是不是能被 `m` 整除：
     - 如果能整除（`(n - base_sum) % m == 0`），恭喜你找到了！
     - 计算偏移量 `k = (n - base_sum) // m`。
     - 最终的序列就是 `1+k, 2+k, ..., m+k`。
3. 停止寻找，输出结果。

### 3. Python 代码实现

```python
import sys

def solve():
    line = sys.stdin.readline().strip()
    if not line:
        return
    n = int(line)

    # 从长度 m = 2 开始尝试
    m = 2
    while True:
        # 1. 计算长度为 m 的最小连续正整数之和 (1+2+...+m)
        base_sum = m * (m + 1) // 2
        
        # 2. 如果最小的和都超过了 n，后面更不可能了
        if base_sum > n:
            print("N")
            break
        
        # 3. 检查剩余的部分 (n - base_sum) 是否能平分给这 m 个位置
        if (n - base_sum) % m == 0:
            # 找到了最短的 m！
            k = (n - base_sum) // m
            # 实际的起始数字就是 1 + k
            start_num = 1 + k
            
            # 构造输出格式：n=a+b+c
            res = []
            for i in range(m):
                res.append(str(start_num + i))
            print(f"{n}=" + "+".join(res))
            break
            
        # 4. 尝试下一个长度
        m += 1

if __name__ == "__main__":
    solve()
```

### 4. 为什么这个解法好理解？
*   **不写复杂的数学公式**：它其实是在模拟“填格子”。比如 $n=21, m=3$：
    - 先在 3 个格子里放 `1, 2, 3`，总和是 6。
    - 离 21 还差 `21 - 6 = 15`。
    - 把 15 平均分给 3 个格子，每个格子加 5。
    - 结果就是 `1+5, 2+5, 3+5` 即 `6, 7, 8`。
*   **性能依然很高**：虽然 $n$ 最大是 $2^{30}$，但 `base_sum` 是按 $m^2$ 增长的，所以循环最多跑约 45000 次，计算机瞬间就能算完。
*   **自动满足最小 m**：因为我们是从 $m=2$ 递增检查的，第一个撞上的肯定就是最短的序列。
