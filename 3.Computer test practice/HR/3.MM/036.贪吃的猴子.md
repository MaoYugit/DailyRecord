一只贪吃的猴子，来到一个果园，发现许多串香蕉排成一行，每串香蕉上有若干根香蕉。每串香蕉的根数由数组numbers给出。猴子获取香蕉，每次都只能从行的开头或者未尾获取，并且只能获取N次，求猴子最多能获取多少根香蕉。
**输入描述**
第一行为数组numbers的长度
第二行为数组numbers的值每个数字通过空格分开
第三行输入为N，表示获取的次数
**输出描述**
按照题目要求能获取的最大数值

**示例1**
输入
7
1 2 2 7 3 6 1

3
输出
10

**示例2**

输入
3
1 2 3
3

输出
6

说明
全部获取所有的香蕉，因此最终根数为1+2+3 = 6

**示例3：**

输入
4
4 2 2 3
2

输出
7

说明
第一次获取香蕉为行的开头，第二次获取为行的末尾，因此最终根数为4+3 =7



### 题目分析

1.  **核心规则**：
    *   你只能从数组的**开头**或者**末尾**拿香蕉。
    *   总共只能拿 $N$ 次。
    *   目标是让拿到的香蕉总数最大。

2.  **解题思路**：
    *   假设我们从左边拿了 $i$ 个，那么剩下的 $N-i$ 个就必须从右边拿。
    *   $i$ 的取值范围是从 $0$ 到 $N$。
    *   我们可以先假设全部从左边拿（即 $i=N$），算出总和。
    *   然后，我们通过“退还”左边最后一个拿到的，并“换成”右边最后一个，来计算新的总和。
    *   在所有可能的情况（从左边拿 $N, N-1, ..., 0$ 个）中，记录最大的那个总和。

### 代码实现 (Python)

```python
import sys

def solve():
    # 读取所有输入数据
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    # 1. 解析输入
    # 数组长度
    length = int(input_data[0])
    # 香蕉数组
    numbers = [int(x) for x in input_data[1:1+length]]
    # 获取次数 N
    n = int(input_data[1+length])
    
    # 2. 边界处理：如果次数 N 大于等于总串数，直接全拿
    if n >= length:
        print(sum(numbers))
        return

    # 3. 初始方案：先假设全部取左边的前 N 个
    # 例如：numbers = [1, 2, 2, 7, 3, 6, 1], N = 3
    # 初始 current_sum = 1 + 2 + 2 = 5
    current_sum = sum(numbers[:n])
    max_sum = current_sum
    
    # 4. 尝试替换：把左边的拿掉，换成右边的
    # 循环 n 次，每次把左边最靠近中间的那个“退掉”，换成右边最末尾的一个
    for i in range(1, n + 1):
        # 移除左边第 (n-i) 个下标的元素
        # 加入右边倒数第 i 个元素（下标为 length - i）
        current_sum = current_sum - numbers[n - i] + numbers[length - i]
        
        # 更新最大值
        if current_sum > max_sum:
            max_sum = current_sum
            
    # 5. 输出结果
    print(max_sum)

if __name__ == "__main__":
    solve()
```

### 示例逻辑推演

以 **示例1** 为例：`numbers = [1, 2, 2, 7, 3, 6, 1]`, `N = 3`

1.  **初始状态** (全取左边)：
    *   取出：`[1, 2, 2]`，`current_sum = 5`。
    *   此时 `max_sum = 5`。

2.  **第一次循环** (取左边2个，右边1个)：
    *   去掉左边的 `2`（下标2），加上右边的 `1`（下标6）。
    *   取出：`[1, 2]` + `[1]`，`current_sum = 5 - 2 + 1 = 4`。
    *   `max_sum` 仍为 5。

3.  **第二次循环** (取左边1个，右边2个)：
    *   去掉左边的 `2`（下标1），加上右边的 `6`（下标5）。
    *   取出：`[1]` + `[6, 1]`，`current_sum = 4 - 2 + 6 = 8`。
    *   更新 `max_sum = 8`。

4.  **第三次循环** (取左边0个，右边3个)：
    *   去掉左边的 `1`（下标0），加上右边的 `3`（下标4）。
    *   取出：`[]` + `[3, 6, 1]`，`current_sum = 8 - 1 + 3 = 10`。
    *   更新 `max_sum = 10`。

**最终输出：10**。

### 为什么这个方法高效？
*   **时间复杂度**：$O(N)$。我们只需要遍历 $N$ 次替换过程，不需要穷举所有组合。
*   **空间复杂度**：$O(1)$。除了存储输入数组外，只使用了几个变量进行求和计算。
