模拟AP安装，将AP的位置投影到二维坐标系中，给出每个AP的WIFI信号强度，信号强度会随着距离的增加而减弱。

**给定:** 

第一行是2个整数N,D(N<=100,D<=100)，其中N表示AP数量，D表示AP能够的信号能够覆盖的最大距离。

接下来的N行里，每行包含3个整数x,y,s，表示这个AP在坐标系的位置为(x,y)，x,y>0，信号强度为s。

所有坐标点是在X-Y坐标系内的整数坐标。

为了简化计算，两个坐标之间的距离用切比雪夫距离表示(在二维空间内，两个点之间的切比雪夫距离为它们横坐标之差的绝对值与纵坐标之差的绝对值的最大值)

需要你计算WIFI信号最好的坐标，

信号衰减计算方式: 如果第i个AP能到达(x,y)，那么该AP在此处的信号为 [s/(1+d)」(向下取整)，d表示这个AP跟此坐标的切比雪夫距离。一个坐标的信号强度是所有能到达该坐标的AP的信号强度之和。

**输入描述**
第一行是2个整数N,D(N<=100,D<=100)，其中N表示AP数量，D表示AP能够的信号能够覆盖的最大距离 接下来N行，每行包含3个整数

x,y,s，表示这个AP在坐标系的位置为(x,y)，x,y>0，信号强度为s

**输出描述**
WIFI信号最好的坐标，如果存在多个信号一致的坐标，输出字典序最小的非负坐标 坐标(x1,y1)字典序比另一个坐标(x2,y2)小，需满足以下条件之一:
要么 x1<x2, 要么x1==x2 且y1<y2

**示例1：**

输入：

3 2
1 2 3
2 1 3
3 1 3

输出：

1 2

**说明：**

坐标[1,2]处的wifi信号最好



这道题是一道典型的**二维网格模拟题**。它的核心在于处理“信号叠加”和“切比雪夫距离”。

### 1. 核心知识点：切比雪夫距离与网格模拟

*   **切比雪夫距离 (Chebyshev Distance)**：
    在二维坐标系中，两点 $(x_1, y_1)$ 和 $(x_2, y_2)$ 的切比雪夫距离为：
    $$d = \max(|x_1 - x_2|, |y_1 - y_2|)$$
    这意味着一个 AP 覆盖的范围实际上是以 $(x, y)$ 为中心，边长为 $2D$ 的**正方形**。

*   **信号计算**：
    只有当距离 $d \le D$ 时，AP 才会贡献信号。贡献值为 $\lfloor s / (1 + d) \rfloor$。

*   **搜索范围优化**：
    由于 $N$ 和 $D$ 的范围较小（均为 100），我们不需要遍历整个无限大的坐标系。最好的信号点一定出现在某个 AP 的覆盖范围内。我们可以使用一个**字典（Hash Map）**来存储每一个被覆盖到的坐标点的总信号强度。

### 2. 解题思路

1.  **数据读取**：获取 $N, D$ 和每个 AP 的坐标及强度。
2.  **信号累加**：
    *   遍历每一个 AP。
    *   对于每一个 AP，计算它覆盖的正方形区域（即 $x \in [x_i-D, x_i+D]$，$y \in [y_i-D, y_i+D]$）。
    *   在该范围内，计算每个点到 AP 的切比雪夫距离 $d$。
    *   将计算出的信号强度累加到该点的坐标上。
3.  **寻找最优坐标**：
    *   遍历字典中记录的所有坐标点。
    *   找到信号强度最大的点。
    *   如果有多个点强度相同，按照 $x$ 从小到大、$y$ 从小到大的顺序（字典序）选择最小的。

### 3. 题解代码 (Python)

```python
import sys

def solve():
    # 1. 输入处理
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0])
    d_max = int(input_data[1])
    
    aps = []
    ptr = 2
    for _ in range(n):
        x = int(input_data[ptr])
        y = int(input_data[ptr+1])
        s = int(input_data[ptr+2])
        aps.append((x, y, s))
        ptr += 3

    # 2. 信号叠加计算
    # 使用字典存储 (x, y) -> 累计信号强度
    # 这样只处理有信号的区域，节省空间和时间
    signal_map = {}

    for ax, ay, s in aps:
        # 该AP覆盖范围是 [ax-d_max, ax+d_max] x [ay-d_max, ay+d_max]
        for nx in range(max(0, ax - d_max), ax + d_max + 1):
            for ny in range(max(0, ay - d_max), ay + d_max + 1):
                # 计算切比雪夫距离
                dist = max(abs(nx - ax), abs(ny - ay))
                if dist <= d_max:
                    strength = s // (1 + dist)
                    if strength > 0:
                        pos = (nx, ny)
                        signal_map[pos] = signal_map.get(pos, 0) + strength

    # 3. 寻找最优坐标
    max_s = -1
    best_x, best_y = -1, -1

    # 遍历所有被信号覆盖过的点
    for (x, y), total_s in signal_map.items():
        if total_s > max_s:
            max_s = total_s
            best_x, best_y = x, y
        elif total_s == max_s:
            # 字典序比较：如果信号相同，取 x 较小的；若 x 相同，取 y 较小的
            if x < best_x or (x == best_x and y < best_y):
                best_x, best_y = x, y

    # 4. 输出结果
    if best_x != -1:
        print(f"{best_x} {best_y}")

if __name__ == "__main__":
    solve()
```

### 4. 评价与应试考点

*   **时间复杂度分析**：
    *   共有 $N$ 个 AP，每个 AP 覆盖区域约为 $(2D+1) \times (2D+1)$。
    *   总计算次数约为 $100 \times 201 \times 201 \approx 4 \times 10^6$。
    *   在 Python 中，400万次循环大约耗时 0.5~1.0 秒，完全符合大多数机考 1-2 秒的限制。

*   **字典序逻辑**：
    代码中 `elif total_s == max_s` 部分的处理非常重要。题目要求“字典序最小”，即先看 $x$ 再看 $y$。如果你是用双重循环遍历 $x, y$ 的，其实可以直接按照 $x$ 递增、$y$ 递增的顺序找，第一个遇到的最大值就是答案。

*   **空间复杂度**：
    使用字典（Map）而不是二维数组。如果 AP 的坐标非常分散（比如一个在 1，一个在 10000），二维数组 `grid[10000][10000]` 会造成内存溢出。**字典只记录有信号的点**，是更通用的做法。

### 5. 建议
这类“信号覆盖/辐射”类的题目在机考中很常见，务必掌握以下两点：
1.  **距离定义**：看清是**欧几里得距离**（勾股定理）、**曼哈顿距离**（$|x1-x2|+|y1-y2|$）还是**切比雪夫距离**。
2.  **边界处理**：坐标不能为负数，所以 `max(0, ax - d_max)` 是一个防错细节。



```python
import sys


def solve():
    try:
        # 读取第一行数据
        line1 = sys.stdin.readline().strip().split()
        if not line1:
            return
        # AP 数量
        n = int(line1[0])
        # AP 信号最远距离
        d_max = int(line1[1])

    except ValueError:
        return

    # 存储信号的字典方便查找
    # key: (x, y) 坐标
    # value: 信号强度总和
    signal_map = {}

    # 遍历读取剩余 n 行读取 AP 信息
    for i in range(n):
        # 读取
        line = sys.stdin.readline().strip().split()
        x = int(line[0])  # x 坐标
        y = int(line[1])  # y 坐标
        s = int(line[2])  # 信号强度

        # 计算当前 AP 对周围的影响

        # 真实的信号范围
        # 虽然最大距离是 d_max，但是根据公式 s // (1 + d) 当实际距离大于 s-1 的时候就没信号了
        # 所以对于每个 AP 信号最远的距离应该是 s-1 和 d_max 中较小的那一个
        real_s = min(s - 1, d_max)

        # 遍历正方形区域（切比雪夫距离的特性）
        # 这里的 dx, dy 是相对于 AP 位置的偏移量
        for dx in range(-real_s, real_s + 1):
            for dy in range(-real_s, real_s + 1):
                nx = x + dx
                ny = y + dy

                if nx < 0 or ny < 0:
                    continue

                # 切比雪夫距离
                distance = max(abs(dx), abs(dy))

                # 计算信号强度
                strength = s // (1 + distance)

                if strength > 0:
                    if (nx, ny) in signal_map:
                        signal_map[(nx, ny)] += strength
                    else:
                        signal_map[(nx, ny)] = strength

    # 遍历字典，找出最佳坐标

    # 初始化
    best_x = 0
    best_y = 0
    max_signal = 0

    # signal_map.items() 返回的是 [(坐标, 强度), (坐标, 强度)...]
    for pos, val in signal_map.items():
        cx = pos[0]
        cy = pos[1]

        # 情况1：发现更强的信号
        if val > max_signal:
            max_signal = val
            best_x = cx
            best_y = cy

        # 情况2：信号强度一样，比较坐标（字典序）
        # 题目要求：x 小的优先；x 一样的话，y 小的优先
        elif val == max_signal:
            if cx < best_x:
                best_x = cx
                best_y = cy
            elif cx == best_x and cy < best_y:
                best_x = cx
                best_y = cy

    # --- 第六步：输出结果 ---
    print(f"{best_x} {best_y}")

if __name__ == '__main__':
    solve()
```
