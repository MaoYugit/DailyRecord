在一个网络文件存储系统中，有众多的文件按照不同的文件夹进行分类存储。现在要对这些文件进行整理排序，以便便于快速地查找特定文件。

每个文件都有一个创建的时间戳(用整数标识，代表从特定时刻到文件创建时所经历的秒数)，并且文件夹之间存在层级关系。

现要求实现一个函数，对给定地某个文件夹下的所有文件(包含子文件夹中的文件)按照创建时间戳进行排序，可采用你熟悉的排序算法。

**输入描述**

首先输入一个整数n，表示接下来要输入的文件及文件夹信息的行数。

然后输入一指定文件夹的名称，用于说明获取哪个文件夹下的全部文件，并进行排序;

最后逐行输入文件或文件夹信息，行数为第一句输入的整数n。

对于文件，每行格式为:文件名 创建时间戳;

对于文件夹，每行格式为:文件夹名 -1(-1表示这是一个文件夹)。

如果文件夹包含子文件或子文件夹，则在后序行中继续输入其内。通过缩进(四个短横线)表示层级关系(例如，子文件或子文件的信息相比其父文件夹缩进4个短线)。

**示例**
5
Documents
Documents -1
----file1.txt 1600000000
----file2.txt 1600000100
----SubFolder1 -1
--------file3.txt 1600002000

**输出描述**

输出排序后的文件列表，每行格式为:文件名 创建时间戳口，按照时间截从小到大进行排序
补充说明:文件和文件夹名称只会出现 A-Z  a-z 0-9和字符. 。不会出现特殊字符。不会出现相同时间戳的文件，不会出现重名的文件或文件夹。
如果文件系统中不存在该文件，则返回字符串"No file"

这道题考察的是**层级数据解析（树形结构模拟）**和**排序算法**。

### 1. 核心知识点：线性结构还原树形层级

题目给出的输入是线性的，但通过“缩进（四个短横线 `----`）”表达了树状关系。解析这种结构的关键在于：
1.  **深度计算**：通过统计行首 `-` 的数量除以 4，可以得到当前文件/文件夹的深度（Depth）。
2.  **范围判定**：当我们进入目标文件夹 `target_folder` 后，后续所有深度比它**大**的行，都属于它的子内容。一旦遇到一行深度**小于或等于**目标文件夹深度，则表示已经离开了该文件夹范围。

### 2. 解题思路

1.  **输入解析**：读取 $N$ 和目标文件夹名称。
2.  **遍历寻找**：
    *   计算当前行的深度 `depth`。
    *   判定当前行是文件（值 $\neq -1$）还是文件夹（值 $= -1$）。
    *   如果遇到了名称等于 `target_folder` 且值为 `-1` 的行，标记“进入目标区域”，并记录当前的深度 `target_depth`。
    *   在“目标区域”内，如果是文件，就将其文件名和时间戳存入列表。
    *   如果遇到深度 `depth <= target_depth` 的行（且不是目标文件夹本身），说明目标文件夹结束，退出采集。
3.  **排序输出**：对采集到的文件列表按时间戳升序排序。如果列表为空，输出 "No file"。

### 3. 题解代码 (Python)

```python
import sys

def solve():
    # 使用 splitlines 获取所有行，防止 read().split() 把带有空格的文件名切碎
    input_data = sys.stdin.read().splitlines()
    if not input_data:
        return
    
    # 第一行是 N，第二行是目标文件夹名
    n = int(input_data[0].strip())
    target_name = input_data[1].strip()
    
    # 获取接下来的 n 行数据
    tree_data = input_data[2 : 2 + n]
    
    result_files = []
    is_inside_target = False
    target_depth = -1
    
    for line in tree_data:
        if not line.strip():
            continue
            
        # 1. 计算深度：统计前导 '-' 的数量，每4个为一层
        content = line.lstrip('-')
        depth = (len(line) - len(content)) // 4
        
        # 2. 解析名称和值
        # 注意：文件名可能包含空格（视题目严谨度），通常 split() 即可
        parts = content.split()
        if len(parts) < 2:
            continue
        name = parts[0]
        val = int(parts[1])
        
        # 3. 逻辑判断
        # 如果当前在目标文件夹内部，但深度回退到了目标文件夹同级或更高级
        if is_inside_target and depth <= target_depth:
            # 如果这一行不是目标文件夹本身（防止第一行直接退出）
            if name != target_name:
                is_inside_target = False
        
        # 如果找到目标文件夹
        if name == target_name and val == -1:
            is_inside_target = True
            target_depth = depth
            continue # 文件夹本身不计入文件列表
            
        # 如果在目标区域内且是文件，记录下来
        if is_inside_target and val != -1:
            result_files.append((name, val))
            
    # 4. 排序与输出
    if not result_files:
        print("No file")
    else:
        # 按时间戳（索引1）从小到大排序
        result_files.sort(key=lambda x: x[1])
        for file_name, timestamp in result_files:
            print(f"{file_name} {timestamp}")

if __name__ == "__main__":
    solve()
```

### 4. 关键点拨

*   **关于 `sys.stdin.read().splitlines()`**：
    在处理带缩进或空格的题目时，`split()` 会把原本在一行的 `SubFolder1 -1` 拆成两个元素，而 `splitlines()` 会保留每一行的完整性，方便我们用 `lstrip('-')` 计算深度。
*   **边界条件（Example 2）**：
    如果目标文件夹下只有子文件夹，没有文件，`result_files` 将为空。这时必须输出 `No file`。
*   **排序效率**：
    Python 的 `sort` (Timsort) 效率极高，处理 $N=1000$ 级别的数据绰绰有余。
*   **误区提醒**：
    不要试图用字典来存储。虽然题目说“不会重名”，但树形结构中，不同层级可能有同名文件（尽管本题补充说明不会出现）。用**深度判定法**是最通用的处理层级文本的方案。

### 5. 复习建议
这种“模拟文件系统”的题目在机考中很常见，建议掌握以下变体：
1.  **求某文件夹的总大小**：累加所有子文件的 size。
2.  **求最深的文件路径**：用一个栈（Stack）维护当前路径。
3.  **查找特定后缀的文件**：在采集时增加 `if name.endswith('.txt')`。

import sys

def solve():
    try:
        line1 = sys.stdin.readline().strip()
        if not line1:
            return
        n = int(line1)
        target_document = sys.stdin.readline().strip()
    except ValueError:
        return

    file_list = []
    for i in range(n):
        line = sys.stdin.readline().strip()
        if line == target_document+ " -1":
            for j in range(i+1, n):
                file_line = sys.stdin.readline().strip()
                if not file_line.startswith("----"):
                    break
                cur_list = file_line.split()
                if cur_list[1] == "-1":
                    continue
                else:
                    cur_file_name = ""
                    for char in cur_list[0]:
                        if char == "-":
                            continue
                        else:
                            cur_file_name += char
                    file_list.append((cur_file_name, cur_list[1]))
        break

    if len(file_list) == 0:
        print("No file")
    file_list.sort(key=lambda x:x[1])

    for file_name, create_time in file_list:
        print(file_name, create_time)

if __name__ == '__main__':
    solve()
