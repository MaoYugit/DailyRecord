小明和朋友玩跳格子游戏，有 n 个连续格子，每个格子有不同的分数，小朋友可以选择以任意格子起跳，但是不能跳连续的格子，也不能回头跳； 

给定一个代表每个格子得分的非负整数数组，计算能够得到的最高分数。

**输入描述：**

给定一个数列，如: 1 2 3 1 

1 ≤ nums.length ≤ 100 

0 <= nums[i] <= 1000

**输出描述：**

输出能够得到的最高分，如: 4

示例1：

输入：

2 7 9 3 1

输出：

12

这道题是一道经典的动态规划（Dynamic Programming）题目，在算法界通常被称为**“打家劫舍”（House Robber）**问题。

### 题目分析

1.  **核心规则**：
    *   不能选择相邻的格子（即如果选了第 $i$ 个，就不能选第 $i-1$ 和第 $i+1$ 个）。
    *   只能往后跳（不能回头）。
    *   目标是总分最高。

2.  **解题思路（动态规划）**：
    *   假设 $dp[i]$ 表示跳到第 $i$ 个格子时能获得的最高分数。
    *   对于当前的第 $i$ 个格子，小明只有两种选择：
        1.  **跳入该格子**：那么他前一步一定不能在第 $i-1$ 个格子，所以最高分数是：**当前格子的分数 + 到达第 $i-2$ 个格子的最高分**，即 `nums[i] + dp[i-2]`。
        2.  **不跳入该格子**：那么他当前的最高分数就等于到达上一个格子的最高分，即 `dp[i-1]`。
    *   **状态转移方程**：`dp[i] = max(dp[i-1], nums[i] + dp[i-2])`

### 代码实现 (Python)

```python
import sys

def solve():
    # 1. 读取输入
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    # 将输入转化为整数数组
    nums = [int(x) for x in input_data]
    n = len(nums)
    
    # 2. 边界情况处理
    if n == 0:
        print(0)
        return
    if n == 1:
        print(nums[0])
        return
    
    # 3. 初始化 DP 数组
    # dp[i] 表示前 i 个格子能获得的最大分数
    dp = [0] * n
    
    # 初始状态
    dp[0] = nums[0]                   # 只有一个格子，必选
    dp[1] = max(nums[0], nums[1])     # 有两个格子，选分数高的那个
    
    # 4. 开始递推
    for i in range(2, n):
        # 决策：是不选当前格子(dp[i-1])，还是选当前格子并加上前前个格子的最大分(nums[i] + dp[i-2])
        dp[i] = max(dp[i-1], nums[i] + dp[i-2])
        
    # 5. 输出结果
    print(dp[n-1])

if __name__ == "__main__":
    solve()
```

### 空间优化版本（进阶）

在上面的代码中，我们发现 `dp[i]` 只和 `dp[i-1]` 以及 `dp[i-2]` 有关。因此，我们不需要开辟一个长度为 $n$ 的数组，只需要两个变量来记录之前的状态即可，这样可以将空间复杂度从 $O(N)$ 降低到 $O(1)$。

```python
def solve_optimized():
    input_data = sys.stdin.read().split()
    if not input_data: return
    nums = [int(x) for x in input_data]
    
    prev_max = 0 # 相当于 dp[i-2]
    curr_max = 0 # 相当于 dp[i-1]
    
    for x in nums:
        # 核心逻辑：当前的最高分 = max(不选当前, 选当前+前前个最高分)
        temp = curr_max
        curr_max = max(curr_max, prev_max + x)
        prev_max = temp
        
    print(curr_max)
```

### 示例模拟 (以 `2 7 9 3 1` 为例)

*   **第1步 (2)**：只能选 2。`curr_max = 2`, `prev_max = 0`
*   **第2步 (7)**：选 2 还是选 7？选 7。`curr_max = 7`, `prev_max = 2`
*   **第3步 (9)**：
    *   方案A：不选 9，得分为上一步的 7。
    *   方案B：选 9，加上前前步的 2，得分 11。
    *   取最大值：`curr_max = 11`, `prev_max = 7`
*   **第4步 (3)**：
    *   方案A：不选 3，得分为 11。
    *   方案B：选 3，加上前前步的 7，得分 10。
    *   取最大值：`curr_max = 11`, `prev_max = 11`
*   **第5步 (1)**：
    *   方案A：不选 1，得分为 11。
    *   方案B：选 1，加上前前步的 11，得分 12。
    *   取最大值：`curr_max = 12`

**最终输出：12**。这与示例输出完全一致。
