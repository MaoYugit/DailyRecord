一贫如洗的樵夫阿里巴巴在去砍柴的路上，无意中发现了强盗集团的藏宝地，藏宝地有编号从0~N的箱子，每个箱子上面贴有一个数字。
阿里巴巴念出一个咒语数字，查看宝箱是否存在两个不同箱子，这两个箱子上贴的数字相同，同时这两个箱子的编号之差的绝对值小于等于咒语数字，
如果存在这样的一对宝箱，请返回最先找到的那对宝箱左边箱子的编号，如果不存在则返回-1。

**输入描述:**
第一行输入一个数字字串，数字之间使用逗号分隔，例如: 1,2,3,1字串中数字个数>=1，<=100000; 每人数字值>=-100000，<=100000:第二行输入咒语数字，例如: 3，咒语数字>=1，<=100000

**输出描述:**
存在这样的一对宝箱，请返回最先找到的那对宝箱左边箱子的编号，如果不存在则返回-1

**示例1**

输入:
6,3,1,6

3
输出:

0
**示例2**

输入:
5, 6, 7, 5, 6,7

2
输出:

-1

---

这道题可以抽象为一个经典的“滑动窗口”或者“哈希表”问题。我们需要在给定的数组中寻找一对相同的数字，且它们的下标之差不超过 $k$。

### 算法思路

1.  **数据结构选择**：使用一个**哈希表（字典）**来记录每个数字**最近一次出现的位置（索引）**。
2.  **遍历过程**：
    *   从左到右遍历数组，记录当前数字为 `num`，当前索引为 `i`。
    *   检查哈希表中是否已经存在 `num`：
        *   如果存在，取出上一次出现的索引 `prev_idx`。
        *   判断 `i - prev_idx <= k` 是否成立。
        *   如果成立，说明找到了符合条件的宝箱对。因为我们是从左往右遍历的，第一个满足条件的 `i` 对应的 `prev_idx` 就是题目要求的“最先找到的那对宝箱左边箱子的编号”。
    *   无论是否满足条件，都要**更新**哈希表中 `num` 对应的索引为当前的 `i`（因为越往后的索引，越有可能与后面出现的相同数字满足距离限制）。
3.  **结果返回**：如果整个数组遍历完都没有找到符合条件的，返回 -1。

### Python 代码实现

```python
import sys

def solve():
    # 1. 处理输入
    # 第一行是逗号分隔的数字
    line1 = sys.stdin.readline().strip()
    if not line1:
        return
    
    try:
        nums = [int(x) for x in line1.split(',')]
        # 第二行是咒语数字 k
        k_line = sys.stdin.readline().strip()
        if not k_line:
            return
        k = int(k_line)
    except ValueError:
        return

    # 2. 哈希表记录数字最近出现的索引
    # key: 箱子上的数字, value: 该数字上一次出现的下标
    last_seen = {}
    
    # 3. 遍历数组寻找目标对
    for i, num in enumerate(nums):
        if num in last_seen:
            prev_idx = last_seen[num]
            # 检查下标之差绝对值是否 <= k
            if i - prev_idx <= k:
                # 找到最先出现的满足条件的对，返回左边索引
                print(prev_idx)
                return
        
        # 更新该数字的最新索引位置
        last_seen[num] = i
        
    # 4. 未找到满足条件的
    print("-1")

if __name__ == "__main__":
    solve()
```

### 复杂度分析

*   **时间复杂度**：$O(N)$。我们只需要对数组进行一次线性遍历。哈希表的插入和查询操作在平均情况下都是 $O(1)$ 的。
*   **空间复杂度**：$O(N)$。在最坏的情况下（数组中没有重复数字），哈希表需要存储所有 $N$ 个数字及其索引。

### 示例逻辑推演

**示例 1：**
输入：`6,3,1,6` 和 `3`
1.  `i=0, num=6`: 哈希表为空，存入 `{6: 0}`
2.  `i=1, num=3`: 哈希表无3，存入 `{6: 0, 3: 1}`
3.  `i=2, num=1`: 哈希表无1，存入 `{6: 0, 3: 1, 1: 2}`
4.  `i=3, num=6`: 哈希表已有6，取出 `prev_idx=0`。计算 `3 - 0 = 3`。
5.  `3 <= 3` 成立，输出 `0` 并结束。

**示例 2：**
输入：`5,6,7,5,6,7` 和 `2`
1.  `i=3, num=5` 时，发现 `prev_idx=0`，但 `3-0=3 > 2`，不满足，更新 `5: 3`。
2.  `i=4, num=6` 时，发现 `prev_idx=1`，但 `4-1=3 > 2`，不满足，更新 `6: 4`。
3.  以此类推，最终返回 `-1`。
