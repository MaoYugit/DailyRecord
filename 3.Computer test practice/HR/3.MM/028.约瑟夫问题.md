输入一个由随机数组成的数列（数列中每个数均是大于 0 的整数，长度已知），和初始计数值 m。

从数列首位置开始计数，计数到 m 后，将数列该位置数值替换计数值 m，

并将数列该位置数值出列，然后从下一位置从新开始计数，直到数列所有数值出列为止。

如果计数到达数列尾段，则返回数列首位置继续计数。

请编程实现上述计数过程，同时输出数值出列的顺序。

比如：输入的随机数列为：3,1,2,4，初始计数值 m=7，从数列首位置开始计数（数值 3 所在位置）

第一轮计数出列数字为 2，计数值更新 m=2，出列后数列为 3,1,4，从数值 4 所在位置从新开始计数

第二轮计数出列数字为 3，计数值更新 m=3，出列后数列为 1,4，从数值 1 所在位置开始计数

第三轮计数出列数字为 1，计数值更新 m=1，出列后数列为 4，从数值 4 所在位置开始计数

最后一轮计数出列数字为 4，计数过程完成。输出数值出列顺序为：2,3,1,4。

要求实现函数：

void array_iterate(int len, int input_array[], int m, int output_array[])

【输入】 int len：输入数列的长度； int intput_array[]：输入的初始数列 int m：初始计数值

【输出】 int output_array[]：输出的数值出列顺序

【返回】 无示例:

输入： int input_array[] = {3,1,2,4}，int len = 4， m=7

输出： output_array[] = {2,3,1,4}

---

这道题是**约瑟夫环（Josephus Problem）**的一个变种。与标准约瑟夫环不同的是，这里的报数上限 $m$ 会随着出列数值的变化而动态更新。

### 核心逻辑分析

1.  **起始位置**：从索引 `0` 开始报数。
2.  **报数规则**：
    *   当前位置算作报数的第 `1` 下。
    *   要报到第 `m` 下，意味着从当前索引向后移动 `m - 1` 步。
    *   由于是环形，移动后的索引为：`(当前索引 + m - 1) % 当前数组长度`。
3.  **出列与更新**：
    *   取出该位置的数值，记录到输出数组中。
    *   **更新 $m$**：将出列的数值赋值给 $m$。
    *   **更新下一轮起点**：在数组中删掉该元素后，原来该位置后面的元素会自动递补上来，所以下一轮报数的起始索引就是本次被删除元素的索引位置（如果删的是末尾，则回到开头）。

### Python 代码实现

```python
def array_iterate(length, input_array, m, output_array):
    # 将输入数组转为 list 方便进行删除操作
    current_list = list(input_array)
    current_idx = 0
    
    while len(current_list) > 0:
        # 1. 计算要出列的元素索引
        # (当前位置 + 步进 m - 1) 对当前长度取模
        target_idx = (current_idx + m - 1) % len(current_list)
        
        # 2. 元素出列
        removed_value = current_list.pop(target_idx)
        output_array.append(removed_value)
        
        # 3. 更新计数值 m 为出列的数值
        m = removed_value
        
        # 4. 更新下一轮的起始索引
        # 因为 pop 操作后，后面的元素会自动补到 target_idx 位置
        # 所以 current_idx 直接设为 target_idx 即可
        current_idx = target_idx

# 示例调用
if __name__ == "__main__":
    input_arr = [3, 1, 2, 4]
    n = 4
    initial_m = 7
    output_arr = []
    
    array_iterate(n, input_arr, initial_m, output_arr)
    print("出列顺序为:", output_arr)
```

### 过程推导

1.  **初始**：`[3, 1, 2, 4]`, `m=7`, `idx=0`
    *   目标：`(0 + 7 - 1) % 4 = 2`
    *   出列：`input[2]` 即 **2**
    *   更新：`m=2`, 剩余 `[3, 1, 4]`, `idx=2` (指向数字 4)
2.  **第二轮**：`[3, 1, 4]`, `m=2`, `idx=2`
    *   目标：`(2 + 2 - 1) % 3 = 0`
    *   出列：`input[0]` 即 **3**
    *   更新：`m=3`, 剩余 `[1, 4]`, `idx=0` (指向数字 1)
3.  **第三轮**：`[1, 4]`, `m=3`, `idx=0`
    *   目标：`(0 + 3 - 1) % 2 = 0`
    *   出列：`input[0]` 即 **1**
    *   更新：`m=1`, 剩余 `[4]`, `idx=0` (指向数字 4)
4.  **第四轮**：`[4]`, `m=1`, `idx=0`
    *   目标：`(0 + 1 - 1) % 1 = 0`
    *   出列：`input[0]` 即 **4**
    *   完成。

**最终输出**：`2, 3, 1, 4`。符合题目要求。
