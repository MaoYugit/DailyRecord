给你一个整数数组 nums 和一个整数 k。如果某个连续子数组中恰好有 k 个奇数数字，我们就认为这个子数组是「优美子数组」。

请返回这个数组中 「优美子数组」 的数目。

**输入描述：**

第一行为逗号分割的正整数数组

第二行一个整数k

**输出描述：**

数组中 「优美子数组」 的数目

**示例 1**：

输入：
1,1,2,1,1
3
输出：
2
解释：包含 3 个奇数的子数组是 [1,1,2,1] 和 [1,2,1,1] 。

**示例 2：**

输入：
2,4,6
1
输出：
0
解释：数列中不包含任何奇数，所以不存在优美子数组。

**示例 3：**

输入：
2,2,2,1,2,2,1,2,2,2
2
输出：
16

```python
import sys


def solve():
    try:
        line1 = sys.stdin.readline().replace(',', ' ').strip().split()
        if not line1: return
        nums = list(map(int, line1))
        line2 = sys.stdin.readline().strip()
        if not line2: return
        k = int(line2)
    except EOFError:
        return

    # 2. 核心逻辑：前缀和统计
    # cnt[i] 表示到目前为止，奇数个数为 i 的路径出现了多少次
    cnt = [0] * (len(nums) + 1)
    cnt[0] = 1  # 初始：奇数为0个的情况出现了1次

    cur_odd = 0
    ans = 0

    for x in nums:
        if x % 2 != 0:
            cur_odd += 1

        # 如果当前奇数个数 >= k，那么 [cur_odd - k] 就是我们需要找的“左端点”
        if cur_odd >= k:
            ans += cnt[cur_odd - k]

        # 记录当前奇数个数出现的次数
        cnt[cur_odd] += 1

    print(ans)


if __name__ == '__main__':
    solve()
```
