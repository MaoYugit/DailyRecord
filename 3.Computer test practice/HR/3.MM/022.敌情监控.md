H国最近在和M国打仗，H国间谍头子Peter负责监视敌国M的兵力部署四情况。M国沿边境线布置了N个营地，Peter的任务就是监视这些营地的兵力部署情况。中

央情报局要研究敌情，所以Peter要汇报一段兵营中哪个连续的K个营地驻兵最少之和是多少，可以作为攻击的突破点，例如:"Peter、快汇报第2个营地到第10个营

地中H连续的3座兵营人数之和最少";而且每个营地的人数在不断变化。请你帮Peter设计一个程序，快速计算汇到的结果

**输入描述**

第一行3个正整数:N K L

N(N<=50000),表示敌人营地兵营的数量，每个营地编号为1,2,3..N.

K表示连续的兵营数,

L表示后续要问的命令数量;接下来有N个正整数，第i个正整数ai代表第i个营地里开始时有ai个人(1<=ai<=50000)

接下来有行有L条命令。

命令有3种形式:
(1) Add i j

i和j为正整数，表示第i个营地增加j个人(j不超过30)

(2)Sub i j

i和j为正整数，表示第i个营地减少j个人(j不超过30)

(3)Query i j

i和j为正整数,i<=j，表示询问问第i个营地到第j个营地，连续H个兵营人数之和最少的总人数其中: j-i+1>=K，每组数据最多有50条命令输出描述

对于每个Query询问，输出一个整数并回车，表示询问的该段中的连续的K座兵营人数之和最少的数量，这个数保持在int以内。

**示例1：**

输入：

5 2 3
1 2 2 3 3
Query 1 3
Add 3 6
Query 2 4


输出：

3

10

**说明：**

说明 第一行第一个正整数5，表示敌人有5个营地，第二个正整数2，表示连续营地 的数量是2，第3个正整数3，表示后续会有3条询问的命令;

接下来一行有 5个正整数，分别表示每个营地里开始的人数，第1个营地开始有1个人，第 2个营地开始有2个人，第3个营地开始有2个人，第4个营地开始有3个人，第5个营地开始有3个人;

接下来每行有一条命令:第1条命令:Query13表示要查询第1到第3个营地的总人数，结果:1+2=3第一个输出是:3

第2条命令:Add36表示第3个营地增加6个人无需输出

第3条命令:Query24表示查询第2到第4个营地的总人数，结果:2+8=10 第一个输出是:10，注意这里第3个营地人数在第2条命令中增加了6

```python
import sys

def solve():
    # 读取第一行参数
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    idx = 0
    N = int(input_data[idx]); idx += 1
    K = int(input_data[idx]); idx += 1
    L = int(input_data[idx]); idx += 1
    
    # 读取营地初始人数 (下标从1开始，所以前面补个0)
    camps = [0] + [int(x) for x in input_data[idx:idx+N]]
    idx += N
    
    # 处理命令
    for _ in range(L):
        cmd = input_data[idx]; idx += 1
        a = int(input_data[idx]); idx += 1
        b = int(input_data[idx]); idx += 1
        
        if cmd == 'Add':
            camps[a] += b
        elif cmd == 'Sub':
            camps[a] -= b
        elif cmd == 'Query':
            # 在区间 [a, b] 中找连续 K 个的最小和
            # 窗口起始位置范围: [a, b-K+1]
            
            # 1. 计算第一个窗口的和
            current_window_sum = sum(camps[a : a + K])
            min_sum = current_window_sum
            
            # 2. 滑动窗口寻找最小值
            # 窗口右边界从 a+K 开始直到 b
            for r in range(a + K, b + 1):
                # 减去旧的左边界 camps[r-K]，加上新的右边界 camps[r]
                current_window_sum = current_window_sum - camps[r - K] + camps[r]
                if current_window_sum < min_sum:
                    min_sum = current_window_sum
            
            print(min_sum)

solve()
```

```python
import sys

def solve():
    # 使用一次性读取，自动处理所有换行符和空格
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    ptr = 0
    # 1. 读取 N, K, L
    n = int(input_data[ptr]); ptr += 1
    k = int(input_data[ptr]); ptr += 1
    l = int(input_data[ptr]); ptr += 1

    # 2. 读取初始营地人数
    soldiers = []
    for _ in range(n):
        soldiers.append(int(input_data[ptr]))
        ptr += 1

    # 3. 处理 L 条命令
    for _ in range(l):
        op = input_data[ptr]; ptr += 1
        val1 = int(input_data[ptr]); ptr += 1
        val2 = int(input_data[ptr]); ptr += 1

        if op == "Add":
            # val1 是编号，val2 是增加的人数
            soldiers[val1 - 1] += val2
        
        elif op == "Sub":
            # val1 是编号，val2 是减少的人数
            soldiers[val1 - 1] -= val2
        
        elif op == "Query":
            # val1, val2 是查询的左右边界营地编号
            i_idx = val1 - 1
            j_idx = val2 - 1
            
            # 初始窗口：从 i_idx 到 i_idx + k - 1
            cur_sum = sum(soldiers[i_idx : i_idx + k])
            min_sum = cur_sum
            
            # 滑动窗口：从下一个位置开始，直到窗口右端点到达 j_idx
            # 窗口左端点最大移动到 j_idx - k + 1
            for start_idx in range(i_idx + 1, j_idx - k + 2):
                # 滑动更新：减去移出的左侧，加上新进的右侧
                cur_sum = cur_sum - soldiers[start_idx - 1] + soldiers[start_idx + k - 1]
                if cur_sum < min_sum:
                    min_sum = cur_sum
            
            # Python 的 print 自带回车
            sys.stdout.write(str(min_sum) + '\n')

if __name__ == "__main__":
    solve()
```
