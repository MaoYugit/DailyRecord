产品选代开发期间，会规划多个版本。现在有一批字符串，需要过滤出来合法的版本号，并将其整理为规范格式。

**合法版本号:** 

1. 完整的版本号由"V“版本，“R"版本，"C”版本，"B”版本构成。每个维度的版本只能出现一次。例如:"V001R025C010B013"。
2. B版本为非必填项，其他维度的版本为必填项。例如:"V001R025C010"。
3. 每个纬度的版本后的数字最少有1位，最多有3位。

**输入描述**

一个整数N，表示带整理版本号的个数，取值范围为[1,100)接下来N行，每行字符串是一个待整理的版本号(长度不能超过50)

**输出描述**

所有字母为大写，去除所有空格。如果某个维度版本的数字不满3位，则在前边补0 。各维度版本 按照V,R,C,B的顺序输出 去重后，按照字典序降序输出。如果全部为非法版本号，则返回-1

**示例1**

**输入**

7
v02 R20c1B 02
Vv02R1 c1
v2R20B 12c01
v2R20c01B12aB
v2 b002R2 0c0 1
v 0 2c101R20
v23B23R1     

**输出**

V002R020C101
V002R020C001B012
V002R020C001B002

说明
“Vv02R1 c1”、“2R20c01B12ab”、“v23B23R1"是非法的“v02 R20c1B 02"与“v2 b002R2 0c0 1”重复



这道版本号处理题是华为、大疆等企业上机考试中常见的**字符串模拟题**。它考查了字符串清洗、正则匹配（或逻辑解析）、补齐格式化以及自定义排序。

### 1. 核心知识点

1.  **字符串预处理**：利用 `upper()` 统一大小写，`replace(" ", "")` 去除所有空格。
2.  **逻辑校验**：
    *   **存在性**：V、R、C 必须出现且仅出现一次，B 最多出现一次。
    *   **合法性**：除了 V、R、C、B 和数字外，不能有其他字符。
    *   **约束性**：每个字母后的数字位数必须在 1~3 位之间。
3.  **格式化**：使用 `zfill(3)` 或 `"{:03d}".format()` 进行前导零补齐。
4.  **去重与排序**：使用 `set` 去重，使用 `sorted(reverse=True)` 进行字典序降序排列。

### 2. 题解代码 (Python)

```python
import sys

def parse_version(s):
    # 1. 预处理：转大写，去空格
    s = s.upper().replace(" ", "")
    
    # 定义合法字母
    valid_letters = "VRCB"
    
    # 检查是否包含非法字符
    for char in s:
        if char not in valid_letters and not char.isdigit():
            return None
            
    # 2. 解析各维度数字
    # 用字典记录每个维度出现的次数和对应的数字字符串
    counts = {}
    data = {}
    for key in valid_letters:
        counts[key] = 0
        data[key] = ""
    
    current_key = None
    for char in s:
        if char in valid_letters:
            current_key = char
            counts[char] += 1
            # 每个维度只能出现一次
            if counts[char] > 1:
                return None
        elif char.isdigit():
            # 数字必须跟在字母后面
            if current_key is None:
                return None
            data[current_key] += char
    
    # 3. 校验必填项 (V, R, C)
    if counts['V'] != 1 or counts['R'] != 1 or counts['C'] != 1:
        return None
    
    # 4. 校验数字位数 (1-3位)
    for key in valid_letters:
        if counts[key] == 1:
            num_str = data[key]
            if len(num_str) < 1 or len(num_str) > 3:
                return None
                
    # 5. 规范化格式：按 V-R-C-B 顺序拼接，数字补齐3位
    res = f"V{data['V'].zfill(3)}R{data['R'].zfill(3)}C{data['C'].zfill(3)}"
    if counts['B'] == 1:
        res += f"B{data['B'].zfill(3)}"
    
    return res

def solve():
    # 读取输入
    input_lines = sys.stdin.read().splitlines()
    if not input_lines:
        return
    
    try:
        n = int(input_lines[0].strip())
    except:
        return
        
    valid_versions = set()
    
    # 处理每一行
    for i in range(1, n + 1):
        if i >= len(input_lines): break
        ver = parse_version(input_lines[i])
        if ver:
            valid_versions.add(ver)
            
    # 6. 输出结果
    if not valid_versions:
        print("-1")
    else:
        # 字典序降序排列
        for v in sorted(list(valid_versions), reverse=True):
            print(v)

if __name__ == "__main__":
    solve()
```

### 3. 解题细节避坑指南

1.  **数字前导零**：题目要求补齐到3位。`"2".zfill(3)` 会变成 `"002"`。注意不要先转成 `int` 再转回 `str`，直接操作字符串或格式化输出最稳妥。
2.  **非法字符判断**：示例中 `v2R20c01B12aB` 因为含有 `a` 是非法的。在解析前先检查一遍整个字符串的组成成分非常重要。
3.  **顺序无关性**：输入可能是 `v2B1R1C1`（B在R前面），但输出必须规范为 `V...R...C...B...`。所以代码中采用字典存储，最后按固定顺序拼接。
4.  **去重**：示例 1 中两个不同的输入解析后是一样的，必须去重。使用 Python 的 `set` 数据结构可以自动处理。
5.  **空结果**：如果 $N$ 个版本号都校验失败，必须输出 `-1`。

### 4. 复习建议

这类题目在 600 题中属于“**字符串复杂模拟**”。
*   **练习重点**：学会如何优雅地拆分字符串。除了上面的遍历法，你也可以尝试学习 **正则表达式 (re模块)**，如 `re.findall(r'([VRCB])(\d+)', s)`，但逻辑校验依然是核心。
*   **上机技巧**：如果考试时逻辑太乱，先做简单的 `replace` 和 `upper`，拿到基础分。
