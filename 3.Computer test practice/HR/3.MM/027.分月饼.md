中秋节，公司分月饼，m个员工，买了n个月饼，m<=n，每个员工至少分1个月饼，但可以分多个，单人份到最多月饼的个数为Max1，单人分到第二多月饼的个数是Max2，Max1-Max2<=3,。同理，单人分到第n-1多月饼的个数是Max(n-1)，单人分到第n多月饼的个数是Max(n)，Max(n-1)-Max(n)<=3。请问有多少种分月饼的方法？

**输入描述：**

第一行输入m n，表示m个员工，n个月饼，m<=n

**输出描述：**

输出有多少种月饼分法

示例1：

输入：

2 4

输出：

2

说明：

4 = 1+3 （和3+1算一种分法）

4 = 2+2
共两种方案

---

我们可以手动使用一个**字典（Dictionary）**来实现记忆化缓存，或者直接编写带剪枝的递归函数。

在这个问题中，为了保证“1+3和3+1算一种”，我们约定员工分到的月饼数量是**按从小到大排序的**。

### 解题思路
1.  **非递减排列**：设 $m$ 个员工分到的月饼分别为 $a_1, a_2, \dots, a_m$，且满足 $a_1 \le a_2 \le \dots \le a_m$。
2.  **相邻约束**：根据题目，相邻排名的人月饼差值不超过 3，即 $a_{i+1} - a_i \le 3$。
3.  **递归参数**：
    *   `index`: 当前正在分第几个员工（从 0 到 $m-1$）。
    *   `last_val`: 上一个员工分到的数量（当前员工分到的必须 $\ge$ 这个值）。
    *   `current_sum`: 当前已经分出去的月饼总数。
4.  **剪枝（优化点）**：
    *   **下界**：当前员工最少要拿 `last_val` 个。
    *   **上界**：
        *   不能超过 `last_val + 3`（除非是第一个人）。
        *   剩下的月饼平摊到剩下的人头上，当前这个人不能拿超过“平均值”，否则后面的人为了保持非递减，总和一定会超过 $n$。

### Python 代码实现

```python
import sys

def solve():
    # 读取输入
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    m = int(input_data[0]) # 员工数
    n = int(input_data[1]) # 月饼总数

    # 基础情况判断
    if m > n:
        print(0)
        return
    if m == 1:
        print(1)
        return

    # 手动建立缓存字典，key 为 (当前员工索引, 上一人分配量, 已分配总量)
    memo = {}

    def backtrack(idx, last_val, current_sum):
        # 状态记录，如果计算过则直接返回结果
        state = (idx, last_val, current_sum)
        if state in memo:
            return memo[state]

        # 如果分到了最后一个员工
        if idx == m - 1:
            last_person_gets = n - current_sum
            # 最后一个人必须满足：
            # 1. 不少于前一个人
            # 2. 与前一个人差距不超过 3
            if last_person_gets >= last_val and last_person_gets <= last_val + 3:
                return 1
            else:
                return 0

        res = 0
        
        # 确定当前员工可以领取的月饼范围
        # 下限：不少于上一个人，且至少为 1
        lower = max(1, last_val)
        
        # 上限：
        # 1. 题目约束：如果是后续员工，不能比上一个多出 3
        # 2. 剩余总量约束：如果当前人拿 v 个，后面剩下 m-idx-1 人至少也得拿 v 个
        #    所以 v + (m-idx-1)*v <= (n - current_sum)
        upper = (n - current_sum) // (m - idx)
        
        if idx > 0:
            upper = min(upper, last_val + 3)

        # 遍历所有可能的选择
        for v in range(lower, upper + 1):
            res += backtrack(idx + 1, v, current_sum + v)
        
        # 记录缓存并返回
        memo[state] = res
        return res

    # 从第 0 个员工开始分，前一个人的参考值为 0，已分总量 0
    print(backtrack(0, 0, 0))

if __name__ == "__main__":
    solve()
```

### 代码关键点解释：

1.  **为什么 `upper = (n - current_sum) // (m - idx)`？**
    *   假设还剩 3 个人（包括当前这个），还剩 10 个月饼。
    *   如果当前这个人拿了 4 个，因为我们要求后面的人拿的必须 $\ge 4$，那么后面两个人都拿 4 个的话，总数 $4+4+4=12 > 10$，就不够分了。
    *   所以当前这个人最多只能拿 $10 \div 3 = 3$ 个。这就是最强力的“剪枝”，能极大地减少计算量。

2.  **为什么不直接写 `if current_sum == n`？**
    *   在分最后一个人的时候，由于总量是固定的，最后一个人拿多少是确定的（`n - current_sum`）。我们直接判断这个值是否合法即可，这样比再去跑一层循环效率更高。

3.  **字典 `memo` 的作用**：
    *   虽然这个题 $n, m$ 较小时不加缓存也能过，但在 $n$ 较大（如 100 以上）时，会出现很多重复的计算状态。
    *   例如：前两个员工分了 `(1, 4)` 剩 15 个，和前两个员工分了 `(2, 3)` 剩 15 个。对于第 3 个员工往后的分配来说，只要“上一个人分了多少”和“还剩多少”是一样的，结果就是一样的。缓存能把复杂度从指数级降下来。
