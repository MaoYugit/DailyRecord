一支攻城部队， 有若干种大炮各座， 以及数量有限的火药，每种大炮的威力不尽相同，且在每次开火之前都需要一定时间填充火药， 请你帮助指挥官在给定的时间结束之前或者火药存量耗尽之前给予城池最大的打击。

**约束：**

大炮每次开火的威力一样；
火药剩余量不小于大炮的消耗量，该大炮才能开火；
填充火药之外的时间忽略不计；
不同种大炮可以同时开火。

**输入描述**
第一行，整数 N ，M ，T ， N 表示大炮种类个数， M 表示火药数量， T 表示攻城时间，1 <= N,M,T<=1000。

接下来N 行，每一行三个整数A ， B ， C 。分别表示大炮的威力，大炮每次攻击消耗的火药量，大炮每次攻击填充火药的时间，0<=A,B,C <=100000。

**输出描述**
输出在给定的时间结束之前或者火药存量耗尽之前给予城池最大的打击。

**样例**
样例一：
**输入**

3 100 20
10 8 5
5 2 1
20 25 8
**输出**

160
**样例解释**

总共有 3 种大炮，火药存量 100 ， 攻城时间 20 ;

第 1 种大炮威力 10 ，每次攻击消耗火药 8 ，每次攻击填充火药时间 5 ；

第 2 种大炮威力 5 ，每次攻击消耗火药 2 ，每次攻击填充火药时间 1 ；

第 3 种大炮威力 20 ，每次攻击消耗火药 25 ，每次攻击填充火药时间 8 ；

样例二：
输入

2 10 10
1 1 1
2 2 2
输出

10
样例解释

总共有 2 种大炮，火药存量 10 ，攻城时间 10 ；

第 1 种大炮威力 1 ，每次攻击消耗火药 1 ，每次攻击填充火药时间 1 ；

第 2 种大炮威力 2 ，每次攻击消耗火药 2 ，每次攻击填充火药时间 2 ；

---

这道题是一个经典的算法建模题。通过分析题目约束，我们可以将其转化为计算机科学中非常著名的**“多重背包问题”（Bounded Knapsack Problem）**。

### 1. 核心知识点：多重背包问题

在这道题中，我们要“最大化打击威力”，这等同于背包问题中的“最大化价值”。

*   **背包容量**：火药总量 $M$。
*   **物品种类**：大炮的种类 $N$。
*   **物品重量**：每门大炮开火一次消耗的火药量 $B$。
*   **物品价值**：每门大炮开火一次产生的威力 $A$。
*   **物品数量限制**：这是关键！由于有时间限制 $T$ 和填充时间 $C$，每门大炮在规定时间内**最多能开火的次数**是有限的。
    *   开火次数 $K = \lfloor T / C \rfloor$（如果 $C=0$，则次数仅受火药量限制，可视为 $M/B$）。

**为什么是背包问题？**
题目提到“不同种大炮可以同时开火”，这意味着不同大炮之间不需要排队等待时间，它们唯一的共同约束是**共享火药库 $M$**。因此，我们的目标是在火药总量 $M$ 的限制下，从 $N$ 种大炮中选择每种大炮开火的次数（不超过 $K_i$），使得总威力最大。

---

### 2. 解题思路

1.  **计算限制条件**：对于每种大炮，计算它在时间 $T$ 内最多能开火几次：$count = T // C$。
2.  **二进制拆分优化**（进阶技巧）：
    *   如果直接把每门大炮的 $count$ 次开火看作 $count$ 个独立的物品，题目规模会变得很大（$1000 \times 1000$），计算会很慢。
    *   **技巧**：将 $count$ 个物品拆分成重量和价值为原物品 $1, 2, 4, 8...$ 倍的“打包组合”。例如，某种大炮能开火 7 次，我们可以把它拆成三个组合：开火 1 次的组合、开火 2 次的组合、开火 4 次的组合。通过这三个组合，我们可以凑出 1 到 7 之间的任何次数。
    *   这样可以把复杂度从 $O(M \cdot \sum count)$ 降到 $O(M \cdot \sum \log(count))$。
3.  **动态规划 (DP)**：使用一维数组 `dp[j]` 表示消耗 $j$ 份火药能获得的最大威力。

---

### 3. 题解代码 (Python)

```python
import sys

def solve():
    # 读取所有输入数据
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    ptr = 0
    N = int(input_data[ptr]); ptr += 1 # 大炮种类
    M = int(input_data[ptr]); ptr += 1 # 火药总量
    T = int(input_data[ptr]); ptr += 1 # 攻城时间

    # dp[j] 表示消耗 j 火药量能达到的最大威力
    dp = [0] * (M + 1)

    # 处理每一种大炮
    for _ in range(N):
        A = int(input_data[ptr]); ptr += 1 # 威力
        B = int(input_data[ptr]); ptr += 1 # 耗药
        C = int(input_data[ptr]); ptr += 1 # 填充时间

        # 1. 计算该大炮在时间内最多能开几次火
        if C == 0:
            # 如果填充时间为0，理论上只受火药限制，等同于完全背包
            # 这里为了统一处理，给它一个火药能支持的最大上限
            max_hits = M // B if B > 0 else M 
        else:
            max_hits = T // C
            
        if max_hits == 0 or A == 0:
            continue

        # 2. 二进制拆分：将 max_hits 拆分成 1, 2, 4, 8... 个大炮的组合
        k = 1
        items = []
        while k <= max_hits:
            items.append((k * A, k * B)) # (组合总威力, 组合总耗药)
            max_hits -= k
            k *= 2
        if max_hits > 0:
            items.append((max_hits * A, max_hits * B))

        # 3. 对拆分出的组合进行 0/1 背包更新
        for item_power, item_cost in items:
            for j in range(M, item_cost - 1, -1):
                if dp[j - item_cost] + item_power > dp[j]:
                    dp[j] = dp[j - item_cost] + item_power

    # 输出在 M 火药内能获得的最大威力
    print(dp[M])

if __name__ == '__main__':
    solve()
```

---

### 4. 为什么这样写能过机考？

1.  **输入处理**：使用 `sys.stdin.read().split()` 是最稳妥的，因为它不关心数据是换行还是空格分割，能处理各种变态的输入格式。
2.  **二进制拆分**：这是多重背包的标准优化手段。如果不做这个优化，直接写三重循环，在遇到 $T=1000, C=1$ 这种情况时，内部循环会跑 1000 次，总计算量过亿，Python 绝对会超时。
3.  **空间优化**：使用一维 `dp` 数组而不是二维数组，大大节省了内存（只需 1000 个长度的列表）。

### 5. 给你的复习建议
这道题属于**背包问题变形**。在你的 600 题计划中，建议重点掌握以下几种背包模型：
1.  **0/1 背包**：每种物品只能选一次（最基础）。
2.  **完全背包**：每种物品可以选无限次。
3.  **多重背包**：每种物品有数量限制（本题原型）。
4.  **分组背包**：好几组物品，每组只能选一个。

这道大炮题只要你能识别出“大炮开火次数是有上限的”以及“火药是共同资源”，就能联想到多重背包。加油！
