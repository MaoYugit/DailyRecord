实现一个简单的绘图模块，绘图模块仅支持矩形的绘制和擦除。

当新绘制的矩形与已有图形重叠时，对图形取并集；
当新擦除的矩形与已有图形重叠时，对图形取差集。
给定一系列绘制和擦除操作，计算最终图形的面积。
**输入描述**
第一行为操作数N，接下来的N行格式为：

d x1 y1 x2 y2：d表示绘制操作，(x1,y1)为矩形左上角坐标，(x2,y2)为右下角坐标；
e x1 y1 x2 y2：e表示擦除操作，坐标含义同上。
坐标均为整数且范围在[-100, 100]内，用例保证坐标有效性。
**输出描述**
输出最终图形的面积。

示例1
输入：

2  
d 0 2 2 0  
d -1 1 1 -1  
输出：
7

示例2
输入：

2  
d 0 2 2 0  
e -1 1 1 -1  
输出：
3

这道题的坐标范围非常小（从 -100 到 100），这是一个非常关键的信号。在算法面试中，当**坐标范围限定在几百以内**时，最简单、最稳妥的方法通常是**“像素网格法”（网格染色法）**。

### 1. 核心知识点：像素网格映射 (Grid Mapping)

我们不需要去算复杂的几何并集或差集公式。由于坐标是整数且范围小，我们可以把这块区域看作一个由 $1 \times 1$ 的小方格组成的网格。

*   **空间大小**：$x$ 从 -100 到 100，共 200 个单位长度；$y$ 也是 200 个单位。总共只有 $200 \times 200 = 40,000$ 个单位小方格。
*   **操作逻辑**：
    *   **绘制 (d)**：把矩形覆盖范围内的所有小方格标记为“有色”（例如设置为 1）。
    *   **擦除 (e)**：把矩形覆盖范围内的所有小方格标记为“无色”（例如设置为 0）。
*   **最终结果**：统计网格中标记为 1 的方格总数，即为面积。

### 2. 坐标映射技巧
由于数组索引不能是负数，我们将坐标统一加上 100 偏移量，使其映射到 $[0, 200]$ 的索引区间：
*   $x = -100 \rightarrow$ 索引 $0$
*   $x = 100 \rightarrow$ 索引 $200$

**注意**：一个从 $x_1$ 到 $x_2$ 的矩形，它覆盖的单位方格数量是 $|x_1 - x_2|$。例如，从 $x=0$ 到 $x=2$，覆盖的是索引为 $0$ 和 $1$ 的两个方格，不包括索引 $2$。

### 3. 题解代码 (Python)

```python
import sys

def solve():
    # 使用 sys.stdin.read().split() 批量读取所有输入，应对复杂的换行情况
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    N = int(input_data[0])
    # 初始化一个 200x200 的二维数组（网格），初始全部为 0
    # 范围 [-100, 100] 对应长度为 200
    grid = [[0] * 200 for _ in range(200)]
    
    ptr = 1
    for _ in range(N):
        op = input_data[ptr]
        x1 = int(input_data[ptr+1])
        y1 = int(input_data[ptr+2])
        x2 = int(input_data[ptr+3])
        y2 = int(input_data[ptr+4])
        ptr += 5
        
        # 归一化坐标，确保 x_start < x_end
        x_start, x_end = min(x1, x2), max(x1, x2)
        y_start, y_end = min(y1, y2), max(y1, y2)
        
        # 坐标偏移映射到 0-200 索引范围
        # 注意：矩形覆盖的是 [start, end) 的单位格子
        # 比如 x 从 0 到 2，填涂的是 grid[100] 和 grid[101]
        for i in range(x_start + 100, x_end + 100):
            # 为了提高 Python 性能，可以使用切片赋值
            fill_val = 1 if op == 'd' else 0
            # 这一行相当于 for j in range(y_start + 100, y_end + 100): grid[i][j] = fill_val
            grid[i][y_start + 100 : y_end + 100] = [fill_val] * (y_end - y_start)

    # 统计所有为 1 的方格数量
    total_area = sum(sum(row) for row in grid)
    print(total_area)

if __name__ == "__main__":
    solve()
```

### 4. 为什么这样写？（应试建议）

1.  **避开复杂的几何算法**：如果是大坐标（如 $0$ 到 $10^9$），必须用“扫描线”算法，那非常难写且容易出错。但这道题坐标只有 100，网格法是**开发效率最高、最不容易写错**的方法。
2.  **性能优化（切片赋值）**：在 Python 中，双重 `for` 循环（$40,000 \times N$）可能会比较慢。使用 `grid[i][start:end] = [...]` 这种切片赋值，是由 Python 底层 C 代码执行的，速度比普通循环快几十倍，足以通过所有测试用例。
3.  **鲁棒性**：题目给出了“左上角”和“右下角”，但为了保险，代码中使用了 `min()` 和 `max()` 重新确定边界，防止输入坐标顺序颠倒导致循环不执行。

### 5. 易错点总结
*   **边界问题**：矩形坐标从 $0$ 到 $2$，面积是 $2$。在循环中应该是 `range(0, 2)`，只包含索引 $0$ 和 $1$。
*   **偏移量**：记得所有坐标都要加 $100$，否则负数坐标会导致索引错误。
*   **擦除操作**：擦除不是减去面积，而是把该区域置为 $0$。如果该区域原本就是空的，擦除后依然是 $0$。

如果你在剩下的 600 题中遇到类似的**坐标范围小、涉及面积并集**的题目，请优先考虑这种“网格映射法”。
