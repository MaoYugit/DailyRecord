# [234. 回文链表](https://leetcode.cn/problems/palindrome-linked-list/)

简单

给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true` ；否则，返回 `false` 。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2021/03/03/pal1linked-list.jpg)

```
输入：head = [1,2,2,1]
输出：true
```

**示例 2：**

![img](https://assets.leetcode.com/uploads/2021/03/03/pal2linked-list.jpg)

```
输入：head = [1,2]
输出：false
```

**提示：**

- 链表中节点数目在范围`[1, 105]` 内
- `0 <= Node.val <= 9`

**进阶：**你能否用 `O(n)` 时间复杂度和 `O(1)` 空间复杂度解决此题？



```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        if not head or not head.next:
           return True
        # 用作复制链表
        dummy = ListNode(-1)
        tail = dummy
        cur = head

        # 用作反转链表
        pre = None

        while cur:
            # 1. 复制
            # 创建新节点
            new_node = ListNode(cur.val)
            # 凭借新节点
            tail.next = new_node

            tail = tail.next

            # 2. 反转
            next_node = cur.next
            cur.next = pre
            pre = cur
            cur = next_node

        while pre and dummy.next:
            if pre.val != dummy.next.val:
                return False
            pre = pre.next
            dummy.next = dummy.next.next
        return pre is None and dummy.next is None 

```

这是回文链表的**最优解**（空间复杂度 $O(1)$，时间复杂度 $O(N)$）。

### 核心思路：快慢指针 + 反转后半段

我们不使用额外的空间（不复制链表），而是直接在原链表上动手术：
1.  **找中点：** 使用**快慢指针**找到链表的中间位置。
2.  **反转：** 将链表的**后半段**原地反转。
3.  **对比：** 一个指针从头走，一个指针从后半段的头走，互相比较。
4.  *(可选)* **恢复：** 为了礼貌，比对完可以把链表再反转回去（LeetCode 不强制，但面试是加分项）。

### 最优解代码

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        # 0. 边界条件
        if not head or not head.next:
            return True
        
        # 1. 找中点 (快慢指针)
        # 循环结束时，slow 指针会停在链表的中间位置（如果是偶数，停在后半段的开头）
        slow = head
        fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            
        # 2. 反转后半段 (从 slow 开始反转)
        # 这段代码就是标准的反转链表逻辑
        prev = None
        curr = slow
        while curr:
            temp = curr.next
            curr.next = prev
            prev = curr
            curr = temp
        
        # 此时，prev 是反转后的后半段链表的头
        
        # 3. 前后半段对比
        p1 = head  # 前半段头
        p2 = prev  # 后半段头 (从末尾反向走)
        
        while p2: # 只要后半段没走完
            if p1.val != p2.val:
                return False
            p1 = p1.next
            p2 = p2.next
            
        return True
```

### 逻辑图解

假设链表：`1 -> 2 -> 3 -> 2 -> 1`

**Step 1: 找中点**
*   Slow 走到 `3`，Fast 走到 `1` (末尾)。

**Step 2: 反转后半段**
*   从 `3` 开始反转。
*   原链表变成：`1 -> 2 -> 3 <- 2 <- 1`
*   结构变成两条相交的线：
    *   左边：`1 -> 2 -> 3` (3指向None，或者此时被修改，具体看实现细节，通常为了方便，前半段尾巴连着也没事)
    *   右边（被反转）：`1 -> 2 -> 3` (这里的1是原来的尾巴，现在是 `p2` 头)

**Step 3: 对比**
*   `p1` 从左边头 `1` 开始。
*   `p2` 从右边头 `1` 开始。
*   `1 == 1`, `2 == 2`, `3 == 3`。
*   全部通过 -> `True`。

### 为什么这是最优解？

1.  **空间复杂度 $O(1)$：** 我们没有创建任何新节点（不像你刚才的方法需要复制整个链表），只用了几个指针变量。
2.  **时间复杂度 $O(N)$：** 找中点走 $N/2$，反转走 $N/2$，对比走 $N/2$。加起来还是 $O(N)$。

这是面试官最想看到的解法，因为它展示了你对**快慢指针**和**链表反转**的综合运用能力。
