# [1154. 一年中的第几天](https://leetcode.cn/problems/day-of-the-year/)

给你一个字符串 `date` ，按 `YYYY-MM-DD` 格式表示一个 [现行公元纪年法](https://baike.baidu.com/item/公元/17855) 日期。返回该日期是当年的第几天。

**示例 1：**

```
输入：date = "2019-01-09"
输出：9
解释：给定日期是2019年的第九天。
```

**示例 2：**

```
输入：date = "2019-02-10"
输出：1
```

**提示：**

- `date.length == 10`
- `date[4] == date[7] == '-'`，其他的 `date[i]` 都是数字
- `date` 表示的范围从 1900 年 1 月 1 日至 2019 年 12 月 31 日

```python
class Solution:
    def dayOfYear(self, date: str) -> int:
        month_day = {
            1: 31,
            3: 31,
            5: 31,
            7: 31,
            8: 31, 
            10: 31,
            12: 31,
            4: 30,
            6: 30,
            9: 30,
            11: 30
        }
        days = 0
        [year, month, day] = date.split('-')
        year = int(year)
        month = int(month)
        day = int(day)

        if month == 1:
            return day
        elif month == 2:
            return 31 + day
        else:
            for i in range(1, month):
                if i !=2:
                    days += month_day[i]
                else:
                    if((year%4 == 0 and year % 100 !=0) or (year % 400 == 0)):
                        days += 29
                    else:
                        days += 28
            return days + day
        
        
```





```python
class Solution:
    def dayOfYear(self, date: str) -> int:
        [year, month, day] = map(int, date.split('-'))
        count = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
        if year % 400 == 0 or (year % 4 == 0 and year % 100 != 0):
            count[2] += 1
        return sum(count[:month]) + day
```

### **sum(切片)**

`sum(列表[切片])` 是 Python 中非常高效且常用的技巧，特别是在需要**累加列表中的某一部分**时。

我们将这个操作拆解为两步来理解：
1.  **切片 (Slicing)**：先从大列表中“切”出一个小列表。
2.  **求和 (Summing)**：把这个小列表里的数字加起来。

---

**1. 核心语法解析**

假设有一个列表 `nums`：

```python
nums = [10, 20, 30, 40, 50]
# 索引： 0   1   2   3   4
```

**语法一：`sum(nums[:n])` —— 计算前 n 个数的和**

*   `nums[:n]` 表示从索引 `0` 开始，一直取到索引 `n`（**但不包含 n**）。
*   也就是取索引为 `0, 1, ..., n-1` 的元素。

**示例**：
```python
# 计算前 3 个数的和 (10 + 20 + 30)
print(sum(nums[:3])) 
# 过程：
# 1. nums[:3] 得到新列表 [10, 20, 30]
# 2. sum([10, 20, 30]) 得到 60
```

**语法二：`sum(nums[start:end])` —— 计算中间一段的和**

*   从索引 `start` 开始，取到 `end`（**不包含 end**）。

**示例**：
```python
# 计算第 2 个到第 3 个数的和 (20 + 30) -> 索引 1 到 3
print(sum(nums[1:3]))
# 过程：
# 1. nums[1:3] 得到 [20, 30]
# 2. sum(...) 得到 50
```

---

**2. 结合刚才的日期题目讲解**

在刚才的代码中，我们使用了这样一个技巧来计算“当前月份之前所有月份的总天数”：

```python
# 0是占位符，让索引1对应1月，索引2对应2月...
amount = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
# 索引：  0   1   2   3   4 ...

month = 4  # 假设现在是 4月15日
day = 15

# 我们想算：1月 + 2月 + 3月 的天数
# 对应的索引是 amount[1], amount[2], amount[3]
```

**代码操作 `sum(amount[:month])`**：

当 `month = 4` 时：
1.  **切片**：`amount[:4]`
    *   Python 会截取索引 `0, 1, 2, 3` 的元素。
    *   结果是：`[0, 31, 28, 31]`
2.  **求和**：`sum([0, 31, 28, 31])`
    *   计算结果：`0 + 31 + 28 + 31 = 90`

这样就直接得到了 4 月之前（1、2、3月）的总天数，非常简洁，避免了写 `for` 循环。

---

**3. 为什么要加占位符 `0`？**

如果不加占位符，列表是这样的：
```python
amount_no_zero = [31, 28, 31, 30, ...]
# 索引：            0   1   2   3
# 实际月份：        1月 2月 3月 4月
```

如果现在是 4月 (`month=4`)，我们需要加前 3 个月（索引 0, 1, 2）。
切片就需要写成：
`sum(amount_no_zero[:month-1])`  -> `[:3]`

**加了占位符的好处**：
*   索引和月份直接对齐（索引1就是1月）。
*   切片时直接用 `[:month]`，意思就是“取 `month` 索引之前的所有元素”，逻辑上更直观（正好包含 0 到 month-1，也就是 1月 到 month-1月，外加那个 0）。

**4. 总结**

*   **`nums[:i]`**：拿到列表的前 `i` 个元素。
*   **`sum(nums[:i])`**：快速计算列表前缀和（前 `i` 个元素的总和）。

这种写法是典型的 **Pythonic**（Python 风格）写法，比写 `for` 循环累加要快且易读。
