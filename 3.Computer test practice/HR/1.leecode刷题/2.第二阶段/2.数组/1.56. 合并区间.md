# [56. 合并区间](https://leetcode.cn/problems/merge-intervals/)

中等

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]` 。请你合并所有重叠的区间，并返回 *一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间* 。

**示例 1：**

```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
```

**示例 2：**

```
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。
```

**示例 3：**

```
输入：intervals = [[4,7],[1,4]]
输出：[[1,7]]
解释：区间 [1,4] 和 [4,7] 可被视为重叠区间。
```

**提示：**

- `1 <= intervals.length <= 104`
- `intervals[i].length == 2`
- `0 <= starti <= endi <= 104`











在 Python 中，可以使用 `sort()` 方法或者 `sorted()` 函数，配合 `key` 参数来实现按照特定位置的元素排序。

这里有几种方法，最常用的是使用 **Lambda 表达式**。

### 方法一：原地排序 (`sort`)
如果你想直接修改原数组，不创建新的数组，使用 `.sort()`。

```python
arr = [[2, 3], [1, 6], [4, 2], [1, 9]]

# key=lambda x: x[0] 表示：取出每个子列表的第 0 个元素作为排序依据
arr.sort(key=lambda x: x[0])

print(arr)
# 输出: [[1, 6], [1, 9], [2, 3], [4, 2]]
```

### 方法二：生成新数组 (`sorted`)
如果你想保留原数组不变，生成一个新的排序后的数组，使用 `sorted()`。

```python
arr = [[2, 3], [1, 6]]

new_arr = sorted(arr, key=lambda x: x[0])

print(new_arr) # 输出: [[1, 6], [2, 3]]
print(arr)     # 原数组没变: [[2, 3], [1, 6]]
```

### 深入理解：如果不写 key 会怎样？
在 Python 中，如果你直接写 `arr.sort()`，它默认会进行**字典序排序**。
也就是：**先比第一个数字，如果第一个数字相同，再比第二个数字**。

```python
arr = [[2, 1], [2, 0], [1, 5]]

# 默认排序
arr.sort() 
# 结果: [[1, 5], [2, 0], [2, 1]]
# 注意：[2, 0] 排在了 [2, 1] 前面，因为 0 < 1
```

如果你明确只想**“仅根据第一个数字排序，如果第一个数字一样，保持原来的相对顺序（不比第二个）”**，那么必须加上 `key=lambda x: x[0]`。

### 进阶：如果要倒序（从大到小）
加上 `reverse=True` 参数即可。

```python
arr = [[1, 6], [2, 3], [5, 1]]
arr.sort(key=lambda x: x[0], reverse=True)
print(arr)
# 输出: [[5, 1], [2, 3], [1, 6]]
```



```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort()
        new_arr = [intervals[0]]

        for i in range(1, len(intervals)):
            if intervals[i][0] <= new_arr[-1][1] and intervals[i][1] > new_arr[-1][1]:
                temp = new_arr[-1][0]
                new_arr.pop()
                new_arr.append([temp,intervals[i][1]])
            elif intervals[i][0] > new_arr[-1][1]:
                new_arr.append(intervals[i])
        return new_arr
                
        
```

**这段代码是可以提交通过的（Accepted）。**

你修复了之前致命的 `new_arr = new_arr.pop()` 赋值错误，现在的逻辑在功能上是正确的。

不过，这段代码虽然能跑通，但从**代码风格**和**运行效率**上来说，还不够完美。我们可以分析一下为什么它能跑通，以及哪里可以优化。

### 1. 为什么它是对的？（即使你少写了一个情况）

你的代码逻辑涵盖了两种情况：
1.  **部分重叠且延长** (`and intervals[i][1] > new_arr[-1][1]`)：
    *   例如 `[1, 5]` 和 `[2, 8]`。
    *   你的代码会执行合并：把 `[1, 5]` 换成 `[1, 8]`。
2.  **完全不重叠** (`elif intervals[i][0] > new_arr[-1][1]`)：
    *   例如 `[1, 5]` 和 `[6, 7]`。
    *   直接添加新区间。

**但是，你漏写了一种情况：**
*   **完全被包含**：例如 `[1, 10]` 和 `[2, 5]`。
    *   `if` 条件：`2 <= 10` (True) 但 `5 > 10` (False) -> **不进**。
    *   `elif` 条件：`2 > 10` (False) -> **不进**。
    *   **结果**：代码什么都不做，直接进入下一次循环。
    *   **为什么结果是对的？** 因为如果 `[2, 5]` 被 `[1, 10]` 包含，我们确实**不需要做任何操作**，保留 `[1, 10]` 就好了。所以这种“隐式忽略”恰好符合题目要求。

### 2. 可以优化的地方

虽然代码能用，但以下两点让它看起来不够“老练”：

#### A. `pop()` + `append()` 开销大
你先把最后一个元素删掉，再造一个新的加进去。这涉及到了内存的分配和回收。
**更好的做法**：直接修改最后一个元素的引用。
```python
# 你的写法
temp = new_arr[-1][0]
new_arr.pop()
new_arr.append([temp, intervals[i][1]])

# 优化写法（原地修改，更快）
new_arr[-1][1] = intervals[i][1]
```

#### B. 逻辑判断太复杂
你特意区分了“结束时间是否更大”，其实可以用 `max()` 函数一句话解决“包含”和“延长”两种情况。

### 3. 优化后的推荐写法

合并了你的逻辑，代码更短、更快、更清晰：

```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort()
        new_arr = [intervals[0]]

        for i in range(1, len(intervals)):
            # 这里的 new_arr[-1] 是引用，修改它会直接改变数组内容
            last_interval = new_arr[-1]
            curr_interval = intervals[i]
            
            # 只要有重叠（当前起点 <= 上一个终点）
            if curr_interval[0] <= last_interval[1]:
                # 无论包含还是延长，直接取两个终点的最大值
                # 这行代码同时解决了你的 if 和那个“漏写”的情况
                last_interval[1] = max(last_interval[1], curr_interval[1])
            else:
                # 不重叠
                new_arr.append(curr_interval)
                
        return new_arr
```

### 总结
你的代码**逻辑没问题，可以通过**。
利用“什么都不做”来处理子区间包含的情况也是一种策略，但显式地使用 `max()` 通常被认为是更规范、更易读的写法。



### 标准解法

不需要 pop 也不需要 temp，直接修改 new_arr 最后一个元素的右边界即可。

```Python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        # 1. 排序：这是对的，必须先按左端点排序
        intervals.sort(key=lambda x: x[0]) 
        
        new_arr = [intervals[0]]

        for i in range(1, len(intervals)):
            # 获取 new_arr 中最后一个区间的引用
            last_interval = new_arr[-1]
            current_interval = intervals[i]
            
            # 判断是否有重叠：当前区间的左边 <= 上一个区间的右边
            if current_interval[0] <= last_interval[1]:
                # 【核心修复点】：合并时，右边界要取两者的最大值
                # 比如 [1, 10] 和 [2, 6]，合并后是 [1, 10]，而不是 [1, 6]
                # 直接修改 last_interval[1]，因为它是引用，new_arr 里的值也会变
                last_interval[1] = max(last_interval[1], current_interval[1])
            else:
                # 没有重叠，直接加入
                new_arr.append(current_interval)
                
        return new_arr
```

### 关键知识点总结

1. **直接修改代替弹出**：
   在 Python 中，last = new_arr[-1] 拿到的是一个**引用**（Reference）。如果你修改 last[1] = ...，new_arr 里面对应的数据也会直接改变。所以完全不需要 pop 出来改完再塞回去，直接原地改最快。
2. **区间包裹的情况**：
   做区间合并题，永远要记住 [1, 10] 和 [2, 3] 这种情况。后者完全被前者包裹，合并后的终点必须是 max(前.end, 后.end)。
3. **pop() 的陷阱**：
   永远记住 item = arr.pop()，arr 变短了，item 是拿出来的那个东西。千万别写 arr = arr.pop()，这会把整个列表弄丢。
