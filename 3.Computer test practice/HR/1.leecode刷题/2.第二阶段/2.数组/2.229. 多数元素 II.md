# [229. 多数元素 II](https://leetcode.cn/problems/majority-element-ii/)

中等

提示

给定一个大小为 *n* 的整数数组，找出其中所有出现超过 `⌊ n/3 ⌋` 次的元素。

**示例 1：**

```
输入：nums = [3,2,3]
输出：[3]
```

**示例 2：**

```
输入：nums = [1]
输出：[1]
```

**示例 3：**

```
输入：nums = [1,2]
输出：[1,2]
```

**提示：**

- `1 <= nums.length <= 5 * 104`
- `-109 <= nums[i] <= 109`

**进阶：**尝试设计时间复杂度为 O(n)、空间复杂度为 O(1)的算法解决此问题。





```python
class Solution:
    def majorityElement(self, nums: List[int]) -> List[int]:
        length = len(nums)
        goal = length // 3
        ans = []
        tem_dic = {}
        for num in nums:
            if num in tem_dic:
                tem_dic[num] += 1
            else:
                tem_dic[num] = 1

        for num in tem_dic:
            if tem_dic[num] > goal:
                ans.append(num)
        return ans
        
```

### 详细复杂度分析

1.  **时间复杂度：$O(N)$**
    *   遍历一遍数组统计频率，字典的插入和查询平均是 $O(1)$，所以是 $O(N)$。
    *   遍历字典找出符合要求的数，最坏情况字典大小为 $N$，也是 $O(N)$。
    *   总体符合要求。

2.  **空间复杂度：$O(N)$** (这是进阶挑战的痛点)
    *   `tem_dic` 在最坏情况下（例如数组是 `[1, 2, 3, 4, 5]`）需要存储 $N$ 个键值对。
    *   题目进阶要求 $O(1)$ 空间，意味着无论数组多长，你只能申请固定数量的变量。

---

### 进阶解法：摩尔投票法 (Boyer-Moore Voting Algorithm)

如果面试官问：“能把空间优化到 $O(1)$ 吗？”，这就需要用到**摩尔投票法**的升级版。

#### 核心逻辑
*   **找 > n/2 的数**：相当于“一换一”。两个不同的数对掉，剩下的那个可能是众数。维护 **1个** 候选人。
*   **找 > n/3 的数**：相当于“一换一换一”。**三个不同的数**遇到一起，就同归于尽（抵消）。剩下的可能是众数。
    *   数学原理：出现次数超过 `n/3` 的数，**最多只有 2 个**。
    *   所以我们维护 **2个** 候选人 (`cand1`, `cand2`) 和对应的票数 (`cnt1`, `cnt2`)。

#### 算法步骤
1.  **配对阶段（第一遍遍历）**：
    *   如果投给 `cand1`，`cnt1` 加 1。
    *   如果投给 `cand2`，`cnt2` 加 1。
    *   如果 `cnt1` 为 0，更新 `cand1`。
    *   如果 `cnt2` 为 0，更新 `cand2`。
    *   如果投的数既不是 `c1` 也不是 `c2`，说明出现了第三者，**三个数互斥，一起抵消** -> `cnt1` 和 `cnt2` 都减 1。

2.  **计数阶段（第二遍遍历）**：
    *   由于抵消过程可能会误伤（比如 `[3, 3, 2]`，如果不回头检查，2 可能会留在候选区），所以需要再遍历一次数组，统计这两个幸存候选人的真实票数，判断是否真的超过 `n/3`。

#### $O(1)$ 空间代码实现

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> List[int]:
        if not nums:
            return []
        
        # 初始化两个候选人和票数
        candidate1, count1 = 0, 0
        candidate2, count2 = 0, 0
        
        # --- 第一阶段：抵消（选出嫌疑人） ---
        for num in nums:
            # 1. 投给候选人1
            if num == candidate1:
                count1 += 1
            # 2. 投给候选人2
            elif num == candidate2:
                count2 += 1
            # 3. 候选人1位置空缺，上位
            elif count1 == 0:
                candidate1 = num
                count1 = 1
            # 4. 候选人2位置空缺，上位
            elif count2 == 0:
                candidate2 = num
                count2 = 1
            # 5. 三个不同的数遇到了，大家一起扣血（核心）
            else:
                count1 -= 1
                count2 -= 1
        
        # --- 第二阶段：复查（确认嫌疑人是否真的达标） ---
        # 必须清零重新统计，因为刚才的 count 是抵消后的剩余值，不是真实值
        count1, count2 = 0, 0
        for num in nums:
            if num == candidate1:
                count1 += 1
            elif num == candidate2:
                count2 += 1
        
        ans = []
        n = len(nums)
        if count1 > n // 3:
            ans.append(candidate1)
        if count2 > n // 3:
            ans.append(candidate2)
            
        return ans
```
