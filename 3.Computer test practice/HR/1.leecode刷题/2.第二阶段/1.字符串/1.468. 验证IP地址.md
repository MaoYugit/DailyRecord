# [468. 验证IP地址](https://leetcode.cn/problems/validate-ip-address/)

中等

给定一个字符串 `queryIP`。如果是有效的 IPv4 地址，返回 `"IPv4"` ；如果是有效的 IPv6 地址，返回 `"IPv6"` ；如果不是上述类型的 IP 地址，返回 `"Neither"` 。

**有效的IPv4地址** 是 `“x1.x2.x3.x4”` 形式的IP地址。 其中 `0 <= xi <= 255` 且 `xi` **不能包含** 前导零。例如: `“192.168.1.1”` 、 `“192.168.1.0”` 为有效IPv4地址， `“192.168.01.1”` 为无效IPv4地址; `“192.168.1.00”` 、 `“192.168@1.1”` 为无效IPv4地址。

**一个有效的IPv6地址** 是一个格式为`“x1:x2:x3:x4:x5:x6:x7:x8”` 的IP地址，其中:

- `1 <= xi.length <= 4`
- `xi` 是一个 **十六进制字符串** ，可以包含数字、小写英文字母( `'a'` 到 `'f'` )和大写英文字母( `'A'` 到 `'F'` )。
- 在 `xi` 中允许前导零。

例如 `"2001:0db8:85a3:0000:0000:8a2e:0370:7334"` 和 `"2001:db8:85a3:0:0:8A2E:0370:7334"` 是有效的 IPv6 地址，而 `"2001:0db8:85a3::8A2E:037j:7334"` 和 `"02001:0db8:85a3:0000:0000:8a2e:0370:7334"` 是无效的 IPv6 地址。

**示例 1：**

```
输入：queryIP = "172.16.254.1"
输出："IPv4"
解释：有效的 IPv4 地址，返回 "IPv4"
```

**示例 2：**

```
输入：queryIP = "2001:0db8:85a3:0:0:8A2E:0370:7334"
输出："IPv6"
解释：有效的 IPv6 地址，返回 "IPv6"
```

**示例 3：**

```
输入：queryIP = "256.256.256.256"
输出："Neither"
解释：既不是 IPv4 地址，又不是 IPv6 地址
```

**提示：**

- `queryIP` 仅由英文字母，数字，字符 `'.'` 和 `':'` 组成。

```python
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        if '.' in queryIP:
            temp = queryIP.split('.')
            length = len(temp)
            if length == 4:
                for s in temp:
                    if not s.isdigit():
                        return "Neither"
                    if ((s[0]) == '0' and len(s) > 1) or int(s) < 0 or int(s) > 255:
                        return "Neither"
                return "IPv4"
            else:
                return "Neither"
        elif ":" in queryIP:
            temp = queryIP.split(':')
            length = len(temp)
            if length == 8:
                for s in temp:
                    if len(s) > 4 or len(s) == 0:
                        return "Neither"
                    for char in s:
                        if not char.isalnum() or char.lower() > 'f':
                            return "Neither"
                return "IPv6"
            else:
                return "Neither"
        else:
           return "Neither" 

                
        
```

### 1. 代码评价

**优点：**
*   **逻辑清晰**：直接按照题目要求，分情况讨论 IPv4 和 IPv6，容易理解。
*   **边界条件覆盖较好**：考虑了段数长度（4或8）、前导零、空字符串、非数字字符、数值范围等。
*   **安全性**：在 IPv4 判断中，利用 `if not s.isdigit()` 提前拦截了非数字和空字符串，避免了后面 `s[0]` 访问空字符串可能导致的 `IndexError` 报错。

**可优化/冗余之处：**
1.  **判定入口略显粗糙**：
    `if '.' in queryIP:` 这个判断有点“武断”。虽然根据题意如果同时包含 `.` 和 `:` 肯定是无效的，但更好的做法是检查 **分隔符的数量**（IPv4 应该有3个点，IPv6 应该有7个冒号），这样能更精准地进入分支。
2.  **冗余检查**：
    在 IPv4 中，既然已经判断了 `if not s.isdigit():`，说明 `s` 必定是 **非负整数**。后面的 `or int(s) < 0` 是永远不会触发的废话，可以删掉。
3.  **IPv6 字符判断繁琐**：
    双重循环检查字符是否 valid 稍微有点啰嗦，虽然效率是 O(N)，但写起来比较累。

---

### 2. 更好的解法思路（面试推荐）

面试中，为了展现代码构建能力，通常建议采用 **“分治法” (Divide and Conquer)** 的结构：写两个辅助函数 `is_IPv4` 和 `is_IPv6`，主函数只负责分发。

这样代码结构更漂亮，可读性更强。

#### 改进版代码（结构化 + Pythonic）

```python
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        # 通过统计分隔符的数量来决定进入哪个检查逻辑
        # 这样比 if '.' in queryIP 更精准
        if queryIP.count('.') == 3:
            return self.check_ipv4(queryIP)
        elif queryIP.count(':') == 7:
            return self.check_ipv6(queryIP)
        else:
            return "Neither"

    def check_ipv4(self, s: str) -> str:
        parts = s.split('.')
        for part in parts:
            # 1. 长度检查：空字符串或太长都不行
            if not part or len(part) > 3:
                return "Neither"
            # 2. 纯数字检查 (isdigit拒绝负号、小数、空格)
            if not part.isdigit():
                return "Neither"
            # 3. 前导零检查 (长度大于1且首位是0)
            if len(part) > 1 and part[0] == '0':
                return "Neither"
            # 4. 数值范围检查
            if int(part) > 255:
                return "Neither"
        return "IPv4"

    def check_ipv6(self, s: str) -> str:
        parts = s.split(':')
        # 创建一个允许的字符集合，查找更快
        hexdigits = '0123456789abcdefABCDEF'
        
        for part in parts:
            # 1. 长度检查：1到4位
            if not (1 <= len(part) <= 4):
                return "Neither"
            # 2. 合法字符检查
            # 你的写法很好，这里提供另一种写法：
            # all() 函数检查是否所有字符都在允许集合中
            if not all(c in hexdigits for c in part):
                return "Neither"
        return "IPv6"
```

### 3. 另一种思路：正则表达式 (Regex)

如果在工程实践中（或者面试官允许），正则表达式是最简洁的写法，但很难写对（尤其是 IPv4 的 0-255 范围）。

**注意：** 如果面试时你写不出完美的正则，建议坚持上面的“字符串模拟法”，稳妥且不容易出错。

```python
import re

class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        # IPv4 正则分块逻辑：
        # ([0-9]                  # 0-9
        # |[1-9][0-9]             # 10-99
        # |1[0-9][0-9]            # 100-199
        # |2[0-4][0-9]            # 200-249
        # |25[0-5])               # 250-255
        ipv4_chunk = r'([0-9]|[1-9][0-9]|1[0-9][0-9]|2[0-4][0-9]|25[0-5])'
        # 重复4次，中间加点
        ipv4_pattern = re.compile(r'^(' + ipv4_chunk + r'\.){3}' + ipv4_chunk + r'$')
        
        # IPv6 正则：1-4位十六进制字符
        ipv6_chunk = r'[0-9a-fA-F]{1,4}'
        # 重复8次，中间加冒号
        ipv6_pattern = re.compile(r'^(' + ipv6_chunk + r':){7}' + ipv6_chunk + r'$')
        
        if ipv4_pattern.match(queryIP):
            return "IPv4"
        elif ipv6_pattern.match(queryIP):
            return "IPv6"
        else:
            return "Neither"
```
