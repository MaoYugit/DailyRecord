# [151. 反转字符串中的单词](https://leetcode.cn/problems/reverse-words-in-a-string/)

中等

给你一个字符串 `s` ，请你反转字符串中 **单词** 的顺序。

**单词** 是由非空格字符组成的字符串。`s` 中使用至少一个空格将字符串中的 **单词** 分隔开。

返回 **单词** 顺序颠倒且 **单词** 之间用单个空格连接的结果字符串。

**注意：**输入字符串 `s`中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

**示例 ：**

```
输入：s = "the sky is blue"
输出："blue is sky the"
```

**示例 2：**

```
输入：s = "  hello world  "
输出："world hello"
解释：反转后的字符串中不能存在前导空格和尾随空格。
```

**示例 3：**

```
输入：s = "a good   example"
输出："example good a"
解释：如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。
```

**提示：**

- `1 <= s.length <= 104`
- `s` 包含英文大小写字母、数字和空格 `' '`
- `s` 中 **至少存在一个** 单词

**进阶：**如果字符串在你使用的编程语言中是一种可变数据类型，请尝试使用 `O(1)` 额外空间复杂度的 **原地** 解法。

### 1. `split()` —— “拆分者” (字符串方法)

它的作用是：**把一个字符串，切成一个列表 (List)。**

#### 核心用法 A：`split()` 不带参数（最常用，最智能）
*   **规则**：它会把**空格、换行符(`\n`)、制表符(`\t`)**都当作分隔符。
*   **特异功能**：它会自动**忽略**连续的空格，并且自动**去除**首尾的空格。
*   **适用场景**：处理英文句子、不规则的文本输入。

```python
s = "  Hello    World  "
result = s.split() 
# 结果: ['Hello', 'World']
# 注意：周围的空格没了，中间的多个空格也被算作一个断点。
```

#### 核心用法 B：`split('指定字符')` （较严格）
*   **规则**：严格按照你指定的字符切分。
*   **坑**：如果两个分隔符连在一起，它会切出一个**空字符串 `''`**。

```python
s = "Hello,,World"
result = s.split(',')
# 结果: ['Hello', '', 'World']
# 中间那个空字符串，是因为两个逗号之间“什么都没有”。
```

> **回到你刚才的代码**：
> 你用了 `s.split(' ')`。这意味着如果原句是 `"a  b"`（中间两个空格），它会切出 `['a', '', 'b']`。
> 而 `s.split()` 则会切出 `['a', 'b']`。通常做算法题，我们选后者。

---

### 2. `join()` —— “粘合剂” (字符串方法)

它的作用是：**把一个列表里的字符串，拼成一个长字符串。**

#### 语法记忆
这是初学者最容易晕的地方：**是谁调用了 `join`？是那个“胶水”！**

```python
# 语法： "胶水".join(一堆碎片)
```

#### 例子
```python
words = ['I', 'love', 'Python']

# 1. 用空格粘起来
s1 = " ".join(words)
print(s1)  # 输出: "I love Python"

# 2. 用下划线粘起来
s2 = "_".join(words)
print(s2)  # 输出: "I_love_Python"

# 3. 直接粘在一起（不用胶水）
s3 = "".join(words)
print(s3)  # 输出: "IlovePython"
```

#### 注意事项
1.  `join` 括号里的列表，里面的元素**必须全是字符串**。如果有数字，会报错。
2.  `join` **不会修改**原来的列表，它会**返回**一个新的字符串。

> **回到你刚才的代码**：
> 你写了 `new_s.join(temp[i])`。
> `temp[i]` 是单个单词（比如 `"World"`）。
> `"".join("World")` 的结果还是 `"World"`。
> 最重要的是，**你没有把结果赋值给任何人**，所以这行代码白跑了。

---

### 3. `append()` —— “追加者” (列表方法)

它的作用是：**往列表的屁股后面，添加一个元素。**

#### 核心特点：原地修改 (In-place)
这是最容易踩的坑！`append` 直接修改那个列表，**它的返回值是 `None`（空）**。

#### 正确用法
```python
fruits = ['apple', 'banana']
fruits.append('orange')  # 只要这一行，不需要赋值！

print(fruits) 
# 输出: ['apple', 'banana', 'orange']
```

#### 错误用法 (经典死局)
```python
fruits = ['apple']
# 千万不要这样写！！！
fruits = fruits.append('banana') 

print(fruits) 
# 输出: None
# 解释：因为 fruits.append(...) 执行完返回 None，你把 None 赋值给了 fruits，列表丢了！
```

### 总结：它们如何配合解决“翻转单词”？

把这三个知识点串起来，就是解决你那道题的标准流程：

```python
s = "  the sky is blue  "

# 1. split(): 把字符串拆成列表，顺便去掉多余空格
words_list = s.split()  
# 此时 words_list = ['the', 'sky', 'is', 'blue']

# 2. 列表操作: 翻转列表
# (可以用 list.reverse() 也可以用切片 [::-1])
words_list.reverse()
# 此时 words_list = ['blue', 'is', 'sky', 'the']

# 如果你想用 append 手动做这步（为了练习）：
# new_list = []
# for i in range(len(words_list)-1, -1, -1):
#     new_list.append(words_list[i])  # 注意：append 不需要赋值

# 3. join(): 用空格把列表里的单词粘回去
result = " ".join(words_list)
# 此时 result = "blue is sky the"
```

### 直接回答

**我们刚才写的解法（`split` + `join`）绝对不是 O(1) 空间的，它的空间复杂度是 O(N)。**

为什么？
1.  **`split()`**：创建了一个包含所有单词的新列表。如果字符串很长，这个列表占用的内存是线性的 O(N)。
2.  **`join()`**：在 Python 中字符串是**不可变**的，所以拼接时必须创建一个全新的字符串，这也占用 O(N) 的空间。
3.  **Python 的特性**：在 Python 中，几乎**不可能**做到真正意义上的 O(1) 空间翻转字符串，因为你无法修改原字符串（不像 C++ 的 `string` 或 C 的 `char[]` 可以直接修改内存）。

---

### 所谓的“原地解法” (O(1) Space) 是什么逻辑？

在 C++ 或 Java (char array) 中，经典的 O(1) 解法逻辑非常巧妙，面试时经常考这个思路（即使你用 Python，面试官也可能让你模拟这个过程）。

**核心思想：** **“整体翻转 + 局部翻转”**

步骤如下：
1.  **移除多余空格**（这一步在 C++ 中通常双指针原地做，Python 只能转成列表做）。
2.  **翻转整个字符串**。
    *   原：`"the sky is blue"`
    *   翻：`"eulb si yks eht"`
3.  **再翻转每个单词**。
    *   `"eulb"` -> `"blue"`
    *   `"si"` -> `"is"`
    *   `"yks"` -> `"sky"`
    *   `"eht"` -> `"the"`
4.  **结果**：`"blue is sky the"`

#### Python 模拟版（用来理解算法逻辑）
虽然 Python 必须转成 list (O(N) 空间)，但我们可以**模拟**这个算法过程：

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        # 1. 必须转成列表才能修改（Python限制）
        # 这一步已经用了 O(N) 空间，没办法
        l = list(s)
        
        # 2. 翻转整个列表
        self.reverse(l, 0, len(l) - 1)
        
        # 3. 翻转每个单词
        self.reverse_each_word(l)
        
        # 4. 去除多余空格（这一步比较繁琐，通常 split() 更好）
        # 为了演示逻辑，这里简化，假设已经处理好空格或者最后处理
        
        return "".join(l) # 如果要完美处理空格，这里需要更复杂的逻辑

    # 辅助函数：翻转列表指定区间
    def reverse(self, l, left, right):
        while left < right:
            l[left], l[right] = l[right], l[left]
            left += 1
            right -= 1

    def reverse_each_word(self, l):
        n = len(l)
        start = 0
        end = 0
        while start < n:
            # 找到单词的末尾
            while end < n and l[end] != ' ':
                end += 1
            # 翻转当前单词
            self.reverse(l, start, end - 1)
            # 跳过空格，找下一个单词
            start = end + 1
            end += 1
```
*注意：上面的代码主要是为了演示“两次翻转”的算法思想，处理空格的细节比较繁琐，实战中 Python 很少这样写。*

### 其他普通解法（面试常见）

除了 `split()[::-1]` 这种“作弊”般的写法，还有两种常见的解法，体现了不同的数据结构思维。

#### 解法 1：双端队列 (Deque) —— 效率高
**思路**：遍历字符串，提取出单词，把单词插入到队列的**头部**。
*   第一个单词 "the" -> 放入队列：`["the"]`
*   第二个单词 "sky" -> 插到头部：`["sky", "the"]`
*   ...
*   最后得到的自然就是倒序的。

```python
from collections import deque

class Solution:
    def reverseWords(self, s: str) -> str:
        # left, right 双指针用来去除首尾空格
        left, right = 0, len(s) - 1
        while left <= right and s[left] == ' ':
            left += 1
        while left <= right and s[right] == ' ':
            right -= 1
            
        d = deque()
        word = []
        
        while left <= right:
            if s[left] == ' ' and word:
                # 碰到空格，说明一个单词结束了，把它放到队列头部
                d.appendleft("".join(word))
                word = []
            elif s[left] != ' ':
                word.append(s[left])
            left += 1
            
        d.appendleft("".join(word)) # 把最后一个单词放进去
        
        return " ".join(d)
```
**优点**：不用像 `split()` 那样先生成一个大列表再翻转，而是边读边放到正确的位置。

#### 解法 2：双指针 (Two Pointers) —— 倒序遍历
**思路**：从字符串的**屁股后面**往前找单词。
1.  指针 `i` 从后往前扫，找到非空格字符（单词尾）。
2.  指针 `j` 继续往前扫，找到空格（单词头）。
3.  截取 `s[j+1 : i+1]` 放入结果。
4.  重复。

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        s = s.strip() # 去掉首尾空格
        i = len(s) - 1
        res = []
        
        while i >= 0:
            while i >= 0 and s[i] == ' ': # 跳过单词间的空格
                i -= 1
            
            right = i # 记录单词结束位置
            
            while i >= 0 and s[i] != ' ': # 找到单词开始位置
                i -= 1
            
            # 截取单词
            # 注意：如果 i < 0 且 right < 0，说明扫完了
            if right >= 0:
                res.append(s[i+1 : right+1])
                
        return " ".join(res)
```

### 总结建议

1.  **对于 Python**：直接用 `return " ".join(s.split()[::-1])` 是最优解，代码最短，实际运行速度也是最快的（因为 C 语言底层优化过）。
2.  **对于面试**：
    *   先写出 Python 简洁版。
    *   如果面试官问：“如果不能用 split，或者要求空间 O(1)（针对 C++ 语境）怎么办？”
    *   这时候回答：“我会用**双指针**，先翻转整个句子，再翻转每个单词。”（展示你懂算法底层逻辑）。
