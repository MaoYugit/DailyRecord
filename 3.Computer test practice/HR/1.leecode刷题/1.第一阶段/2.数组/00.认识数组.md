### 第一部分：数组的底层逻辑与 Python 的“特权”

#### 1. 数组在内存中长什么样？
在计算机科学的经典定义中，数组是**一块连续的内存空间**。
*   **关键点**：因为是连续的，所以我们可以通过下标（Index）直接计算出内存地址。
*   **超能力**：**随机访问（Random Access）**。只要你知道下标 `i`，访问 `nums[i]` 的时间复杂度永远是 **$O(1)$**。这是数组最强的武器。

#### 2. Python 的 List vs 传统数组
你用的是 Python，Python 的 `list` 其实是**动态数组**（Dynamic Array）。
*   **传统数组（如 C/Java 原始数组）**：声明时必须指定大小（例如 `int arr[10]`），满了就不能塞了。
*   **Python List**：
    *   **自动扩容**：你尽管 `append`，Python 会在底层自动开辟更大的内存把旧数据搬过去（虽然偶尔发生，但很方便）。
    *   **存的是引用**：`[1, "a", Object]`，Python 数组里存的其实是对象的内存地址（引用），所以能存不同类型的数据。但在刷算法题时，我们通常假设数组里都是同一种类型（比如全是 `int`）。

#### 3. 面试必考：时间复杂度（记死它！）
这是面试官最在乎的指标，决定了你的代码会不会超时（Time Limit Exceeded, TLE）。

| 操作              | Python 代码                    | 时间复杂度 | 解释                                              |
| :---------------- | :----------------------------- | :--------- | :------------------------------------------------ |
| **访问**          | `x = nums[i]`                  | **$O(1)$** | 极快，直接定位。                                  |
| **尾部添加**      | `nums.append(x)`               | **$O(1)$** | 平均是 $O(1)$，偶尔扩容是 $O(N)$，总体算 $O(1)$。 |
| **尾部删除**      | `nums.pop()`                   | **$O(1)$** | 极快。                                            |
| **中间/头部插入** | `nums.insert(0, x)`            | **$O(N)$** | **巨坑！** 插入位置之后的所有元素都要向后挪一位。 |
| **中间/头部删除** | `nums.pop(0)` 或 `del nums[i]` | **$O(N)$** | **巨坑！** 删除位置之后的所有元素都要向前挪一位。 |
| **查找**          | `x in nums`                    | **$O(N)$** | 必须从头遍历到尾才能确定。                        |

> **刷题直觉**：如果你在 `for` 循环（$O(N)$）里用了 `nums.insert(0, ...)` 或者 `nums.pop(0)`，总复杂度就变成了 $O(N^2)$，数据量超过 1万 基本上就超时了。

#### 4. Python 刷数组题的“神技”
在 LeetCode 上，利用 Python 的语法糖可以极大地简化代码，但要用对地方。

**A. 切片 (Slicing)**
*   `nums[i:j]`：获取子数组（注意：左闭右开，包含 `i` 不包含 `j`）。
*   `nums[::-1]`：数组翻转，面试常考。
*   **注意**：切片操作会生成新列表，复杂度是 **$O(K)$**（K是切片长度），不要在深层循环里滥用。

**B. 列表推导式 (List Comprehension)**
*   快速生成：`squares = [x**2 for x in range(10)]`
*   二维数组初始化（必背）：
    ```python
    # ❌ 错误写法（浅拷贝陷阱）：所有行都指向同一个对象
    rows = [[0] * 5] * 5 
    
    # ✅ 正确写法
    rows = [[0] * 5 for _ in range(5)]
    ```

**C. 同时获取下标和值 (Enumerate)**
很多题目需要同时用到索引和值，千万别写 `range(len(nums))` 然后再去查 `nums[i]`。
```python
# 推荐写法
for index, value in enumerate(nums):
    print(f"Index: {index}, Value: {value}")
```

### 一、 左右对撞指针 (Left-Right Pointers)

**场景**：通常用于**已排序数组**，或者涉及**翻转**、**回文**、**配对**的问题。
**逻辑**：一个指针从头开始（`left`），一个指针从尾开始（`right`），向中间逼近，直到它们相遇。

#### 核心代码模板
```python
left, right = 0, len(nums) - 1

while left < right:
    # 你的业务逻辑，比如判断 nums[left] + nums[right] 是否达标
    if 满足某种条件:
        return 结果
    elif 需要让值变大:
        left += 1
    else: # 需要让值变小
        right -= 1
```

#### 经典案例解析：两数之和 II - 输入有序数组 (LeetCode 167)
*题目：给你一个下标从 1 开始的整数数组 numbers ，该数组已按**非递减顺序排列**，请你从数组中找出满足相加之和等于目标数 target 的两个数。*

**如果不思考：** 两层 `for` 循环，超时。
**双指针思路：**
1. 因为数组是有序的，最小的在左边，最大的在右边。
2. 计算 `sum = nums[left] + nums[right]`。
3. 如果 `sum > target`：说明和太大了，需要变小一点，所以只能让右边的 `right` 往左移。
4. 如果 `sum < target`：说明和太小了，需要变大一点，所以只能让左边的 `left` 往右移。
5. 只要一碰头，循环结束。

```python
def twoSum(numbers, target):
    left, right = 0, len(numbers) - 1
    while left < right:
        current_sum = numbers[left] + numbers[right]
        if current_sum == target:
            # 题目要求下标从1开始，所以+1
            return [left + 1, right + 1]
        elif current_sum > target:
            right -= 1
        else:
            left += 1
    return []
```

### 二、 快慢指针 (Fast-Slow Pointers)

**场景**：通常用于**原地（In-place）修改数组**，比如去重、移除元素、移动零等。
**逻辑**：
*   **快指针 (`fast`)**：像侦察兵，一直往前走，负责寻找如果不删除/不修改应该保留的元素。
*   **慢指针 (`slow`)**：像大本营，只有当 `fast` 找到了“有效元素”，`slow` 才向前移动一步，并把那个有效元素记录下来。

**口诀**：`fast` 用来探索，`slow` 用来收集结果。

#### 经典案例解析：删除有序数组中的重复项 (LeetCode 26)
*题目：给你一个升序排列的数组 nums ，请你**原地**删除重复出现的元素，使每个元素只出现一次。*

**思路：**
1. 如果数组是空的，直接返回 0。
2. 定义 `slow = 0`。
3. 让 `fast` 从 `1` 开始遍历整个数组。
4. 如果 `nums[fast] != nums[slow]`：说明发现了一个新元素（不重复的）！
    *   先让 `slow` 往前走一步 (`slow += 1`)。
    *   把新元素复制过来：`nums[slow] = nums[fast]`。
5. 如果 `nums[fast] == nums[slow]`：说明是重复的，`fast` 继续走，`slow` 此时不动（等待下一个新元素覆盖这里）。

**代码实现：**
```python
def removeDuplicates(nums):
    if not nums:
        return 0
    
    slow = 0
    for fast in range(1, len(nums)):
        # 只要 fast 发现跟 slow 不一样的值，说明是新大陆
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    
    # 题目要求返回新长度，索引是 slow，长度就是 slow + 1
    return slow + 1
```
*看懂了吗？这种方法不需要额外的数组空间，直接在原数组上操作，空间复杂度 $O(1)$，非常受面试官欢迎。*

### 三、 Python 刷题小贴士：While 还是 For？

*   对于**左右指针**：通常用 `while left < right`，因为我们不确定什么时候结束，且两个指针移动逻辑不固定。
*   对于**快慢指针**：通常用 `for fast in range(len(nums))`，因为 `fast` 指针肯定是要从头走到尾遍历一遍的。

### 一、 滑动窗口 (Sliding Window)

**核心心法**：**“进一个，出一个”** 或者 **“吃进肚子，再吐出来”**。

它本质上也是双指针（Left 和 Right），但不仅是移动指针，更重要的是维护两个指针之间这个“窗口”里的**状态**（比如窗口内的和、最大值、字符计数等）。

#### 1. 窗口的两种形态

1.  **固定窗口**：窗口大小固定为 `k`。
    *   *就像拿着一个固定长度的框在数组上滑。*
    *   **操作**：右边加一个新元素，左边必定减一个旧元素。
2.  **可变窗口**（面试重点）：窗口大小不固定，寻找满足条件的最小/最大窗口。
    *   *像一条毛毛虫，先伸长（Right++），吃到满足条件了，尾巴再缩短（Left++）。*

#### 2. 可变窗口通用模板（背诵！）

```python
def slidingWindow(nums):
    left = 0
    right = 0
    # 定义维护的变量，比如窗口内的 sum, count 等
    window_sum = 0 
    ans = float('inf') # 求最小值时初始化为无穷大

    # 1. 右指针一直往右走，扩张窗口
    for right in range(len(nums)):
        # 【进】：新元素进入窗口，更新状态
        window_sum += nums[right]
        
        # 2. 当窗口内的条件满足时（或者不满足限制时），左指针开始收缩
        while window_sum >= target: # 假设题目找 >= target 的最小长度
            # 更新结果（因为此时满足条件）
            ans = min(ans, right - left + 1)
            
            # 【出】：左边元素移出窗口，更新状态
            window_sum -= nums[left]
            left += 1 # 左指针右移
            
    return ans if ans != float('inf') else 0
```

#### 经典案例：长度最小的子数组 (LeetCode 209)
*题目：给定一个含有 n 个正整数的数组和一个整数 target。找出该数组中满足其和 ≥ target 的长度最小的连续子数组。*

**如果不思考**：暴力穷举所有子数组，$O(N^2)$，必超时。
**滑动窗口思路**：
1.  `right` 主动向右走，累加 `sum`。
2.  一旦 `sum >= target`，说明当前窗口达标了！
3.  但我们要找**最小**的，所以这时候 `right` 停下，`left` 开始向右缩，看看删掉左边的数是不是还能达标？如果还能达标，长度就更短了！
4.  直到 `sum < target`，`left` 停下，`right` 继续走。

### 二、 前缀和 (Prefix Sum)

**核心心法**：**“不要重复算，算好存起来”**。

如果你发现题目需要**频繁查询**某一段连续区间的和（比如问你下标 100 到 5000 的和是多少），每次都去遍历加一遍太慢了。前缀和就是预先算好**从头到每个位置的和**。

#### 1. 原理
创建一个新数组 `P`，其中 `P[i]` 表示 `nums` 中前 `i` 个数的和。
*   `P[0] = 0` (为了方便计算，通常多开一个位置)
*   `P[1] = nums[0]`
*   `P[2] = nums[0] + nums[1]`
*   ...

**神奇公式**：
想求 `nums[i]` 到 `nums[j]` 的和？
**`Sum(i, j) = P[j+1] - P[i]`**
时间复杂度从 $O(N)$ 降为 **$O(1)$**！

#### 2. Python 实现技巧
```python
nums = [1, 2, 3, 4]
# 构造前缀和数组，多加一个 0 方便处理边界
pre_sum = [0] * (len(nums) + 1)
for i in range(len(nums)):
    pre_sum[i+1] = pre_sum[i] + nums[i]

# pre_sum 现在是 [0, 1, 3, 6, 10]
# 想求 nums[1] 到 nums[2] (即 2+3=5)? 
# 也就是求下标 1 到 2 的范围。
# 公式：pre_sum[3] - pre_sum[1] = 6 - 1 = 5。秒解。
```

> **Python 捷径**：虽然可以用 `itertools.accumulate`，但面试建议手写上面的循环，证明你懂原理。

#### 经典案例：和为 K 的子数组 (LeetCode 560) —— **高频难点**
*题目：给你一个整数数组 nums 和一个整数 k ，请你统计和为 k 的连续子数组的个数。*

这题不能用滑动窗口（因为数组可能有负数，加一个数不一定变大，窗口没法判断何时收缩）。
必须用**前缀和 + 哈希表**。

**思路**：
1.  子数组和 `Sum(i, j) = P[j] - P[i] = k`。
2.  移项一下：**`P[i] = P[j] - k`**。
3.  当我们遍历到 `j` 的时候，当前的 `P[j]` 是已知的。我们只需要问：**“在我之前（左边），有多少个 `P[i]` 等于 `P[j] - k` ？”**
4.  用一个字典（HashMap）存之前出现过的所有前缀和的次数。

```python
def subarraySum(nums, k):
    count = 0
    current_sum = 0
    # 字典 key: 前缀和的值, value: 出现的次数
    # 初始化 {0: 1} 是为了处理从头开始累计刚好等于 k 的情况
    prefix_counts = {0: 1}
    
    for num in nums:
        current_sum += num
        # 核心：看看历史上有多少个前缀和等于 (current_sum - k)
        diff = current_sum - k
        if diff in prefix_counts:
            count += prefix_counts[diff]
        
        # 把当前的前缀和记录下来
        prefix_counts[current_sum] = prefix_counts.get(current_sum, 0) + 1
        
    return count
```

### 三、 怎么区分用“滑动窗口”还是“前缀和”？

这是一个很好的经验总结：

1.  **滑动窗口**：适用于**全部是正数**（或能保证单调性）的数组。如果包含了负数，加法不一定变大，滑动窗口逻辑失效。
    *   关键词：*“最小长度”、“最大长度”、“包含所有字符”。*
2.  **前缀和**：适用于**可能有负数**，或者需要**静态查询**区间和。
    *   关键词：*“和为 K 的个数”、“区间和查询”。*

### 一、 摩尔投票法 (Boyer-Moore Voting Algorithm)

**场景**：找出数组中出现次数**超过一半**的那个数（众数）。
*   *LeetCode 169. 多数元素*

**如果不思考**：
1.  用哈希表统计次数：空间复杂度 $O(N)$。
2.  排序后取中间的数：时间复杂度 $O(N \log N)$。

**面试官想要**：时间 $O(N)$，空间 **$O(1)$**。这就必须用摩尔投票法。

**核心逻辑：极限一换一**
想象这就是一场混战。数组里的数字代表不同的阵营（比如 1 是魏国，2 是蜀国）。
*   规则：如果你遇到一个跟我不一样的，我们就**同归于尽**（两个都删掉）。
*   结论：因为众数的数量超过了一半，所以无论怎么兑换，**最后活下来的那个**肯定就是众数。

**Python 模板**：
```python
def majorityElement(nums):
    candidate = None
    count = 0
    
    for num in nums:
        # 1. 如果计数器为0，说明之前的都死光了，当前这个数占领高地
        if count == 0:
            candidate = num
        
        # 2. 如果是自己人，兵力+1；如果是敌人，同归于尽（兵力-1）
        if num == candidate:
            count += 1
        else:
            count -= 1
            
    return candidate
```

### 二、 原地哈希 / 索引映射 (In-Place Hashing)

**场景**：
*   题目限定数组长度为 `N`。
*   元素范围也在 `1` 到 `N` 之间（或者 `0` 到 `N-1`）。
*   要求找到**缺失的数字**或**重复的数字**。
*   **重点要求：** 空间复杂度 **$O(1)$**（不能创建新的 Hash Set）。

**核心逻辑：鸽巢原理（萝卜坑）**
既然数字范围是 1~N，那么理论上，数字 `x` 就应该乖乖待在下标 `x-1` 的位置上。
*   数字 1 应该在 `nums[0]`。
*   数字 5 应该在 `nums[4]`。

**骚操作：负数标记法**
我们可以遍历数组，把访问到的数字对应的**下标位置的数**变成负数，以此来标记“这个下标对应的数字已经出现过了”。

*   *LeetCode 448. 找到所有数组中消失的数字*

**演示**：
数组：`[4, 3, 2, 7, 8, 2, 3, 1]`
1.  读到 4：把下标 3 (即 `4-1`) 的数标记为负 -> `nums[3] = -7`。
2.  读到 3：把下标 2 的数标记为负。
3.  ...
4.  最后再遍历一遍，**谁还是正数，说明谁对应的下标没有被访问过**，那个下标就是缺失的数字！

**Python 代码**：
```python
def findDisappearedNumbers(nums):
    # 第一步：遍历并标记
    for n in nums:
        # 注意：因为之前的操作可能把数变成负的了，所以我们要取 abs()
        index = abs(n) - 1 
        # 把该位置的数变成负数，表示 index + 1 这个数出现过了
        if nums[index] > 0:
            nums[index] *= -1
            
    # 第二步：检查谁没变负
    res = []
    for i in range(len(nums)):
        if nums[i] > 0:
            res.append(i + 1)
    return res
```

### 三、 二维数组（矩阵 Matrix）

在 Python 中，二维数组就是 `List of Lists`。
`matrix = [[1,2,3], [4,5,6], [7,8,9]]`
访问：`matrix[row][col]`

#### 1. 模拟法（螺旋矩阵）
面试极高频题：*LeetCode 54. 螺旋矩阵*
**思路**：设定四个边界 `top`, `bottom`, `left`, `right`。
1.  向右填，填完 `top += 1`。
2.  向下填，填完 `right -= 1`。
3.  向左填，填完 `bottom -= 1`。
4.  向上填，填完 `left += 1`。
这就是纯逻辑题，考察代码控制能力，不涉及复杂算法。

#### 2. 矩阵旋转
*LeetCode 48. 旋转图像*（顺时针旋转90度）
**数学技巧（记住就赢了）**：
顺时针旋转 90 度 = **先对角线翻转（转置），再左右水平翻转**。

```python
def rotate(matrix):
    n = len(matrix)
    # 1. 转置 (Transpose)
    for i in range(n):
        for j in range(i, n): # 注意从 i 开始，避免重复交换
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    
    # 2. 左右翻转 (Reverse each row)
    for row in matrix:
        row.reverse()
```

### 🎓 数组专题总复习：面试决策树

当你拿到一道数组题，按这个顺序思考：

1.  **数据已排序？**
    *   $\rightarrow$ **二分查找**（以后讲）或 **双指针（左右对撞）**。
2.  **找连续子数组（和/积/最大值）？**
    *   全正数？$\rightarrow$ **滑动窗口**。
    *   有负数？$\rightarrow$ **前缀和**。
3.  **原地移除、去重、移动零？**
    *   $\rightarrow$ **双指针（快慢指针）**。
4.  **找众数、找缺失、找重复（限定范围 1-N）？**
    *   $\rightarrow$ **摩尔投票** 或 **原地哈希（负数标记）**。
5.  **二维矩阵操作？**
    *   $\rightarrow$ **模拟边界** 或 **数学翻转**。
