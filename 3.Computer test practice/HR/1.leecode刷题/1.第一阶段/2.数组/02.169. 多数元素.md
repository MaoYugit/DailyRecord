# [169. 多数元素](https://leetcode.cn/problems/majority-element/)

简单

给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**示例 1：**

```
输入：nums = [3,2,3]
输出：3
```

**示例 2：**

```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

**提示：**

- `n == nums.length`
- `1 <= n <= 5 * 104`
- `-109 <= nums[i] <= 109`
- 输入保证数组中一定有一个多数元素。

**进阶：**尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。



```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        dic = {}
        for num in nums:
            if num in dic:
                dic[num] += 1
            else:
                dic[num] = 1
        max_val = 1
        max_key = 1
        for key in dic:
            if dic[key] >= max_val:
                max_val = dic[key]
                max_key = key
        if max_val >= len(nums) / 2:
            return max_key    
        
```

### 评价你的题解

你的代码逻辑是**正确**的，使用了**哈希表（字典）**来统计词频，思路非常清晰。

#### 评分：80分
*   **优点**：思路好理解，时间复杂度是 $O(N)$，符合常规解法。
*   **缺点**：
    1.  **代码稍微有点啰嗦**：你先统计完所有数字的次数，然后再遍历字典找最大值。其实可以在统计的过程中直接判断。
    2.  **初始化的小隐患**：`max_key = 1` 这种写法在工程上不太好（万一数组里没有1，且逻辑没覆盖到怎么办？虽然后面的循环覆盖了它，但建议用 `nums[0]` 或者 `None` 初始化）。
    3.  **空间复杂度**：使用了字典，空间复杂度是 $O(N)$。题目最后的**进阶**要求是空间 $O(1)$。

### 优化方案 1：优化你的字典法（最推荐你面试用）

既然你熟悉字典，我们把代码写得更聪明一点。**不需要等统计完再找最大值，每加一次直接检查有没有超过一半**。

这样代码短了一半，而且一旦找到就直接结束，不用跑完整个循环。

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        dic = {}
        # 只需要算一次这个标准线
        half_len = len(nums) / 2
        
        for num in nums:
            # 存入字典
            if num in dic:
                dic[num] += 1
            else:
                dic[num] = 1
            
            # 【关键优化】每次加完直接看：超过一半了吗？
            if dic[num] > half_len:
                return num
                
        return 0 # 题目保证一定有答案，这行其实走不到
```

### 优化方案 2：排序法（虽然是 O(N log N)，但极其好记）

如果面试时你突然紧张，脑子空白了，就用这个“懒人法”。
**逻辑**：既然一个数字出现了超过一半的次数，那么把它排好序后，**正中间**那个数一定是它！

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        nums.sort()
        # 直接返回正中间的数
        return nums[len(nums) // 2]
```
*   **优点**：代码只需 2 行。
*   **缺点**：时间复杂度 $O(N \log N)$，比字典慢一点，但通常也能通过。

### 优化方案 3：摩尔投票法（进阶满分答案）

这是题目要求的 **空间 O(1)** 解法。面试官如果问“能不能不用字典（不额外占内存）？”，就必须用这个。

**核心思想（拼刺刀/一换一）：**
把众数看作“我方军队”，其他所有数字看作“敌方军队”。
因为“我方”人数超过总数的一半，所以哪怕**一个换一个**（和我方不同的就同归于尽），最后剩下的**一定是我方**。

#### 代码实现（背下来，非常经典）：

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        winner = nums[0] # 假设第一个人是擂主
        count = 1        # 擂主目前的票数
        
        for i in range(1, len(nums)):
            if count == 0:
                # 如果票数归零了，说明前面的都“同归于尽”了，换新的擂主
                winner = nums[i]
                count = 1
            elif nums[i] == winner:
                # 如果是友军，票数 +1
                count += 1
            else:
                # 如果是敌人，一换一，票数 -1
                count -= 1
                
        return winner
```
