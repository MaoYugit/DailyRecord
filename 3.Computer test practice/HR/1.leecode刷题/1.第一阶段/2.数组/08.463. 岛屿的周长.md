# [463. 岛屿的周长](https://leetcode.cn/problems/island-perimeter/)

简单

给定一个 `row x col` 的二维网格地图 `grid` ，其中：`grid[i][j] = 1` 表示陆地， `grid[i][j] = 0` 表示水域。

网格中的格子 **水平和垂直** 方向相连（对角线方向不相连）。整个网格被水完全包围，但其中恰好有一个岛屿（或者说，一个或多个表示陆地的格子相连组成的岛屿）。

岛屿中没有“湖”（“湖” 指水域在岛屿内部且不和岛屿周围的水相连）。格子是边长为 1 的正方形。网格为长方形，且宽度和高度均不超过 100 。计算这个岛屿的周长。

**示例 1：**

![img](https://assets.leetcode-cn.com/aliyun-lc-upload/uploads/2018/10/12/island.png)

```
输入：grid = [[0,1,0,0],[1,1,1,0],[0,1,0,0],[1,1,0,0]]
输出：16
解释：它的周长是上面图片中的 16 个黄色的边
```

**示例 2：**

```
输入：grid = [[1]]
输出：4
```

**示例 3：**

```
输入：grid = [[1,0]]
输出：4
```

**提示：**

- `row == grid.length`
- `col == grid[i].length`
- `1 <= row, col <= 100`
- `grid[i][j]` 为 `0` 或 `1`



```python
class Solution:
    def islandPerimeter(self, grid: List[List[int]]) -> int:
        rows_len = len(grid)
        cols_len = len(grid[0])

        ans = 0

        directions = [(-1,0), (1,0), (0, -1), (0, 1)]

        for i in range(rows_len):
            for j in range(cols_len):
                if grid[i][j] == 1:
                    ans += 4
                    for dr, dc in directions:
                        next_r, next_c = i + dr, j + dc
                        if 0 <= next_r < rows_len and 0 <= next_c < cols_len and grid[next_r][next_c] == 1 :
                            ans-=1
                    
                
        return ans


        
```





在 Python 中，二维数组通常是用**列表的列表 (List of Lists)** 来实现的。

关于解题和算法面试（如 LeetCode），掌握二维数组的操作是基础中的基础。以下我将从**基础遍历**、**进阶技巧（方向数组）**、**Python 特有骚操作**以及**常用解题套路**四个方面为你详细讲解。

### 一、 基础遍历方法

假设我们有一个 $M \times N$ 的矩阵：

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
# 获取行数和列数
R = len(matrix)       # 行数 (Rows)
C = len(matrix[0])    # 列数 (Cols)
```

#### 1. 基于索引遍历 (最常用)
这是最通用的方式，因为你可以同时获得元素的坐标 `(r, c)` 和值。

```python
for r in range(R):
    for c in range(C):
        print(f"坐标: ({r}, {c}), 值: {matrix[r][c]}")
```

#### 2. 直接遍历元素 (Pythonic)
如果你不需要坐标，只需要值：

```python
for row in matrix:
    for val in row:
        print(val)
```

#### 3. 带着索引遍历 (Enumerate)
既想要 Pythonic 的写法，又想要坐标：

```python
for r, row in enumerate(matrix):
    for c, val in enumerate(row):
        print(r, c, val)
```

### 二、 核心解题技巧：方向数组 (Direction Arrays)

这是解决**迷宫、岛屿、搜索 (DFS/BFS)** 类题目最重要的技巧。不要写 4 个 `if` 来判断上下左右，那样代码很长且容易错。

#### 技巧：定义 `directions` 数组
比如你要向**上、下、左、右**四个方向移动：

```python
# 定义方向偏移量：(行变化, 列变化)
# 上(-1,0), 下(1,0), 左(0,-1), 右(0,1)
directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

# 当前坐标
curr_r, curr_c = 1, 1

# 遍历四个相邻节点
for dr, dc in directions:
    next_r, next_c = curr_r + dr, curr_c + dc
    
    # 这里必须检查边界！(技巧接下文)
    if 0 <= next_r < R and 0 <= next_c < C:
        print(f"邻居: {matrix[next_r][next_c]}")
```

**扩展：** 如果是**八个方向**（包括对角线），只需往 `directions` 里加更多元组即可。

### 三、 边界检查与初始化陷阱

#### 1. 封装边界检查
在写递归或搜索时，条件判断往往很长。建议写一个简单的 `check` 或 `in_area` 函数，或者作为一行判断模板：

```python
# 模板写法
if 0 <= next_r < R and 0 <= next_c < C:
    # 也就是：next_r 在 [0, R-1] 之间 且 next_c 在 [0, C-1] 之间
    pass
```

#### 2. 初始化陷阱 (浅拷贝) ⚠️ **非常重要**
当你需要创建一个全为 0 的 $M \times N$ 矩阵时：

❌ **错误写法：**
```python
# 这样写，修改 grid[0][0] 会导致每一行的第0个元素都被修改！
# 因为里面的列表引用的是同一个对象。
grid = [[0] * C] * R 
```

✅ **正确写法：**
```python
# 使用列表推导式
grid = [[0] * C for _ in range(R)]
```

### 四、 Python 特有的“骚操作”

#### 1. 矩阵转置 (Transpose)
将行变成列，列变成行。在 Python 中利用 `zip` 和解包 `*` 可以一行搞定：

```python
matrix = [[1, 2, 3], [4, 5, 6]]
# 转置
transposed = list(zip(*matrix))
# 结果: [(1, 4), (2, 5), (3, 6)] (变为元组列表)
# 变回列表: [list(row) for row in zip(*matrix)]
```

#### 2. 矩阵旋转 90 度
这是 LeetCode 常见题（如 "Rotate Image"）。
*   **顺时针旋转 90 度** = 先转置，再反转每一行。
    ```python
    rotated = [list(row)[::-1] for row in zip(*matrix)]
    ```
*   **逆时针旋转 90 度** = 先反转每一行，再转置。

### 五、 进阶算法套路 (解题模型)

#### 1. 二维坐标转一维 (Flattening)
有时候为了使用**二分查找**或**并查集 (Union Find)**，我们需要把二维矩阵看作一个长的一维数组。

*   二维坐标 `(r, c)` 转一维索引 `idx`：
    $$idx = r \times C + c$$
*   一维索引 `idx` 转二维坐标 `(r, c)`：
    $$r = idx // C$$
    $$c = idx \% C$$

**应用场景：** 在一个有序的二维矩阵中查找某个值（视作一维有序数组二分）。

#### 2. 二维前缀和 (2D Prefix Sum)
如果你需要频繁计算矩阵中某个**子矩形区域的和**，使用前缀和可以将查询优化到 $O(1)$。

构建 `P[i][j]` 表示从 `(0,0)` 到 `(i,j)` 的矩形和：
```python
# dp[i][j] = matrix[i-1][j-1] + 上 + 左 - 左上重叠部分
sum_val = matrix[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]
```
求子矩阵 `(r1, c1)` 到 `(r2, c2)` 的和：
```python
result = P[r2][c2] - P[r1-1][c2] - P[r2][c1-1] + P[r1-1][c1-1]
```

#### 3. 差分数组 (2D Difference Array)
如果你需要频繁对矩阵的某个**子区域的所有元素加/减一个值**。
技巧：只修改区域的四个角，最后再复原。

#### 4.原地修改 (In-place Modification)
有时候题目限制空间复杂度为 $O(1)$，你需要直接在原数组上标记状态。
*   **技巧：** 利用位运算，或者利用范围外的值。
*   **例子：** 《生命游戏》。如果 0 变 1，不要直接改 1，可以改成 2（代表“曾经是0，现在是1”），最后再遍历一次把 2 变回 1。这样遍历时可以通过 `%` 运算获取原始状态。

### 六、 总结实战代码模板 (DFS 搜索岛屿)

这是一个最经典的二维数组遍历模板（计算岛屿数量）：

```python
def numIslands(grid):
    if not grid: return 0
    
    R, C = len(grid), len(grid[0])
    count = 0
    
    def dfs(r, c):
        # 1. 边界检查
        if not (0 <= r < R and 0 <= c < C):
            return
        # 2. 是否已经是水(0)或者访问过(2)
        if grid[r][c] != '1':
            return
        
        # 3. 标记已访问 (原地修改，省去 visited 数组)
        grid[r][c] = '2' 
        
        # 4. 方向数组遍历
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        for dr, dc in directions:
            dfs(r + dr, c + dc)

    for r in range(R):
        for c in range(C):
            if grid[r][c] == '1':
                count += 1
                dfs(r, c) # 将与该陆地相连的所有陆地淹没
                
    return count
```

### 总结
1.  **熟练掌握 `for r` `for c` 循环。**
2.  **死记 `directions` 数组写法**，这是 Grid 类问题的核心。
3.  **小心初始化 `[[0]*N]*M` 陷阱。**
4.  **学会坐标映射**（一维转二维，转置 `zip`）。
