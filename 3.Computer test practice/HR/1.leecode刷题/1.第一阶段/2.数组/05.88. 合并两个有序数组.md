# [88. 合并两个有序数组](https://leetcode.cn/problems/merge-sorted-array/)

简单

给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n` ，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你 **合并** `nums2` 到 `nums1` 中，使合并后的数组同样按 **非递减顺序** 排列。

**注意：**最终，合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为了应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 `0` ，应忽略。`nums2` 的长度为 `n` 。

**示例 1：**

```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
解释：需要合并 [1,2,3] 和 [2,5,6] 。
合并结果是 [1,2,2,3,5,6] ，其中斜体加粗标注的为 nums1 中的元素。
```

**示例 2：**

```
输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
解释：需要合并 [1] 和 [] 。
合并结果是 [1] 。
```

**示例 3：**

```
输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
解释：需要合并的数组是 [] 和 [1] 。
合并结果是 [1] 。
注意，因为 m = 0 ，所以 nums1 中没有元素。nums1 中仅存的 0 仅仅是为了确保合并结果可以顺利存放到 nums1 中。
```

**提示：**

- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-109 <= nums1[i], nums2[j] <= 109`

**进阶：**你可以设计实现一个时间复杂度为 `O(m + n)` 的算法解决此问题吗？



```python
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        """
        Do not return anything, modify nums1 in-place instead.
        """
        length = m + n -1
        m = m - 1
        n = n - 1
        while m >= 0 and n >= 0:
            if nums1[m] > nums2[n]:
                nums1[length] = nums1[m]
                m -= 1
            else:
                nums1[length] = nums2[n]
                n -= 1
            length -= 1
            
        if m < 0 :
            for i in range(n, -1, -1):
                nums1[i] = nums2[i]
```

### 更好的写法推荐

既然用了 Python，我们可以利用 **切片（Slicing）** 来代替繁琐的循环，同时逻辑上可以更简化。

#### 推荐写法 1：标准双指针 + 切片收尾（面试满分写法）

```python
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        """
        三指针法：
        p1 指向 nums1 有效数据的末尾
        p2 指向 nums2 的末尾
        p  指向 nums1 总长度的末尾 (填坑位置)
        """
        p1 = m - 1
        p2 = n - 1
        p = m + n - 1

        # 只要两个数组都有数据，就比较大小，谁大谁填在最后
        while p1 >= 0 and p2 >= 0:
            if nums1[p1] > nums2[p2]:
                nums1[p] = nums1[p1]
                p1 -= 1
            else:
                nums1[p] = nums2[p2]
                p2 -= 1
            p -= 1
        
        # 【关键点】
        # 循环结束有两种情况：
        # 1. p1 先走完（m用完了）：nums2 还有剩余，直接把 nums2 剩下的搬过去。
        # 2. p2 先走完（n用完了）：nums1 剩下的本来就在原地，不用动！
        # 所以只需要处理 p2 >= 0 的情况
        nums1[:p2 + 1] = nums2[:p2 + 1]
```

#### 为什么这个写法更好？

1. **修复了 Bug**：使用 nums1[:p2 + 1] = nums2[:p2 + 1] 替代了你的 for 循环，利用 Python 底层批量赋值，速度快且不会写错范围。
2. **逻辑简化**：你原本写了 if m < 0，其实不用判断 m。
   - 
   - 如果 nums1 的元素还没用完（p1 >= 0），它们本身就在 nums1 里，位置是对的，不需要动。
   - 只有当 nums2 还有剩（p2 >= 0）时，才需要把它们补到 nums1 的最前面。

#### 推荐写法 2：极简赖皮法（仅限想偷懒时）

虽然不符合“进阶”的 

```
O(m+n)O(m+n)
```

 要求，但如果面试官没特别卡复杂度，或者你想先快速过一遍，可以这样写：

```python
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        # 把 nums2 接到 nums1 的后半段
        nums1[m:] = nums2
        # 直接调用标准库排序
        nums1.sort()
```

- **评价**：时间复杂度 

  ```
  O((m+n)log⁡(m+n))O((m+n)log(m+n))
  ```

  虽然慢一点，但在 LeetCode 上也能通过，且代码极短，不容易出错

**总结**
**面试建议**：使用 **推荐写法 1**，并将最后的收尾工作改成切片操作 nums1[:p2+1] = nums2[:p2+1]，这体现了你对 Python 语言特性的熟悉以及对边界条件的清晰认识。
