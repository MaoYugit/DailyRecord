[1502. 判断能否形成等差数列](https://leetcode.cn/problems/can-make-arithmetic-progression-from-sequence/)

简单

给你一个数字数组 `arr` 。

如果一个数列中，任意相邻两项的差总等于同一个常数，那么这个数列就称为 **等差数列** 。

如果可以重新排列数组形成等差数列，请返回 `true` ；否则，返回 `false` 。

**示例 1：**

```
输入：arr = [3,5,1]
输出：true
解释：对数组重新排序得到 [1,3,5] 或者 [5,3,1] ，任意相邻两项的差分别为 2 或 -2 ，可以形成等差数列。
```

**示例 2：**

```
输入：arr = [1,2,4]
输出：false
解释：无法通过重新排序得到等差数列。
```

**提示：**

- `2 <= arr.length <= 1000`
- `-10^6 <= arr[i] <= 10^6`



```python
class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        arr.sort()
        temp = arr[1] - arr[0]
        for i in range(2, len(arr)):
            if arr[i] - arr[i-1] != temp:
                return False
        return True
```

### 有没有更好的解法？（麻烦死了）

虽然你的解法已经是**标准答案**，但如果要追求极致（或者面试官故意刁难问你能不能 $O(N)$），是存在**数学+哈希表**的 $O(N)$ 解法的。

#### 进阶解法：数学 + 哈希表 ($O(N)$ 时间复杂度)

**核心原理：**
1.  找到最大值 `max_val` 和最小值 `min_val`。
2.  如果不构成等差数列，直接 False。
3.  如果构成等差数列，公差 $d$ 一定等于 `(max_val - min_val) / (n - 1)`。
4.  利用哈希表（集合）来查重和验证每个数是否在正确的位置上。

**代码演示（作为知识储备，面试时除非被问到，否则写你原来的就行）：**

```python
class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        min_val = min(arr)
        max_val = max(arr)
        n = len(arr)
        
        # 1. 如果最大值等于最小值，说明所有数都一样（公差为0），直接是等差数列
        if max_val == min_val:
            return True
        
        # 2. 如果差值不能被 (n-1) 整除，说明无法平均分配，肯定不行
        if (max_val - min_val) % (n - 1) != 0:
            return False
            
        diff = (max_val - min_val) // (n - 1)
        
        # 3.把所有数字放入集合，方便快速查找
        num_set = set(arr)
        
        # 4. 模拟一遍等差数列，看是否每个数都在集合里
        # 从最小值开始，每次加 diff，一共加 n 次
        curr = min_val
        for _ in range(n):
            if curr not in num_set:
                return False
            curr += diff
            
        return True
```
