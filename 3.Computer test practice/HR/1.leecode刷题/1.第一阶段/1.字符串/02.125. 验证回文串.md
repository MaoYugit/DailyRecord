# [125. 验证回文串](https://leetcode.cn/problems/valid-palindrome/)

如果在将所有大写字符转换为小写字符、并移除所有非字母数字字符之后，短语正着读和反着读都一样。则可以认为该短语是一个 **回文串** 。

字母和数字都属于字母数字字符。

给你一个字符串 `s`，如果它是 **回文串** ，返回 `true` ；否则，返回 `false` 。

**示例 1：**

```
输入: s = "A man, a plan, a canal: Panama"
输出：true
解释："amanaplanacanalpanama" 是回文串。
```

**示例 2：**

```
输入：s = "race a car"
输出：false
解释："raceacar" 不是回文串。
```

**示例 3：**

```
输入：s = " "
输出：true
解释：在移除非字母数字字符之后，s 是一个空字符串 "" 。
由于空字符串正着反着读都一样，所以是回文串。
```

**提示：**

- `1 <= s.length <= 2 * 105`
- `s` 仅由可打印的 ASCII 字符组成



```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        s = ''.join(i.lower() for i in s if i.isalnum())
        return s == s[::-1]

```



```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        i = 0
        j = len(s) - 1
        while i < j:
            if not s[i].isalnum():
                i += 1
                continue
            if not s[j].isalnum():
                j -= 1
                continue
           
            if s[i].lower() != s[j].lower():
                return False
            i += 1
            j -= 1
        return True
```





















`isalnum()` 是编程（主要是 **Python**，但 C++ 等语言也有类似函数）中的一个常用字符串方法。

它是 **"Is Alphanumeric"**（是字母或数字）的缩写。

### 核心含义
它的作用是检测一个字符串是否**只由字母和数字组成**。

*   **返回 True**：如果字符串中**所有字符**都是字母（a-z, A-Z）或数字（0-9），且字符串不为空。
*   **返回 False**：如果字符串中包含空格、标点符号、特殊字符（如 @, #, !），或者字符串为空。

---

### 记忆方法
*   **is** = 是否
*   **al** = **Al**pha (Alphabet，字母)
*   **num** = **Num**eric (Number，数字)
*   即：“是否全是字母或数字？”

---

### Python 中的示例代码

```python
# 1. 只有字母 -> True
print("Python".isalnum())  # True

# 2. 只有数字 -> True
print("12345".isalnum())   # True

# 3. 字母和数字混合 -> True
print("User123".isalnum()) # True

# 4. 包含空格 -> False (空格不是字母也不是数字)
print("User 123".isalnum()) # False

# 5. 包含标点符号/特殊字符 -> False
print("User@123".isalnum()) # False
print("www.google.com".isalnum()) # False (因为有小数点)

# 6. 空字符串 -> False
print("".isalnum()) # False
```

### 特别注意（关于中文）
在 **Python 3** 中，`isalnum()` 支持 Unicode 字符。这意味着**汉字**通常也会被视为“字母”的一种，从而返回 `True`。

```python
# 汉字 + 数字
print("你好123".isalnum())  # True (在 Python 3 中)
```

### 常见用途
它通常用于验证用户输入，例如：
*   **用户名检查**：很多网站要求用户名只能包含字母和数字，不能包含空格或特殊符号。
*   **数据清洗**：从乱码数据中筛选出有效的文本和数字部分





**isalpha()**：是不是**全是字母**？（**Is Alpha**bet）

- 不包含数字、空格、符号。
- *注意：汉字在 Python 3 中也被视为“字母”。*

```python
"abc".isalpha()   # True
"你好".isalpha()  # True
"abc1".isalpha()  # False (因为有数字)
```

**isdigit()**：是不是**全是数字**？（**Is Digit**）

- 只能是 0-9，不包含小数点、负号。

```python
"123".isdigit()   # True
"12.3".isdigit()  # False (小数点不算数字字符)
"-10".isdigit()   # False (负号不算)
```



**islower()**：是不是**全是小写**？

- 必须包含至少一个字母，且所有字母都是小写。

```python
"abc".islower()   # True
"abc1".islower()  # True (数字被忽略，只要字母是小写就行)
"Abc".islower()   # False
```

**isupper()**：是不是**全是大写**？

```python
"ABC".isupper()   # True
"ABC1".isupper()  # True
```

这个操作符的意思非常简单粗暴：**把字符串倒序（翻转）**。

### 1. 核心含义
`s[::-1]` 是 Python 切片（Slicing）的一种特殊写法，作用是**生成一个倒着排列的新字符串**。

*   **s**：要操作的字符串。
*   **[ : : -1]**：切片语法，意思是“从头取到尾，但是步长为 **-1**（即反向走）”。

---

### 2. 代码示例

```python
s = "Hello"
print(s[::-1]) 
# 输出: "olleH"

s = "12345"
print(s[::-1]) 
# 输出: "54321"
```

---

### 3. 原理解析（为什么是两个冒号？）

Python 的切片完整语法是 `[start : end : step]`
*   **start** (开始索引)：不写 默认为 0（开头）。
*   **end** (结束索引)：不写 默认为 最后一个字符。
*   **step** (步长)：
    *   如果是 `1`（默认），就是从左往右一个一个取。
    *   如果是 **`-1`**，就是**从右往左**一个一个取。

所以 `[::-1]` 的潜台词是：“**不管开始和结束在哪里，反正我要全选，并且倒着走。**”

---

### 4. 结合你之前的题目（回文串）

在 **LeetCode 125 (验证回文串)** 中，判断回文的核心逻辑就是看“正着读”和“反着读”是否一样。

结合你刚才学的 `isalnum()` 和 `join`，完整的**一行流**解法如下：

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        # 1. 清洗：只留字母数字 + 转小写
        clean_s = ''.join(i.lower() for i in s if i.isalnum())
        
        # 2. 判断：正着读 == 反着读？
        return clean_s == clean_s[::-1]
```

*   **`clean_s`**：是处理干净的字符串（例如 "aba"）。
*   **`clean_s[::-1]`**：是翻转后的字符串（例如 "aba"）。
*   **`==`**：如果两者相等，就是回文，返回 True。

这是 Python 面试中最标准、最优雅的写法。
