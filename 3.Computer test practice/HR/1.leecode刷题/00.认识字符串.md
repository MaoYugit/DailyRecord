### 第一部分：字符串面试通关指南 —— 基础与核心套路

#### 1. 磨刀不误砍柴工：语言特性的陷阱

在开始刷题前，你必须非常清楚你所用语言中字符串的**可变性（Mutability）**，否则会写出时间复杂度爆炸的代码。

*   **Java / Python / C# / Go**：字符串通常是**不可变（Immutable）**的。
    *   **陷阱**：在循环中做 `s = s + "c"` 或 `s += "c"`。
    *   **后果**：每次拼接都会申请新的内存并拷贝旧内容，导致 $O(N^2)$ 的复杂度。
    *   **对策**：必须使用 `StringBuilder` (Java), `list` 或 `[].join()` (Python), `strings.Builder` (Go)。
*   **C++**：`std::string` 是**可变（Mutable）**的。
    *   可以直接通过下标 `s[i] = 'a'` 修改，非常方便。

**面试考点**：有些题目要求“原地修改”（In-place），如果你用的是 Python/Java，你需要向面试官说明：“由于语言特性，我必须先转成字符数组（char array）处理，再转回字符串。”

#### 2. 核心套路一：双指针法 (Two Pointers)

这是字符串题目的“起手式”，主要解决**反转**、**回文**、**字符交换**类问题。

**模型 A：对撞指针（左右指针）**
*   **场景**：回文串判断、反转字符串。
*   **写法**：`left = 0`, `right = n - 1`，向中间逼近。
*   **经典例题**：
    *   **反转字符串 (LeetCode 344)**：也就是 `s[i]` 和 `s[n-1-i]` 交换。
    *   **验证回文串 (LeetCode 125)**：忽略非字母字符后，判断左右是否相等。

**模型 B：快慢指针**
*   **场景**：原地移除元素、字符串压缩、单词拆分。
*   **写法**：`fast` 指针负责遍历寻找目标，`slow` 指针指向下一个要更新的位置。
*   **经典例题**：
    *   **压缩字符串 (LeetCode 443)**。
    *   **替换空格**（剑指 Offer）：先扩容，然后双指针从后往前搬运数据（避免覆盖）。

#### 3. 核心套路二：滑动窗口 (Sliding Window)

**这是面试中的重中之重！** 只要看到题目问“**最长/最短/包含...的子串**”，第一时间想到滑动窗口。

**核心概念区分**：
*   **子串 (Substring)**：必须连续。（例如 "abc" 是 "abcde" 的子串）-> **用滑动窗口**。
*   **子序列 (Subsequence)**：可以不连续，但保持相对顺序。（例如 "ace" 是 "abcde" 的子序列）-> **通常用动态规划（DP）**。

**通用模板**：
维护一个窗口 `[left, right]`，通常配合**哈希表**（记录窗口内字符出现的次数或位置）。

```python
# 伪代码逻辑
def slidingWindow(s):
    window = {} # 哈希表
    left = 0
    result = 0
    
    for right in range(len(s)):
        # 1. 移入字符：将 s[right] 加入窗口
        char = s[right]
        window[char] = window.get(char, 0) + 1
        
        # 2. 判断窗口是否需要收缩（不满足条件了，或者找到了可行解要尝试更短的）
        while (窗口需要收缩的条件):
            # 3. 移出字符：将 s[left] 移出窗口
            d_char = s[left]
            window[d_char] -= 1
            left += 1
            
        # 4. 更新结果
        result = max/min(result, right - left + 1)
```

**必刷题目**：
1.  **无重复字符的最长子串 (LeetCode 3)**：绝对的高频题。
2.  **最小覆盖子串 (LeetCode 76)**：Hard 难度，但逻辑就是标准的滑动窗口，考察细节处理。
3.  **找到字符串中所有字母异位词 (LeetCode 438)**：固定长度的滑动窗口。

#### 4. 核心套路三：哈希表与统计

字符串本质上是字符的数组。如果题目涉及**统计字符数量**、**判断能否重组**，通常用哈希表或数组（如果是只有 26 个小写字母，用 `int[26]` 数组比 HashMap 快得多）。

**概念：异位词 (Anagram)**
*   定义：两个字符串包含的字符种类和数量完全相同，只是顺序不同。
*   **解法**：

### 一、 Python 字符串的“致命”特性与应对

在 Python 中，字符串是**不可变（Immutable）**的。这意味着你**不能**直接修改字符串中的某个字符。

#### 1. 错误示范（面试必挂）
```python
s = "hello"
s[0] = "H"  # 报错：TypeError: 'str' object does not support item assignment
```

#### 2. 性能陷阱
很多初学者会在循环里拼接字符串：
```python
# ❌ 千万别这样写
res = ""
for char in s:
    res += char  # 每次拼接都会创建新的字符串对象，复杂度是 O(N^2)
```

#### 3. 正确的 Pythonic 写法
在面试中，如果需要频繁修改或拼接字符串，**必须**使用列表（List）作为缓冲区，最后再 `join` 起来。

```python
# ✅ 标准写法
chars = []
for char in s:
    chars.append(char) # 只是往列表末尾加元素，O(1)
res = "".join(chars)   # 最后一次性拼接，O(N)
```

**另外两个 Python 神技（常用）：**
*   **切片（Slicing）**：`s[::-1]` 可以直接反转字符串，面试官通常允许使用，但如果题目核心就是考反转，你要会双指针。
*   **ASCII 转换**：
    *   `ord('a')` -> 97 （获取字符的整数码）
    *   `chr(97)` -> 'a' （将整数转回字符）
    *   用途：比如计算两个字符的距离，或者把字符映射到数组下标（`index = ord(c) - ord('a')`）。

### 二、 深度解析：双指针法 (Two Pointers)

这是字符串题的“物理外挂”。我们不把字符串看作一个整体，而是用两个“手指”分别指向字符串的不同位置，根据规则移动。

#### 场景：验证回文串 (LeetCode 125)
**题目**：给定一个字符串，忽略大小写和非字母数字字符，判断它是否是回文（正读反读一样）。

**逻辑拆解**：
1.  **指针对撞**：左手 (`left`) 指向开头，右手 (`right`) 指向结尾。
2.  **过滤垃圾**：如果左手指的不是字母/数字，左手往右移；右手同理。
3.  **比较**：如果左右手指的字符（转小写后）不一样，那就肯定不是回文，直接返回 False。
4.  **收缩**：匹配成功，左手+1，右手-1，继续往中间走。
5.  **结束**：当左手跑到右手右边去了 (`left >= right`)，说明全都检查完了。

**Python 代码详解**：

```python
def isPalindrome(s: str) -> bool:
    left, right = 0, len(s) - 1
    
    while left < right:
        # 1. 左指针跳过非字母数字
        # isalnum() 是 python 内置方法，检查是否是字母或数字
        while left < right and not s[left].isalnum():
            left += 1
        
        # 2. 右指针跳过非字母数字
        while left < right and not s[right].isalnum():
            right -= 1
            
        # 3. 比较（统一转小写）
        if s[left].lower() != s[right].lower():
            return False # 发现不对，立即判死刑
        
        # 4. 收缩
        left += 1
        right -= 1
        
    return True
```
*   **细节**：注意 `while left < right` 这个条件在内部循环也必须加上，防止全是符号导致指针越界（例如字符串是 "!!!"）。

### 三、 深度解析：滑动窗口 (Sliding Window)

这是最难理解但**性价比最高**的技巧。想象一个可变长方形的框，在字符串上滑过。

**核心心法**：**进 - 算 - 出**
1.  **进**：右边界 (`right`) 往右扩，把新字符加进来。
2.  **算**：看看现在窗口里的字符满足条件了吗？如果不满足（比如重复了），就进入第3步。
3.  **出**：左边界 (`left`) 往右缩，把旧字符扔出去，直到窗口恢复正常。

#### 典型案例：无重复字符的最长子串 (LeetCode 3)
**题目**：输入 "abcabcbb"，最长不重复子串是 "abc"，长度 3。

**逻辑演示**：
*   字符串：`a b c a b c b b`
*   `window` (用来记窗口里有什么字符): Set()
*   `left` = 0, `right` = 0

1.  `right` 指向 'a' -> 没见过 -> 加入 window -> 长度 1
2.  `right` 指向 'b' -> 没见过 -> 加入 window -> 长度 2
3.  `right` 指向 'c' -> 没见过 -> 加入 window -> 长度 3 (`abc`)
4.  **关键点**：`right` 指向 'a'。
    *   window 里已经有 'a' 了！**冲突发生**。
    *   我们要移动 `left`，把窗口最左边的东西扔掉，直到窗口里没有 'a' 为止。
    *   扔掉 `s[0]` ('a')。现在 window 变成了 `{'b', 'c'}`。
    *   好了，不冲突了，把新的 'a' 加进来。
5.  继续...

**Python 代码详解**：

```python
def lengthOfLongestSubstring(s: str) -> int:
    # 使用集合 set 来快速查找字符是否在窗口中
    window_chars = set()
    left = 0
    max_len = 0
    
    # right 负责主动向右探索
    for right in range(len(s)):
        current_char = s[right]
        
        # 如果新字符已经在窗口里了，这就是“冲突”
        # 我们必须不断移动 left，把字符移出窗口，直到冲突解决
        while current_char in window_chars:
            window_chars.remove(s[left]) # 移除最左边的字符
            left += 1 # 左指针右移
        
        # 此时窗口干净了，把新字符加进去
        window_chars.add(current_char)
        
        # 每次循环都更新一下最大长度
        # 窗口长度 = right - left + 1
        max_len = max(max_len, right - left + 1)
        
    return max_len
```
*   **思考题**：如果用 `dict` 记录字符最后出现的位置，是不是可以不用一步步移动 `left`，而是直接把 `left` 跳过去？（这是进阶优化，面试时先写出上面这个最稳）。

### 四、 深度解析：哈希表与异位词 (Anagram)

这类题核心在于：**不要关注字符的排列顺序，只关注字符出现的次数**。

Python 有一个超级好用的库：`collections.Counter`。面试时可以用，但建议你也掌握手写 `dict` 的方法，以防万一。

#### 典型案例：有效的字母异位词 (LeetCode 242)
**题目**：判断 `s = "anagram"`, `t = "nagaram"` 是不是由相同的字符组成。

**Python 的三种流派**：

**流派 1：暴力排序（简单但慢）**
```python
return sorted(s) == sorted(t)
# 复杂度 O(N log N)，因为排序比较耗时。
```

**流派 2：Counter 神器（推荐）**
```python
from collections import Counter
return Counter(s) == Counter(t)
# 复杂度 O(N)。Counter 会生成类似 {'a':3, 'n':1...} 的字典并自动比较。
```

**流派 3：手写数组/字典（最显功底）**
如果是纯小写字母，可以用一个长度 26 的数组代替哈希表，速度更快。

```python
def isAnagram(s: str, t: str) -> bool:
    if len(s) != len(t):
        return False
        
    # 创建一个长度26的列表，对应 a-z，初始全是0
    count = [0] * 26
    
    for char in s:
        # ord(char) - ord('a') 将字符映射为 0-25 的索引
        count[ord(char) - ord('a')] += 1
        
    for char in t:
        count[ord(char) - ord('a')] -= 1
        
    # 如果最后所有位置都是0，说明刚好抵消
    for c in count:
        if c != 0:
            return False
            
    return True
```

### 一、 模拟法：字符串转换整数 (String to Integer)

这类题目看起来最简单，完全就是按照人的逻辑去读字符串。但是，**边界条件（Corner Cases）**非常多，是很多大厂用来刷人的第一题。

#### 典型案例：字符串转换整数 (atoi) (LeetCode 8)
**题目**：实现 `atoi`，将字符串转为整数。要处理空格、正负号、非数字字符中断、以及整数溢出。

**Python 的痛点**：
Python 的整数是无限精度的（不会溢出），但题目通常要求你模拟 C++/Java 的 32 位整数环境（范围 $[-2^{31}, 2^{31}-1]$）。你需要手动检查是否越界。

**逻辑拆解（按顺序执行，严谨得像个机器）**：
1.  **去空**：去掉开头的空格。
2.  **看符号**：检查第一个字符是 `+` 还是 `-`。
3.  **读数字**：从刚才的位置开始，读连续的数字，遇到非数字就立刻停止。
4.  **截断**：如果不小心读出来的数太大（比如 99999999999），要把它强行变成最大值（$2^{31}-1$）。

**Python 代码详解**：

```python
def myAtoi(s: str) -> int:
    s = s.strip() # 1. 去掉首尾空格
    if not s:
        return 0 # 如果全是空，直接返回
    
    res = 0
    sign = 1 # 默认是正数
    index = 0
    
    # 2. 检查符号
    if s[0] == '-':
        sign = -1
        index += 1
    elif s[0] == '+':
        index += 1
        
    # 3. 读取连续数字
    # index < len(s) 防止越界
    while index < len(s) and s[index].isdigit():
        digit = int(s[index])
        res = res * 10 + digit
        index += 1
        
    # 加上符号
    res = res * sign
    
    # 4. 模拟 32 位整数的截断（面试关键点）
    int_min, int_max = -2**31, 2**31 - 1
    if res < int_min:
        return int_min
    if res > int_max:
        return int_max
        
    return res
```

**细节点拨**：
*   `s.strip()` 是 Python 最好用的清洗函数。
*   `s[index].isdigit()` 用来判断是否是 '0'-'9'。
*   最后那个**截断判断**一定要写，这是考察你对计算机底层数字存储的理解。

### 二、 中心扩散法：最长回文子串

在第一部分我们学了“验证回文串”（双指针向中间逼近）。现在问题升级了：**找出一个字符串里最长的那段回文**。

#### 典型案例：最长回文子串 (LeetCode 5)
**题目**：输入 "babad"，输出 "bab" 或 "aba"。

**思路误区**：
很多人想用“滑动窗口”，但滑动窗口不适合回文，因为回文不是简单的“多一个字符少一个字符”的逻辑。

**正确思路：中心扩散 (Expand Around Center)**
回文串一定有一个“中心”。
*   `"aba"` 的中心是 `'b'`（奇数长度）。
*   `"abba"` 的中心是中间的缝隙（偶数长度）。

**算法逻辑**：
遍历字符串的每一个位置，把它当作中心，向左右两边扩散，直到左右字符不一样为止。

**Python 代码详解**：

```python
def longestPalindrome(s: str) -> str:
    if not s: return ""
    
    res = ""
    
    # 定义一个扩散函数
    def expand(left, right):
        # 当没越界，且左右字符相等时，继续往外扩
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        # while 结束时，s[left] 和 s[right] 已经不相等了（或者越界了）
        # 所以回文的真实范围是 (left + 1) 到 (right - 1)
        # Python 切片是左闭右开，所以取 s[left+1 : right]
        return s[left+1 : right]

    for i in range(len(s)):
        # 情况1：奇数回文，中心是 s[i]，比如 "aba"
        s1 = expand(i, i)
        
        # 情况2：偶数回文，中心是 s[i]和s[i+1]之间，比如 "abba"
        s2 = expand(i, i + 1)
        
        # 更新最长的那个结果
        if len(s1) > len(res): res = s1
        if len(s2) > len(res): res = s2
            
    return res
```

**为什么这很重要？**
虽然这道题有 $O(N)$ 的解法（Manacher 算法），但面试中 **95% 的情况只要写出这个 $O(N^2)$ 的中心扩散法就是满分**。因为它逻辑清晰，不容易写错。

### 三、 前缀树 / 字典树 (Trie)

这是一个高级数据结构，但在处理**字符串前缀**问题时是无敌的。

**场景**：
*   搜索引擎的自动补全（输入 "app"，提示 "apple", "app store"）。
*   “单词是否存在？”
*   “是否有以 'pre' 开头的单词？”

**原理**：
把单词拆开，一个字母一个字母地挂在树上。
根节点 -> 'a' -> 'p' -> 'p' -> 'l' -> 'e' (标记结束)。

**Python 实现（面试只要背下这个模板）**：
Python 的字典（Dict）非常适合做 Trie 的节点。

#### 典型案例：实现 Trie (LeetCode 208)

```python
class TrieNode:
    def __init__(self):
        self.children = {} # 存放子节点，key是字符，value是TrieNode
        self.is_end = False # 标记这里是不是一个单词的结尾

class Trie:
    def __init__(self):
        self.root = TrieNode()

    # 插入单词
    def insert(self, word: str) -> None:
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode() # 没有路就造路
            node = node.children[char] # 往下走
        node.is_end = True # 走完单词，打个标记

    # 查找单词完整存在
    def search(self, word: str) -> bool:
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end # 必须完全匹配且是结尾

    # 查找是否有这个前缀
    def startsWith(self, prefix: str) -> bool:
        node = self.root
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True # 只要能顺着走完前缀就行，不需要是结尾
```

**怎么用？**
```python
trie = Trie()
trie.insert("apple")
print(trie.search("apple"))   # True
print(trie.search("app"))     # False (因为 app 只是前缀，不是完整单词)
print(trie.startsWith("app")) # True
```

### KMP 的核心痛点：暴力法太傻了

假设文本串是 `S`，模式串（要找的词）是 `P`。

**暴力法 (Brute Force)**：
*   比对 `S[i]` 和 `P[j]`。
*   如果匹配，继续。
*   **如果不匹配**：`i` 退回到起点的下一位，`j` 退回到 0。**（这就是最傻的地方，i 之前的努力全白费了）**

**KMP 的聪明之处**：
*   当匹配失败时，**`i`（文本指针）绝不后退**。
*   我们只移动 `P`（模式串），把它往右多移几位，跳过那些明知道不可能匹配的位置。

---

### 核心难点：Next 数组 (前缀表)

KMP 怎么知道该跳几位？这需要一个**秘密武器**：`next` 数组（在某些教材里叫 `pi` 数组）。

**直观理解**：
这个数组记录了模式串中，**每个子串的“最长相等前后缀”的长度**。

*   **前缀**：从头开始切的子串（不包含最后一个字符）。
*   **后缀**：从尾巴开始切的子串（不包含第一个字符）。
*   **相等前后缀**：比如 `ABA`，前缀有 `A`, `AB`；后缀有 `A`, `BA`。相等的只有 `A`，长度是 1。

**举例：模式串 `P = "ABABCA"`**

| 子串 (0~i) | 字符串内容 | 最长相等前后缀 | 长度 (Next[i]) | 说明                   |
| :--------- | :--------- | :------------- | :------------- | :--------------------- |
| `A`        | A          | 无             | 0              | 只有一个字符，没前后缀 |
| `AB`       | AB         | 前:A, 后:B     | 0              | A != B                 |
| `ABA`      | ABA        | 前:A, 后:A     | **1**          | 匹配了 "A"             |
| `ABAB`     | ABAB       | 前:AB, 后:AB   | **2**          | 匹配了 "AB"            |
| `ABABC`    | ABABC      | 无             | 0              | C 破坏了队形           |
| `ABABCA`   | ABABCA     | 前:A, 后:A     | 1              | 又是 A                 |

**Next 数组的作用**：
当你匹配到 `ABAB` **C** 发现不对劲（Mismatch）时，你看它前面是 `ABAB`。
查表可知 `ABAB` 的 Next 值是 **2**。
这就意味着：你不需要从头匹配了，你可以直接把模式串的第 2 位（下标是从0开始的，所以是第3个字符）对准当前位置继续比。

---

### Python 代码实现 (面试通用模板)

KMP 分为两步：
1.  **构建 Next 数组**。
2.  **利用 Next 数组进行匹配**。

#### 第一步：构建 Next 数组
这是一个“自己匹配自己”的过程。

```python
def build_next(p: str):
    """
    构建 next 数组
    next[i] 表示 p[0...i] 这个子串的最长相等前后缀长度
    """
    next_arr = [0] * len(p)
    j = 0 # j 代表前缀的末尾位置，也代表当前的最长相等前后缀长度
    
    # i 从 1 开始遍历（因为第一个字符 next[0] 肯定是 0）
    for i in range(1, len(p)):
        # 1. 前后缀不匹配时
        # j 就像被弹回一样，找更短的前缀尝试匹配
        # 这是一个 while 循环，可能要回退多次
        while j > 0 and p[i] != p[j]:
            j = next_arr[j - 1]
        
        # 2. 前后缀匹配时
        if p[i] == p[j]:
            j += 1
            
        # 3. 更新 next 数组
        next_arr[i] = j
        
    return next_arr
```

#### 第二步：主匹配逻辑 (KMP)
这个逻辑和构建 Next 数组几乎一模一样！

```python
def kmp_search(s: str, p: str) -> int:
    """
    在 s 中寻找 p，返回 p 第一次出现的下标，找不到返回 -1
    """
    if not p: return 0
    if not s or len(s) < len(p): return -1
    
    next_arr = build_next(p)
    j = 0 # p 的指针
    
    for i in range(len(s)): # i 是 s 的指针，只增不减
        # 1. 冲突发生！模式串指针 j 回退
        while j > 0 and s[i] != p[j]:
            j = next_arr[j - 1] # 这里的逻辑是 KMP 的灵魂
            
        # 2. 匹配成功，j 前进
        if s[i] == p[j]:
            j += 1
            
        # 3. 既然 j 走到了 len(p)，说明 p 已经匹配完了
        if j == len(p):
            return i - len(p) + 1 # 返回起始坐标
            # 如果要找所有出现位置，这里可以记录结果，然后让 j = next_arr[j-1] 继续找
            
    return -1
```

### 必考点总结（怎么背？）

如果面试官让你写 KMP，记住这个口诀：**“一模一样的两个循环”**。

1.  **构造 Next** 和 **主查找** 的代码结构几乎一模一样。
2.  核心都是 `while j > 0 and x != y: j = next[j-1]`。这个 `while` 是为了找到上一个可用的“公共前缀”，防止 `j` 直接变成 0。
3.  变量含义：`i` 扫描长串，`j` 扫描短串（或前缀）。

### 替代方案：Rabin-Karp (滚动哈希)

如果 KMP 实在太难记，你可以记一下 **Rabin-Karp** 的思路作为备选。
*   **思路**：把字符串看成数字（计算 Hash 值）。
*   比较 `Hash("abc")` 和 `Hash("abd")` 是否相等。如果相等，再逐字比较。
*   **优点**：代码逻辑符合直觉（滑动窗口 + 哈希）。
*   **缺点**：遇到大量哈希冲突时会退化，但在 Python 中实现起来比 KMP 容易解释。

1.  **优先级**：先熟练掌握 `Double Pointers` (双指针) 和 `Sliding Window` (滑动窗口)。

### 一、 核心思维：把字符串变成“二维表格”

当题目给你**两个字符串** `s1` 和 `s2`，问你它们的最长公共部分、或者把 A 变成 B 需要几步时，**99% 的情况**都要画一个表格。

*   **行 (Rows)**：代表 `s1` 的每一个字符。
*   **列 (Cols)**：代表 `s2` 的每一个字符。
*   `dp[i][j]`：通常代表 `s1` 的前 `i` 个字符和 `s2` 的前 `j` 个字符处理后的结果。

### 二、 最长公共子序列 (LCS)

**题目**：LeetCode 1143. Longest Common Subsequence
**描述**：给定 `text1 = "abcde"`, `text2 = "ace"`. 它们的最长公共子序列是 `"ace"`，长度为 3。
*   注意：**子序列**不需要连续（区别于子串），但顺序不能乱。

**逻辑推导**：
假设我们正在比较 `text1` 的第 `i` 个字符和 `text2` 的第 `j` 个字符：

1.  **如果相等 (`text1[i] == text2[j]`)**：
    *   太好了！找到了一个公共字符。
    *   那么长度就是“去掉这两个字符后剩下的部分的最长长度” + 1。
    *   公式：`dp[i][j] = dp[i-1][j-1] + 1`

2.  **如果不相等**：
    *   那这两个字符不可能同时选。
    *   我们要么扔掉 `text1` 的这个字符，看看前面的；要么扔掉 `text2` 的这个字符，看看前面的。
    *   我们想要最长的，所以取最大值。
    *   公式：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

**Python 代码详解**：

```python
def longestCommonSubsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    
    # 初始化 DP 表格
    # 大小是 (m+1) x (n+1)。为什么要 +1？
    # 因为第 0 行和第 0 列代表“空字符串”的情况，方便处理边界。
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # 开始填表（从 1 开始，因为 0 是空串）
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            
            # 注意：dp 表的下标 i 对应字符串的下标 i-1
            if text1[i - 1] == text2[j - 1]:
                # 字符匹配：继承左上角的结果 + 1
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                # 字符不匹配：看上面和左边，谁大听谁的
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
                
    # 表格右下角就是最终结果
    return dp[m][n]
```

### 三、 编辑距离 (Edit Distance) —— 终极 BOSS

**题目**：LeetCode 72. Edit Distance
**描述**：给你两个单词 `word1` 和 `word2`，计算将 `word1` 转换成 `word2` 所使用的最少操作数。你可以：插入、删除、替换。

**逻辑推导**：
这道题的思维和 LCS 非常像，但是这里求的是**最小值**（最小步数）。

比较 `word1[i]` 和 `word2[j]`：

1.  **如果相等**：
    *   不需要任何操作，大家都很开心。步数等于前面的步数。
    *   `dp[i][j] = dp[i-1][j-1]`

2.  **如果不相等**（必须操作一次，步数 +1）：
    *   我们有三种选择，选代价最小的那个：
    *   **删除** `word1[i]`：看 `dp[i-1][j]`（即 `word1` 前面部分变成 `word2` 的代价）。
    *   **插入**（相当于在 `word1` 后面加一个和 `word2[j]` 一样的）：看 `dp[i][j-1]`。
    *   **替换**（把 `word1[i]` 变成 `word2[j]`）：看 `dp[i-1][j-1]`。

**Python 代码详解**：

```python
def minDistance(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    # 1. 初始化边界（Base Case）
    # 如果 word2 是空的，word1 要变成它，必须删除所有字符
    for i in range(m + 1):
        dp[i][0] = i
    # 如果 word1 是空的，要变成 word2，必须插入所有字符
    for j in range(n + 1):
        dp[0][j] = j
        
    # 2. 填表
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            
            if word1[i - 1] == word2[j - 1]:
                # 字符一样，啥都不用做
                dp[i][j] = dp[i - 1][j - 1]
            else:
                # 字符不一样，取增删改三者中的最小值 + 1
                dp[i][j] = min(
                    dp[i - 1][j],    # 删除
                    dp[i][j - 1],    # 插入
                    dp[i - 1][j - 1] # 替换
                ) + 1
                
    return dp[m][n]
```

### 四、 字符串 + 栈 (Stack)

除了 DP，还有一类字符串题目不考算法，考**数据结构**。当字符串里出现**括号**、**嵌套**结构时，立刻想到**栈**。

**典型题目**：LeetCode 394. Decode String
**描述**：输入 `3[a2[c]]`，输出 `accaccacc`。

**逻辑拆解**：
我们从左到右读字符串，遇到不同的东西做不同的事：
1.  **数字**：可能有多位（比如 10），要算出来。
2.  **`[`**：表示一个新的嵌套开始了。把当前的数字和之前积累的字符串**压入栈 (Push)**，然后清空，准备处理括号里面的东西。
3.  **字母**：直接拼接到当前临时的字符串上。
4.  **`]`**：嵌套结束了。
    *   **弹出栈 (Pop)**：拿出上一层的字符串和倍数。
    *   **计算**：`新字符串 = 上一层字符串 + (当前字符串 * 倍数)`。

**Python 代码详解**：

```python
def decodeString(s: str) -> str:
    stack = []
    current_num = 0
    current_str = ""
    
    for char in s:
        if char.isdigit():
            # 处理多位数字，比如 "12"
            current_num = current_num * 10 + int(char)
            
        elif char == '[':
            # 遇到 [，把前面的状态存档（入栈）
            stack.append((current_str, current_num))
            # 重置当前状态，准备处理括号里的内容
            current_str = ""
            current_num = 0
            
        elif char == ']':
            # 遇到 ]，说明这一层处理完了，读档
            last_str, multiplier = stack.pop()
            # 组合：旧字符串 + (括号里的字符串 * 倍数)
            current_str = last_str + (current_str * multiplier)
            
        else:
            # 普通字母
            current_str += char
            
    return current_str
```
