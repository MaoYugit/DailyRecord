# [417. 太平洋大西洋水流问题](https://leetcode.cn/problems/pacific-atlantic-water-flow/)

中等

有一个 `m × n` 的矩形岛屿，与 **太平洋** 和 **大西洋** 相邻。 **“太平洋”** 处于大陆的左边界和上边界，而 **“大西洋”** 处于大陆的右边界和下边界。

这个岛被分割成一个由若干方形单元格组成的网格。给定一个 `m x n` 的整数矩阵 `heights` ， `heights[r][c]` 表示坐标 `(r, c)` 上单元格 **高于海平面的高度** 。

岛上雨水较多，如果相邻单元格的高度 **小于或等于** 当前单元格的高度，雨水可以直接向北、南、东、西流向相邻单元格。水可以从海洋附近的任何单元格流入海洋。

返回网格坐标 `result` 的 **2D 列表** ，其中 `result[i] = [ri, ci]` 表示雨水从单元格 `(ri, ci)` 流动 **既可流向太平洋也可流向大西洋** 。

**示例 1：**

![img](https://assets.leetcode.com/uploads/2021/06/08/waterflow-grid.jpg)

```
输入: heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]
输出: [[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
```

**示例 2：**

```
输入: heights = [[2,1],[1,2]]
输出: [[0,0],[0,1],[1,0],[1,1]]
```

**提示：**

- `m == heights.length`
- `n == heights[r].length`
- `1 <= m, n <= 200`
- `0 <= heights[r][c] <= 105`





417题（太平洋大西洋水流问题）其实是 DFS 里非常经典的一道**“脑筋急转弯”**题。

你现在的思路是：**“我是水，我想试着往下流，看看能不能流到海里。”**
这符合直觉，但写起来非常难。因为你要同时判断两个终点，而且还要防止在平地上无限转圈，非常容易超时或者写成死循环。

---

### 🧠 逆向思维：海王争霸

我们换个思路：**不要让水往下流，我们要让海浪往上爬！**

1.  **太平洋队（Pacific）**：从地图的**最左边**和**最上边**开始，逆着水流往高处爬。凡是能爬到的格子，标记为“太平洋地盘”。
2.  **大西洋队（Atlantic）**：从地图的**最右边**和**最下边**开始，逆着水流往高处爬。凡是能爬到的格子，标记为“大西洋地盘”。
3.  **结局**：既是“太平洋地盘”又是“大西洋地盘”的格子，就是答案。

**为什么这样简单？**
因为从海边出发，只需要无脑 DFS 往高处走就行了，不用管终点在哪里，只要能走通就是自己的地盘。

---

### 🗺️ 代码架构

我们需要两个集合（Set）来当“记账本”：
*   `pacific`：太平洋能爬到的坐标。
*   `atlantic`：大西洋能爬到的坐标。

**DFS 的逻辑变了**：
*   以前：能不能走？（是不是陆地？）
*   现在：能不能爬？（**下一个格子的高度 >= 我现在的高度**）

---

### 💻 代码实现（详细注释版）

请仔细看 `dfs` 函数里的判断条件，和之前都不太一样。

```python
class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        # 判空处理
        if not heights: return []
        
        rows, cols = len(heights), len(heights[0])
        
        # 1. 准备两个小本本，分别记录两个海洋能爬到的地方
        # 使用 set 是为了去重，查找也快
        pacific_visited = set()
        atlantic_visited = set()
        
        # 2. 定义爬山专用的 DFS
        # r, c: 当前坐标
        # visited: 是哪个海洋的本本？
        # prev_height: 上一步的高度（因为我们是逆流而上，所以要对比上一步）
        def dfs(r, c, visited, prev_height):
            # --- 保命连击 (Base Case) ---
            # 1. 越界了吗？
            if r < 0 or r >= rows or c < 0 or c >= cols:
                return
            
            # 2. 已经来过这了吗？（防止死循环）
            if (r, c) in visited:
                return
            
            # 3. 【核心逻辑】水往低处流，但我们现在是逆流往上爬
            # 所以，如果我们现在的高度 < 刚才那个格子的高度，说明爬不上来，水流断了。
            if heights[r][c] < prev_height:
                return
            
            # --- 标记 ---
            visited.add((r, c))
            
            # --- 扩散 ---
            # 现在的 prev_height 变成了 heights[r][c]
            dfs(r + 1, c, visited, heights[r][c])
            dfs(r - 1, c, visited, heights[r][c])
            dfs(r, c + 1, visited, heights[r][c])
            dfs(r, c - 1, visited, heights[r][c])

        # 3. 启动引擎：从边缘出发
        for r in range(rows):
            # 左边界：属于太平洋，从这里开始往里爬
            dfs(r, 0, pacific_visited, heights[r][0])
            # 右边界：属于大西洋，从这里开始往里爬
            dfs(r, cols - 1, atlantic_visited, heights[r][cols-1])
            
        for c in range(cols):
            # 上边界：属于太平洋
            dfs(0, c, pacific_visited, heights[0][c])
            # 下边界：属于大西洋
            dfs(rows - 1, c, atlantic_visited, heights[rows-1][c])
            
        # 4. 找交集：既在太平洋本本里，又在大西洋本本里
        # set 的 & 运算可以直接求交集，超级方便
        return list(pacific_visited & atlantic_visited)
```

**记住：** 这种“两个终点”或者“多源头”的问题，通常都采用 **逆向思维** —— 从终点出发往回找！
