## 🚀 第一阶段：心法与二叉树

#### 1. 什么是 DFS？（直觉理解）

想象你在走一个迷宫，DFS 的策略是：**“一条道走到黑，不撞南墙不回头”。**

*   你选定一条路，一直往前走。
*   如果前面没路了（撞南墙了），你就退回到上一个路口（回溯）。
*   换一条没走过的路继续走。
*   直到走完所有路。

在编程里，实现这个逻辑的神器就是 **递归（Recursion）**。

#### 2. 递归的核心模板（背下来！）

很多初学者写不出 DFS，是因为不知道怎么写递归。递归只有 **三个要素**，任何 DFS 代码都逃不出这个框架：

```python
def dfs(当前节点):
    # 1. 截止条件（撞南墙）
    # 如果当前节点是空的，或者是无效的，赶紧停下来返回
    if not 当前节点:
        return 

    # 2. 做点什么（处理当前层）
    # 比如打印节点值，或者把它加到结果里
    print(当前节点.val)

    # 3. 这里的风景看完了，去下一层（分身术）
    dfs(当前节点.左边)
    dfs(当前节点.右边)
```

**关键点：** 你要把 `dfs` 函数看作是一个**哪怕死也会完成任务的“包工头”**。你只要告诉他“去做”，不要去想他到底怎么一层层做的，**相信他能做完**。

#### 3. 实战演练：LeetCode 104. 二叉树的最大深度

这是最经典的入门题。
**题目：** 给你一个二叉树，求它最深有多少层？

**思考逻辑（DFS版）：**
假设你现在站在根节点（Root），你想知道这棵树有多深。
如果你比较“懒”，你会怎么做？
你会对你的两个手下（左子节点、右子节点）说：
*   “左边那位，你去量量你那边有多深？”
*   “右边那位，你也去量量你那边有多深？”
*   等他们汇报回来，你选一个更大的，然后 **+1**（加上你自己这一层），就是答案。

**代码实现（Python）：**

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        # 1. 截止条件（撞南墙）
        # 如果当前节点是 None（空的），那深度肯定是 0
        if not root:
            return 0
        
        # 2. & 3. 递归调用（分身去干活）
        # 这里的 maxDepth 就是那个“包工头”
        left_depth = self.maxDepth(root.left)   # 左边有多深？
        right_depth = self.maxDepth(root.right) # 右边有多深？
        
        # 汇报总结
        # 我这一层的深度 = 左边和右边较大的那个 + 1 (我自己)
        return max(left_depth, right_depth) + 1
```

**为什么这段代码能工作？**
你不需要人肉模拟每一层（那样脑子会炸）。你只需要相信：`self.maxDepth(root.left)` 既然叫这个名字，它就一定能返回左边的深度。这就是**递归的“信任”**。

#### 4. 实战演练：LeetCode 144. 二叉树的前序遍历

**题目：** 给你一个二叉树，返回它的节点值列表。顺序是：中 -> 左 -> 右。

**套用我们的模板：**

```python
class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = [] # 这是一个小本本，用来记数字
        
        def dfs(node):
            # 1. 截止条件
            if not node:
                return
            
            # 2. 做点什么（题目要求：中 -> 左 -> 右）
            # 所以我们先记录当前节点（中）
            res.append(node.val) 
            
            # 3. 去下一层
            dfs(node.left)  # 接着去左边
            dfs(node.right) # 最后去右边
        
        # 启动引擎
        dfs(root)
        return res
```

**如果是中序遍历（LeetCode 94）怎么办？**
只要改一下顺序！
*   前序：中 -> `dfs(左)` -> `dfs(右)`
*   中序：`dfs(左)` -> 中 -> `dfs(右)`
*   后序：`dfs(左)` -> `dfs(右)` -> 中

你看，这就是 DFS 的魅力，**结构永远不变，只变处理数据的位置**。

### 🗺️ 从“二叉树”到“二维网格”的进化

在二叉树里（第一阶段），我们的选择很少：只有 **左** 和 **右** 两条路。
但在二维网格里（比如一个棋盘），如果你站在一个格子上，你有 **4 个方向** 可以走：**上、下、左、右**。

**最大的区别是：**
*   **二叉树**：只能往下走，不会走回头路。
*   **网格**：可以绕圈圈！如果你不加限制，DFS 就会在两个格子之间无限循环（左 -> 右 -> 左 -> 右...），直到报错。

所以，网格 DFS 多了一个核心逻辑：**标记你去过的地方（Mark Visited）**。

### 🏝️ 经典案例：LeetCode 200. 岛屿数量 (Number of Islands)

这是网格 DFS 的**鼻祖**。学会这一道题，后面几十道题都是换汤不换药。

**题目**：给你一个由 `'1'`（陆地）和 `'0'`（水）组成的二维网格，请计算网格中岛屿的数量。（连在一起的 1 算一个岛）。

**思路：生化危机（病毒感染法）**
想象你是上帝，你在遍历这个地图。
1.  当你第一次发现一块陆地（`'1'`）时，**岛屿数量 +1**。
2.  但是！为了防止之后重复数这块地，你要立刻对这块地投放“病毒”（启动 DFS）。
3.  **DFS 的作用**：这个病毒会把当前这块陆地传染变成水（`'0'`），并且向四周扩散。凡是和它连着的陆地，统统变成水。
4.  **结果**：整块岛屿直接就在地图上“消失”了（被炸沉了）。
5.  这样当你继续遍历地图时，再遇到刚才那块岛屿的任何部分，看到的都是水，就不会重复计数了。

---

### 📝 核心模板（背下来！）

这是处理网格问题的**万能公式**。任何网格 DFS 都要先写这几行 **“保命代码”**（Base Case）。

**坐标系小知识**：
*   `grid` 是一个二维数组。
*   `r` (row) 代表行号（上下）。
*   `c` (col) 代表列号（左右）。
*   向上走：`(r-1, c)`，向下走：`(r+1, c)`
*   向左走：`(r, c-1)`，向右走：`(r, c+1)`

**代码实现：**

```python
class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        if not grid:
            return 0
            
        # 1. 这种题目，先算出地图长宽，方便后面用
        rows = len(grid)
        cols = len(grid[0])
        count = 0  # 记录岛屿数量
        
        # 2. 定义我们的“病毒” DFS 函数
        def dfs(r, c):
            # --- 核心保命 4 连击 (Base Case) ---
            # 如果坐标越界（跑出地图了），赶紧停！
            if r < 0 or r >= rows or c < 0 or c >= cols:
                return
            
            # 如果这里已经是水（'0'）了，或者是已经炸过的岛，赶紧停！
            if grid[r][c] == '0':
                return
            
            # --- 做点什么 ---
            # 走到这里，说明 grid[r][c] 肯定是 '1' (陆地)
            # 把它变成 '0' (淹没它/标记为已访问)，防止回头
            grid[r][c] = '0' 
            
            # --- 分身术（向 4 个方向扩散） ---
            dfs(r - 1, c) # 上
            dfs(r + 1, c) # 下
            dfs(r, c - 1) # 左
            dfs(r, c + 1) # 右

        # 3. 上帝视角：遍历地图的每一个格子
        for r in range(rows):
            for c in range(cols):
                # 只有发现新大陆（'1'）的时候，才触发逻辑
                if grid[r][c] == '1':
                    count += 1  # 发现一个岛！记下来
                    dfs(r, c)   # 派病毒去把这个岛彻底铲平（避免重复数）
                    
        return count
```

---

### 🧐 详细拆解“保命 4 连击”

新手写网格 DFS，最容易报 `IndexError`（数组越界）。
你必须在 dfs 函数的第一行，像念咒语一样写下这判断：

```python
if r < 0 or r >= rows or c < 0 or c >= cols:
    return
```
*   `r < 0`: 太靠上了，出界了。
*   `r >= rows`: 太靠下了，出界了。
*   `c < 0`: 太靠左了，出界了。
*   `c >= cols`: 太靠右了，出界了。

只要满足任何一条，说明你跑出地图了，必须立刻 `return`。

### ⚔️ 实战演练：LeetCode 695. 岛屿的最大面积

这道题和上面那道题（200）几乎一模一样，只是要求变了。
*   200 题：求岛屿的**个数**（dfs 只负责炸岛，不返回值）。
*   695 题：求最大的那个岛有**多大**（dfs 需要返回面积）。

**修改思路：**
DFS 函数现在变成了“测量员”。
1.  如果出界或者是水，面积是 0。
2.  如果是陆地，先把地淹了（标记），然后面积 = 1（自己）+ 上面的面积 + 下面的面积 + 左 + 右。

**代码（尝试看懂区别）：**

```python
class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        max_area = 0 # 记录目前为止见过的最大面积
        
        def dfs(r, c):
            # 1. 保命连击 + 遇到水就停
            # 注意：这题里的水是 0，陆地是 1 (数字)
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == 0:
                return 0 # 没地，面积是 0
            
            # 2. 标记已访问 (淹没它)
            grid[r][c] = 0 
            
            # 3. 算面积：我自己(1) + 四个方向汇报上来的面积
            return 1 + dfs(r-1, c) + dfs(r+1, c) + dfs(r, c-1) + dfs(r, c+1)

        # 4. 遍历全图
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1:
                    # 这次我们需要 DFS 给我们返回一个面积数字
                    current_area = dfs(r, c)
                    # 更新最大值
                    max_area = max(max_area, current_area)
                    
        return max_area
```
