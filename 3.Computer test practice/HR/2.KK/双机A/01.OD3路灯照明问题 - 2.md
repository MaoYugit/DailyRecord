一条长l的笔直的街道上有n个路灯，若这条街的起点为0，终点为l，第i个路灯坐标为a[i] ，每盏灯可以覆盖到的最远距离为d，

为了照明需求，所有灯的灯光必须覆盖整条街，但是为了省电，要使这个d最小，请找到这个最小的d。

输入描述:

每组数据第一行两个整数n和l（n大于0小于等于1000，l小于等于1000000000大于0）。

第二行有n个整数(均大于等于0小于等于l)，为每盏灯的坐标，多个路灯可以在同一点。

输出描述:

输出答案，保留两位小数。

示例1   输入输出示例仅供调试，后台判题数据一般不包含示例

输入

7 15
15 5 3 7 9 14 0

输出

2.50





**注意首尾情况判别**

```python
import sys

def solve():
    try:
        line1 = sys.stdin.readline().strip()
        list1 = list(map(int, line1.split()))
        n = list1[0]
        l = list1[1]

        line2 = sys.stdin.readline().strip()
        list2 = list(map(int, line2.split()))

        list2.sort()
    except ValueError:
        return

    min_wide = 0
    for i in range(1, n):
        current_lit_wide = (list2[i] - list2[i - 1]) / 2
        min_wide = max(min_wide, current_lit_wide)

    if list2[n - 1] + min_wide < l:
        min_wide = l - list2[n - 1]
    if list2[0] > min_wide:
        min_wide = list2[0]

    print(f"{min_wide:.2f}")

if __name__ == '__main__':
    solve()



```
