### 题目描述

某公司研发了一款高性能AI处理器。每台物理设备具备8颗AI处理器，编号分别为0、1、2、3、4、5、6、7。

编号0-3的处理器处于同一个链路中，编号4-7的处理器处于另外一个链路中，不同链路中的处理器不能通信。

现给定服务器可用的处理器编号数组array，以及任务申请的处理器数量num，找出符合下列亲和性调度原则的芯片组合。

如果不存在符合要求的组合，则返回空列表。

**亲和性调度原则：**

-如果申请处理器个数为1，则选择同一链路，剩余可用的处理器数量为1个的最佳，其次是剩余3个的为次佳，然后是剩余2个，最后是剩余4个。

-如果申请处理器个数为2，则选择同一链路剩余可用的处理器数量2个的为最佳，其次是剩余4个，最后是剩余3个。

-如果申请处理器个数为4，则必须选择同一链路剩余可用的处理器数量为4个。

-如果申请处理器个数为8，则申请节点所有8个处理器。

**提示：**

任务申请的处理器数量只能是1、2、4、8。
编号0-3的处理器处于一个链路，编号4-7的处理器处于另外一个链路。
处理器编号唯一，且不存在相同编号处理器。
输入描述

**输入**包含可用的处理器编号数组array，以及任务申请的处理器数量num两个部分。

第一行为array，第二行为num。例如：

[0, 1, 4, 5, 6, 7]

表示当前编号为0、1、4、5、6、7的处理器可用。任务申请1个处理器。

0 <= array.length <= 8

0 <= array[i] <= 7

num in [1, 2, 4, 8]

**输出描述**

输出为组合列表，当array=[0，1，4，5，6，7]，num=1 时，输出为[[0], [1]]。

示例1 输入输出示例仅供调试，后台判题数据一般不包含示例

输入

[0, 1, 4, 5, 6, 7]

1

**输出**

[[0], [1]]

**说明**

根据第一条亲和性调度原则，在剩余两个处理器的链路（0, 1, 2, 3）中选择处理器。

由于只有0和1可用，则返回任意一颗处理器即可。





```python
import sys
import json


def solve():
    try:
        line1 = sys.stdin.readline().strip()
        if not line1:
            return
        line2 = sys.stdin.readline().strip()
    except ValueError:
        return
    array = json.loads(line1)
    num = int(line2)

    link1 = []
    link2 = []
    out1 = []

    for core in array:
        if core < 4:
            link1.append(core)
        else:
            link2.append(core)

    if num == 8:
        if len(array) == 8:
            print([array])
        else:
            print([])
        return

    strategies = []
    if num == 1:
        strategies = [1, 3, 2, 4]
    if num == 2:
        strategies = [2, 4, 3]
    if num == 4:
        strategies = [4]

    links = [link1, link2]
    for count_needed in strategies:
        found = False
        for link in links:
            if len(link) == count_needed:
                if num == 1:
                    for x in link:
                        out1.append([x])
                elif num == 2:
                    n = len(link)
                    for i in range(n):
                        for j in range(i + 1, n):
                            out1.append([link[i], link[j]])
                elif num == 4:
                    out1.append(link)

                found = True
        if found:
            break

    print(out1)


if __name__ == '__main__':
    solve()
```

```python
import sys
import json
from itertools import combinations

def solve():
    # 1. 获取输入 (使用最稳健的 json.loads)
    try:
        line1 = sys.stdin.readline().strip()
        if not line1: return
        array = json.loads(line1)
        num = int(sys.stdin.readline().strip())
    except ValueError:
        return

    # 2. 预处理：将处理器分为两个链路
    # link1: 0-3, link2: 4-7
    link1 = [x for x in array if x < 4]
    link2 = [x for x in array if x >= 4]
    # 放入列表方便后续统一遍历
    links = [link1, link2]

    # 3. 特殊情况：申请 8 个
    # 必须两个链路都满，即总数必须是8
    if num == 8:
        if len(array) == 8:
            print([array]) # 只有一种组合，就是全选
        else:
            print([])
        return

    # 4. 定义策略表 (核心逻辑)
    # key = 申请数量
    # value = [优先级1(剩余数量), 优先级2(剩余数量), ...]
    priority_map = {
        1: [1, 3, 2, 4],
        2: [2, 4, 3],
        4: [4]
    }

    # 获取当前申请数量对应的优先级规则
    strategies = priority_map.get(num, [])
    
    res = []
    
    # 5. 遍历优先级策略
    # 比如 num=1, 先找有没有链路上只剩1个的，没有再找剩3个的...
    for count_needed in strategies:
        found_in_this_strategy = False
        
        # 遍历两个链路
        for link in links:
            # 如果某链路的剩余数量 == 当前策略要求的数量
            if len(link) == count_needed:
                # 生成组合：从该链路中取出 num 个元素的所有组合
                # combinations([0, 1], 1) -> [(0,), (1,)]
                combs = list(combinations(link, num))
                # 转成列表格式并加入结果
                for c in combs:
                    res.append(list(c))
                found_in_this_strategy = True
        
        # 如果在当前最高优先级找到了结果，就停止，不需要找次佳方案了
        if found_in_this_strategy:
            break

    # 6. 输出结果
    # 题目要求输出组合列表，排序是个好习惯（虽然itertools生成的通常有序）
    res.sort() 
    print(res)

if __name__ == '__main__':
    solve()
```
