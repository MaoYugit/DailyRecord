### 题目名称
路灯照明问题

### 题目描述
在一条笔直的公路上安装了 N个路灯，从位置 0 开始安装，路灯之间相距 100$米（即路灯坐标为 0, 100, 200, ...）。

每个路灯都有自己的照明半径 r，每个路灯的照明范围为 `[pos - r, pos + r]`。
测试用例保证 N$个路灯的照明半径 r 均大于 0。

请计算在第一个路灯（位置 $0$）和最后一个路灯（位置 $(N-1) \times 100$）之间，**无法被路灯照明的区域的总长度**。

### 输入描述
- 第一行输入一个整数 N ，表示路灯的个数。
- 第二行输入 N 个整数，表示每个路灯的照明半径 r，整数之间用空格分隔。

### 输出描述
- 输出一个整数，表示未照明区域的总长度。

### 示例 1
**输入**
```text
2
50 50
```
**输出**
```text
0
```
**说明**
路灯1覆盖 [-50, 50]，路灯2覆盖 [50, 150]。
[0, 100]区域完全被覆盖，未照明长度为 0。

### 示例 2
**输入**
```text
4
50 70 20 70
```
**输出**
```text
20
```
**说明**
路灯位置分别为 0, 100, 200, 300。
我们只统计 [0, 300] 范围内的未照明区域。
经计算，区间 [170, 180] 和 [220, 230] 未被照明。
总长度为 10 + 10 = 20。

---

### 正确解题思路：区间合并法

1.  **转换**：将每个路灯视为一个区间。
    *   第 `i`个路灯的位置是 `i * 100`。
    *   它的覆盖区间是 `[i * 100 - r, i * 100 + r]`。
2.  **排序**：将所有区间按照**左边界（起点）**从小到大排序。
3.  **扫描（合并）**：
    *   我们需要覆盖的总长度是 `0` 到 `(N-1) \times 100`。
    *   用一个变量 `current_cover_end` 记录当前已经连续覆盖到的最远距离，初始为 0。
    *   遍历每个区间：
        *   如果区间的**起点**大于 `current_cover_end`，说明中间断开了（有未照明区域），累加缺口长度，并更新 `current_cover_end`。
        *   如果区间的**起点**小于等于 `current_cover_end`，说明接上了，更新 `current_cover_end` 为更远的位置。

---

### 满分代码（ACM 模式）

这是可以拿 100 分的标准写法，可以直接运行。

```python
import sys

def solve():
    # 1. 更加稳健的输入读取方式
    # 读取全部输入并按空白切分
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    # 获取路灯数量 N
    n = int(input_data[0])
    # 获取 N 个半径
    radii = list(map(int, input_data[1:]))

    # 题目要求的总路程终点：(N-1) * 100
    total_length = (n - 1) * 100
    
    # 2. 生成所有路灯的覆盖区间
    intervals = []
    for i in range(n):
        pos = i * 100
        r = radii[i]
        # 区间：[pos - r, pos + r]
        start = pos - r
        end = pos + r
        intervals.append((start, end))

    # 3. 按区间左边界排序
    intervals.sort(key=lambda x: x[0])

    # 4. 扫描计算未照明长度
    unlit_length = 0
    # 当前连续覆盖到的最右边位置（初始为0，因为我们只关心从0开始的路程）
    current_cover_end = 0

    for start, end in intervals:
        # 优化：如果当前区间完全在 0 的左边且接触不到 0，其实对覆盖正方向没帮助
        # 但由于排序了且逻辑包含 max，下面的逻辑也能自动处理，不需要特判

        if start > current_cover_end:
            # 【情况A】：出现断档
            # 当前区间的起点 在 已覆盖区域 之后
            # 缺口范围是 [current_cover_end, start]
            
            # 注意：我们要统计的缺口必须在 total_length 范围内
            # 如果断档开始的位置都已经超过总长度了，就不用算了
            if current_cover_end >= total_length:
                break
                
            # 计算缺口长度（注意不能超过 total_length）
            gap_start = current_cover_end
            gap_end = min(start, total_length)
            
            unlit_length += (gap_end - gap_start)
            
            # 更新已覆盖位置
            current_cover_end = end
        else:
            # 【情况B】：区间重叠或相连
            # 扩展最远覆盖距离
            current_cover_end = max(current_cover_end, end)

    # 5. 检查最后一段
    # 遍历完所有路灯后，如果覆盖的最远距离还不到终点，说明最后有一段没亮
    if current_cover_end < total_length:
        unlit_length += (total_length - current_cover_end)

    print(unlit_length)

if __name__ == "__main__":
    solve()
```

### 代码逻辑图解

假设输入 `2` 个路灯，半径 `50 50`。总长 `100`。
1.  区间生成：
    *   灯0：位置0，半径50 $\rightarrow$ `[-50, 50]`
    *   灯1：位置100，半径50 $\rightarrow$ `[50, 150]`
2.  `current_cover_end` 初始为 0。
3.  遍历 `[-50, 50]`：
    *   `start` (-50) < `current_cover_end` (0)。没断档。
    *   更新 `current_cover_end` = max(0, 50) = **50**。
4.  遍历 `[50, 150]`：
    *   `start` (50) == `current_cover_end` (50)。没断档（刚好接上）。
    *   更新 `current_cover_end` = max(50, 150) = **150**。
5.  循环结束。
6.  检查结尾：`current_cover_end` (150) >= `total_length` (100)。
7.  结果：未照明 0。

假设输入 `2` 个路灯，半径 `10 10`。总长 `100`。
1.  区间：`[-10, 10]`, `[90, 110]`。
2.  `current_cover_end` = 0。
3.  遍历 `[-10, 10]`：
    *   更新 `current_cover_end` = 10。
4.  遍历 `[90, 110]`：
    *   `start` (90) > `current_cover_end` (10)。**断档！**
    *   缺口 = `90 - 10 = 80`。
    *   更新 `current_cover_end` = 110。
5.  结果：80。

这才是符合 ACM/OD 标准的解法。

from typing import List, Optional

def notLightArea(n: int, radius: List[int]) -> int:
    ans = 0
    for i in range(n-1):
        if radius[i] + radius[i+1] < 100:
            ans += 100 - radius[i] - radius[i+1]
    return ans
