### 题目名称
相对开音节

### 题目描述
相对开音节构成的结构为 **辅音 + 元音（aeiou）+ 辅音（r除外）+ e**。
常见的单词有 `bike`、`cake` 等。

给定一个字符串，以空格为分隔符，反转每个单词的字母。
**规则：**
1. 如果单词中包含如数字、标点符号等其他**非字母**字符，则该单词**不进行反转**。
2. 如果单词中只包含字母（a-z, A-Z），则进行反转。
3. 反转后，计算整个句子中含有**相对开音节结构**的子串个数。

**注意：**
- 单词之间以空格分割。
- 相对开音节是连续的子串。
- 连续的子串中，部分字符可以重复（即支持重叠计算）。
- 字母判断时只考虑小写（即处理时通常将大写转换为小写进行判断）。

### 输入描述
- 输入一行字符串，包含多个单词，单词之间用空格分隔。
- 字符串长度 $< 10000$。
- 单词可能包含字母、数字、符号。

### 输出描述
- 输出一个整数，代表整个字符串中符合“相对开音节”结构的子串总数。

---

### 示例 1
**输入**
```text
ekam a ekac
```

**输出**
```text
2
```

**说明**
1.  `ekam` 全是字母，反转为 `make`。
2.  `a` 全是字母，反转为 `a`。
3.  `ekac` 全是字母，反转为 `cake`。
4.  处理后的字符串为 `make a cake`。
    - `make` 包含相对开音节 `make` (m辅 + a元 + k辅非r + e)。
    - `cake` 包含相对开音节 `cake` (c辅 + a元 + k辅非r + e)。
    - 总计为 2。

### 你的代码主要存在以下 3 个严重问题：

1.  **忽略了大小写问题**：
    *   题目通常隐含（或明确说明）字母判断只考虑小写，或者输入包含大写时需要识别。
    *   你的代码没有将字符转为小写。如果输入 `MAKE`，`A` 不在 `yuanyin` 集合中，逻辑直接崩盘。
2.  **漏掉了题目核心条件：`r` 除外**：
    *   题目要求：相对开音节结构为 `辅音 + 元音 + 辅音(r除外) + e`。
    *   你的代码在判断第 3 个字符（`flag=2` 跳转到 `flag=3`）时，只判断了 `not in yuanyin`，**忘记判断它不能是 `r`**。
3.  **状态机（Flag）逻辑难以处理“重叠”**：
    *   题目允许重叠（例如 `kekeke` 可能包含两个 `keke`）。
    *   你的 `flag` 逻辑是线性的，当匹配成功或失败时，很难正确回退到“当前字符可能是下一个模式的开头”这种状态。
    *   **解决方案**：对于固定长度（4个字符）的子串匹配，**滑动窗口**（Sliding Window）是最简单且不易出错的方法，完全不需要复杂的状态跳转。

### 修正后的标准题解（ACM 风格）

这里使用 **滑动窗口** 方法，逻辑清晰，能够拿满分。

```python
import sys

# 辅助函数：判断是否为元音
def is_vowel(char):
    return char in "aeiou"

# 辅助函数：判断是否为辅音
def is_consonant(char):
    return char.isalpha() and not is_vowel(char)

def solve():
    # 输入
    input_data = sys.stdin.read()
    if not input_data:
        print(0)
        return
    # 存储每一个“单词“
    words = input_data.split()
    # 存储处理过的单词
    processed_words = []

    # 反转符合条件的单词
    for word in words:
        if word.isalpha():
            processed_words.append(word[::-1])
        else:
            processed_words.append(word)

    # 统计相对开音节数量
    count = 0

    for word in processed_words:
        # 长度小于4一定不满足条件
        if len(word) < 4:
            continue

        # 转换为小写再处理
        lower_word = word.lower()

        for i in range(len(word) - 3):
            c1 = lower_word[i]
            c2 = lower_word[i + 1]
            c3 = lower_word[i + 2]
            c4 = lower_word[i + 3]

            if not (c1.isalpha() and c2.isalpha() and c3.isalpha() and c4.isalpha()):
                continue

            if (is_consonant(c1) and is_vowel(c2) and is_consonant(c3) and c3 != "r" and c4 == "e"):
                count += 1
    print(count)


if __name__ == "__main__":
    solve()
```

### 为什么这个代码更好？

1.  **逻辑分离**：先处理反转，再处理计数。
2.  **滑动窗口 (`range(len(word) - 3)`)**：
    *   这是处理固定长度子串匹配的神器。
    *   比如 `kekeke`：
        *   `i=0`: 取 `keke` -> 符合 -> count+1
        *   `i=1`: 取 `ekek` -> 不符合
        *   `i=2`: 取 `keke` -> 符合 -> count+1
    *   这完美解决了重叠问题，而不需要复杂的 flag 状态管理。
3.  **严谨的条件判断**：明确写出了 `c3 != 'r'` 和 `c4 == 'e'`。
4.  **大小写处理**：使用 `word.lower()` 确保判断时不受大小写影响，同时 `isalpha()` 确保了只在纯字母段中计数。

# 这是一个基于你原本思路的修正，但强烈建议使用上面的滑动窗口法
from typing import List

def opTwoYin(s: str) -> int:
    yuanyin = set("aeiou")
    sList = s.split(" ")
    count = 0

    # 1. 反转逻辑
    for i in range(len(sList)):
        if sList[i].isalpha():
            sList[i] = sList[i][::-1]

    # 2. 统计逻辑
    for word in sList:
        # 必须转小写，否则大写字母无法识别
        temp_word = word.lower() 
        
        # 使用切片（滑动窗口）代替 Flag 状态机
        # 因为 Flag 状态机在处理 "辅元辅e" 这种重叠结构时非常容易写错
        for i in range(len(temp_word) - 3):
            sub = temp_word[i:i+4]
            
            # 检查是否有非字母（针对那些没有反转的含符号单词）
            if not sub.isalpha():
                continue
                
            c1, c2, c3, c4 = sub[0], sub[1], sub[2], sub[3]
            
            # 核心判断逻辑
            if (c1 not in yuanyin and         # 辅音
                c2 in yuanyin and             # 元音
                c3 not in yuanyin and         # 辅音
                c3 != 'r' and                 # 不能是 r
                c4 == 'e'):                   # 必须是 e
                count += 1
                
    return count

print(opTwoYin(input()))
