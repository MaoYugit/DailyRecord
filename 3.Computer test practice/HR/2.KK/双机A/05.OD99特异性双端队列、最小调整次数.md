### 题目描述

有一个特异性的双端队列，该队列可以从**头部**或**尾部**添加数据，但是只能从**头部**移出数据。

现在有一个数据序列（$1$ 到 $n$），小A 依次执行 $2n$ 个指令，其中包括 $n$ 个“添加数据”指令和 $n$ 个“移出数据”指令。
*   添加指令：包含 `head add` (从头部添加) 和 `tail add` (从尾部添加)。**注意：添加的数据是按照 $1, 2, 3, \dots, n$ 的顺序依次添加的。**
*   移出指令：`remove` (从头部移出)。

**要求：**
移出数据的顺序必须是严格的 $1, 2, 3, \dots, n$。
如果在执行 `remove` 指令时，队列头部的数据**不是**当前应该移出的那个数，则需要进行**调整**。
**调整**定义为：你可以将队列中的数据进行任意重新排列（通常理解为一次调整就可以让队列变成理想的有序状态）。

请问，为了满足移出顺序为 $1, 2, \dots, n$，小A **最少**需要调整队列多少次？

### 输入描述

1.  第一行一个整数 $n$，表示数据的范围（即添加的数据是 $1$ 到 $n$）。
2.  接下来 $2n$ 行，每一行都是一条指令。
    *   指令格式可能为：
        *   `head add` （说明：题目隐含了每次add的数据是递增的，输入可能带数字也可能不带，通常机考输入如 `head add 1`）
        *   `tail add`
        *   `remove`

### 输出描述

*   输出一个整数，表示最小的调整次数。

---

### 示例

**示例 1**

*   **输入：**
    ```text
    5
    head add 1
    tail add 2
    remove
    head add 3
    tail add 4
    head add 5
    remove
    remove
    remove
    remove
    ```

*   **输出：**
    ```text
    1
    ```

*   **说明：**
    1.  `head add 1` -> 队列: `[1]`
    2.  `tail add 2` -> 队列: `[1, 2]`
    3.  `remove` -> 期望移出 1，队头是 1。匹配！移除。队列: `[2]`
    4.  `head add 3` -> 队列: `[3, 2]`
    5.  `tail add 4` -> 队列: `[3, 2, 4]`
    6.  `head add 5` -> 队列: `[5, 3, 2, 4]`
    7.  `remove` -> 期望移出 2，队头是 5。不匹配！**需要调整**。
        *   调整次数 +1。
        *   调整后，我们将队列变为有序（最佳策略），队列变成 `[2, 3, 4, 5]`。
        *   移除 2。队列: `[3, 4, 5]`。
    8.  `remove` -> 期望移出 3，队头是 3。匹配。移除。
    9.  `remove` -> 期望移出 4，队头是 4。匹配。移除。
    10. `remove` -> 期望移出 5，队头是 5。匹配。移除。
    
    总共调整次数：1。

### 解题核心思路（简要）

1.  **模拟**一个双端队列（`deque`）。
2.  维护一个变量 `target`，初始为 1，表示当前需要 remove 的数字。
3.  遍历所有指令：
    *   如果是 `add`，根据是 head 还是 tail 将数字加入队列（输入的数字其实不重要，重要的是它们是连续递增进来的，你只需要按顺序把 1, 2... 放进去）。
    *   如果是 `remove`：
        *   检查队列是否为空（正常逻辑不会）。
        *   检查 `deque.peekFirst()` 是否等于 `target`。
        *   **如果相等**：直接弹出，`target += 1`。
        *   **如果不相等**：说明顺序乱了。**调整次数 +1**。
            *   关键点：调整后，我们可以假设队列已经变成了**完美的顺序**（即排好了序），所以直接清空当前模拟的队列，并按顺序重新放入剩余的元素（或者逻辑上标记为“已排序”）。在代码中，可以直接将队列**排序**。
            *   排序后，队头肯定是 `target`，弹出，`target += 1`。

这就是这道题的标准解法。



这是华为OD机考中【特异性双端队列】（最小调整顺序次数）的完整 Python 代码。

### 解题思路回顾
1.  **模拟**：使用 Python 的 `collections.deque` 模拟双端队列。
2.  **计数器**：维护一个变量 `next_add_val` (当前要放入的数，从1开始) 和 `next_remove_val` (当前期望移出的数，从1开始)。
3.  **判断逻辑**：
    *   如果是 `add` 指令：按题目要求加到头部或尾部。
    *   如果是 `remove` 指令：
        *   检查队头元素是否等于 `next_remove_val`。
        *   **相等**：直接移出。
        *   **不相等**：说明顺序乱了，**调整次数 +1**。此时我们将队列里的所有元素**重新排序**（这是最贪心的策略，一次调整后让剩余元素完全有序，能最大程度避免后续的调整），然后移出队头。

### Python 代码

```python
import sys
from collections import deque

def solve():
    try:
        # 1. 读取 N 的值
        # sys.stdin.readline() 读取速度快，且能处理最后可能没有换行符的情况
        line = sys.stdin.readline().strip()
        if not line:
            return
        n = int(line)
    except ValueError:
        return

    # 初始化双端队列
    dq = deque()
    
    # 按照题目规则：添加的数据是从 1 到 n 依次递增的
    next_add_val = 1
    
    # 期望移出的数据也是从 1 到 n 依次递增的
    next_remove_val = 1
    
    # 记录调整次数
    adjust_count = 0

    # 题目说明一共会有 2n 条指令
    for _ in range(2 * n):
        command = sys.stdin.readline().strip()
        
        # --- 处理 head add ---
        if command.startswith("head add"):
            dq.appendleft(next_add_val)
            next_add_val += 1
            
        # --- 处理 tail add ---
        elif command.startswith("tail add"):
            dq.append(next_add_val)
            next_add_val += 1
            
        # --- 处理 remove ---
        elif command.startswith("remove"):
            if not dq:
                continue # 防御性编程，防止空队列报错
            
            # 检查队头元素是否是期望的数字
            head_val = dq[0]
            
            if head_val == next_remove_val:
                # 匹配：直接移出
                dq.popleft()
            else:
                # 不匹配：需要调整
                adjust_count += 1
                
                # 贪心策略：既然可以任意重排，为了后续不调整，
                # 我们将当前队列里的所有元素按升序排列。
                # 这样队头一定是 next_remove_val，且后续元素也是有序的。
                
                # 注意：deque 本身没有 sort 方法，需要转 list 排序后再转回 deque
                # 虽然这样做看似耗时，但在本题数据规模下是可以接受的
                sorted_list = sorted(list(dq))
                dq = deque(sorted_list)
                
                # 调整完后，队头肯定是期望值，移出
                dq.popleft()
            
            # 无论是否调整，移出成功后，期望的下一个值 +1
            next_remove_val += 1

    # 输出最小调整次数
    print(adjust_count)

if __name__ == "__main__":
    solve()
```

### 代码关键点解析

1.  **为什么需要排序？**
    题目说“可以进行任意重新排列”。为了让“调整次数最少”，我们需要让这次调整的效果最大化。将队列变为**升序**（1, 2, 3...）是最佳状态，因为这样不仅当前要移除的数（最小的）在队头，后面紧跟着的数也是下一次 `remove` 可能需要的数。

2.  **输入处理技巧**
    题目输入可能包含 `head add` 或 `head add 1`。代码中使用 `command.startswith("head add")` 可以同时兼容这两种情况。且我们要移除的具体数值由 `next_add_val` 变量控制，不依赖输入字符串里的数字，这样更稳健。

3.  **时间复杂度**
    虽然在调整时使用了 `sorted()`，其复杂度是 $O(K \log K)$（K为当前队列长度）。但在最坏情况下（每次都调整），整体复杂度也不会超过限制（通常 $N \le 1000$ 或几千），Python 这种写法足以通过华为 OD 的用例。
