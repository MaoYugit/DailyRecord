很多教程一上来就给你画表格、写 `dp[i]`，让人摸不着头脑。其实，动态规划的本质是：**拒绝重复劳动**。

我们先忘掉“动态规划”这四个字。我们就聊聊 **递归**。

---

### 🟢 第一阶段：斐波那契与爬楼梯（DP 的本质）

#### 1. 概念引入：递归的痛点

假设我们要计算斐波那契数列的第 `n` 项：`1, 1, 2, 3, 5, 8, 13...`
公式是：$f(n) = f(n-1) + f(n-2)$。

**写法 1：暴力递归（傻递归）**

```python
def fib(n):
    if n <= 2: return 1
    return fib(n-1) + fib(n-2)
```

**问题在哪里？**
假设你要算 `fib(5)`：
*   算 `fib(5)` 需要算 `fib(4)` 和 `fib(3)`。
*   算 `fib(4)` 需要算 `fib(3)` 和 `fib(2)`。
*   **注意！** `fib(3)` 被计算了两次！
*   如果你算 `fib(20)`，`fib(18)` 会被重复计算几千次。这就是**时间爆炸**，复杂度是 $O(2^n)$。

---

#### 2. 进化：带备忘录的递归（Memoization）

既然算过的东西会忘，那我们拿个**记事本**（字典或数组）把它记下来。
每次计算前，先查记事本：

1.  **查**：记事本里有吗？有就直接返回，别算了。
2.  **算**：记事本里没有，那我老老实实算一遍。
3.  **记**：算完赶紧记下来，下次用。

**写法 2：记忆化搜索（自顶向下）**

```python
class Solution:
    def fib(self, n: int) -> int:
        # 记事本
        memo = {}

        def helper(x):
            if x <= 1: return x # LeetCode 509 从 0 开始：0, 1, 1, 2...
            
            # 1. 查：如果算过了，直接给
            if x in memo:
                return memo[x]
            
            # 2. 算：正常递归
            res = helper(x-1) + helper(x-2)
            
            # 3. 记：存入记事本
            memo[x] = res
            return res

        return helper(n)
```

**这一步，其实就是动态规划的一半了！** 我们把 $O(2^n)$ 降到了 $O(n)$。

---

#### 3. 终极进化：动态规划（Tabulation / 自底向上）

上面的写法是“从上往下”查（求 5 查 4，求 4 查 3）。
动态规划是**“从下往上”填表**。

既然我们要算 `f(5)`，那我们能不能先算 `f(0)`, `f(1)`, `f(2)`... 一路推上去？
这就不需要递归了，只需要一个 `for` 循环。

**写法 3：标准的动态规划**

```python
class Solution:
    def fib(self, n: int) -> int:
        if n <= 1: return n
        
        # 1. 创建 dp 数组（dp table）
        # 我们需要存 0 到 n，所以长度是 n+1
        dp = [0] * (n + 1)
        
        # 2. 初始化（Base Case）
        dp[0] = 0
        dp[1] = 1
        
        # 3. 遍历顺序：从前向后
        for i in range(2, n + 1):
            # 4. 状态转移方程
            dp[i] = dp[i-1] + dp[i-2]
            
        return dp[n]
```

### 🧱 实战演练：爬楼梯 (LeetCode 70)

这是面试中最最经典的 DP 入门题。

**场景**：
假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。
每次你可以爬 `1` 或 `2` 个台阶。
你有多少种不同的方法可以爬到楼顶？

**五部曲分析法（请死记硬背这个流程）**：

1.  **`dp[i]` 的含义**：
    到达第 `i` 阶楼梯，一共有 `dp[i]` 种方法。

2.  **递推公式（状态转移）**：
    想一下，我怎么才能跳到第 `i` 层？
    *   情况 A：我从第 `i-1` 层，跳 **1步** 上来。
    *   情况 B：我从第 `i-2` 层，跳 **2步** 上来。
    *   除此之外没有别的方法了。
    *   所以：**走到 i 的方法数 = 走到 i-1 的方法数 + 走到 i-2 的方法数**。
    *   公式：`dp[i] = dp[i-1] + dp[i-2]`。
    *   *你看，这不就是斐波那契数列吗！*

3.  **初始化**：
    *   `dp[1] = 1` （第1层只有1种方法：直接跳1步）
    *   `dp[2] = 2` （第2层有2种方法：1步+1步，或者直接2步）

4.  **遍历顺序**：
    从第 3 层开始，一直算到第 n 层。

5.  **举例推导**：
    `n = 5`
    *   dp[1] = 1
    *   dp[2] = 2
    *   dp[3] = 1 + 2 = 3
    *   dp[4] = 2 + 3 = 5
    *   dp[5] = 3 + 5 = 8

**Python 代码**：

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2: return n
        
        # 1. 定义 dp 数组
        dp = [0] * (n + 1)
        
        # 2. 初始化
        dp[1] = 1
        dp[2] = 2
        
        # 3. 从小到大遍历
        for i in range(3, n + 1):
            # 4. 递推公式
            dp[i] = dp[i-1] + dp[i-2]
            
        return dp[n]
```

### 🧪 进阶挑战：使用最小花费爬楼梯 (LeetCode 746)

这题比上一题多了一个“花费”。

**场景**：
`cost[i]` 是第 `i` 个台阶的过路费。你可以选择从下标 `0` 或 `1` 开始。每次爬 1 或 2 个台阶。求到达楼顶（数组之外）的最小花费。

**五部曲分析**：

1.  **`dp[i]` 的含义**：
    **到达**第 `i` 个台阶所需要的**最小花费**。（注意：是到达这里，还没交这里的钱，或者理解为到达这里累计花了多少钱）。
    *更准确的理解：题目要求到达楼顶（len(cost)），所以我们要算的是到达 `len(cost)` 这一层的花费。*

2.  **递推公式**：
    我要到达第 `i` 层，可以怎么来？
    *   从 `i-1` 层来：也就是 `dp[i-1]` (之前的花费) + `cost[i-1]` (i-1层本身的过路费)。
    *   从 `i-2` 层来：也就是 `dp[i-2]` (之前的花费) + `cost[i-2]` (i-2层本身的过路费)。
    *   我们要省钱，所以取最小值。
    *   `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`

3.  **初始化**：
    *   题目说“可以选择从下标 0 或 1 开始”。
    *   意味着到达 0 层不需要花钱（起点），到达 1 层也不需要花钱（也是起点）。
    *   `dp[0] = 0`
    *   `dp[1] = 0`

4.  **遍历顺序**：
    从 2 开始，一直到 `len(cost)`。

**Python 代码**：

```python
class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        n = len(cost)
        # 我们要到达第 n 层（楼顶），所以数组长度是 n + 1
        dp = [0] * (n + 1)
        
        # 初始化：可以直接站在 0 或 1 层，初始花费为 0
        dp[0] = 0
        dp[1] = 0
        
        for i in range(2, n + 1):
            # 状态转移：选一条便宜的路走
            # 从 i-1 跳上来，要付 cost[i-1]
            # 从 i-2 跳上来，要付 cost[i-2]
            dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])
            
        return dp[n]
```

### 🟡 第二阶段：打家劫舍（做选择的艺术）

#### 1. 题目：打家劫舍 (LeetCode 198) - ⭐️ 1D DP 的里程碑

**场景**：
你是一个专业的小偷，计划偷窃沿街的房屋。每间房都有一定的现金 `nums[i]`。
唯一限制是：**相邻的房屋装有互连防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。
求今晚能偷到的**最高金额**。

**例子**：`[1, 2, 3, 1]`
*   偷 1 -> 偷 3 = 4
*   偷 2 -> 偷 1 = 3
*   答案是 4。

**五部曲分析**：

1.  **`dp[i]` 的含义**：
    考虑下标 `0` 到下标 `i` 的所有房屋，所能偷到的**最大金额**。

2.  **递推公式（核心难点）**：
    对于第 `i` 间房子，我们只有 **两个选择**：

    *   **选择 A：偷第 `i` 间房**。
        *   如果你偷了第 `i` 间，你就**绝不能**偷第 `i-1` 间。
        *   所以你的累积金额应该是：`第 i-2 间房为止的最高金额` + `第 i 间房的钱`。
        *   即：`dp[i-2] + nums[i]`。

    *   **选择 B：不偷第 `i` 间房**。
        *   既然我不偷这间，那我可以大摇大摆地拿着“第 `i-1` 间房为止的最高金额”。
        *   即：`dp[i-1]`。

    *   **决策**：我们要钱最多的，所以取最大值。
    *   `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

3.  **初始化**：
    *   `dp[0]`：只有一间房，当然偷它。`dp[0] = nums[0]`。
    *   `dp[1]`：有两间房（0和1），不能同时偷，偷那个钱多的。`dp[1] = max(nums[0], nums[1])`。

4.  **遍历顺序**：
    从 `i = 2` 开始向后遍历。

**Python 代码**：

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        if not nums: return 0
        if len(nums) == 1: return nums[0]
        
        # 1. 定义 DP 数组
        dp = [0] * len(nums)
        
        # 2. 初始化
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1]) # 注意这里！选大的那个
        
        # 3. 遍历
        for i in range(2, len(nums)):
            # 4. 状态转移：偷i 和 不偷i 哪个划算？
            dp[i] = max(dp[i-1], dp[i-2] + nums[i])
            
        return dp[-1] # 返回最后一个状态，即考虑所有房子后的最大值
```

#### 2. 题目：打家劫舍 II (LeetCode 213) - ⭐️ 环形问题破解

**场景**：
这题和上一题唯一的区别是：**房屋连成了一圈**。
意思是：**第一间房和最后一间房是紧挨着的**。如果你偷了第一间，就不能偷最后一间，反之亦然。

**解题思路（破圈法）**：
环形结构很难直接写递推公式。我们要把它拆成**线性结构**（就是拆成上一题的样子）。
既然首尾不能同时取，那我们就分情况讨论：

*   **情况 1**：一定**不偷**最后一间房。
    *   那我们就只需要考虑 `0` 到 `n-2` 的范围。这不就是把数组切片成 `nums[:-1]` 然后做一次 LC 198 吗？
*   **情况 2**：一定**不偷**第一间房。
    *   那我们就只需要考虑 `1` 到 `n-1` 的范围。这不就是把数组切片成 `nums[1:]` 然后做一次 LC 198 吗？

**最终答案**：`max(情况1的结果, 情况2的结果)`。

**Python 代码**：

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        if not nums: return 0
        if len(nums) == 1: return nums[0]
        if len(nums) == 2: return max(nums[0], nums[1])
        
        # 封装一下刚才的逻辑，方便复用
        def rob_linear(arr):
            if not arr: return 0
            if len(arr) == 1: return arr[0]
            
            dp = [0] * len(arr)
            dp[0] = arr[0]
            dp[1] = max(arr[0], arr[1])
            
            for i in range(2, len(arr)):
                dp[i] = max(dp[i-1], dp[i-2] + arr[i])
            return dp[-1]
        
        # 情况1：不含尾（0 到 n-2）
        result1 = rob_linear(nums[:-1])
        
        # 情况2：不含头（1 到 n-1）
        result2 = rob_linear(nums[1:])
        
        return max(result1, result2)
```

#### 3. 题目：删除并获得点数 (LeetCode 740) - ⭐️ 变色龙题目

**场景**：
给你一个整数数组 `nums`。如果你选择获得 `nums[i]` 的点数，你就必须删除所有等于 `nums[i] - 1` 和 `nums[i] + 1` 的元素。求最大点数。
例如：`nums = [2, 2, 3, 3, 3, 4]`。
选了 3，就获得 `3*3 = 9` 分，但 2 和 4 都不能要了。

**分析**：
这题看着不像打家劫舍，但仔细一看：
*   选了 `x`，就不能选 `x-1` 和 `x+1`。
*   这不就是 **“选了这间房，就不能选相邻的房”** 吗？

**转化步骤**：
1.  把 `nums` 转化为一个新数组 `arr`，其中 `arr[i]` 代表原数组中所有数字 `i` 的总和。
    *   `nums = [2, 2, 3, 3, 3, 4]`
    *   数字 2 有两个 -> 4分。
    *   数字 3 有三个 -> 9分。
    *   数字 4 有一个 -> 4分。
    *   构造出的数组（下标对应数字）：`index 0: 0, index 1: 0, index 2: 4, index 3: 9, index 4: 4`。
    *   `arr = [0, 0, 4, 9, 4]`。
2.  对 `arr` 做一次“打家劫舍”！
    *   `dp[i] = max(dp[i-1], dp[i-2] + arr[i])`。

**Python 代码**：

```python
class Solution:
    def deleteAndEarn(self, nums: List[int]) -> int:
        if not nums: return 0
        
        # 1. 数据预处理：构造 sum 数组
        max_val = max(nums)
        arr = [0] * (max_val + 1)
        
        for num in nums:
            arr[num] += num
            
        # 2. 现在问题变成了：对 arr 进行打家劫舍
        # 以下代码完全照搬 LC 198
        dp = [0] * (max_val + 1)
        dp[0] = arr[0]
        if max_val >= 1:
            dp[1] = max(arr[0], arr[1])
            
        for i in range(2, max_val + 1):
            dp[i] = max(dp[i-1], dp[i-2] + arr[i])
            
        return dp[-1]
```

### 🟠 第三阶段：2D 网格路径（地图探索）

#### 1. 题目：不同路径 (LeetCode 62) - ⭐️ 二维 DP 的“Hello World”

**场景**：
一个机器人位于 `m x n` 网格的左上角（起始点）。
机器人每次只能**向下**或者**向右**移动一步。
问：到达右下角一共有多少种不同的路径？

**五部曲分析**：

1.  **`dp[i][j]` 的含义**：
    机器人走到坐标 `(i, j)` （第 `i` 行，第 `j` 列）时，一共有 **`dp[i][j]` 种不同的路径**。

2.  **递推公式**：
    想象你在 `(i, j)` 这个位置，你是怎么来的？
    *   可能是从上面 `(i-1, j)` 走下来的。
    *   可能是从左边 `(i, j-1)` 走过来的。
    *   所以：**走到当前格子的方法数 = 走到上面格子的方法数 + 走到左边格子的方法数**。
    *   `dp[i][j] = dp[i-1][j] + dp[i][j-1]`

3.  **初始化**：
    *   **第一行**：机器人只能一直向右走，没办法向下绕。所以第一行所有格子的路径数都是 **1**。
    *   **第一列**：机器人只能一直向下走。所以第一列所有格子的路径数也是 **1**。

4.  **遍历顺序**：
    我们要算 `(i, j)`，需要用到上面和左边的数据，所以自然是 **从上到下，从左到右** 遍历。

5.  **举例**：
    3x7 的网格。
    `dp[0][0]` 到 `dp[0][6]` 全是 1。
    `dp[1][1] = dp[0][1] + dp[1][0] = 1 + 1 = 2`。

**Python 代码**：

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # 1. 创建二维 dp 数组
        # 注意 Python 创建二维数组的坑：不要用 [[0]*n]*m，那是浅拷贝！
        dp = [[0] * n for _ in range(m)]
        
        # 2. 初始化
        # 第一列全是 1
        for i in range(m):
            dp[i][0] = 1
        # 第一行全是 1
        for j in range(n):
            dp[0][j] = 1
            
        # 3. 遍历（从 [1][1] 开始，因为 0 行 0 列已经初始化了）
        for i in range(1, m):
            for j in range(1, n):
                # 4. 状态转移
                dp[i][j] = dp[i-1][j] + dp[i][j-1]
                
        return dp[m-1][n-1]
```

#### 2. 题目：不同路径 II (LeetCode 63) - ⭐️ 有障碍物怎么办？

**场景**：
和上一题一样，但是网格中有障碍物（用 `1` 表示）。
障碍物的地方不能走，路径数自然是 0。

**分析变化**：
这题的核心逻辑和 LC 62 一模一样，只是加了个 `if` 判断。

1.  **遇到障碍物**：
    如果 `obstacleGrid[i][j] == 1`，那么 `dp[i][j] = 0`（死路）。
2.  **初始化时的坑**：
    *   如果第一行某个位置有石头，那这个石头**后面**的所有格子都走不到了（因为只能向右走，被堵死了）。
    *   同理，第一列如果有石头，石头**下面**的格子全废了。

**Python 代码**：

```python
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        m = len(obstacleGrid)
        n = len(obstacleGrid[0])
        
        # 如果起点或终点就有障碍，直接完蛋
        if obstacleGrid[0][0] == 1 or obstacleGrid[m-1][n-1] == 1:
            return 0
            
        dp = [[0] * n for _ in range(m)]
        
        # 初始化第一列
        for i in range(m):
            if obstacleGrid[i][0] == 1:
                break # 遇到障碍，后面全为 0（不用赋值了，默认就是0），直接退出循环
            dp[i][0] = 1
            
        # 初始化第一行
        for j in range(n):
            if obstacleGrid[0][j] == 1:
                break
            dp[0][j] = 1
            
        # 遍历
        for i in range(1, m):
            for j in range(1, n):
                if obstacleGrid[i][j] == 1:
                    dp[i][j] = 0 # 障碍物，路不通
                else:
                    dp[i][j] = dp[i-1][j] + dp[i][j-1]
                    
        return dp[m-1][n-1]
```

#### 3. 题目：最小路径和 (LeetCode 64) - ⭐️ 求路径代价

**场景**：
网格里填的是数字（过路费）。
寻找一条从左上角到右下角的路径，使得路径上的**数字总和最小**。

**五部曲分析**：

1.  **`dp[i][j]` 的含义**：
    走到坐标 `(i, j)` 时，最小的路径总和是多少。

2.  **递推公式**：
    我在 `(i, j)`，要算最小花费。
    *   我肯定希望从那个“已经花费最少”的格子里走过来。
    *   是从上面 `(i-1, j)` 下来便宜？还是从左边 `(i, j-1)` 过来便宜？
    *   `dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`
    *   （别忘了加上当前格子自己的过路费 `grid[i][j]`）

3.  **初始化**：
    *   `dp[0][0] = grid[0][0]`
    *   **第一行**：只能从左边一路累加过来。
    *   **第一列**：只能从上面一路累加下来。

**Python 代码**：

```python
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m = len(grid)
        n = len(grid[0])
        
        dp = [[0] * n for _ in range(m)]
        
        # 初始化起点
        dp[0][0] = grid[0][0]
        
        # 初始化第一列 (只能从上面下来)
        for i in range(1, m):
            dp[i][0] = dp[i-1][0] + grid[i][0]
            
        # 初始化第一行 (只能从左边过来)
        for j in range(1, n):
            dp[0][j] = dp[0][j-1] + grid[0][j]
            
        # 遍历其余格子
        for i in range(1, m):
            for j in range(1, n):
                # 选一条便宜的路，加上当前的过路费
                dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
                
        return dp[m-1][n-1]
```

###  **第四阶段：背包问题（Knapsack Problem）**。

这是动态规划中 **最核心、最庞大、也是面试官最爱问** 的一个分支。
很多 LeetCode 题目表面上看不出是背包，但剥了皮其实就是“装东西”。

**核心场景**：
给你一个容量为 `W` 的背包，和一堆物品（每个物品有重量 `w` 和价值 `v`）。
**问：怎么装，才能让背包里的价值最大？**

我们要攻克两大魔王：
1.  **0/1 背包**：每个物品只有 1 个（要么装，要么不装）。
2.  **完全背包**：每个物品有无数个（想装几个装几个）。

### 🔴 第一部分：0/1 背包（倒序遍历的魔法）

#### 1. 理论基础：从二维到一维

假设背包容量为 4。
物品：
*   物品0: 重量1, 价值15
*   物品1: 重量3, 价值20
*   物品2: 重量4, 价值30

**二维 DP 思路（了解即可，面试通常写一维）**：
`dp[i][j]` 表示：从下标 `0-i` 的物品里任意取，放进容量为 `j` 的背包，最大价值是多少。
公式：`dp[i][j] = max(不取物品i, 取物品i)`
`dp[i][j] = max(dp[i-1][j], dp[i-1][j - weight[i]] + value[i])`

**一维 DP 思路（滚动数组 - ⭐️ 重点掌握）**：
其实我们不需要记录上一行的状态，直接在**当前行**更新就行。
`dp[j]`：容量为 `j` 的背包，所能装的最大价值。

**公式**：
`dp[j] = max(dp[j], dp[j - weight[i]] + value[i])`

**关键点：遍历顺序！**
对于 0/1 背包（物品只能用一次），**内层循环必须从大到小（倒序）遍历**。
*   **为什么？**
    *   如果我们从左往右（正序）算：计算 `dp[2]` 时，可能会用到 `dp[1]`。而此时的 `dp[1]` 已经是“放入了当前物品”后的新值了。这就导致**一个物品被加了两次**。
    *   如果我们从右往左（倒序）算：计算 `dp[4]` 时，用到 `dp[3]`。此时 `dp[3]` 还是**上一轮**（没放当前物品）的旧值。这就保证了每个物品只被计算一次。

#### 2. 题目：分割等和子集 (LeetCode 416) - ⭐️ 0/1 背包变种

**场景**：
给你一个数组 `[1, 5, 11, 5]`。问能不能把它分成两个子集，使得两个子集的和相等。

**转化思维**：
*   “分成两个和相等的子集” $\rightarrow$ 等价于 **“能不能从数组里选几个数，让它们的和恰好等于 `总和 / 2`”**。
*   这不就是背包问题吗？
    *   **背包容量**：`target = sum(nums) / 2`。
    *   **物品重量**：元素的数值。
    *   **物品价值**：元素的数值（这题里重量和价值是一样的）。
    *   **目标**：把背包装满（最大价值 == target）。

**Python 代码**：

```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total_sum = sum(nums)
        # 如果总和是奇数，肯定分不开
        if total_sum % 2 == 1:
            return False
            
        target = total_sum // 2
        
        # 1. dp[j] 代表容量为 j 的背包，最大能凑出的子集和
        # 我们希望最后 dp[target] == target
        dp = [0] * (target + 1)
        
        # 2. 遍历物品
        for num in nums:
            # 3. 遍历背包容量（0/1背包必须倒序！）
            # 只有当背包容量 j >= num 时，才装得下
            for j in range(target, num - 1, -1):
                dp[j] = max(dp[j], dp[j - num] + num)
                
        # 4. 如果背包装满了，说明找到了
        if dp[target] == target:
            return True
        return False
```

#### 3. 题目：最后一块石头的重量 II (LeetCode 1049) - ⭐️ 0/1 背包变种

**场景**：
有一堆石头，两两对撞，粉碎剩下的是差值。求最后剩下的最小石头重量。
比如 `[2,7,4,1,8,1]`。

**转化思维**：
*   两两抵消，其实就是把石头分成**两堆**。
*   让这两堆的总重量 **尽可能接近**。
*   假设总重 30。最好分成 15 和 15，这样抵消就是 0。
*   如果分不到 15，能不能凑出 14？那剩下就是 16，抵消剩 2。
*   **转化**：背包容量为 `sum // 2`。求最大能装多少石头。

**代码逻辑**：
和 LC 416 一模一样！
最后答案是 `(sum - dp[target]) - dp[target]`。
*(一堆是 dp[target]，另一堆是 sum - dp[target]，相减即可)*。

### 🟣 第二部分：完全背包（正序遍历的魔法）

**定义**：每个物品可以取 **无数次**。

**唯一的区别**：
*   0/1 背包为了防止重复取，内层循环是 **倒序**。
*   完全背包为了允许重复取，内层循环改为 **正序（从小到大）**。

#### 4. 题目：零钱兑换 II (LeetCode 518) - ⭐️ 组合方案数

**场景**：
给你面额 `coins = [1, 2, 5]`，目标金额 `amount = 5`。
问有多少种凑法？（比如 `1+2+2` 和 `2+1+2` 算同一种）。

**五部曲分析**：

1.  **`dp[j]` 的含义**：
    凑满金额 `j`，一共有 `dp[j]` 种方法。

2.  **递推公式**：
    这是一个 **求方案数** 的问题（不是求最大价值）。
    公式是累加：`dp[j] += dp[j - coins[i]]`。
    *意思是：如果不选这个硬币，我有 A 种方法；如果选了这个硬币，我有 B 种方法。现在方法总数是 A+B。*

3.  **初始化**：
    `dp[0] = 1`。凑出金额 0，只有一种方法（什么都不选）。如果不初始化为 1，后面累加全是 0。

4.  **遍历顺序（关键）**：
    *   **先遍历物品，再遍历背包**（这是组合数，不分顺序）。
    *   **背包正序遍历**（因为是完全背包，硬币无限用）。

**Python 代码**：

```python
class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        # 1. dp[j]：凑成金额 j 的组合数
        dp = [0] * (amount + 1)
        
        # 2. 初始化
        dp[0] = 1
        
        # 3. 遍历物品（硬币）
        for coin in coins:
            # 4. 遍历背包（正序！因为硬币可以重复用）
            # 从 coin 开始，因为比 coin 小的背包装不下
            for j in range(coin, amount + 1):
                dp[j] += dp[j - coin]
                
        return dp[amount]
```

#### 5. 题目：零钱兑换 (LeetCode 322) - ⭐️ 求最小个数

**场景**：
`coins = [1, 2, 5]`, `amount = 11`。
求凑出 11 的 **最少硬币个数**。

**分析**：
*   硬币无限用 $\rightarrow$ **完全背包** $\rightarrow$ **正序遍历**。
*   求最小个数 $\rightarrow$ `dp[j] = min(dp[j], dp[j-coin] + 1)`。

**Python 代码**：

```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        # 1. dp[j]: 凑足金额 j 所需的最少硬币个数
        # 初始化为无穷大，方便后面取 min
        dp = [float('inf')] * (amount + 1)
        dp[0] = 0
        
        for coin in coins:
            for j in range(coin, amount + 1):
                # 只有当 dp[j-coin] 有解时，才更新
                if dp[j - coin] != float('inf'):
                    dp[j] = min(dp[j], dp[j - coin] + 1)
                    
        return dp[amount] if dp[amount] != float('inf') else -1
```

4.  **求组合数**：`dp[j] += dp[j-w]`
5.  **求最小个数**：`dp[j] = min(dp[j], dp[j-w] + 1)`

### 🟣 第五阶段：子序列问题（LIS & LCS & 编辑距离）

#### 1. 题目：最长递增子序列 (LeetCode 300) - ⭐️ 1D 子序列之王

**场景**：
给你 `nums = [10, 9, 2, 5, 3, 7, 101, 18]`。
找到最长的严格递增子序列的长度。
答案是 `[2, 3, 7, 101]`，长度为 4。

**五部曲分析**：

1.  **`dp[i]` 的含义（非常重要）**：
    **以 `nums[i]` 这个数结尾** 的最长递增子序列的长度。
    *   注意：必须包含 `nums[i]`！如果不包含它，状态转移没法写。

2.  **递推公式**：
    我们要算 `dp[i]`（也就是以 `nums[i]` 结尾的长度）。
    我们就得 **回头看** `0` 到 `i-1` 的所有位置 `j`。
    *   如果 `nums[i] > nums[j]`：说明 `nums[i]` 可以接在 `nums[j]` 后面，形成一个更长的序列。
    *   那么长度就是 `dp[j] + 1`。
    *   我们要找最长的那个：`dp[i] = max(dp[i], dp[j] + 1)`。

3.  **初始化**：
    每个数字本身至少也是一个长度为 1 的子序列。
    `dp` 数组全初始化为 1。

4.  **遍历顺序**：
    两层循环。
    *   外层 `i` 从 `0` 到 `n-1`。
    *   内层 `j` 从 `0` 到 `i-1`。

**Python 代码**：

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        if not nums: return 0
        
        # 1. 初始化 dp 数组，每个位置至少是 1
        dp = [1] * len(nums)
        
        # 2. 外层遍历每个数
        for i in range(len(nums)):
            # 3. 内层回头看 i 之前的所有数
            for j in range(i):
                # 4. 如果发现前面的数比我小，我就可以接在它后面
                if nums[i] > nums[j]:
                    dp[i] = max(dp[i], dp[j] + 1)
                    
        # 5. 结果不是 dp[-1]，而是 dp 数组里的最大值
        # 因为最长子序列不一定是以最后一个元素结尾的
        return max(dp)
```

#### 2. 题目：最长公共子序列 (LeetCode 1143) - ⭐️ 2D 子序列之王 (LCS)

**场景**：
`text1 = "abcde"`, `text2 = "ace"`。
最长公共子序列是 `"ace"`，长度 3。

**五部曲分析**：

1.  **`dp[i][j]` 的含义**：
    长度为 `[0, i-1]` 的字符串 `text1` 与 长度为 `[0, j-1]` 的字符串 `text2` 的 **最长公共子序列长度**。
    *   这里为了处理空字符串，通常 `dp` 数组大小设为 `(len1 + 1) * (len2 + 1)`。`i=1` 对应 `text1[0]`。

2.  **递推公式**：
    我们要算 `text1[i-1]` 和 `text2[j-1]` 这两个字符：
    *   **情况 A：两个字符相等** (`text1[i-1] == text2[j-1]`)
        *   太好了！找到了一个公共字符。
        *   就在它俩 **“左上方”** 的基础上 + 1。
        *   `dp[i][j] = dp[i-1][j-1] + 1`
    *   **情况 B：两个字符不相等**
        *   那这两个字符不能同时做贡献。
        *   要么看“上面”（`text1` 少一个字符的结果）。
        *   要么看“左面”（`text2` 少一个字符的结果）。
        *   我们要最长的：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

3.  **初始化**：
    `dp[0][...]` 和 `dp[...][0]` 都是 0（空字符串没有公共子序列）。

**Python 代码**：

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        
        # dp[i][j] 对应 text1[:i] 和 text2[:j]
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 注意：dp索引是 i, j，但在字符串里的索引是 i-1, j-1
                if text1[i-1] == text2[j-1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
                    
        return dp[m][n]
```

#### 3. 题目：编辑距离 (LeetCode 72) - ⭐️ DP 最终大 Boss

**场景**：
给你两个单词 `word1` 和 `word2`。
你可以进行三种操作：**插入、删除、替换**。
问最少操作几次，能把 `word1` 变成 `word2`？
比如 `horse` -> `ros`，最少 3 步。

**五部曲分析**：

1.  **`dp[i][j]` 的含义**：
    把 `word1` 的前 `i` 个字符，变成 `word2` 的前 `j` 个字符，所需要的 **最小操作数**。

2.  **递推公式**：
    比较 `word1[i-1]` 和 `word2[j-1]`：
    *   **情况 A：相等**
        *   不需要操作！直接继承之前的。
        *   `dp[i][j] = dp[i-1][j-1]`
    *   **情况 B：不相等（必须操作，+1）**
        *   我们需要从以下三种操作里选一个代价最小的：
        1.  **删除** `word1` 的字符：相当于从 `dp[i-1][j]` 转移过来（i 少了一个）。
        2.  **插入** `word1` 的字符（等于删除 `word2`）：相当于从 `dp[i][j-1]` 转移过来。
        3.  **替换**：相当于从 `dp[i-1][j-1]` 转移过来（两个都变了）。
        *   `dp[i][j] = min(删除, 插入, 替换) + 1`
        *   `dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1`

3.  **初始化**：
    *   `dp[i][0]`：把 `word1` 的前 `i` 个变成空串，只能全删了，代价是 `i`。
    *   `dp[0][j]`：把空串变成 `word2` 的前 `j` 个，只能全插入，代价是 `j`。

**Python 代码**：

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        # 初始化第一列
        for i in range(m + 1):
            dp[i][0] = i
            
        # 初始化第一行
        for j in range(n + 1):
            dp[0][j] = j
            
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i-1] == word2[j-1]:
                    # 字符相同，不用操作
                    dp[i][j] = dp[i-1][j-1]
                else:
                    # 字符不同，取 增、删、换 的最小值 + 1
                    dp[i][j] = min(dp[i-1][j],    # 删除
                                   dp[i][j-1],    # 插入
                                   dp[i-1][j-1]   # 替换
                                  ) + 1
        
        return dp[m][n]
```

**🧠 核心心法回顾**：

1.  **爬楼梯/斐波那契**：`dp[i] = dp[i-1] + dp[i-2]` （来源清晰）。
2.  **打家劫舍**：`dp[i] = max(偷, 不偷)` （做选择）。
3.  **网格路径**：`dp[i][j] = dp[i-1][j] + dp[i][j-1]` （坐标系来源）。
4.  **背包问题**：
    *   0/1 背包：倒序遍历 `dp[j] = max(不放, 放)`。
    *   完全背包：正序遍历。
5.  **子序列问题**：
    *   LIS：`dp[i] = max(dp[j] + 1)` （回头看）。
    *   LCS / 编辑距离：`dp[i][j]` 看左边、上边、左上边。
