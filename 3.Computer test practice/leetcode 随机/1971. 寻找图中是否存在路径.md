## LeetCode 1971. 寻找图中是否存在路径

这是一道**基础的图连通性问题**，可以使用多种方法解决。下面我会给出几种不同的解法。

### 问题描述
给定一个有 `n` 个顶点的**无向图**，以及边的列表 `edges` 和两个顶点 `source` 和 `destination`。判断是否存在从 `source` 到 `destination` 的路径。

### 解法一：BFS（广度优先搜索）

```python
from collections import defaultdict, deque

class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        # 1. 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # 2. 特殊情况处理
        if source == destination:
            return True
        
        # 3. BFS遍历
        queue = deque([source])
        visited = set([source])
        
        while queue:
            node = queue.popleft()
            
            # 遍历当前节点的所有邻居
            for neighbor in graph[node]:
                if neighbor == destination:
                    return True
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        
        return False
```

**时间复杂度**：O(V + E)，其中V是顶点数，E是边数

### 解法二：DFS（深度优先搜索）

```python
from collections import defaultdict

class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        # 1. 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # 2. DFS递归
        visited = set()
        
        def dfs(node):
            if node == destination:
                return True
            visited.add(node)
            
            for neighbor in graph[node]:
                if neighbor not in visited:
                    if dfs(neighbor):
                        return True
            return False
        
        return dfs(source)
```

### 解法三：并查集（Union-Find）⭐推荐

这是最适合这道题的解法，简单高效：

```python
class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        # 初始化并查集
        parent = list(range(n))
        
        def find(x):
            # 路径压缩
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        
        def union(x, y):
            root_x = find(x)
            root_y = find(y)
            if root_x != root_y:
                parent[root_y] = root_x
        
        # 合并所有边
        for u, v in edges:
            union(u, v)
        
        # 检查source和destination是否连通
        return find(source) == find(destination)
```

**并查集解法详解**：

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n  # 按秩合并优化
    
    def find(self, x):
        # 带路径压缩的查找
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x == root_y:
            return
        
        # 按秩合并
        if self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        elif self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1

class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        if source == destination:
            return True
        
        uf = UnionFind(n)
        
        # 合并所有连通分量
        for u, v in edges:
            uf.union(u, v)
        
        # 检查是否属于同一连通分量
        return uf.find(source) == uf.find(destination)
```

### 解法四：DFS迭代版（避免递归深度限制）

```python
from collections import defaultdict

class Solution:
    def validPath(self, n: int, edges: List[List[int]], source: int, destination: int) -> bool:
        if source == destination:
            return True
        
        # 构建邻接表
        graph = defaultdict(list)
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        
        # 迭代DFS
        stack = [source]
        visited = set([source])
        
        while stack:
            node = stack.pop()
            
            for neighbor in graph[node]:
                if neighbor == destination:
                    return True
                if neighbor not in visited:
                    visited.add(neighbor)
                    stack.append(neighbor)
        
        return False
```

### 测试用例

```python
# 测试示例
solution = Solution()

# 示例1
print(solution.validPath(3, [[0,1],[1,2],[2,0]], 0, 2))  # True

# 示例2
print(solution.validPath(6, [[0,1],[0,2],[3,5],[5,4],[4,3]], 0, 5))  # False

# 边界情况
print(solution.validPath(1, [], 0, 0))  # True (只有1个顶点)
```

### 各解法对比

| 方法       | 时间复杂度 | 空间复杂度 | 优点               | 缺点         |
| ---------- | ---------- | ---------- | ------------------ | ------------ |
| **BFS**    | O(V+E)     | O(V)       | 能找到最短路径     | 需要队列     |
| **DFS**    | O(V+E)     | O(V)       | 实现简单           | 可能栈溢出   |
| **并查集** | O(E·α(V))  | O(V)       | **最优解**，查询快 | 不能记录路径 |

### 推荐使用并查集的原因：

1. **时间复杂度最优**：接近O(1)的查询和合并操作
2. **适合多次查询**：如果需要多次判断连通性，并查集优势明显
3. **代码简洁**：逻辑清晰，易于理解和实现

### 关键点总结：
1. 无向图需要双向构建邻接表
2. 注意边界情况：起点终点相同
3. 避免重复访问（使用visited集合）
4. 并查集是最适合这种连通性问题的数据结构

根据题目特点，我建议使用**并查集**解法，因为它是最自然、最高效的解决这类连通性问题的方法。
