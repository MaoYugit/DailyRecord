# LeetCode 997. 找到小镇的法官

## 问题描述

在一个小镇里，有 `n` 个人，编号从 `1` 到 `n`。传言其中有一个秘密的法官。

如果法官存在，那么：
1. 法官不相信任何人（法官的出度为0）
2. 每个人都相信法官（除了法官自己，其他人的入度为n-1）
3. 恰好有一个人同时满足属性1和属性2

给定一个数组 `trust`，其中 `trust[i] = [aᵢ, bᵢ]` 表示编号为 `aᵢ` 的人信任编号为 `bᵢ` 的人。

如果法官存在，请返回法官的编号，否则返回 `-1`。

## 解法一：入度出度统计法（最优解）

```python
from typing import List

class Solution:
    def findJudge(self, n: int, trust: List[List[int]]) -> int:
        # 统计每个人的入度和出度
        in_degree = [0] * (n + 1)  # 入度：被多少人信任
        out_degree = [0] * (n + 1)  # 出度：信任多少人
        
        for a, b in trust:
            out_degree[a] += 1  # a信任别人，出度+1
            in_degree[b] += 1   # b被别人信任，入度+1
        
        # 寻找法官：入度为n-1，出度为0
        for i in range(1, n + 1):
            if in_degree[i] == n - 1 and out_degree[i] == 0:
                return i
        
        return -1
```

**时间复杂度**：O(n + m)，其中m是trust数组的长度  
**空间复杂度**：O(n)

### 详细解释：

以n=4, trust=[[1,3],[2,3],[3,1]]为例：
```
人1: 出度=1 (信任3), 入度=1 (被3信任)
人2: 出度=1 (信任3), 入度=0
人3: 出度=1 (信任1), 入度=2 (被1和2信任)
人4: 出度=0, 入度=0

没有人同时满足入度=n-1=3且出度=0，返回-1
```

## 解法二：单数组计数优化

```python
class Solution:
    def findJudge(self, n: int, trust: List[List[int]]) -> int:
        # 使用一个数组：信任别人时减1，被别人信任时加1
        count = [0] * (n + 1)
        
        for a, b in trust:
            count[a] -= 1  # 这个人信任别人，不可能是法官
            count[b] += 1  # 这个人被别人信任
        
        # 法官的条件：count[i] == n-1
        for i in range(1, n + 1):
            if count[i] == n - 1:
                return i
        
        return -1
```

**原理**：
- 法官被所有人信任（除了自己）：`count[i] += (n-1)`
- 法官不信任任何人：不会执行`count[i] -= 1`
- 所以法官最终的`count[i] = n-1`

## 解法三：图论方法（邻接表）

```python
from collections import defaultdict

class Solution:
    def findJudge(self, n: int, trust: List[List[int]]) -> int:
        if n == 1 and not trust:
            return 1
        
        # 构建邻接表：谁信任谁
        trust_map = defaultdict(list)
        # 被信任次数统计
        trusted_count = [0] * (n + 1)
        
        for a, b in trust:
            trust_map[a].append(b)
            trusted_count[b] += 1
        
        # 寻找法官
        candidates = []
        for i in range(1, n + 1):
            if len(trust_map[i]) == 0 and trusted_count[i] == n - 1:
                candidates.append(i)
        
        return candidates[0] if len(candidates) == 1 else -1
```


## 解题思路详解

### 关键理解：
1. **法官的两个条件必须同时满足**：
   - 不信任任何人（出度=0）
   - 被除自己外的所有人信任（入度=n-1）

2. **信任关系的单向性**：
   - 如果A信任B，不代表B信任A
   - 信任关系是有向的

3. **特殊情况处理**：
   - 当n=1时，这个人一定是法官
   - 当trust为空时，只有n=1的情况才存在法官

### 算法步骤：
1. 初始化入度和出度数组（或一个综合计数数组）
2. 遍历trust数组，更新相关计数
3. 遍历所有人，找到满足条件的人
4. 检查是否恰好有一个人满足条件

### 为什么解法一最优？
- 直观易理解：直接对应法官的两个条件
- 时间复杂度最优：只遍历trust数组一次，再遍历n个人一次
- 空间复杂度低：只需要两个长度为n+1的数组

## 常见错误

1. **忽略n=1的情况**：
   ```python
   # 错误代码
   def findJudge(self, n, trust):
       if n == 0: return -1  # 错误！
       # 正确应该是检查n=1的情况
   ```

2. **条件判断不完整**：
   ```python
   # 错误：只检查入度，忽略出度
   if in_degree[i] == n - 1:
       return i
   ```

3. **索引处理错误**：
   - 人的编号从1开始，数组需要长度为n+1
   - 遍历时应该从1到n
