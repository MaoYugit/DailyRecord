### 🟢 第一阶段：计数神器 `Counter`

在面试中，你经常会遇到这种需求：**“统计数组/字符串中每个元素出现的次数”**。

#### 1. 传统写法 vs Counter 写法

**场景**：统计 `s = "banana"` 中每个字母出现的次数。

**❌ 痛苦的传统写法**：
```python
s = "banana"
count_dict = {}
for char in s:
    if char in count_dict:
        count_dict[char] += 1
    else:
        count_dict[char] = 1
# 结果: {'b': 1, 'a': 3, 'n': 2}
```

**✅ Counter 外挂写法**：
```python
from collections import Counter

s = "banana"
counts = Counter(s) 
# 结果: Counter({'a': 3, 'n': 2, 'b': 1})
# 看起来像字典，用起来也像字典，但它自动帮你统计好了！
```

#### 2. Counter 的核心必会技能

`Counter` 本质上是一个 `dict` 的子类，所以字典能用的方法（如 `.keys()`, `.values()`, `counts['a']`）它都能用。但它有几个**独门绝技**：

##### A. `most_common(n)` —— 找前 n 个出现次数最多的
这是华为 OD 考题中处理“热点问题”、“排序问题”的神技。

```python
from collections import Counter

nums = [1, 1, 1, 2, 2, 3]
c = Counter(nums)

# 找出出现次数最多的 2 个元素
# 返回的是一个列表，里面是元组：(元素, 次数)
top_2 = c.most_common(2) 

print(top_2) 
# 输出: [(1, 3), (2, 2)] 
# 解释: 1出现了3次，2出现了2次
```

##### B. 能够做减法 —— 解决“抵消”问题
如果你有两个字符串 `s` 和 `t`，想看它们包含的字符是不是完全一样（只是顺序不同）。

```python
s = "anagram"
t = "nagaram"

c1 = Counter(s)
c2 = Counter(t)

print(c1 == c2) # True
```

甚至可以相减（比如：我想知道 `s` 比 `t` 多了哪些字符）：
```python
a = Counter("aabbb")
b = Counter("ab")

diff = a - b
print(diff) 
# 输出: Counter({'b': 2, 'a': 1})
# 解释: 'b' 原来有3个，减去1个剩2个；'a' 原来有2个，减去1个剩1个。
```

#### 3. 实战演练：LeetCode 高频题

让我们看看如何用 `Counter` 秒杀题目。

**题目：有效的字母异位词 (LeetCode 242)**
给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词（即字符种类和数量都一样，只是顺序不同）。

**代码**：
```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        # 一行代码秒杀
        return Counter(s) == Counter(t)
```

**题目：字符串中的第一个唯一字符 (LeetCode 387)**
给定一个字符串，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 -1。

**思路**：
1. 先用 `Counter` 统计所有字符的次数。
2. 再遍历一遍字符串，如果某个字符的次数是 1，直接返回索引。

**代码**：
```python
from collections import Counter

class Solution:
    def firstUniqChar(self, s: str) -> int:
        # 1. 先统计所有字符频率
        count = Counter(s) 
        
        # 2. 再次遍历字符串
        for i, char in enumerate(s):
            # 查表，如果次数为 1，就是它
            if count[char] == 1:
                return i
                
        return -1
```

### 🟡 第二阶段：万能字典 `defaultdict`

#### 1. 痛点：普通字典的烦恼

假设我们要把一堆单词按首字母分组。
数据：`words = ["apple", "banana", "ant", "bat", "cat"]`
目标：`{'a': ['apple', 'ant'], 'b': ['banana', 'bat'], 'c': ['cat']}`

**❌ 痛苦的传统写法**：
```python
words = ["apple", "banana", "ant", "bat", "cat"]
groups = {}

for word in words:
    first_char = word[0]
    # 必须先判断 key 是否存在，否则报错！
    if first_char not in groups:
        groups[first_char] = [] # 初始化为空列表
    groups[first_char].append(word)
```
每次都要写 `if key not in d`，这在逻辑复杂的题目里非常干扰思路。

**✅ `defaultdict` 外挂写法**：
```python
from collections import defaultdict

# 定义：如果你访问一个不存在的 key，自动给我创建一个 list
groups = defaultdict(list) 

for word in words:
    first_char = word[0]
    # 直接 append！不用管 key 存不存在！
    # 如果 'a' 不在，它自动创建一个 []，然后 append
    groups[first_char].append(word)

print(groups)
# 输出: defaultdict(<class 'list'>, {'a': ['apple', 'ant'], ...})
```

---

#### 2. 核心用法详解

`defaultdict` 接受一个 **工厂函数** 作为参数，这就是它的“默认值类型”。

##### A. `defaultdict(list)` —— 分组神器（华为 OD 必考）
这是最常用的模式。
*   **用途**：
    1.  **哈希分组**：把具有相同特征的元素归到一类（如上面的例子）。
    2.  **构建图（邻接表）**：做 DFS/BFS 题目时，存图必备！

**构建图的例子**：
题目告诉你：`edges = [[0, 1], [1, 2], [0, 2]]` 表示 0 连接 1，1 连接 2...
```python
graph = defaultdict(list)
edges = [[0, 1], [1, 2], [0, 2]]

for u, v in edges:
    graph[u].append(v)
    graph[v].append(u) # 如果是无向图

# graph 现在是: {0: [1, 2], 1: [0, 2], 2: [1, 0]}
# 这样你就可以直接遍历 graph[0] 找到所有相邻节点了
```

##### B. `defaultdict(int)` —— 计数累加
这就有点像 `Counter`，但它更适合**累加数值**，而不仅仅是统计出现次数。

```python
scores = [("Alice", 10), ("Bob", 20), ("Alice", 5), ("Bob", 10)]
total_score = defaultdict(int) # 默认值为 0

for name, score in scores:
    total_score[name] += score # 直接加！不用初始化

print(total_score)
# 输出: {'Alice': 15, 'Bob': 30}
```

#### 3. 实战演练：LeetCode 高频题

**题目：字母异位词分组 (LeetCode 49)**
给定一个字符串数组，将字母异位词组合在一起。
输入: `["eat", "tea", "tan", "ate", "nat", "bat"]`
输出: `[["bat"],["nat","tan"],["ate","eat","tea"]]`

**思路**：
1.  字母异位词的特点是：**排序后长得一样**。比如 `eat` 和 `tea` 排序后都是 `aet`。
2.  我们可以用 **排序后的字符串** 作为 Key，原单词列表作为 Value。
3.  因为要收集一堆单词，所以用 `defaultdict(list)`。

**代码**：
```python
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        # 1. 创建一个默认值为 list 的字典
        group_dict = defaultdict(list)
        
        for s in strs:
            # 2. 生成 Key：将字符串排序
            # sorted(s) 返回的是列表 ['a', 'e', 't']，需要 join 成字符串 "aet" 做 key
            key = "".join(sorted(s))
            
            # 3. 直接 append，无需检查 key 是否存在
            group_dict[key].append(s)
            
        # 4. 返回字典里的所有 values（即分好组的列表）
        return list(group_dict.values())
```

### 🟢 第三阶段：双端队列 `deque`

#### 1. 痛点：为什么 `list` 不行？

队列（Queue）的特点是：**先进先出**（First In, First Out）。
我们需要在**尾部添加**元素，在**头部取出**元素。

*   **List 的问题**：
    *   `list.append(x)`：在尾部加，速度很快，$O(1)$。
    *   **`list.pop(0)`：在头部删，速度极慢，$O(N)$。**
    *   为什么慢？因为一旦你删除了第 0 个元素，后面的所有元素（第 1 到第 N 个）都要**向前挪动一位**来填补空缺。如果列表有一百万个数据，删一次就要挪动一百万次。

*   **Deque 的救赎**：
    *   `deque` (Double-Ended Queue) 是双端队列，经过特殊设计。
    *   不管是在头部还是尾部进行插入/删除，时间复杂度都是 **$O(1)$**。

---

#### 2. 核心用法详解

首先导入：`from collections import deque`

```python
from collections import deque

# 1. 初始化
q = deque([1, 2, 3])

# 2. 尾部操作（和 list 一样）
q.append(4)      # [1, 2, 3, 4]
x = q.pop()      # 弹出 4

# 3. 头部操作（deque 的独门绝技）
q.appendleft(0)  # [0, 1, 2, 3] -> 头部插入
y = q.popleft()  # 弹出 0 -> 头部删除 (速度 O(1))
```

**⚠️ 记住一点：**
只要你是写 **BFS** 或者需要 **“先进先出”** 的逻辑，**请无脑使用 `deque`，并且用 `popleft()` 取出元素。**

#### 3. 实战演练：BFS 广度优先搜索

华为 OD 非常喜欢考网格图（Grid）、树的层序遍历、最短路径问题。这些统统都要用 BFS。

**题目：二叉树的层序遍历 (LeetCode 102)**
给你一个二叉树，请你返回其按 **层序遍历** 得到的节点值。（即逐层地，从左到右访问所有节点）。

**BFS 通用模板（背下来！）**：

```python
from collections import deque

class Solution:
    def levelOrder(self, root: TreeNode) -> List[List[int]]:
        if not root: return []
        
        result = []
        # 1. 初始化队列，把起点放进去
        queue = deque([root])
        
        # 2. 只要队列不空，就一直循环
        while queue:
            level_nodes = [] # 存放当前这一层的所有节点值
            
            # 3. 这一步很关键：固定遍历当前层的长度
            # 为什么？因为我们在遍历过程中会不断 append 新节点，
            # 不锁住长度的话，就分不清哪是当前层，哪是下一层了。
            current_level_size = len(queue)
            
            for _ in range(current_level_size):
                # 4. 队头出队 (O(1) 效率)
                node = queue.popleft()
                level_nodes.append(node.val)
                
                # 5. 把子节点加入队列（队尾入队）
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            
            # 这一层完事了
            result.append(level_nodes)
            
        return result
```

#### 4. 实战演练：网格图 BFS（华为 OD 高频）

**题目：腐烂的橘子 (LeetCode 994)**
网格里有新鲜橘子（1）、腐烂橘子（2）和空格（0）。
每分钟，腐烂橘子会把上下左右相邻的新鲜橘子变腐烂。
问：多少分钟后所有橘子都变腐烂？如果不可能，返回 -1。

**思路**：
这是一道经典的 **多源 BFS**。
1.  先把所有一开始就是腐烂的橘子（2），全部扔进 `deque`。
2.  每次从队列里取出一个橘子，向四周扩散。
3.  如果把新鲜橘子（1）感染了，就把它变成（2），并加入队列。
4.  一圈一圈地扩散，直到队列为空。

**代码片段**：

```python
from collections import deque

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        queue = deque()
        fresh_count = 0
        
        # 1. 初始化：找所有烂橘子，数所有好橘子
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    queue.append((r, c, 0)) # (行, 列, 当前分钟数)
                elif grid[r][c] == 1:
                    fresh_count += 1
        
        minutes = 0
        
        # 2. BFS 开始
        while queue:
            r, c, minutes = queue.popleft() # 弹出队头
            
            # 向四个方向扩散
            for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                nr, nc = r + dr, c + dc
                # 检查边界 + 必须是新鲜橘子
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2 # 感染它
                    fresh_count -= 1
                    # 把新感染的加入队列，时间 + 1
                    queue.append((nr, nc, minutes + 1))
        
        return minutes if fresh_count == 0 else -1
```
