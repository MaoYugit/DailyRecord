### **第一阶段: Node.js 核心与异步编程思想 **

Node.js不仅仅是“能运行在服务器端的JavaScript”，其**异步、非阻塞I/O**的特性是核心，也是与前端JavaScript在思维模式上最大的不同之处。

这个阶段的目标是：**深刻理解Node.js的运行机制，熟练掌握其异步编程模型，并能运用核心模块处理常见的后端任务。**

---

#### **模块一：后端世界观与Node.js初探**

**目标：** 建立宏观认知，从“浏览器”思维切换到“服务器”思维。

1.  **后端核心概念重述**
    *   **客户端-服务器模型**: 深入理解两者如何通过HTTP协议通信。
    *   **请求(Request)与响应(Response)**: 学习一个HTTP请求报文的构成（请求行、请求头、请求体）和响应报文的构成（状态行、响应头、响应体）。
    *   **API (Application Programming Interface)**: 理解它作为前后端沟通“合同”的角色。
    *   **I/O (输入/输出)**: 明白后端大量的操作都与I/O相关，如读取文件（磁盘I/O）、请求数据库（网络I/O），并理解I/O操作通常是耗时的。

2.  **Node.js 是什么？**
    *   **定义**: 不仅仅是JavaScript，而是一个基于Chrome V8引擎的JavaScript **运行时环境 (Runtime Environment)**。
    *   **关键特性**:
        *   **单线程 (Single-Threaded)**: 主执行线程只有一个。
        *   **事件驱动 (Event-Driven)**: 通过事件循环来处理并发任务。
        *   **异步非阻塞I/O (Asynchronous Non-Blocking I/O)**: 这是Node.js高性能的核心。 也是本阶段的学习重点。

3.  **环境搭建与第一个程序**
    *   **安装 nvm (Node Version Manager)**:
        *   学习 `nvm install <version>`, `nvm use <version>`, `nvm ls` 等常用命令。这能让你在不同项目间轻松切换Node版本。
    *   **运行你的第一个 `.js` 文件**:
        *   编写 `console.log('Hello, Node.js!');` 并通过 `node your-file.js` 成功运行。
    *   **REPL 环境**: 学习直接在命令行中输入 `node` 进入交互式环境，快速测试代码片段。

---

#### **模块二：Node.js 异步编程核心 **

**目标：** 彻底搞懂Node.js如何处理并发和耗时操作，这是与前端JS最大的区别。

1.  **事件循环 (The Event Loop)**
    *   **学习内容**: 这是Node.js的心脏。 需要理解它不是JavaScript语言的一部分，而是Node.js运行时提供的机制。 了解其基本工作流程：检查是否有待处理的事件，如果有，就执行对应的回调函数，否则就进入休眠，直到新事件产生。
    *   **关键概念**: 调用栈 (Call Stack)、回调队列 (Callback Queue) / 任务队列 (Task Queue)。

2.  **异步编程模式的演进**
    *   **回调函数 (Callbacks)**:
        *   理解什么是“回调地狱 (Callback Hell)”。
        *   掌握错误优先的回调风格 `(err, data) => {}`，这是Node.js早期API的通用模式。
    *   **Promises**:
        *   学习 `Promise` 的三种状态: `pending`, `fulfilled`, `rejected`。
        *   熟练使用 `.then()` 处理成功情况，`.catch()` 捕获错误。
        *   了解 `Promise.all()` 和 `Promise.race()` 的用途。
    *   **Async/Await (现代标准)**:
        *   **终极目标**: 在第一阶段，你应该能**熟练地使用 `async/await`** 来编写清晰、同步风格的异步代码。
        *   理解 `async` 函数总是返回一个Promise。
        *   理解 `await` 关键字必须在 `async` 函数中使用，它会“暂停”函数执行，等待Promise完成。
        *   学会使用 `try...catch` 结构来捕获`await`表达式中的错误。

#### **模块三：Node.js 核心模块深入 **

**目标：** 掌握最常用、最重要的内建模块，解决实际问题。

1.  **`fs` (File System) - 文件系统**
    *   **异步操作 (推荐)**:
        *   `fs.readFile(path, options, callback)` - 异步读取文件。
        *   `fs.writeFile(path, data, options, callback)` - 异步写入文件。
        *   `fs.appendFile(...)` - 异步追加内容。
    *   **同步操作**:
        *   `fs.readFileSync(...)`, `fs.writeFileSync(...)` - 会阻塞事件循环，仅在特殊场景（如应用启动时加载配置文件）下使用。
    *   **Promise 版本**: 学习使用 `require('fs/promises')`，它提供了基于Promise的API，可以完美配合`async/await`使用。**这是现代Node.js开发的首选方式**。
        *   例如: `const fs = require('fs/promises'); async function() { const data = await fs.readFile(...) }`

2.  **`path` - 路径处理**
    *   **核心功能**: 处理文件和目录路径，屏蔽操作系统差异（Windows的`\` vs macOS/Linux的`/`）。
    *   **常用API**:
        *   `path.join([...paths])`: **极其常用**，用于拼接路径片段。
        *   `path.resolve([...paths])`: 将路径或路径片段的序列解析为绝对路径。
        *   `__dirname`: 一个全局变量，表示当前文件所在的目录的绝对路径。
        *   `__filename`: 一个全局变量，表示当前文件的绝对路径。

3.  **`http` - 创建你的第一个服务器**
    *   **学习内容**:
        *   `http.createServer((req, res) => { ... })`: 创建一个HTTP服务器实例。
        *   `req` 对象:
            *   `req.url`: 获取请求的URL。
            *   `req.method`: 获取HTTP请求方法 (GET, POST等)。
        *   `res` 对象:
            *   `res.writeHead(statusCode, headers)`: 发送响应头。
            *   `res.write(chunk)`: 发送响应体的一部分。
            *   `res.end([data])`: **必须调用**，表示响应结束。
    *   **目标**: 亲手创建一个能根据不同URL (`/about`, `/contact`) 和不同方法 (`GET`) 返回不同文本内容的简单Web服务器。

4.  **模块系统 (Module System)**
    *   **CommonJS (CJS)**: **必须精通**。
        *   `require()`: 用于导入模块。
        *   `module.exports`: 用于导出一个模块的内容。
        *   理解 `exports` 只是 `module.exports` 的一个引用别名。
    *   **ES Modules (ESM) in Node.js (了解)**:
        *   了解如何在Node.js中使用 `import`/`export` 语法（通常通过在`package.json`中设置 `"type": "module"`）。
        *   知道它与CommonJS的一些差异（例如ESM是异步加载）。

#### **模块四：NPM 与项目管理 **

**目标：** 学会像一个工程师一样管理你的项目。

1.  **`package.json` 详解**
    *   通过 `npm init -y` 快速创建。
    *   理解核心字段: `name`, `version`, `description`, `main` (入口文件), `scripts` (项目脚本)。
2.  **依赖管理**
    *   `npm install <package>`: 安装依赖。
    *   `dependencies`: 生产环境需要的依赖（如Express）。
    *   `devDependencies`: 开发和测试时需要的依赖（如`nodemon`）。
        *   使用 `npm install <package> --save-dev` 或 `-D` 来安装。
    *   `node_modules` 目录和 `package-lock.json` 文件的作用。
3.  **实用工具**
    *   **`nodemon`**: **必备工具**。它会监视你的文件变化并自动重启服务，极大提升开发效率。
    *   在 `package.json`的 `scripts` 中配置 `"dev": "nodemon index.js"`，然后通过 `npm run dev` 启动项目。

🏁 **第一阶段最终里程碑 (验收标准):**

1.  **理论**: 能清晰地向别人解释什么是Node.js的事件循环和非阻塞I/O。能解释`async/await`如何解决回调地狱问题。
2.  **代码实践一 (文件操作)**: 编写一个Node.js脚本，使用`fs/promises`和`async/await`完成以下任务：
    *   读取一个名为`input.json`的文件内容（内容是一个JSON数组）。
    *   解析JSON，对数组中的数据进行一些处理（例如，筛选或映射）。
    *   将处理后的结果写入一个新的`output.json`文件。
3.  **代码实践二 (Web服务器)**: 使用`http`模块创建一个服务器，实现：
    *   当用户访问 `GET /` 时，返回 "Welcome to the homepage!"。
    *   当用户访问 `GET /api/user` 时，返回一个JSON字符串 `{"name": "Alice", "age": 30}`。 (提示: 使用 `res.writeHead(200, { 'Content-Type': 'application/json' });`)
    *   访问其他任何URL时，返回 "404 Not Found" 并设置状态码为 `404`。
4.  **项目管理**: 成功创建一个NPM项目，安装`nodemon`作为开发依赖，并配置`npm run dev`脚本来运行你的HTTP服务器。
