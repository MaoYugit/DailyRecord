### **创建 Spring Boot 项目**

* 使用 IDEA 的 Spring Initializr 创建。

* **依赖勾选:**

  * Spring Web

  * MyBatis Framework

  * MySQL Driver

  * Lombok 

  * PageHelper （在 Spring Initializr（也就是你现在的 IDEA 勾选界面）里，**通常是搜不到 PageHelper 的**。因为它不是 Spring 官方维护的库，而是第三方开源大神写的。）

    ```java
    <!-- PageHelper 分页插件 -->
    <dependency>
        <groupId>com.github.pagehelper</groupId>
        <artifactId>pagehelper-spring-boot-starter</artifactId>
        <version>1.4.7</version>
    </dependency>
    ```

### **配置 `application.yml`**

* 配置数据库连接 URL、用户名、密码。

* 配置 MyBatis 的 Mapper XML 扫描路径。

  ```java
  # ==========================================
  # 服务器配置
  # ==========================================
  server:
    port: 8080  # 后端运行端口，默认 8080
  
  # ==========================================
  # Spring 核心配置
  # ==========================================
  spring:
    application:
      name: myblog-backend # 应用名称
  
    # 数据库连接配置
    datasource:
      # MySQL 8.x 驱动
      driver-class-name: com.mysql.cj.jdbc.Driver
      # 数据库连接串：
      # 1. localhost:3306/myblog_db -> 对应我们之前创建的数据库名
      # 2. serverTimezone=Asia/Shanghai -> 解决时差问题
      # 3. useUnicode=true&characterEncoding=utf-8 -> 解决中文乱码
      url: jdbc:mysql://localhost:3306/myblog_db?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&useSSL=false
      username: root
      password: 123456
  
  # ==========================================
  # MyBatis 配置
  # ==========================================
  mybatis:
    # 告诉 MyBatis SQL XML 文件放在哪里 (classpath 对应 resources 目录)
    mapper-locations: classpath:mapper/*.xml
    # 别名扫描包 (写 XML 时 resultType 可以直接写 "User" 而不用写全限定名)
    type-aliases-package: com.my.blog.entity
    configuration:
      # 开启驼峰命名映射
      # 自动把数据库的 create_time 映射为 Java 的 createTime
      map-underscore-to-camel-case: true
      # 打印 SQL 日志
      log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
  
  # ==========================================
  # PageHelper 分页插件配置
  # ==========================================
  pagehelper:
    helper-dialect: mysql
    reasonable: true           # 分页合理化 (比如查第100页没数据，会自动返回最后一页，防止报错)
    support-methods-arguments: true
  ```

  

### **规划包结构 (Standard Packaging)**

良好的目录结构能让你思路清晰：

```text
com.my.blog
├── common          // 通用模块 (结果封装类、工具类)
├── config          // 配置类 (跨域配置、拦截器配置)
├── controller      // 控制层 (接收前端请求)
├── entity          // 实体类 (对应数据库表)
├── mapper          // DAO层 (MyBatis接口)
├── service         // 业务逻辑层接口
│   └── impl        // 业务逻辑层实现
└── BlogApplication.java
```

### **封装统一响应结果 (`Result` 类)**

*   不要直接返回 String 或 Object。
*   定义一个 `Result<T>` 类，包含 `code` (状态码), `msg` (消息), `data` (数据)。前后端交互必须统一格式。

```java
package com.my.blog.common;

import lombok.Data;

/**
 * 统一响应结果封装类
 * @param <T> 数据载体的类型 (比如 User, List<Article>, String 等)
 */
@Data // Lombok注解：自动生成 Getter, Setter, toString 等
public class Result<T> {

    // 状态码：200成功，其他失败
    private Integer code;

    // 提示信息
    private String msg;

    // 返回的数据
    private T data;

    // 构造方法私有化，强制使用静态方法创建对象
    private Result() {}

    // 全参构造
    private Result(Integer code, String msg, T data) {
        this.code = code;
        this.msg = msg;
        this.data = data;
    }

    /**
     * 成功返回 (带数据)
     * 用法：return Result.success(user);
     */
    public static <T> Result<T> success(T data) {
        return new Result<>(200, "操作成功", data);
    }

    /**
     * 成功返回 (不带数据，比如删除成功)
     * 用法：return Result.success();
     */
    public static <T> Result<T> success() {
        return new Result<>(200, "操作成功", null);
    }

    /**
     * 失败返回
     * 用法：return Result.error("用户名已存在");
     */
    public static <T> Result<T> error(String msg) {
        return new Result<>(500, msg, null);
    }

    /**
     * 失败返回 (自定义状态码)
     */
    public static <T> Result<T> error(Integer code, String msg) {
        return new Result<>(code, msg, null);
    }
}
```
