## 快速排序（Quicksort）

快速排序（Quicksort）是面试中最常被问到的算法之一，也是在实际开发中广泛应用的排序算法。 本教程将为你提供一个全面的指南，深入讲解快速排序的原理、性能分析、实现细节以及针对面试和实际开发的优化策略，并提供 Python 和 Java 的代码实现。

### 什么是快速排序？

快速排序是一种高效、采用**分治法（Divide and Conquer）**策略的排序算法。 它的核心思想是选取一个"基准"（pivot）元素，然后将数组分区（partition），使得所有比基准小的元素都在基准的左边，所有比基准大的元素都在基准的右边。 然后，再对左右两个子数组递归地应用这个过程，直到整个数组有序。 因为它通常是在原数组上直接进行交换操作，所以它也是一种**原地排序（in-place）**算法，不需要额外的存储空间。

### 快速排序的工作原理

快速排序的算法流程可以分为三个主要步骤：

1.  **选择基准（Pick a Pivot）**：从数组中选择一个元素作为基准。选择策略有多种，例如选择第一个元素、最后一个元素、中间元素或随机选择一个元素。
2.  **分区（Partition）**：重新排列数组，将所有小于基准的元素移动到基准的左侧，大于或等于基准的元素移动到右侧。 完成分区后，基准元素就处于其最终排序后的正确位置。
3.  **递归（Recurse）**：对基准左侧和右侧的两个子数组，递归地重复执行前两个步骤。

递归的终止条件是子数组的大小为 0 或 1，这时它自然就是有序的。

#### 一个简单的例子

假设我们要对数组 `[8, 3, 1, 7, 0, 10, 2]` 进行排序。

1.  **选择基准**：我们选择最后一个元素 `2` 作为基准。
2.  **分区**：
    *   遍历数组，将小于 `2` 的元素（`1`, `0`）放到左边，大于 `2` 的元素（`8`, `3`, `7`, `10`）放到右边。
    *   分区后的数组可能看起来像这样：`[1, 0, 2, 7, 8, 10, 3]`。此时，`2` 已经找到了它的最终位置。
3.  **递归**：
    *   对左边的子数组 `[1, 0]` 递归执行快速排序。
    *   对右边的子数组 `[7, 8, 10, 3]` 递归执行快速排序。

这个过程会一直持续下去，直到所有子数组都被排序，最终整个数组变得有序。

### 性能分析：时间与空间复杂度

| 场景         | 时间复杂度 | 空间复杂度 |
| :----------- | :--------- | :--------- |
| **最佳情况** | O(n log n) | O(log n)   |
| **平均情况** | O(n log n) | O(log n)   |
| **最坏情况** | O(n²)      | O(n)       |

*   **最佳和平均情况 O(n log n)**：当每次选择的基准都能将数组大致平分成两个大小相近的子数组时，递归树的深度为 log n，每一层的时间复杂度为 O(n)，总时间复杂度为 O(n log n)。
*   **最坏情况 O(n²)**：当数组已经有序或接近有序，并且每次都选择第一个或最后一个元素作为基准时，分区会极度不平衡。 这会导致递归树的深度为 O(n)，从而使得总时间复杂度退化到 O(n²)。
*   **空间复杂度 O(log n)**：这主要来自于递归调用栈的深度。在平均情况下，递归深度为 O(log n)。 在最坏情况下，递归深度可能达到 O(n)。

### 面试和实际开发中的关键点

#### 1. 基准（Pivot）的选择

基准的选择对快速排序的性能至关重要。

*   **选择第一个或最后一个元素**：实现最简单，但容易在输入数组有序或接近有序时导致最坏情况。
*   **随机选择**：从概率上避免了最坏情况的发生，是一种非常安全和常用的策略。
*   **三数取中（Median-of-Three）**：取数组的第一个、最后一个和中间的元素，选择其中的中位数作为基准。这能有效避免在有序或逆序数组上的最坏情况。

#### 2. 分区方案（Partitioning Scheme）

最常见的分区方案是 **Lomuto 分区方案** 和 **Hoare 分区方案**。上面例子中描述的以及下面代码中实现的通常是 Lomuto 方案，它更容易理解和实现。Hoare 方案在某些情况下效率稍高，但实现稍复杂。

#### 3. 优化策略

在实际开发中，会对经典的快速排序进行优化：

*   **小数组切换到插入排序**：当递归的子数组规模很小时（例如，小于10个元素），递归的开销会变得不划算。此时切换到插入排序会更高效。
*   **三路快排（3-Way Quicksort）**：当数组中存在大量重复元素时，标准的快速排序效率会下降。三路快排将数组分为三部分：小于基准、等于基准和大于基准。 之后只需递归处理小于和大于基准的两部分，对于处理包含大量重复键的数组非常有效。
*   **尾递归优化**：通过将递归调用改为迭代，可以减少递归栈的深度，从而降低空间复杂度，避免栈溢出。

### Python 代码实现

下面是一个使用"三数取中"选择基准并对小数组使用插入排序进行优化的 Python 实现。

```python
def insertion_sort(arr, low, high):
    """对小数组使用插入排序"""
    for i in range(low + 1, high + 1):
        key = arr[i]
        j = i - 1
        while j >= low and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key

def partition(arr, low, high):
    """Lomuto 分区方案"""
    # 三数取中选择基准
    mid = low + (high - low) // 2
    if arr[low] > arr[mid]:
        arr[low], arr[mid] = arr[mid], arr[low]
    if arr[low] > arr[high]:
        arr[low], arr[high] = arr[high], arr[low]
    if arr[mid] > arr[high]:
        arr[mid], arr[high] = arr[high], arr[mid]
    
    # 将中位数作为基准，并将其放到 high-1 的位置
    arr[mid], arr[high - 1] = arr[high - 1], arr[mid]
    pivot = arr[high - 1]
    
    i = low
    for j in range(low, high - 1):
        if arr[j] <= pivot:
            arr[i], arr[j] = arr[j], arr[i]
            i += 1
    arr[i], arr[high - 1] = arr[high - 1], arr[i]
    return i

def quick_sort_optimized(arr, low, high):
    """优化后的快速排序"""
    if low < high:
        # 当数组规模较小时，切换到插入排序
        if high - low + 1 < 10:
            insertion_sort(arr, low, high)
        else:
            pi = partition(arr, low, high)
            quick_sort_optimized(arr, low, pi - 1)
            quick_sort_optimized(arr, pi + 1, high)

# 封装调用
def quick_sort(arr):
    if not arr:
        return []
    quick_sort_optimized(arr, 0, len(arr) - 1)
    return arr

# 示例
my_array = [8, 3, 1, 7, 0, 10, 2, 8, 5]
quick_sort(my_array)
print("Sorted array:", my_array)

```

### Java 代码实现

下面是快速排序的 Java 实现，同样采用了优化策略。

```java
import java.util.Arrays;

public class QuickSort {

    /**
     * 主排序方法
     * @param arr 待排序数组
     */
    public static void sort(int[] arr) {
        if (arr == null || arr.length == 0) {
            return;
        }
        quickSort(arr, 0, arr.length - 1);
    }

    private static void quickSort(int[] arr, int low, int high) {
        if (low < high) {
            // 对小数组使用插入排序
            if (high - low + 1 < 10) {
                insertionSort(arr, low, high);
                return;
            }
            
            int pi = partition(arr, low, high);
            quickSort(arr, low, pi - 1);
            quickSort(arr, pi + 1, high);
        }
    }

    private static int partition(int[] arr, int low, int high) {
        // 三数取中选择基准
        int mid = low + (high - low) / 2;
        if (arr[low] > arr[mid]) swap(arr, low, mid);
        if (arr[low] > arr[high]) swap(arr, low, high);
        if (arr[mid] > arr[high]) swap(arr, mid, high);

        // 将基准放到倒数第二的位置
        swap(arr, mid, high - 1);
        int pivot = arr[high - 1];

        int i = low;
        for (int j = low; j < high - 1; j++) {
            if (arr[j] <= pivot) {
                swap(arr, i, j);
                i++;
            }
        }
        swap(arr, i, high - 1);
        return i;
    }

    private static void insertionSort(int[] arr, int low, int high) {
        for (int i = low + 1; i <= high; i++) {
            int key = arr[i];
            int j = i - 1;
            while (j >= low && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }
            arr[j + 1] = key;
        }
    }

    private static void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

    public static void main(String[] args) {
        int[] myArray = {8, 3, 1, 7, 0, 10, 2, 8, 5};
        QuickSort.sort(myArray);
        System.out.println("Sorted array: " + Arrays.toString(myArray));
    }
}

```

### 总结

*   **优点**：平均性能非常好，为 O(n log n)；是原地排序，空间复杂度低。
*   **缺点**：最坏情况下性能为 O(n²)；不稳定排序，即相等元素的原始顺序可能在排序后改变。

掌握快速排序不仅仅是记住代码，更重要的是理解其分治思想、性能瓶颈以及如何通过选择合适的基准和结合其他排序算法来优化它。在面试中，能够清晰地阐述这些细节，将使你脱颖而出。
