### **第七章：路由管理 (Vue Router)**

到目前为止，我们的应用虽然功能丰富，但本质上仍是一个**单页面应用 (Single Page Application - SPA)**——所有的内容都在同一个 URL 下展示。然而，一个完整的网站通常需要多个页面，例如首页、课程列表页、关于我们页等等。用户希望通过不同的 URL 地址访问到不同的内容。

**Vue Router** 是 Vue.js 的官方路由管理器。它能让我们轻松地将 URL 映射到组件，实现页面的切换，而无需每次都向服务器请求刷新整个页面。这带来了如丝般顺滑的用户体验。

**我们的目标：**

1.  将我们的应用改造成一个多页面结构：一个首页、一个课程详情页。
2.  实现通过 URL 参数动态展示不同课程的详情。
3.  学习如何保护路由，例如，实现一个模拟的“需要登录才能访问”的功能。
4.  掌握路由懒加载，这是优化大型应用首屏加载速度的必备技巧。

#### **7.1 路由基础：绘制你的应用地图**

**步骤一：安装 Vue Router**

在你的项目根目录下打开终端，运行以下命令：

```bash
npm install vue-router@4
```
*注意：Vue 3 必须使用 vue-router 的第 4 版。*

**步骤二：创建路由配置文件**

这是一个标准的最佳实践，能让你的路由配置保持独立和整洁。

1.  在 `src` 目录下，创建一个新文件夹 `router`。
2.  在 `src/router` 文件夹内，创建一个新文件 `index.js`。

**步骤三：配置路由**

打开 `src/router/index.js`，我们将在这里定义我们的“路由地图”。

```javascript
// src/router/index.js
import { createRouter, createWebHistory } from 'vue-router';

// 1. 定义路由组件。
// 为了演示，我们先创建两个简单的页面组件
// 通常我们会把这些页面级别的组件放在一个叫 `views` 的文件夹里
import Home from '../views/Home.vue';
import CourseDetail from '../views/CourseDetail.vue';

// 2. 定义一些路由
// 每个路由都需要映射到一个组件。
const routes = [
  { 
    path: '/',          // URL 路径
    name: 'Home',       // 路由名称 (推荐)
    component: Home     // 映射的组件
  },
  { 
    path: '/course', 
    name: 'Course',
    component: CourseDetail 
  },
];

// 3. 创建路由实例并传递 `routes` 配置
const router = createRouter({
  // 4. 提供 history 实现。我们这里使用 hash 模式。
  history: createWebHistory(import.meta.env.BASE_URL),
  routes, // `routes: routes` 的缩写
});

export default router;
```

> **大师兄提示 (面试常考): `createWebHistory` vs `createWebHashHistory`?**
> *   **`createWebHistory` (History 模式):** 使用标准的浏览器 history API。URL 看起来很“干净”，例如 `https://example.com/course`。**缺点**是需要服务器端配置支持，否则用户直接访问 `https://example.com/course` (比如刷新页面) 会导致 404 错误。这是生产环境的推荐模式。
> *   **`createWebHashHistory` (Hash 模式):** URL 中会带有一个 `#` 符号，例如 `https://example.com/#/course`。**优点**是不需要任何服务器端配置即可工作。

**步骤四：在 Vue 应用中“安装”路由**

打开你的主入口文件 `src/main.js`，告诉 Vue 应用去使用我们刚刚创建的路由实例。

```javascript
// src/main.js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router' // 导入我们的路由实例

const app = createApp(App)

app.use(router) // 安装路由

app.mount('#app')
```

**步骤五：在 `App.vue` 中设置“出口”和“入口”**

现在路由已经准备就绪，但它需要知道在哪里显示匹配到的组件，以及用户如何点击进行导航。

*   **`<router-view>` (出口):** 这是一个占位符组件，它会渲染当前 URL 匹配到的路由组件。
*   **`<router-link>` (入口):** 这是用于声明式导航的组件，它会被渲染成一个 `<a>` 标签。使用它而不是普通的 `<a>` 标签，可以避免整个页面的刷新。

修改 `src/App.vue`，为我们的应用添加一个基本的导航栏。

```vue
<!-- src/App.vue -->
<template>
  <div id="app">
    <nav>
      <!-- to 属性指定了目标路径 -->
      <router-link to="/">首页</router-link> |
      <router-link to="/course">课程详情</router-link>
    </nav>
    
    <!-- 路由匹配到的组件将在这里渲染 -->
    <router-view></router-view>
  </div>
</template>

<style>
/* 添加一些简单的样式 */
nav { padding: 20px; text-align: center; }
nav a { font-weight: bold; color: #2c3e50; text-decoration: none; margin: 0 10px; }
nav a.router-link-exact-active { color: #42b983; } /* vue-router 会自动为当前激活的链接添加这个 class */
</style>
```
现在，你需要创建 `src/views/Home.vue` 和 `src/views/CourseDetail.vue` 这两个文件，并把之前 `App.vue` 的课程卡片逻辑移动到 `CourseDetail.vue` 中。

#### **7.2 动态路由与参数**

我们的课程详情页现在是写死的。我们希望 `/course/1` 显示 ID 为 1 的课程，`/course/2` 显示 ID 为 2 的课程。这就是**动态路由**。

**步骤一：修改路由定义**

在 `src/router/index.js` 中，我们使用 `:` 语法来标记一个动态片段。

```javascript
// src/router/index.js
// ...
const routes = [
  // ...
  { 
    // :id 就是一个动态的“参数”
    path: '/course/:id', 
    name: 'CourseDetail',
    component: CourseDetail 
  },
]
```

**步骤二：在组件中获取参数**

Vue Router 提供了一个 `useRoute` 组合式函数来访问当前路由的信息。

```vue
<!-- src/views/CourseDetail.vue -->
<script setup>
import { useRoute } from 'vue-router';
import { ref, watchEffect } from 'vue';

// 1. 获取当前路由对象
const route = useRoute();
const courseId = ref(route.params.id); // 获取名为 id 的参数

// 假设我们有一个根据 ID 获取课程数据的函数
// const { course, error, isLoading } = useFetchCourse(courseId);

// 当路由参数变化时，确保我们的数据也更新
watchEffect(() => {
  courseId.value = route.params.id;
  console.log(`当前课程ID是: ${courseId.value}`);
  // 在这里可以重新获取数据
});

</script>

<template>
  <div>
    <h1>课程详情页</h1>
    <p>正在查看 ID 为 {{ courseId }} 的课程。</p>
    <!-- 这里可以放之前的课程卡片组件 -->
  </div>
</template>
```

**编程式导航**

除了使用 `<router-link>`，我们还可以在 JavaScript 中进行导航，比如在用户登录成功后跳转到首页。这需要使用 `useRouter` 组合式函数。

> **大师兄提示:** `useRoute` vs `useRouter`
> *   `useRoute` (结尾是 e): 用来**获取**当前路由的信息（参数、路径、查询等）。它是只读的。
> *   `useRouter` (结尾是 r): 用来**执行**导航动作（`push`, `go`, `replace` 等）。它是可写的。

```javascript
<script setup>
import { useRouter } from 'vue-router';

const router = useRouter();

function goToCourse(id) {
  // 字符串路径
  // router.push(`/course/${id}`);
  
  // 或者使用对象，配合命名路由 (推荐，更健壮)
  router.push({ name: 'CourseDetail', params: { id } });
}
</script>

<template>
  <button @click="goToCourse(123)">查看123号课程</button>
</template>
```

#### **7.3 路由守卫：你的应用“保安”**

路由守卫允许你在导航发生之前、期间或之后执行逻辑，非常适合用于权限检查。

**把守卫想象成路由的“收费站”或“检查点”**，它有三个核心参数：
*   `to`: 即将进入的目标路由对象。
*   `from`: 当前导航正要离开的路由对象。
*   `next`: **必须调用**的函数，用来解析这个钩子。
    *   `next()`: 放行，继续导航。
    *   `next(false)`: 中断当前的导航。
    *   `next('/login')`: 重定向到一个不同的地址。

**全局前置守卫 (`router.beforeEach`)**

这是最常用的守卫，非常适合做全局的登录验证。

```javascript
// src/router/index.js
// ...
const router = createRouter({ ... });

// 模拟一个登录状态
const isLoggedIn = () => !!localStorage.getItem('token');

router.beforeEach((to, from, next) => {
  console.log(`导航到: ${to.path}`);
  // 假设我们的“个人中心”页需要登录
  if (to.meta.requiresAuth && !isLoggedIn()) {
    // 用户未登录，重定向到登录页
    next({ name: 'Login' }); // 假设你有一个名为 'Login' 的路由
  } else {
    // 否则，正常放行
    next();
  }
});

// 你需要在路由定义中添加 meta 字段
{
  path: '/profile',
  name: 'Profile',
  component: Profile,
  meta: { requiresAuth: true } // 这个路由需要认证
}
```

**组件内的守卫**

你也可以直接在组件内部定义守卫，例如，在用户离开一个未保存的表单页面时，给出一个提示。

```vue
<!-- src/views/EditForm.vue -->
<script setup>
import { onBeforeRouteLeave } from 'vue-router';
import { ref } from 'vue';

const hasUnsavedChanges = ref(true); // 模拟有未保存的更改

onBeforeRouteLeave((to, from) => {
  if (hasUnsavedChanges.value) {
    const answer = window.confirm('你有未保存的更改，确定要离开吗？');
    if (!answer) {
      return false; // 用户点击“取消”，则中断导航
    }
  }
});
</script>
```

#### **7.4 路由懒加载：优化你的应用性能**

**问题：** 当应用变得庞大时，所有页面的代码都会被打包进一个巨大的 JavaScript 文件。用户打开首页时，必须一次性下载所有页面的代码，即使他们可能永远不会访问“关于我们”页面。这严重拖慢了**首屏加载速度**。

**解决方案：路由懒加载 (Lazy Loading)**

懒加载利用了构建工具（如 Vite/Webpack）的**代码分割**能力。它会把每个路由映射的组件打包成一个独立的、更小的 JavaScript 文件（称为“块”或“chunk”），只有当用户**第一次访问**该路由时，浏览器才会去下载对应的文件。

**如何实现？**
实现起来非常简单，只需将静态的 `import` 改为动态的 `import()` 函数。

**修改前 (所有代码打包在一起):**
```javascript
// src/router/index.js
import CourseDetail from '../views/CourseDetail.vue';

const routes = [
  { 
    path: '/course/:id',
    name: 'CourseDetail',
    component: CourseDetail 
  },
]
```

**修改后 (按需加载):**
```javascript
// src/router/index.js
const routes = [
  { 
    path: '/course/:id',
    name: 'CourseDetail',
    // component 现在是一个返回 import() 的函数
    component: () => import('../views/CourseDetail.vue')
  },
]
```

就是这样！现在，`CourseDetail.vue` 的代码只会在用户访问一个 `/course/...` 路径时才会被加载。这对于大型应用的首屏性能提升是**革命性的**，也是生产环境的**必备**优化项。
