### **第三章：深入响应式系统**

在前两章，我们学会了如何将数据展示在页面上，并与之交互。你可能已经感觉到了 Vue 的神奇之处：当我们在 `addToCart` 方法里修改 `cart.value` 或 `course.value.stock` 时，页面上对应的数字和状态会**自动更新**。

这背后并不是魔法，而是 Vue 的核心——**响应式系统 (Reactivity System)**。这一章，我们将揭开这层神秘的面纱，彻底搞懂它是如何工作的。理解响应式系统，是让你从“会用 Vue”到“精通 Vue”最关键的一步。

**我们的目标：**

1.  重构课程卡片的代码，使用更合适的响应式 API。
2.  添加一个新的“总价”功能，它会根据课程价格和购买数量自动计算。
3.  添加一个“监控”功能，当购物车数量达到某个值时，给用户一个提示。

---

#### **3.1 响应式基础：让数据“活”起来**

想象一下，你在一个 Excel 表格里，单元格 `C1` 的公式是 `=A1+B1`。当你修改 `A1` 或 `B1` 的值时，`C1` 会自动重新计算并更新。Vue 的响应式系统做的就是类似的事情，只不过它更新的是你的网页界面 (UI)。

**1. `ref()`: 我们熟悉的老朋友**

在前两章，我们一直在使用 `ref` 来创建数据，比如 `const cart = ref(0)`。现在，我们来深入理解它。

*   **`ref` 是什么？**
    `ref` (reference 的缩写) 接收一个内部值，并返回一个**响应式的、可变的 ref 对象**。这个对象只包含一个 `.value` 属性，指向该内部值。

    ```javascript
    import { ref } from 'vue'
    
    const count = ref(10)
    
    console.log(count) // 输出一个 ref 对象，看起来像 { value: 10 }
    console.log(count.value) // 输出 10
    
    count.value++ // 修改值
    console.log(count.value) // 输出 11
    ```

*   **为什么需要 `.value`？(面试高频点)**
    JavaScript 的原始类型（如 `number`, `string`）本身不是“响应式”的。如果你把一个普通的 JavaScript 变量 `let a = 10` 传给一个函数，函数只能得到它的**值**，而无法追踪它未来的变化。

    Vue 为了解决这个问题，用一个包含 `value` 属性的对象来“包裹”这个原始值。这样，Vue 就可以持续追踪这个对象的 `.value` 属性的读写操作。当你读取 `count.value` 时，Vue 会“记录”下来：“哦，这个地方用到了 `count`”。当你修改 `count.value` 时，Vue 会“通知”所有记录过的地方：“`count` 变了，你们需要更新！”

    而在 `<template>` 中，我们不需要写 `.value`（例如 `{{ count }}`），是因为 Vue 的模板编译器足够智能，会自动为我们“解包”(unwrap)，让我们写起来更方便。

**2. `reactive()`: 为对象而生**

虽然 `ref` 也可以处理对象 (`ref({})`)，但 Vue 提供了另一个专门用于处理对象（包括数组和 Map、Set 等）的函数：`reactive()`。

*   **`reactive` 是什么？**
    `reactive()` 返回一个对象的**响应式代理 (Proxy)**。

**案例实践：用 `reactive` 重构我们的 `course` 数据**

目前我们的 `course` 是用 `ref` 创建的。我们来试试用 `reactive` 改造它。

1.  打开 `src/App.vue`。
2.  从 `vue` 的导入中加入 `reactive`。
3.  修改 `course` 的定义。

```vue
<!-- src/App.vue -->
<script setup>
// 1. 从 vue 导入 reactive
import { ref, reactive } from 'vue'

// 2. 使用 reactive 替代 ref 来定义 course 对象
const course = reactive({
  name: 'Vue 3 大师课',
  price: 89.9,
  stock: 15,
  onSale: true,
  // ... 其他属性
})

const cart = ref(0)
const quantity = ref(1)

function addToCart() {
  // 3. 注意！现在访问 course 的属性不再需要 .value
  if (course.stock >= quantity.value) {
    cart.value += quantity.value
    course.stock -= quantity.value // 直接访问 course.stock
    quantity.value = 1
  } else {
    alert('库存不足！')
  }
}
</script>
```

你会发现，代码依然能正常工作！但操作 `course` 对象时，不再需要 `.value` 这个中间层了，代码看起来更自然。

> **大师兄提示 (面试必考点): `ref` 和 `reactive` 的核心区别？**
>
> *   **使用场景:**
>     *   `ref` 通常用于**原始类型** (string, number, boolean) 的响应式数据。
>     *   `reactive` 用于**对象类型** (object, array) 的响应式数据。
> *   **底层原理:**
>     *   `ref` 的核心是 `.value` 属性，通过它来实现对值的追踪。
>     *   `reactive` 的核心是 ES6 的 `Proxy`，它会劫持对整个对象的操作（如读取、设置属性），从而实现响应式。
> *   **访问方式:**
>     *   在 `<script>` 中，`ref` 变量必须通过 `.value` 访问。
>     *   `reactive` 对象可以直接访问其属性。
> *   **一个重要的陷阱:**
>     *   **不能直接替换 `reactive` 对象**：例如 `course = { ... }` 会让 `course` 变量失去响应性，因为它切断了与原始代理的连接。你只能修改 `course` 对象的属性，如 `course.name = '... '`。
>     *   **解构 `reactive` 会失去响应性**：`const { stock } = course`，这里的 `stock` 将是一个普通的数字，不再是响应式的。`ref` 则没有这个问题，因为你解构的是 ref 对象本身。
>
> **该如何选择？**
> 个人和团队的编码风格都有。一个常见的最佳实践是：**尽量使用 `ref`**。
> 1.  它可以用在任何类型上，心智负担小。
> 2.  它保证了 `.value` 访问的一致性，不管你处理的是原始值还是对象。
> 3.  它能更好地与组合式函数配合，避免解构带来的响应性丢失问题。
>
> *为了本教程的演示，我们暂时保留 `course` 为 `reactive`，`cart` 和 `quantity` 为 `ref`，以让你更好地感受它们的差异。*

#### **3.2 计算属性 (Computed Properties)**

在我们的项目中，库存状态的显示逻辑是写在 `<template>` 里的：

```html
<p v-if="course.stock > 10">库存充足...</p>
<p v-else-if="course.stock > 0">库存紧张...</p>
<p v-else>已售罄</p>
```

当模板中的逻辑变得复杂时，会让模板变得臃肿且难以维护。对于任何包含响应式依赖的复杂逻辑，都应该使用**计算属性**。

*   **`computed` 是什么？**
    `computed` 接收一个 `getter` 函数，并返回一个**只读的、响应式的 ref 对象**。当其依赖的响应式数据变化时，它的值会自动更新。

**案例实践：用 `computed` 优化库存状态显示**

1.  在 `<script setup>` 中引入 `computed` 并创建计算属性。

    ```vue
    <script setup>
    // 1. 导入 computed
    import { ref, reactive, computed } from 'vue'

    const course = reactive({ /* ... */ })
    // ...

    // 2. 创建一个计算属性
    const stockStatusText = computed(() => {
      if (course.stock > 10) {
        return `库存充足 (剩余 ${course.stock} 件)`
      } else if (course.stock > 0) {
        return `库存紧张 (剩余 ${course.stock} 件)`
      } else {
        return '已售罄'
      }
    })
    </script>
    ```

2.  在 `<template>` 中使用这个计算属性来简化代码。

    ```vue
    <template>
      <!-- ... -->
      <h3>库存状态:</h3>
      <!-- 3. 用一行代码替代原来的三行 v-if/v-else-if -->
      <p>{{ stockStatusText }}</p>
      <!-- ... -->
    </template>
    ```

现在，模板变得干净多了！所有的逻辑都封装在了 `<script>` 部分。

> **大师兄提示 (面试必考点): `computed` vs `methods` 的区别？**
>
> 你可能会想，我写一个方法也能实现同样的效果：
>
> ```javascript
> function getStockStatusText() {
> // ... 同样的逻辑
> return '...';
> }
> ```
>
> ```html
> <p>{{ getStockStatusText() }}</p>
> ```
>
> 它们的核心区别在于：**计算属性是基于其响应式依赖进行缓存的。**
>
> *   **`computed` (计算属性):** 只有在它的依赖（例子中的 `course.stock`）发生改变时，才会重新计算。如果 `course.stock` 不变，无论你访问 `stockStatusText` 多少次，它都会立即返回之前缓存的结果，而不会重新执行函数。
> *   **`methods` (方法):** 每当模板重新渲染时，调用方法**总是会**重新执行函数。
>
> **选择场景:**
>
> *   当你需要根据响应式数据派生出一个**新的值**，并且这个计算比较耗时或你不希望它频繁执行时，用 `computed`。
> *   当你需要在模板中执行一个**动作**（例如响应 `@click` 事件），或者每次渲染都希望重新计算时，用 `methods`。

#### **3.3 侦听器 (Watchers)**

有时候，我们需要在某个数据变化时，执行一些“副作用”(Side Effects)，比如发起网络请求、操作 DOM、或者将数据保存到 `localStorage`。这时，计算属性就不适用了，我们需要**侦听器**。

**1. `watch()`**

`watch` 精确地侦听一个或多个特定的响应式数据源，并在数据源变化时执行一个回调函数。

*   **语法：** `watch(source, callback, [options])`

**案例实践：侦听购物车数量的变化**

我们希望当 `cart` 的数量第一次达到 5 时，给用户一个友好的提示。

```vue
<script setup>
import { ref, reactive, computed, watch } from 'vue'
// ...

const cart = ref(0)
const hasAlerted = ref(false) // 用一个状态防止重复弹窗

// 侦听单个源
watch(cart, (newValue, oldValue) => {
  console.log(`购物车数量从 ${oldValue} 变成了 ${newValue}`)
  if (newValue >= 5 && !hasAlerted.value) {
    alert('您已选购多件商品，结账时可享受优惠！')
    hasAlerted.value = true
  }
})
</script>
```

现在，当你不断点击“加入购物车”，在数量达到 5 的那一刻，就会弹出一个提示。

**侦听 `reactive` 对象的属性：**

如果你想侦听 `reactive` 对象中的某个属性，你需要使用一个返回该属性的 getter 函数作为数据源。

```javascript
// 案例：当库存低于5时，在控制台打印一条警告
watch(() => course.stock, (newStock) => {
  if (newStock < 5 && newStock > 0) {
    console.warn('警告：库存即将耗尽！')
  }
})
```

**2. `watchEffect()`**

`watchEffect` 会**立即执行**一次传入的函数，同时响应式地追踪其依赖，并在依赖变更时重新运行该函数。

*   **用法：** `watchEffect(() => { /* 追踪依赖并执行的代码 */ })`

**案例实践：** 假设我们需要根据课程 ID 和用户 Token 自动获取课程详情。

```vue
import { ref, watchEffect } from 'vue'

const courseId = ref(1)
const userToken = ref('abc-token')

watchEffect(() => {
  // 这个函数会立即执行一次
  // 它同时追踪了 courseId 和 userToken 作为依赖
  console.log(`正在使用 ID: ${courseId.value} 和 Token: ${userToken.value} 获取课程数据...`)
  // fetch(`api/courses/${courseId.value}?token=${userToken.value}`)
})

// 之后，如果你修改了 courseId.value 或 userToken.value，上面的函数会自动重新执行。
```

> **大师兄提示 (面试必考点): `watch` vs `watchEffect` 的区别？**
>
> | 特性         | `watch`                                                      | `watchEffect`                                                |
> | :----------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
> | **依赖追踪** | **手动、明确指定**。你需要告诉它侦听哪个变量。               | **自动、隐式追踪**。它会自动侦听函数体内用到的所有响应式变量。 |
> | **首次执行** | 默认在数据**变化后**才执行。                                 | **立即执行**一次，然后在依赖变化后再次执行。                 |
> | **使用场景** | 1. 需要精确控制侦听哪个数据。<br>2. 需要访问变化前后的值 (`oldValue`)。<br>3. 逻辑开销较大，不希望被意外的依赖触发。 | 1. 逻辑简单，依赖源清晰。<br>2. 需要在初始化时就执行一次的副作用逻辑。 |
>
> **简单记：**
>
> *   想明确“当 **这个** 变了，就做 **那个**”，用 `watch`。
> *   想创建一个“只要用到的数据变了，就**自动重新执行**”的响应式副作用，用 `watchEffect`。

### **本章完整代码示例**

`src/App.vue` (整合了本章所有知识点)

```vue
<script setup>
import { ref, reactive, computed, watch } from 'vue'

// 使用 reactive 定义对象类型数据
const course = reactive({
  name: 'Vue 3 大师课',
  price: 89.9,
  stock: 15,
  onSale: true,
  description: '这是一门帮助你<strong>从入门到精通</strong>Vue 3的课程。',
  image: 'https://vuejs.org/images/logo.png',
  features: [
    '核心基础',
    'Composition API',
    'Vue Router',
    'Pinia',
    '实战项目'
  ]
})

// 使用 ref 定义原始类型数据
const cart = ref(0)
const quantity = ref(1)
const hasAlerted = ref(false)

// 使用 computed 派生出新的、可缓存的响应式数据
const stockStatusText = computed(() => {
  if (course.stock > 10) {
    return `库存充足 (剩余 ${course.stock} 件)`
  } else if (course.stock > 0) {
    return `库存紧张 (剩余 ${course.stock} 件)`
  } else {
    return '已售罄'
  }
})

// 方法，用于执行动作
function addToCart() {
  if (course.stock >= quantity.value) {
    cart.value += quantity.value
    course.stock -= quantity.value
    quantity.value = 1
  } else {
    alert('库存不足！')
  }
}

// 使用 watch 精确地侦听数据变化并执行副作用
watch(cart, (newValue) => {
  if (newValue >= 5 && !hasAlerted.value) {
    alert('您已选购多件商品，结账时可享受优惠！')
    hasAlerted.value = true
  }
})
</script>

<template>
  <div class="card">
    <img :src="course.image" :alt="course.name" class="course-image">
    
    <h1 :class="{ 'on-sale': course.onSale }">{{ course.name }}</h1>
    
    <p :style="{ color: course.onSale ? 'red' : 'black', fontSize: '20px' }">
      价格: ¥{{ course.price }}
    </p>

    <h2>课程描述:</h2>
    <p v-html="course.description"></p>

    <h3>课程特色:</h3>
    <ul>
      <li v-for="feature in course.features" :key="feature">
        {{ feature }}
      </li>
    </ul>

    <h3>库存状态:</h3>
    <!-- 直接使用计算属性，让模板更简洁 -->
    <p>{{ stockStatusText }}</p>
    
    <hr>
    
    <p>购物车数量: {{ cart }}</p>

    <div class="controls">
      <label for="quantity">购买数量:</label>
      <input type="number" id="quantity" v-model.number="quantity" min="1" :max="course.stock">
      
      <button v-if="course.stock > 0" @click="addToCart">
        加入购物车
      </button>
      <button v-else :disabled="true" class="disabled-button">
        已售罄
      </button>
    </div>
  </div>
</template>

<style>

</style>
```
