### **阶段 0：设计与规划 (The Whiteboard Phase)**

#### **1. 核心功能是什么？**
*   展示一个待办事项列表。
*   添加一个新的待办事项。
*   将一个事项标记为“已完成”或“未完成”。
*   删除一个事项。
*   编辑一个已存在事项的文本。

#### **2. 如何拆分组件 (Component Breakdown)？**
单一组件会导致代码臃肿且难以维护。我们需要将功能拆分到不同的组件中，遵循“单一职责原则”。

*   **`App.vue` (主应用/容器组件):**
    *   **职责:** 作为“大脑”。它将持有所有待办事项的数据（the single source of truth）。
    *   **职责:** 管理所有业务逻辑，如添加、删除、修改数据。
    *   **职责:** 渲染其他子组件，并把数据和方法传递给它们。

*   **`ToDoForm.vue` (表单组件):**
    *   **职责:** 只负责一件事——获取用户输入。
    *   **职责:** 当用户提交表单时，它不自己处理逻辑，而是告诉父组件 `App.vue`：“嘿，用户输入了一个新任务，内容是这个，你来处理吧！”

*   **`ToDoItem.vue` (列表项组件):**
    *   **职责:** 只负责展示**一个**待办事项。
    *   **职责:** 当用户在这个事项上进行操作时（如点击复选框、删除按钮、编辑按钮），它同样告诉父组件 `App.vue`：“嘿，用户对 ID 为 'xyz' 的任务进行了xx操作，你来处理吧！”

*   **`ToDoItemEditForm.vue` (编辑表单组件):**
    *   **职责:** 这是一个特殊的表单，只在编辑模式下出现。
    *   **职责:** 获取用户修改后的文本，然后告诉父组件 `ToDoItem.vue`（再由它告诉 `App.vue`）：“用户把任务改成了这个新名字，你来保存吧！”

#### **3. 数据如何流动 (Data Flow)?**
这是 Vue 的核心思想：**Props Down, Events Up**。

*   **Props Down (属性向下传递):** `App.vue` 持有所有数据，它通过 `props` 把数据“传递”给子组件去展示。
    *   `App.vue` -> `ToDoItem.vue` (传递 `label`, `done`, `id`)
*   **Events Up (事件向上传递):** 子组件不直接修改父组件的数据。它通过触发（`emit`）一个事件来“通知”父组件。
    *   `ToDoForm.vue` -> `App.vue` (触发 `todo-added` 事件)
    *   `ToDoItem.vue` -> `App.vue` (触发 `item-deleted`, `item-edited`, `checkbox-changed` 事件)

### **阶段 2：核心 `App.vue`**

这是我们的“大脑”，我们先用 Composition API 把它搭建起来。

1.  **清空 `App.vue`** 并写入以下结构：

    ```vue
    <!-- App.vue -->
    <template>
      <div id="app">
        <h1>To-Do List</h1>
        
        <!-- 表单组件将放在这里 -->

        <h2 id="list-summary" ref="listSummaryEl" tabindex="-1">{{ listSummary }}</h2>
        
        <ul aria-labelledby="list-summary" class="stack-large">
          <!-- 列表项组件将通过 v-for 渲染在这里 -->
        </ul>
      </div>
    </template>

    <script setup>
    // 我们的逻辑将写在这里
    </script>

    <style>
    
    </style>
    ```
    **注意**: 我们使用了 `<script setup>`，这是 Vue 3 中编写 Composition API 的推荐方式，它更简洁。

2.  **引入响应式数据**:
    在 Vue 3 `<script setup>` 中，我们用 `ref` 或 `reactive` 来创建响应式数据。`ref` 通常用于基本类型值或需要整个替换的对象/数组。

    ```javascript
    // App.vue -> <script setup>
    import { ref, computed } from 'vue'; // 从 'vue' 导入我们需要的函数
    import { nanoid } from 'nanoid';
    
    // 1. 使用 ref() 创建响应式数据
    const ToDoItems = ref([
      { id: "todo-" + nanoid(), label: "Learn Vue 3", done: false },
      { id: "todo-" + nanoid(), label: "Create a project with Vite", done: true },
      // ...其他初始数据
    ]);
    
    // 2. 使用 computed() 创建计算属性
    const listSummary = computed(() => {
      const numberFinishedItems = ToDoItems.value.filter(item => item.done).length;
      return `${numberFinishedItems} out of ${ToDoItems.value.length} items completed`;
    });
    ```
    **关键点**: 通过 `ref()` 创建的响应式变量，在 `<script>` 部分访问或修改它时，需要使用 `.value` (`ToDoItems.value`)。但在 `<template>` 中，Vue 会自动“解包”，可以直接使用 `ToDoItems`。

### **阶段 3：子组件**



#### **A. `ToDoForm.vue`**

这个组件负责添加新任务。

1.  创建 `src/components/ToDoForm.vue`。

2.  编写代码：
    ```vue
    <!-- ToDoForm.vue -->
    <template>
      <form @submit.prevent="onSubmit">
        <h2 class="label-wrapper">
          <label for="new-todo-input" class="label__lg">What needs to be done?</label>
        </h2>
        <input
          type="text"
          id="new-todo-input"
          name="new-todo"
          autocomplete="off"
          v-model.trim="label"
          class="input__lg" />
        <button type="submit" class="btn btn__primary btn__lg">Add</button>
      </form>
    </template>
    
    <script setup>
    import { ref } from 'vue';
    
    // 使用 ref 创建一个响应式变量来绑定输入框
    const label = ref('');
    
    // 使用 defineEmits 声明该组件会触发哪些事件
    const emit = defineEmits(['todo-added']);
    
    // 方法就是一个普通的 JS 函数
    function onSubmit() {
      if (label.value === "") {
        return;
      }
      // 使用 emit 触发事件，并传递数据
      emit('todo-added', label.value);
      // 清空输入框
      label.value = "";
    }
    </script>
    ```
    **Vue 3 Composition API 特点**:
    *   **`ref('')`**: 替代了 `data()` 中的 `label: ''`。
    *   **`defineEmits()`**: 这是一个“宏”，用来声明组件可以发出的事件。返回的 `emit` 函数用来触发事件。
    *   **`function onSubmit()`**: 替代了 `methods` 对象。逻辑更集中。
    *   **没有 `this`**: 我们直接访问 `label` 和 `emit`，代码更清晰。

#### **B.  `ToDoItem.vue`**

这个组件最复杂，因为它既要接收数据，又要发送多种事件。

1.  创建 `src/components/ToDoItem.vue`。

2.  编写代码：
    ```vue
    <!-- ToDoItem.vue -->
    <template>
      <!-- 编辑模式和普通模式的切换 -->
      <div class="stack-small" v-if="!isEditing">
        <!-- ... 普通模式的 HTML ... -->
      </div>
      <to-do-item-edit-form
        v-else
        :id="props.id"
        :label="props.label"
        @item-edited="itemEdited"
        @edit-cancelled="editCancelled">
      </to-do-item-edit-form>
    </template>
    
    <script setup>
    import { ref } from 'vue';
    import ToDoItemEditForm from './ToDoItemEditForm.vue';
    
    // 1. 使用 defineProps 接收父组件传来的数据
    const props = defineProps({
      label: { required: true, type: String },
      done: { default: false, type: Boolean },
      id: { required: true, type: String },
    });
    
    // 2. 声明事件
    const emit = defineEmits(['checkbox-changed', 'item-deleted', 'item-edited']);
    
    // 3. 组件内部的响应式状态
    const isEditing = ref(false);
    
    // 4. 方法就是函数
    function deleteToDo() {
      emit('item-deleted');
    }
    function toggleToItemEditForm() {
      isEditing.value = true;
    }
    function itemEdited(newLabel) {
      emit('item-edited', newLabel);
      isEditing.value = false;
      // 焦点管理逻辑之后添加
    }
    function editCancelled() {
      isEditing.value = false;
      // 焦点管理逻辑之后添加
    }
    </script>
    
    <style scoped>
    
    </style>
    ```

#### **C.  `ToDoItemEditForm.vue`**

1.  创建 `src/components/ToDoItemEditForm.vue`。

2.  编写代码：
    ```vue
    <!-- ToDoItemEditForm.vue -->
    <template>
      <!-- ... 表单的 HTML 结构 ... -->
    </template>
    
    <script setup>
    import { ref, onMounted } from 'vue';
    
    const props = defineProps({
      label: { type: String, required: true },
      id: { type: String, required: true },
    });
    
    const emit = defineEmits(['item-edited', 'edit-cancelled']);
    
    // 将 prop 的初始值赋给一个新的 ref 变量，这样我们就可以在组件内部修改它
    const newLabel = ref(props.label);
    
    function onSubmit() {
      if (newLabel.value && newLabel.value !== props.label) {
        emit("item-edited", newLabel.value);
      }
    }
    
    function onCancel() {
      emit("edit-cancelled");
    }
    
    // 模板引用(Template Ref) 和生命周期钩子(Lifecycle Hook)
    const labelInput = ref(null);
    onMounted(() => {
      labelInput.value.focus();
    });
    </script>
    
    <style scoped>
    
    </style>
    ```
    **新知识点**:
    *   **`onMounted()`**: 这是 Vue 3 的生命周期钩子，等同于 Vue 2 的 `mounted()`。它在组件被挂载到 DOM 后执行。
    *   **Template Refs**: 我们创建了一个 `const labelInput = ref(null)`，并在 `<template>` 的 `<input>` 上添加 `ref="labelInput"`。这样，`onMounted` 钩子执行时，我们就可以通过 `labelInput.value` 访问到这个 DOM 元素，并调用 `.focus()` 方法。

### **阶段 4：整合与收尾**

现在所有零件都已用 Vue 3 的方式重构完毕，我们回到 `App.vue` 把它们组装起来。

1.  **在 `App.vue` 中导入并使用组件**：
    ```javascript
    // App.vue -> <script setup>
    import { ref, computed } from 'vue';
    import { nanoid } from 'nanoid';
    import ToDoForm from './components/ToDoForm.vue';   // 导入
    import ToDoItem from './components/ToDoItem.vue';   // 导入
    
    // ... ToDoItems 和 listSummary 的代码 ...
    ```
    在 `<script setup>` 中，导入的组件可以直接在 `<template>` 中使用，无需注册。

2.  **在 `App.vue` 中定义事件处理函数**：
    ```javascript
    // App.vue -> <script setup>
    // ...
    function addToDo(toDoLabel) {
      ToDoItems.value.push({
        id: "todo-" + nanoid(), label: toDoLabel, done: false
      });
    }
    
    function updateDoneStatus(toDoId) {
      const toDoToUpdate = ToDoItems.value.find(item => item.id === toDoId);
      toDoToUpdate.done = !toDoToUpdate.done;
    }
    
    function deleteToDo(toDoId) {
      const itemIndex = ToDoItems.value.findIndex(item => item.id === toDoId);
      ToDoItems.value.splice(itemIndex, 1);
    }
    
    function editToDo(toDoId, newLabel) {
      const toDoToEdit = ToDoItems.value.find(item => item.id === toDoId);
      toDoToEdit.label = newLabel;
    }
    ```

3.  **在 `App.vue` 的 `<template>` 中绑定事件**：
    ```html
    <!-- App.vue -> <template> -->
    <to-do-form @todo-added="addToDo"></to-do-form>
    
    <ul aria-labelledby="list-summary" class="stack-large">
      <li v-for="item in ToDoItems" :key="item.id">
        <to-do-item
          :label="item.label"
          :done="item.done"
          :id="item.id"
          @checkbox-changed="updateDoneStatus(item.id)"
          @item-deleted="deleteToDo(item.id)"
          @item-edited="(newLabel) => editToDo(item.id, newLabel)">
        </to-do-item>
      </li>
    </ul>
    ```
    **注意 `item-edited` 的写法**: 因为 `editToDo` 函数需要两个参数 (`id` 和 `newLabel`)，而子组件只 `emit` 了一个 `newLabel`，所以我们使用了一个箭头函数 `(newLabel) => editToDo(item.id, newLabel)` 来组装参数。

### **最终总结**

**相比 Vue 2 的 Options API，Vue 3 和 Composition API 的优势在于：**

1.  **逻辑组织性更强**: 相关的功能（例如，某个特性的所有 `ref`, `computed`, `methods`）可以写在一起，而不是分散在 `data`, `computed`, `methods` 三个不同的块里。这对于大型组件尤其重要。
2.  **代码更简洁**: `<script setup>` 语法糖省去了很多模板代码。
3.  **告别 `this`**: 不再有 `this` 指向混乱的问题，所有变量和函数都在同一作用域下，更符合现代 JavaScript 的直觉。
4.  **更好的重用性**: 我们可以轻松地将一组逻辑（如 `ref` 和操作它的函数）提取到一个单独的 JS 文件中（这被称为 "Composable"），然后在多个组件中复用。
