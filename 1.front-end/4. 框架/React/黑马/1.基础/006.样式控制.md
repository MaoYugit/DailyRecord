# React 基础样式控制

## 1. 行内样式 (Inline Style)

在 React 中，行内样式不是字符串，而是一个 **JavaScript 对象**。

*   **语法**：`style={{ key: value }}`
    *   第一层 `{}`：表示里面是 JS 表达式。
    *   第二层 `{}`：表示这是一个样式对象。
*   **规则**：属性名必须使用 **小驼峰命名法 (camelCase)**。例如 `background-color` 必须写成 `backgroundColor`。

```jsx
function App() {
  const isSelected = true;
  return (
    <div style={{ 
      color: 'red', 
      fontSize: '20px', // 必须加引号，带单位
      backgroundColor: isSelected ? 'yellow' : 'white' // 动态控制
    }}>
      行内样式文字
    </div>
  );
}
```

## 2. 类名样式 (Class Name)

这是最常用的方式，将样式写在独立的 `.css` 文件中。

*   **语法**：使用 **`className`** 而不是 `class`。
*   **动态类名**：通常配合**模板字符串**或**逻辑表达式**来实现。

### 2.1 基础用法
```css
/* App.css */
.active { color: blue; font-weight: bold; }
.normal { color: gray; }
```

```jsx
import './App.css';

function App() {
  const isActive = true;
  return (
    <div className={isActive ? 'active' : 'normal'}>
      类名样式文字
    </div>
  );
}
```

### 2.2 多类名拼接（模板字符串）
当需要同时应用多个类名（一个固定，一个动态）时：
```jsx
<div className={`base-style ${isActive ? 'active' : ''}`}>内容</div>
```

## 3. 进阶：动态类名解决方案 (clsx / classnames)

在实际开发中，手动拼字符串很痛苦。大厂项目通常使用 `classnames` 或 `clsx` 库。

*   **优势**：通过对象语法优雅地切换类名。

```jsx
import clsx from 'clsx';

function Button({ isPrimary, isLarge }) {
  // 如果 isPrimary 为 true，则添加 'btn-primary' 类
  const btnClass = clsx('base-btn', {
    'btn-primary': isPrimary,
    'btn-large': isLarge
  });
  
  return <button className={btnClass}>提交</button>;
}
```

## 4. 面试高频考点 (Q&A)

### Q1: 为什么 React 使用 `className` 而不是 `class`？
*   **核心原因**：JSX 本质是 JavaScript。在 JS 中，`class` 是一个**保留关键字**（用于定义类）。为了避免语法冲突和解析歧义，React 选择了 `className`。同理，`<label>` 的 `for` 属性在 React 中要写成 `htmlFor`。

### Q2: 行内样式 (Inline) vs 类名样式 (ClassName) 怎么选？
*   **行内样式**：适用于 **高度动态** 的样式（例如：根据鼠标位置改变的偏移量、用户自定义的配色方案）。
*   **类名样式**：适用于 **绝大多数静态样式**。优点是性能好（浏览器有优化）、支持伪类（`:hover`）和媒体查询（`@media`），且遵循结构与表现分离原则。

### Q3: 什么是 CSS Modules？为什么要用它？
*   **背景**：在 React 中直接 `import './App.css'`，样式是**全局生效**的。如果两个组件都有 `.button` 类，会发生冲突（样式污染）。
*   **解决方案**：CSS Modules。
*   **用法**：将文件名改为 `App.module.css`，然后：
    ```jsx
    import styles from './App.module.css';
    <div className={styles.button}>局部样式</div>
    ```
*   **优点**：编译后类名会自动变成 `App_button__hash值`，从根本上解决了 **命名冲突**。

### Q4: 如何在 React 中实现类似 Vue 的 `<style scoped>`？
*   React 官方没有内置 `scoped` 属性。
*   **常用手段**：
    1.  **CSS Modules**（最推荐，CRA 自带支持）。
    2.  **CSS-in-JS** (如 `styled-components`)：通过 JS 写 CSS，样式自动绑定到组件。
    3.  **BEM 命名规范**：通过人为约定命名空间（如 `.UserCard__avatar`）。

### Q5: 样式控制的性能优化点？
*   **避免在 Render 中声明大的样式对象**：如果样式是静态的，应该放在组件外部，避免每次渲染都创建一个新对象。
*   **使用 CSS 变量**：对于动态主题，可以通过行内样式修改 CSS 变量，而让大量的 CSS 逻辑留在样式表中，减少 JS 计算开销。

---

## 5. 总结建议（教学 Tips）

1.  **优先使用 `className`**：保持代码整洁，支持所有 CSS 特性。
2.  **逻辑复杂用 `clsx`**：不要在 JSX 里写又长又臭的模板字符串。
3.  **动态数值用行内**：比如进度条的宽度 `style={{ width: `${percent}%` }}`。
4.  **注意数值单位**：在 `style` 对象中，如果是数字类型（如 `zIndex: 1`），React 会自动处理；但像 `fontSize` 这种，最好手动带上 `'px'`，避免不同浏览器解析差异。
