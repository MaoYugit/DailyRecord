# 环境搭建与项目起步

## 1. 项目创建命令解析

```bash
npx create-react-app react-basic
```

*   **npx**: 是 npm 5.2+ 附带的包运行工具。它的好处是**无需全局安装** `create-react-app`，每次运行都会下载最新版本，创建完后自动删除，节省磁盘空间。
*   **create-react-app**: React 官方提供的脚手架工具，内置了 Webpack、Babel、ESLint 等配置，让我们能“开箱即用”。
*   **react-basic**: 项目名称（注意：不能包含大写字母）。

## 2. 运行项目

```bash
cd react-basic  # 进入项目文件夹
npm start       # 启动本地开发服务器（默认地址：localhost:3000）
```

## 4. 关键代码详解

### 4.1 `index.js` —— 项目的“心脏”
它是连接 React 世界和真实 DOM 世界的桥梁。

```js
// src/index.js
import React from "react"; 
import ReactDOM from "react-dom/client"; // React 18 后的新接口

import App from "./App"; // 引入根组件

// 1. 获取 HTML 中 id 为 'root' 的 DOM 节点
// 2. 使用 ReactDOM 创建一个 React 根
const root = ReactDOM.createRoot(document.getElementById("root"));

// 3. 将根组件 App 渲染到页面上
root.render(
  // <React.StrictMode> 是开启严格模式，辅助开发，会在开发阶段检查潜在问题
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

### 4.2 `App.js` —— 根组件
React 的核心思想是**组件化**。

```js
// src/App.js

// 定义一个函数组件（Function Component）
function App() {
  return (
    // 这不是 HTML，而是 JSX (JavaScript XML)
    <div className="App">
      <h1>Hello, World!</h1>
    </div>
  );
}

// 导出组件，以便在 index.js 中导入
export default App;
```

## 5. 补充重要概念（面试/进阶必知）

### ① 什么是 JSX？
在 `return` 后面写的类似 HTML 的代码叫 **JSX**。
*   **本质**：它是 JavaScript 的语法扩展，最终会被 Babel 编译成普通的 JS 对象。
*   **区别**：
    *   在 HTML 中使用 `class`，在 JSX 中必须写成 `className`（因为 class 是 JS 的保留字）。
    *   JSX 必须有一个根元素（通常用 `<div></div>` 或 `<></>` 包裹）。

### ② 渲染流程图
1.  **定义组件** (`App.js`)
2.  **入口文件挂载** (`index.js`) 找到 `public/index.html` 中的 `<div id="root"></div>`
3.  **渲染**：React 将组件转换成虚拟 DOM，最后渲染成页面上的真实 DOM。

### ③ 常用快捷键（VS Code）
*   安装扩展：**ES7+ React/Redux/React-Native snippets**。
*   输入 `rfc` 然后回车：快速生成一个函数组件模板。
