# JSX 学习笔记

## 1. JSX 概念
**JSX** (JavaScript XML) 是 JavaScript 的语法扩展。它允许我们在 JavaScript 文件中编写类似 HTML 的结构。它是 React 的核心特性，用来描述 UI 的层级结构和逻辑。

## 2. 优势
*   **声明式编程**：代码结构直观，一眼就能看出 UI 的长相。
*   **结合逻辑**：可以在 UI 结构中直接使用 JS 的能力（变量、函数、循环等）。
*   **开发效率高**：配合现代编辑器，有极强的语法提示和报错检查。

## 3. 本质与 Babel
JSX 并不是标准的 JavaScript 语法，浏览器无法直接识别。
*   **本质**：JSX 只是 `React.createElement(component, props, ...children)` 函数的**语法糖**。
*   **Babel 的作用**：Babel 是一个转译器，负责将 JSX 代码编译成浏览器能理解的普通 JavaScript 对象（React Vnode）。
    *   *旧版本*：转译为 `React.createElement`。
    *   *新版本 (React 17+)*：转译为 `_jsxRuntime.jsx`（自动导入，无需显式 import React）。

## 4. JSX 中使用 JS 表达式
在 JSX 中，使用 **大括号 `{ }`** 来包裹 JavaScript 表达式。

### 4.1 使用引号传递字符串
可以直接写，也可以放入大括号。
```jsx
const title = 'Hello React';
const element = <h1 title="这是属性">静态字符串</h1>;
```

### 4.2 使用 JS 变量
```jsx
const name = 'Jack';
const element = <div>你好, {name}</div>;
```

### 4.3 函数调用和方法调用
```jsx
const getAge = () => 18;
const element = (
  <ul>
    <li>函数调用: {getAge()}</li>
    <li>方法调用: {"hello".toUpperCase()}</li>
  </ul>
);
```

### 4.4 使用 JS 对象
注意：**JSX 不能直接渲染完整的对象**（会报错），但可以用于设置 `style` 属性（双大括号）。
```jsx
const styleObj = { color: 'red', fontSize: '20px' };
// 第一层 {} 代表里面是 JS 表达式，第二层 {} 代表这是一个对象
const element = <div style={{ color: 'blue' }}>蓝色文字</div>;
```

## 5. JSX 实现列表渲染
在 React 中，列表渲染统一使用数组的 **`map`** 方法。
*   **注意点**：必须为每一个遍历出来的元素添加一个唯一的 **`key`** 属性（通常是 ID），这有助于 React 优化 DOM 更新性能。

```jsx
const list = [
  { id: 1, name: 'Vue' },
  { id: 2, name: 'React' },
  { id: 3, name: 'Angular' }
];

function App() {
  return (
    <ul>
      {list.map(item => <li key={item.id}>{item.name}</li>)}
    </ul>
  );
}
```

## 6. JSX 实现条件渲染
根据数据的不同状态，展示不同的 UI。

### 6.1 逻辑与运算符 `&&`
适用于：**要么显示，要么不显示**（只有一种情况）。
```jsx
{ isLogin && <span>欢迎回来！</span> }
```

### 6.2 三元表达式 `? :`
适用于：**二选一**（If-Else 逻辑）。
```jsx
{ isLogin ? <button>退出</button> : <button>登录</button> }
```

## 7. JSX 实现复杂条件渲染
当判断逻辑非常复杂（如 3 种及以上状态）时，直接在 JSX 里写三元嵌套会很难读。

### 解决方案：使用函数
将逻辑抽离到一个**辅助函数**中，通过函数返回不同的 JSX。

```jsx
const status = 1; // 0: 未支付, 1: 已支付, 2: 已发货

function getStatusDesc() {
  if (status === 0) return <span>等待付款</span>;
  if (status === 1) return <span>备货中</span>;
  if (status === 2) return <span>已在路上</span>;
  return <span>未知状态</span>;
}

function App() {
  return (
    <div className="App">
      {/* 调用函数获取对应的 JSX */}
      项目状态：{getStatusDesc()}
    </div>
  );
}
```

---

## 总结要点（Tips）
1.  **大括号里能写什么？** 只能写**表达式**（有返回值的代码），不能写语句（如 `if`、`for`、`switch` 语句）。
2.  **根元素**：JSX 必须有一个根节点。如果不想多嵌套一个 `div`，可以使用 `<React.Fragment>` 或简写 `<></>`。
3.  **驼峰命名**：JSX 中的 HTML 属性要遵循驼峰命名法，例如 `onclick` 变 `onClick`，`class` 变 `className`。
