### 基本类型

#### **1. 类型声明**

```ts
// 以后 a 的值只能是 number
let a: number;

a = 'hello' // 报错 不能将类型“string”分配给类型“number”。

let b: string

b = 'hello'

let c: bollean = false;

let s = false // 定义并赋值有自动类型判断，不用继续 : bollean

function sum(a: number, b: number):number {
	return a + b
}
```

#### 2. TypeScript 基本类型一览表

| 类型        | 描述                                                         | 示例代码                                   |
| :---------- | :----------------------------------------------------------- | :----------------------------------------- |
| **number**  | 任意数字，支持整数、浮点数、二进制、十六进制等               | `let age: number = 25;`                    |
| **string**  | 字符串，可以使用单引号、双引号或反引号（模板字符串）         | `let name: string = "TS";`                 |
| **boolean** | 布尔值，只有 `true` 和 `false` 两个值                        | `let isDone: boolean = true;`              |
| **字面量**  | 限制变量的值必须是指定的某些具体值                           | `let sex: 'male' | 'female';`              |
| **any**     | 任意类型。跳过类型检查，通常用于迁移旧代码或不确定类型时。any 类型可以赋值给其他任何类型 | `let x: any = 10; x = "hi";`               |
| **unknown** | 类型安全的 `any`。在使用前必须进行类型判断（收窄），unknown 类型**不**可以赋值给其他任何类型 | `let x: unknown = 10;`                     |
| **void**    | 常用于函数，表示没有任何返回值                               | `function log(): void { ... }`             |
| **never**   | 永远不会出现的值。常用于报错函数或死循环函数                 | `function err(): never { throw Error(); }` |
| **object**  | 泛指所有的非原始类型（即对象、数组、函数等）                 | `let obj: object = { a: 1 };`              |
| **array**   | 数组。有两种写法：`类型[]` 或 `Array<类型>`                  | `let list: number[] = [1, 2, 3];`          |
| **tuple**   | 元组。固定数量和类型的数组                                   | `let x: [string, number] = ["age", 18];`   |
| **enum**    | 枚举。为一组数值赋予友好的名字（默认从0开始递增）            | `enum Color { Red, Blue, Green }`          |

---

**重点类型解析：**

1.  **字面量类型 (Literal Types)**：
    它不仅仅是类型，还是具体的值。常配合联合类型（`|`）使用，比如：
    ```typescript
    let status: 'success' | 'error' | 'loading';
    status = 'success'; // 正确
    // status = 'pending'; // 报错，不在范围内
    ```

2.  **any vs unknown**：
    *   `any` 是“我不管了”，你可以对它做任何事（调用方法、赋值等），TS 不会报错，但容易出 Bug。
    * `unknown` 是“我不知道它是什么”，在你通过 `if (typeof x === 'string')` 这种方式确认它是什么之前，TS 不允许你操作它。它是更推荐的选择。

      ```ts
      let a: any;
      let b: string;
      let c: unknown;
      
      a = 123
      c = '123'
      b = a // 不会报错
      
      b = c // 报错 即使 c 也是字符串，但是他的类型是 unknown
      
      // 必须
      if (typeof c == "string"){
      	b = c // 有了类型判断 不报错
      }
      
      // 或者使用类型断言
      b = c as string; // 类型断言
      b = <string>c; // 也可以使用尖括号语法进行类型断言
      ```
    
3.  **void vs never**：
    *   `void` 是函数执行完了，只是没回传东西（默认返回 `undefined`）。
    * `never` 是函数根本没执行完（半路报错退出了或者一直在死循环）。

      ```ts
      function fn(): never{
      	throw new Error("报错了！");
      }
      ```
    
4.  **enum (枚举)**：
    枚举可以显著增强代码的可读性：
    ```typescript
    enum OrderStatus {
        Pending = 1,
        Shipped = 2,
        Delivered = 3
    }
    if (order.status === OrderStatus.Shipped) { ... }
    ```
