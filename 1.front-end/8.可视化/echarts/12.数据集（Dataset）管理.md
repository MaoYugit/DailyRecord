欢迎来到第三阶段的第三课。

如果说 `resize` 和 `dispose` 是为了让页面不崩溃，那么 **Dataset（数据集）** 就是为了**不让开发者崩溃**。

在 ECharts 4.0 之前，我们处理数据极其痛苦。后端通常返回一个对象数组（Array of Objects），但 ECharts 的 `series` 却要求我们要把数据拆成一个个独立的数组。

**Dataset 的出现，彻底改变了“数据预处理”的逻辑。**

---

### 一、 传统方式 vs Dataset 方式

#### 1. 传统方式（Series 里的 Data）
假设后端给你这样的数据（非常标准的 JSON）：
```javascript
const apiData = [
  { product: '衬衫', sales: 120, date: '2024-01' },
  { product: '羊毛衫', sales: 200, date: '2024-02' },
  { product: '雪纺衫', sales: 150, date: '2024-03' }
];
```

**痛苦点**：你必须写 JS 代码循环遍历，把它们拆开：
```javascript
// 你得自己写数据清洗逻辑
const xData = apiData.map(item => item.product); // ['衬衫', '羊毛衫'...]
const sData = apiData.map(item => item.sales);   // [120, 200...]

option = {
  xAxis: { data: xData }, // 塞进去
  series: [{ data: sData }] // 塞进去
};
```

#### 2. Dataset 方式（数据与样式分离）
**爽点**：直接把后端数据扔给 `dataset.source`，然后告诉 series 去“引用”哪一列。

```javascript
option = {
  // 1. 数据集：类似于一个二维表
  dataset: {
    // 维度（表头），可选，不写 ECharts 也能自动推断
    dimensions: ['product', 'sales', 'date'],
    // 数据源：直接塞入对象数组
    source: apiData 
  },
  
  // 2. 坐标轴：注意！这里不需要写 data 了
  xAxis: { type: 'category' }, 
  yAxis: {},
  
  // 3. 系列：通过 encode 映射数据
  series: [
    {
      type: 'bar',
      // 核心：告诉 ECharts，x轴用 product 字段，y轴用 sales 字段
      encode: {
        x: 'product', 
        y: 'sales'
      }
    }
  ]
};
```

---

### 二、 核心配置：`encode`（映射规则）

`encode` 是 Dataset 的灵魂。它建立了**数据列**与**坐标轴/视觉通道**之间的映射。

*   **`x`**: 映射到 X 轴的维度（列名或索引）。
*   **`y`**: 映射到 Y 轴的维度。
*   **`tooltip`**: 提示框里显示哪些列。
*   **`seriesName`**: 谁来作为系列名称。

#### 示例场景：多系列映射
假设数据源是二维数组（这也是后端常返的格式）：

```javascript
const source = [
  ['Product', '2023销量', '2024销量', '同比增长'],
  ['Latte', 80, 90, 0.12],
  ['Tea', 50, 60, 0.20],
  ['Cocoa', 60, 55, -0.08]
];
```

我们想画两个柱状图对比 2023 和 2024。

```javascript
dataset: { source: source },
xAxis: { type: 'category' }, // 自动取第一列作为类目
yAxis: {},
series: [
  {
    type: 'bar',
    name: '2023年', // 强制指定名字
    encode: { x: 0, y: 1 } // 使用第0列(Product)做X，第1列(2023销量)做Y
  },
  {
    type: 'bar',
    // 如果不写 name，默认会读取 dataset 第一行对应的列名 "2024销量"
    encode: { x: 0, y: 2 } // 使用第0列(Product)做X，第2列(2024销量)做Y
  }
]
```

### 三、 Vue 实战：封装一个 Dataset 组件

我们来升级之前的逻辑。在实际企业开发中，我们甚至可以封装一个**“万能图表组件”**，父组件只管传数据，不用管 Option 结构。

新建 `DatasetChart.vue`：

```vue
<script setup>
import { computed } from 'vue';
import BaseChart from './BaseChart.vue'; // 复用之前的封装

const props = defineProps({
  // 接收后端原始数据 List
  data: { type: Array, default: () => [] },
  // 接收映射配置，例如 { x: 'date', y: 'value', type: 'line' }
  config: { type: Object, required: true }
});

// 动态生成 Option
const chartOption = computed(() => {
  return {
    tooltip: { trigger: 'axis' },
    // 关键：声明 dataset
    dataset: {
      source: props.data
    },
    xAxis: { type: 'category' }, // 声明为类目轴，自动抓取 encode.x
    yAxis: {},
    series: [
      {
        type: props.config.type || 'bar',
        // 关键：透传映射配置
        encode: {
          x: props.config.x,
          y: props.config.y
        },
        // 让柱子好看点
        itemStyle: { borderRadius: [5, 5, 0, 0] }
      }
    ]
  };
});
</script>

<template>
  <BaseChart :option="chartOption" />
</template>
```

**父组件调用：**

```vue
<template>
  <!-- 
    你看，父组件完全不需要碰 ECharts 复杂的 option 结构 
    只需要传“数据”和“业务字段名”
  -->
  <DatasetChart 
    :data="tableData" 
    :config="{ x: 'month', y: 'amount', type: 'line' }" 
  />
</template>

<script setup>
const tableData = [
  { month: 'Jan', amount: 100, cost: 50 },
  { month: 'Feb', amount: 200, cost: 90 },
  { month: 'Mar', amount: 150, cost: 60 }
];
</script>
```

---

### 四、 为什么这是“后端最爱”？

1.  **接口零处理**：后端直接 `SELECT *` 出来的 List，前端不用 `map`，直接塞进 `dataset.source`。
2.  **数据复用**：如果一个 `dataset` 里有 10 列数据，你可以搞 3 个 `series`，分别画第 1 列、第 5 列、第 8 列，而不需要把数据拷贝 3 份。
3.  **动态切换**：如果你想把“按销量排序”改成“按利润排序”，只需要改变 `encode.y` 指向的字段名，数据源完全不用动。

### 五、 课后作业（体验爽感）

**目标**：利用 Dataset 实现一个“一行代码切换维度”的功能。

1.  **数据准备**：
    ```javascript
    const rawData = [
      { product: 'A', score: 80, amount: 1000 },
      { product: 'B', score: 90, amount: 500 },
      { product: 'C', score: 60, amount: 800 }
    ];
    ```
2.  **界面**：
    *   放两个按钮：【看评分】、【看销售额】。
3.  **逻辑**：
    *   点击按钮时，只修改 `series[0].encode.y` 的值为 `'score'` 或 `'amount'`。
    *   **观察**：你不需要去修改 `series.data`，图表会自动变化。

理解了 Dataset，你就掌握了 ECharts 现代开发的精髓。数据层和视图层彻底解耦。
