### 第一阶段：ECharts 核心基础（脱离框架理解本质）
**目标**：理解ECharts的配置逻辑，能在普通HTML文件中手写常见图表。

1.  **环境搭建与Hello World**
    *   CDN引入 vs NPM安装。
    *   **核心五步曲**：DOM容器准备 $\rightarrow$ `echarts.init` $\rightarrow$ 配置 `option` $\rightarrow$ `setOption` $\rightarrow$ 渲染。
2.  **核心配置项详解（背诵级）**
    *   `title` (标题), `legend` (图例), `tooltip` (提示框), `grid` (绘图网格), `toolbox` (工具箱)。
    *   **坐标系**：`xAxis` / `yAxis`（类目轴 vs 数值轴）。
    *   **系列（Series）**：决定图表类型（`type: 'bar'` 等）。
3.  **常用图表实战**
    *   **折线图/柱状图**：堆叠（Stack）、平滑曲线、面积图。
    *   **饼图/环形图**：南丁格尔玫瑰图、标签位置调整。
    *   **混合图表**：双Y轴（左边是金额，右边是百分比），折柱混合。
4.  **样式自定义**
    *   `itemStyle`（图形样式）、`lineStyle`、`areaStyle`。
    *   颜色配置：纯色、**线性渐变**（`echarts.graphic.LinearGradient`）、径向渐变。
    *   格式化：`formatter` 回调函数（自定义Tooltip内容，面试常问）。

### 第二阶段：Vue + ECharts 深度集成（企业级开发核心）
**目标**：掌握在 Vue2/Vue3 中优雅地使用 ECharts，学会封装通用组件。

1.  **Vue 集成方案**
    *   **原生集成（推荐）**：在 `onMounted` 中初始化，使用 `ref` 获取 DOM。
    *   **Vue-ECharts**：了解第三方库的使用，但建议掌握原生封装以应对复杂需求。
2.  **响应式与重绘（核心难点）**
    *   **窗口缩放适配**：监听 `window.resize` 并调用 `chartInstance.resize()`。
    *   **Vue组件大小变化**：使用 `ResizeObserver` 监听容器 DIV 大小变化（比 window.resize 更精准）。
3.  **数据驱动视图**
    *   利用 Vue 的 `watch` 或 `computed` 监听数据变化，自动触发 `setOption` 更新图表。
    *   **增量更新**：理解 `setOption(option, notMerge)` 的第二个参数（是否合并配置）。
4.  **组件封装实战（企业级）**
    *   封装一个 `<BaseChart :options="options" />` 组件。
    *   处理组件销毁：`onUnmounted` 时调用 `dispose` 防止内存泄漏（**面试必问**）。
    *   Loading 状态处理：`showLoading` / `hideLoading`。

### 第三阶段：高级特性与可视化大屏（高薪技能）
**目标**：能够独立开发炫酷的数据可视化大屏（Data Visualization）。

1.  **地图与 GIS 可视化**
    *   **GeoJSON**：理解地图数据格式，如何注册地图 (`registerMap`)。
    *   **常用功能**：省/市下钻、区域热力图、飞线图（物流轨迹）。
    *   *注意：ECharts 官方不再提供地图文件，需掌握如何从阿里云 DataV 获取 GeoJSON。*
2.  **动态与交互**
    *   **事件监听**：`on('click')`，实现点击柱状图跳转或弹窗。
    *   **图表联动**：鼠标悬停在一个图表上，另一个图表同步高亮 (`connect`)。
    *   **动态排序动画**：实现动态赛跑条形图。
3.  **数据集（Dataset）管理**
    *   将**数据**（Data）与**样式**（Option）分离（ECharts 4.0+ 特性，更符合后端接口数据结构）。
4.  **大屏适配方案**
    *   `rem` 方案 vs `scale` (CSS transform) 缩放方案。
    *   全屏 API 的使用。

### 第四阶段：性能优化、原理与面试突击
**目标**：解决卡顿问题，应对面试官的深挖。

1.  **性能优化（Performance）**
    *   **按需引入**：不要 `import *`，使用 `use([CanvasRenderer, BarChart...])` 减小打包体积。
    *   **海量数据渲染**：
        *   开启 `large: true`（针对大数据量的 Canvas 优化）。
        *   降采样算法 (`sampling`)：LTTB 算法。
        *   使用 `appendData` 进行分片加载。
    *   **Canvas vs SVG**：
        *   Canvas：适合数据量大、动画多（位图，基于像素）。
        *   SVG：适合低端设备、清晰度要求高、交互少（矢量，基于DOM节点）。
        *   *面试题：什么时候用 SVG，什么时候用 Canvas？*
2.  **常见面试题准备**
    *   ECharts 的渲染原理是什么？（ZRender 库）。
    *   如何解决 ECharts 内存泄漏问题？（及时 dispose，解绑事件）。
    *   Vue 中 ECharts 图表为什么数据变了没更新？（Vue 响应式深度监听问题，或未调用 setOption）。
    *   如何实现自定义复杂的 Tooltip？（使用 formatter 返回 HTML 字符串 + CSS 样式）。
    *   ECharts 3D 了解吗？（GL 模块，基于 WebGL）。
