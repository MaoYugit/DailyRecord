欢迎来到第二课。如果说 ECharts 是一门语言，那么 `option` 就是它的语法，而我们现在要学的这几个配置项，就是最核心的**名词**。

在企业级开发中，**90% 的时间你都在跟这几个属性打交道**。面试官问 ECharts 熟不熟，其实就是问你这些配置项能不能信手拈来，特别是遇到复杂设计稿时能不能灵活调整。

我们将 `option` 的结构拆解为三层架构：**组件层（辅助）**、**坐标系层（骨架）**、**数据层（血肉）**。

---

### 一、 组件层：图表的“五大护法”

这些组件不直接画数据，但决定了图表的交互和布局。

#### 1. `title` (标题)
*   **作用**：告诉老板这个图表是干嘛的。
*   **常用配置**：
    *   `text`: 主标题。
    *   `subtext`: 副标题。
    *   `left` / `top`: 定位（如 `'center'`, `'20px'`）。
    *   `textStyle`: 修改字体颜色、大小。

#### 2. `legend` (图例)
*   **作用**：控制系列的显示与隐藏（点击图例可以切换）。
*   **关键点**：**`legend.data` 里的名称必须和 `series.name` 一一对应**，否则图例不显示。
*   **常用配置**：
    *   `orient`: `'horizontal'` (水平，默认) / `'vertical'` (垂直)。
    *   `bottom`: 放在底部。

#### 3. `grid` (绘图网格) —— **企业开发最重要布局属性**
*   **作用**：它定义了直角坐标系（柱状图、折线图）在 Canvas 里的**绘图区域**。
*   **为什么重要**：设计师给的大屏 UI，往往图表离边缘有固定的内边距。如果不设 Grid，坐标轴文字过长时会被切断。
*   **核心配置**：
    *   `left`, `right`, `top`, `bottom`: 设置图表距离容器边缘的距离（类似 CSS 的 padding）。
    *   `containLabel`: `true`（**强烈推荐常驻开启**）。开启后，计算距离时会包含坐标轴文字，防止文字显示不全。

#### 4. `tooltip` (提示框) —— **面试高频点**
*   **作用**：鼠标悬停时显示的信息。
*   **核心配置**：
    *   `trigger`:
        *   `'item'`: 鼠标移到具体图形（柱子/点）上才触发（适合散点图、饼图）。
        *   `'axis'`: 鼠标移到这个轴的**垂直区域**就触发（适合折线图、柱状图，**最常用**）。
    *   **`formatter` (自定义内容)**：**面试必问！**
        *   默认的提示框样式可能不符合 UI 设计。你需要用回调函数返回一段 HTML 字符串来自定义显示内容。

#### 5. `toolbox` (工具箱)
*   **作用**：右上角的工具栏，提供“另存为图片”、“数据视图”、“动态类型切换”等功能。
*   **常用**：`feature: { saveAsImage: {} }` (导出图片，老板很喜欢这个功能)。

---

### 二、 坐标系层：骨架 (`xAxis` / `yAxis`)

ECharts 的坐标轴分两种主要类型（`type`）：

1.  **`category` (类目轴)**：
    *   **特征**：必须有 `data` 属性。
    *   **场景**：通常是 **xAxis**，用来放“周一、周二”或“部门A、部门B”。
2.  **`value` (数值轴)**：
    *   **特征**：不需要 `data`，它会自动根据 series 里的数值生成刻度。
    *   **场景**：通常是 **yAxis**，用来展示具体的销量、金额。

> **骚操作**：如果你把 xAxis 设为 `value`，yAxis 设为 `category`，柱状图就会变成**横向条形图**。

---

### 三、 数据层：系列 (`series`)

这是图表的灵魂。是一个数组 `[]`，因为一个图表里可以画多条线。

*   `type`: 决定图表类型 (`'bar'`, `'line'`, `'pie'`)。
*   `name`: 对应 Legend。
*   `data`: 具体数值数组。
*   **常用样式**：
    *   `label`: `{ show: true }` (在图形上直接显示数值)。
    *   `itemStyle`: 控制颜色、圆角。

---

### 四、 代码实战：全家桶配置

请更新你的 `BasicChart.vue` 的 `option` 部分。这段代码涵盖了上述所有知识点，请仔细阅读注释。

```javascript
const option = {
  // 1. 标题
  title: {
    text: '2024年营收报表',
    subtext: '数据来源：财务部',
    left: 'center' // 居中显示
  },

  // 2. 图例
  legend: {
    data: ['线上渠道', '线下门店'], // 必须对应 series 里的 name
    top: 'bottom' // 放到底部
  },

  // 3. 绘图网格 (解决坐标轴文字显示不全问题)
  grid: {
    left: '3%',
    right: '4%',
    bottom: '10%', // 留出空间给图例
    containLabel: true // 包含坐标轴文字
  },

  // 4. 工具箱
  toolbox: {
    feature: {
      saveAsImage: {} // 提供下载图片按钮
    }
  },

  // 5. 提示框 (面试重点：Formatter)
  tooltip: {
    trigger: 'axis', // 坐标轴触发
    axisPointer: { type: 'shadow' }, // 鼠标放上去有阴影指示器
    // 自定义提示内容
    formatter: function (params) {
      // params 是一个数组，包含了当前轴上所有系列的数据
      let htmlStr = `<div style="font-weight:bold">${params[0].axisValue}</div>`;
      params.forEach(item => {
        htmlStr += `
          <div style="margin-top:5px;">
            <span style="display:inline-block;width:10px;height:10px;border-radius:50%;background:${item.color};"></span>
            ${item.seriesName}: <b>${item.value}万</b>
          </div>
        `;
      });
      return htmlStr;
    }
  },

  // 6. X轴 (类目轴)
  xAxis: {
    type: 'category',
    data: ['一月', '二月', '三月', '四月', '五月', '六月'],
    axisLabel: {
      rotate: 45 // 文字太长时倾斜显示
    }
  },

  // 7. Y轴 (数值轴)
  yAxis: {
    type: 'value',
    name: '单位：万元', // 轴名称
    splitLine: { // 网格横线
      lineStyle: { type: 'dashed' } // 虚线
    }
  },

  // 8. 系列数据
  series: [
    {
      name: '线上渠道',
      type: 'bar',
      data: [120, 200, 150, 80, 70, 110],
      itemStyle: {
        borderRadius: [5, 5, 0, 0] // 顶部圆角
      }
    },
    {
      name: '线下门店',
      type: 'line', // 柱状图和折线图混合
      smooth: true, // 平滑曲线
      data: [80, 150, 100, 60, 50, 90],
      areaStyle: { opacity: 0.2 } // 填充面积，变成面积图
    }
  ]
};
```

### 五、 课后作业（验证掌握程度）

请在上面的代码基础上尝试修改，观察效果：

1.  **Grid 实战**：把 `grid.left` 改为 `20%`。你会发现图表整体向右缩进，左边留出大片空白。这在做大屏侧边栏布局时非常有用。
2.  **坐标轴反转**：交换 xAxis 和 yAxis 的配置（记得把 `data` 也搬过去），把柱状图变成横向的。
