这一课的目标非常明确：**不依赖任何复杂的业务逻辑，仅仅是在屏幕上画出你的第一个图表。**

理解了这一步，你就理解了 ECharts 运行的底层逻辑，以后无论是在 React、Vue 还是原生 JS 中使用，原理都是通用的。

### 一、 引入方式：CDN vs NPM

在企业级开发和面试中，你需要清楚这两种方式的区别及适用场景。

#### 1. CDN 引入
通过 `<script>` 标签直接引入远程资源。
*   **适用场景**：快速写 Demo、测试 Bug、非工程化的老项目、或者为了利用浏览器缓存减少服务器带宽压力。
*   **代码**：
    ```html
    <script src="https://cdn.jsdelivr.net/npm/echarts@5.4.3/dist/echarts.min.js"></script>
    ```

#### 2. NPM 安装（Vue 开发必选）
通过包管理器安装到本地依赖。
*   **适用场景**：**企业级 Vue 项目**。它支持模块化开发、TypeScript 类型提示，最重要的是支持**按需引入（Tree Shaking）**，能显著减小打包体积。
*   **命令**：
    ```bash
    npm install echarts --save
    # 或者
    yarn add echarts
    ```

> **面试考点**：
> **Q:** 为什么在项目中推荐使用 NPM 而不是 CDN？
> **A:** NPM 配合构建工具（Webpack/Vite）可以实现**按需加载**，只打包用到的图表组件，减少首屏加载体积。同时方便版本管理，避免 CDN 挂掉导致服务不可用的风险。

### 二、 核心五步曲（代码实战）

无论项目多复杂，ECharts 的渲染流程永远逃不出这 5 步。我们将结合 **Vue 3 + Composition API** 来演示这套流程。

#### 准备工作
请在你的 Vue 项目中新建一个组件 `BasicChart.vue`。

#### 完整代码示例

```vue
<template>
  <!-- 1. DOM 容器准备：必须要有宽度和高度 -->
  <div ref="chartRef" class="chart-container"></div>
</template>

<script setup>
import { ref, onMounted, onUnmounted } from "vue";
// 引入 echarts 核心模块
import * as echarts from "echarts";

// 定义 DOM 引用
const chartRef = ref(null);
let myChart = null; // 用于保存 chart 实例

onMounted(() => {
  // 核心步骤都在这里执行
  initChart();
});

onUnmounted(() => {
  // 销毁实例，防止内存泄漏（企业级开发好习惯）
  if (myChart != null) {
    // 告诉 ECharts 内部：“把你的定时器关了，把监听器撤了，把 Canvas 删了”
    myChart.dispose();
    // 将变量置空，断开 JavaScript 变量引用
    // 帮助 JS 垃圾回收机制（GC）识别这块内存可以被回收了
    myChart = null;
  }
});

const initChart = () => {
  // 2. echarts.init：初始化实例
  // 参数是 DOM 节点，Vue 中通过 ref.value 获取
  myChart = echarts.init(chartRef.value);

  // 3. 配置 option：定义图表的数据和样式（这是未来打交道最多的地方）
  const option = {
    // 标题
    title: {
      text: "我的第一个 ECharts 图表",
    },
    // 提示框组件 (鼠标悬停时的浮层)
    tooltip: {},
    // 图例
    legend: {
      data: ["销量"],
    },
    // x 轴
    xAxis: {
      data: ["衬衫", "羊毛衫", "雪纺衫", "裤子", "高跟鞋", "袜子"],
    },
    // y 轴
    yAxis: {},
    // 系列数据（核心数据区）
    series: [
      {
        name: "销量",
        type: "bar", // 图表类型：柱状图
        data: [5, 20, 36, 10, 10, 20], // 数据
      },
    ],
  };

  // 4. setOption：将配置注入实例
  // 5. 渲染：ECharts 会自动根据 option 画出图表
  myChart.setOption(option);
};
</script>

<style scoped>
.chart-container {
  width: 100%;
  height: 400px; /* ⚠️ 重点：如果没有高度，图表将无法显示 */
  background-color: #f0f2f5;
}
</style>
```

### 三、 深度解析核心五步

#### 1. DOM 容器准备 (The Container)
*   **动作**：在 Template 中放一个 `div`。
*   **关键点**：**必须显式指定高度（Height）**。
*   **新手坑**：很多初学者发现图表不显示，90% 的原因是因为 `div` 高度为 0。ECharts 默认不会撑开容器。

#### 2. 初始化 (`echarts.init`)
*   **动作**：`echarts.init(dom)`。
*   **Vue注意点**：必须在 `onMounted` 生命周期中调用。因为在 `created` 阶段，DOM 还没生成，`ref.value` 是 `null`，会报错。

#### 3. 配置 Option (The Soul)
*   这是一个巨大的 JSON 对象。
*   ECharts 是**配置驱动**的，你不需要告诉它“怎么画线”，你只需要告诉它“x轴是什么，y轴是什么，数据是多少”，它自己会画。

#### 4. `setOption` (The Trigger)
*   **动作**：`myChart.setOption(option)`。
*   **原理**：这是 ECharts 唯一的入口。每次数据更新、样式改变，你都需要修改 `option` 对象，然后**再次调用** `setOption`。
*   **面试点**：`setOption` 默认是**合并模式**。如果你第二次调用 `setOption` 只传了部分配置，它会和旧配置合并。如果想完全替换，需使用 `myChart.setOption(option, true)`（第二个参数 `notMerge` 设为 true）。

#### 5. 渲染 (Rendering)
*   这一步是自动发生的，`setOption` 执行后，Canvas/SVG 就会被绘制到 DOM 中。
