### 一、 为什么需要处理销毁与 Loading？

在面试中，这是区分“新手”和“老手”的关键点：

1.  **内存泄漏（Memory Leak）**：
    *   **原理**：Vue 是单页应用（SPA）。当你切换路由（比如从“首页”跳到“个人中心”）时，旧页面的 Vue 组件被销毁了，DOM 节点被删除了。
    *   **问题**：但是！如果你不手动通知 ECharts，ECharts 的实例（JavaScript 对象）依然存在于内存中，它还在监听 `resize` 事件，还在跑动画定时器，还持有 Canvas 上下文。
    *   **后果**：用户点几次页面，浏览器内存就会飙升，最后页面崩溃。
    *   **解法**：在 `onUnmounted` 里调用 `dispose()`。

2.  **Loading 体验**：
    *   数据请求往往有延迟。如果不加 Loading，用户会看到一个空白的坐标轴，或者旧的数据突然变成新的，体验很差。ECharts 自带了非常优雅的 `showLoading()` 方法。

### 二、 企业级组件完整代码 (`BaseChart.vue`)

请在你的项目中新建 `src/components/BaseChart.vue`。这是一份可以直接在生产环境中使用的代码。

```vue
<template>
  <!-- 容器：宽高由父组件决定，这里设置 min-height 防止塌陷 -->
  <div ref="chartRef" class="base-chart" :style="{ width: width, height: height }"></div>
</template>

<script setup>
import { ref, onMounted, onUnmounted, watch, shallowRef, nextTick } from 'vue';
import * as echarts from 'echarts';
import { debounce } from 'lodash-es'; // 需安装 lodash-es，或使用手写防抖

// 1. 定义 Props
const props = defineProps({
  // 图表配置项 (必填)
  option: {
    type: Object,
    required: true,
    default: () => ({})
  },
  // 宽度 (支持百分比或 px)
  width: {
    type: String,
    default: '100%'
  },
  // 高度
  height: {
    type: String,
    default: '100%'
  },
  // Loading 状态
  loading: {
    type: Boolean,
    default: false
  },
  // 主题 (light / dark)
  theme: {
    type: String,
    default: 'default'
  },
  // 核心：setOption 的模式，true 表示不合并，强制重绘
  notMerge: {
    type: Boolean,
    default: false
  }
});

// 2. 定义 Emits (把点击事件抛给父组件)
const emits = defineEmits(['click', 'zr:click']);

// 3. 内部变量
const chartRef = ref(null); // DOM 引用
const chartInstance = shallowRef(null); // ECharts 实例 (使用 shallowRef 优化性能)
let resizeObserver = null; // 尺寸监听器

// 4. 初始化图表
const initChart = () => {
  if (!chartRef.value) return;

  // 销毁旧实例 (防止重复初始化)
  if (chartInstance.value) {
    chartInstance.value.dispose();
  }

  // 初始化
  chartInstance.value = echarts.init(chartRef.value, props.theme);

  // 绑定点击事件 (点击图形触发)
  chartInstance.value.on('click', (params) => {
    emits('click', params);
  });
  
  // 绑定空白处点击事件 (可选，有时候需要点空白取消选中)
  chartInstance.value.getZr().on('click', (params) => {
    emits('zr:click', params);
  });

  // 渲染
  renderChart();
};

// 5. 渲染逻辑
const renderChart = () => {
  if (!chartInstance.value) return;
  
  // 处理 loading
  if (props.loading) {
    chartInstance.value.showLoading({
      text: '',
      color: '#409EFF',
      textColor: '#000',
      maskColor: 'rgba(255, 255, 255, 0.2)',
      zlevel: 0,
    });
  } else {
    chartInstance.value.hideLoading();
    // 只有在非 loading 状态下才 setOption
    chartInstance.value.setOption(props.option, props.notMerge);
  }
};

// 6. Resize 处理 (防抖 + ResizeObserver)
const handleResize = debounce(() => {
  chartInstance.value?.resize();
}, 100);

// 7. 监听 Props 变化
watch(
  () => props.option,
  () => { renderChart(); },
  { deep: true } // 深度监听，保证 series 数据变动能触发
);

watch(
  () => props.loading,
  () => { renderChart(); }
);

// 8. 生命周期
onMounted(() => {
  // 确保 DOM 渲染完成
  nextTick(() => {
    initChart();
    
    // 开启尺寸监听
    resizeObserver = new ResizeObserver(() => handleResize());
    resizeObserver.observe(chartRef.value);
  });
});

// 面试考点：销毁实例
onUnmounted(() => {
  if (chartInstance.value) {
    chartInstance.value.dispose(); // 销毁实例，释放内存
    chartInstance.value = null;
  }
  if (resizeObserver) {
    resizeObserver.disconnect(); // 停止监听 DOM
  }
  handleResize.cancel(); // 取消未执行的防抖
});

// 9. 暴露方法给父组件 (通过 ref 调用)
defineExpose({
  getInstance: () => chartInstance.value,
  resize: handleResize
});
</script>

<style scoped>
.base-chart {
  /* 默认样式，可被父组件覆盖 */
  overflow: hidden; 
}
</style>
```

### 三、 如何在业务中使用？

假设我们要写一个“首页数据大盘” (`Dashboard.vue`)。

```vue
<template>
  <div class="page-container">
    <div class="chart-wrapper">
      <!-- 
        1. 传入 option
        2. 传入 loading 状态
        3. 接收 click 事件
      -->
      <BaseChart 
        :option="salesOption" 
        :loading="isLoading"
        height="400px"
        @click="handleChartClick"
      />
    </div>
    
    <button @click="refreshData">刷新数据</button>
  </div>
</template>

<script setup>
import { ref, computed } from 'vue';
import BaseChart from './components/BaseChart.vue'; // 引入刚才封装的组件

const isLoading = ref(true);
const rawData = ref([]);

// 生成 Option
const salesOption = computed(() => ({
  tooltip: { trigger: 'axis' },
  xAxis: { type: 'category', data: ['周一', '周二', '周三'] },
  yAxis: { type: 'value' },
  series: [{
    type: 'bar',
    data: rawData.value,
    itemStyle: { color: '#5470c6' }
  }]
}));

// 模拟 API 请求
const refreshData = () => {
  isLoading.value = true;
  setTimeout(() => {
    rawData.value = [120, 200, 150].map(n => n + Math.random() * 50);
    isLoading.value = false;
  }, 1500);
};

// 图表点击交互
const handleChartClick = (params) => {
  console.log(`你点击了第 ${params.dataIndex + 1} 根柱子，数值是 ${params.value}`);
  alert(`详情：${params.name} - ${params.value}`);
};

// 初始化加载
refreshData();
</script>
```

恭喜你！第二阶段（Vue 集成篇）已经圆满结束。现在你手头有了一把“重武器”——`<BaseChart>` 组件。

#### 面试官如果问你 Vue 集成 ECharts 的经验，你可以这样“降维打击”：

> “在集成 ECharts 时，我没有选择现成的 `vue-echarts` 库，而是自己基于 Composition API 进行了封装。
>
> 1.  我使用了 **`shallowRef`** 而不是 `ref` 来保存 chart 实例，避免了 Vue 深度代理导致的性能损耗。
> 2.  针对响应式问题，我使用了 **`ResizeObserver`** 配合 **`Lodash 防抖`**，解决了侧边栏折叠时 `window.resize` 无法触发图表重绘的问题。
> 3.  最重要的内存优化，我在 `onUnmounted` 中严格执行了 **`dispose`** 方法并断开了观察器，防止 SPA 应用长时间运行后的内存泄漏。
> 4.  我还通过 `watch` 深度监听 option 变化，实现了数据驱动视图的无感刷新。”
