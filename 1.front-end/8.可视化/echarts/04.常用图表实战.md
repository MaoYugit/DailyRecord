### 一、 折线/柱状图进阶：堆叠与面积

#### 1. 堆叠图 (Stacked Charts)
*   **场景**：比如展示一周的流量，不仅想看总流量，还想看每天“搜索流量”和“直接访问”各占多少。
*   **核心配置**：在 `series` 中给需要堆叠的项设置**相同的 `stack` 值**（字符串）。
*   **注意**：`stack` 属性值可以是任意字符串（如 `'Total'`），只要相同就会堆叠在一起。

#### 2. 面积图与平滑 (Area & Smooth)
*   **场景**：让折线图看起来不那么生硬，更有科技感（通常用于金融走势或大屏背景）。
*   **核心配置**：
    *   `smooth: true`：开启平滑曲线。
    *   `areaStyle: {}`：开启面积填充。
    *   **进阶**：使用 `echarts.graphic.LinearGradient` 做渐变色填充（**大屏必备**）。

#### **代码演示：堆叠面积图**

```javascript
series: [
  {
    name: '邮件营销',
    type: 'line',
    stack: '总量', // 堆叠标记
    smooth: true, // 平滑
    areaStyle: {}, // 填充
    data: [120, 132, 101, 134, 90, 230, 210]
  },
  {
    name: '联盟广告',
    type: 'line',
    stack: '总量', // 相同的标记，会堆叠在上一条线之上
    smooth: true,
    areaStyle: {},
    data: [220, 182, 191, 234, 290, 330, 310]
  }
]
```

### 二、 饼图/环形图：玩转圆圈

饼图在 ECharts 中没有 X/Y 轴，它只有 `series`。

#### 1. 环形图 (Donut Chart)
*   **原理**：饼图本质是一个实心圆。把它挖空就是环形图。
*   **核心配置**：`radius: ['40%', '70%']`。
    *   数组第一个值是**内半径**（挖空的范围）。
    *   第二个值是**外半径**（饼图的大小）。

#### 2. 南丁格尔玫瑰图 (Nightingale Rose)
*   **原理**：不仅用扇形的**角度**表示数值，还用扇形的**半径**表示数值。
*   **核心配置**：`roseType: 'radius'` (或 `'area'`)。
*   **场景**：数据差异较大时，玫瑰图比普通饼图更具视觉冲击力。

#### 3. 标签位置 (Label Position)
*   **核心配置**：`label: { position: '...' }`
    *   `outside` (默认)：在圆外，通过引导线连接。
    *   `inside`: 在扇形内部。
    *   `center`: 在圆心（常用于环形图中间显示总数）。

#### **代码演示：玫瑰环形图**

```javascript
series: [
  {
    name: '访问来源',
    type: 'pie',
    radius: ['30%', '70%'], // 变成环形
    roseType: 'radius',     // 变成玫瑰图
    itemStyle: {
      borderRadius: 8       // 圆角扇形（更圆润）
    },
    label: {
      show: true
    },
    data: [
      { value: 40, name: 'rose 1' },
      { value: 38, name: 'rose 2' },
      { value: 32, name: 'rose 3' },
      { value: 30, name: 'rose 4' }
    ]
  }
]
```

### 三、 混合图表与双 Y 轴（企业级开发重难点）

这是面试和实际工作中**最常见**的复杂图表需求。
*   **需求**：左边 Y 轴显示“销售额（柱状）”，右边 Y 轴显示“毛利率（折线）”。
*   **难点**：如何把两个不同量级的数据（比如 10000 和 0.5）放在一张图里，且不互相挤压。

#### 核心逻辑
1.  **定义两个 Y 轴**：在 `yAxis` 数组里写两个对象。
2.  **分配 Series**：在 `series` 里通过 `yAxisIndex` 属性指定该数据走哪个轴（默认是 0，即左轴）。

#### **完整实战代码：双 Y 轴折柱混合图**

请把这段 `option` 复制到你的 Vue 组件中运行，仔细观察注释。

```javascript
const option = {
  tooltip: {
    trigger: 'axis',
    axisPointer: { type: 'cross' } // 十字准星指示器，更专业
  },
  legend: {
    data: ['销售额', '毛利率']
  },
  xAxis: [
    {
      type: 'category',
      data: ['1月', '2月', '3月', '4月', '5月', '6月'],
      axisPointer: { type: 'shadow' }
    }
  ],
  // 重点：Y轴变成了一个数组
  yAxis: [
    {
      type: 'value',
      name: '销售额',
      min: 0,
      max: 2500,
      interval: 500,
      axisLabel: { formatter: '{value} 元' }
    },
    {
      type: 'value',
      name: '毛利率',
      min: 0,
      max: 100, // 百分比通常 0-100
      interval: 20,
      axisLabel: { formatter: '{value} %' },
      // 这一行决定了它在右边
      position: 'right',
      // 去掉右侧的网格线，防止和左侧的网格线重叠显得乱
      splitLine: { show: false }
    }
  ],
  series: [
    {
      name: '销售额',
      type: 'bar',
      // 默认 yAxisIndex: 0，走左轴
      data: [200, 490, 700, 232, 256, 767],
      itemStyle: { color: '#5470C6' }
    },
    {
      name: '毛利率',
      type: 'line',
      // ⚠️ 关键点：指定走索引为 1 的轴（即右轴）
      yAxisIndex: 1, 
      data: [20, 22, 33, 45, 63, 12],
      itemStyle: { color: '#91CC75' }
    }
  ]
};
```

### 四、 课后作业（综合实战）

为了巩固“双 Y 轴”和“样式配置”，请完成以下任务：

**目标**：做一个“温度与降水量关系图”。
1.  **左 Y 轴**：表示降水量（ml），使用**柱状图**，颜色设为浅蓝色。
2.  **右 Y 轴**：表示温度（°C），使用**折线图**，颜色设为橙色。
3.  **样式要求**：
    *   折线图要是**平滑曲线** (`smooth: true`)。
    *   折线图下方要有**阴影填充** (`areaStyle`)，体现温度的体感。
    *   **Tooltip** 必须加上单位（例如：`20 ml`，`35 °C`）。

当你完成这个作业，你就掌握了 ECharts 最核心的图表组合逻辑。请回复“**已完成**”，我们将进入**样式自定义**环节，学习如何让图表变得更“色”！
