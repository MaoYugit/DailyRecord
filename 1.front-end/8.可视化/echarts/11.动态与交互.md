静态图表只能展示“结果”，而动态交互能展示“过程”和“关联”。在企业级大屏中，**交互能力是区分 PPT 和 Web 系统的核心**。老板点一下柱子，侧边栏就要弹出来详情；鼠标滑过“销售额”，下面的“利润率”也要跟着亮。

### 一、 事件监听：不仅仅是 Click

ECharts 的事件分为两种：**图表事件**（点击了柱子、折线点）和 **全局事件**（点击了空白处）。

#### 1. 基础点击 (`click`)
这是最常用的。通常用于“下钻”或“跳转详情”。

```javascript
// 在你的 BaseChart 封装内部，或者 setup 中
chartInstance.value.on('click', (params) => {
  // params 是一个包含极其丰富信息的对象
  console.log(params);
  
  // 常用字段：
  // params.name: x轴的名称 (如 "周一")
  // params.value: 数值 (如 120)
  // params.seriesName: 系列名
  // params.dataIndex: 数据在数组中的索引
  
  // 业务逻辑示例：跳转路由
  // router.push(`/detail/${params.name}`);
});
```

#### 2. 空白处点击 (ZRender 事件) —— **高级技巧**
**场景**：用户点击了柱子选吉，现在想**点击空白处取消选中**。
ECharts 的 `on('click')` 只有点在图形上才触发。点空白处需要用底层的 ZRender 实例。

```javascript
// 获取 zrender 实例
chartInstance.value.getZr().on('click', (event) => {
  // 判断点击的是否是空白区域
  // 如果 event.target 存在，说明点到了图形；如果为 undefined，说明点到了空白
  if (!event.target) {
    console.log('点击了空白处，取消高亮！');
    // 执行取消高亮的逻辑，比如清除选中状态
    chartInstance.value.dispatchAction({
      type: 'downplay', // 取消高亮 API
      seriesIndex: 0
    });
  }
});
```

### 二、 图表联动 (`connect`)

**场景**：你有两个图表，一个是“2024年销售额”，一个是“2024年客流量”。它们的 X 轴都是日期。
**需求**：当鼠标悬停在“图表A”的“1月”上时，“图表B”的“1月”也要自动显示 Tooltip 和高亮，方便对比。

#### 核心步骤
1.  给每个 chart 实例设置相同的 `group` 名称。
2.  使用 `echarts.connect` 建立连接。

#### Vue 实战代码
假设一个页面里有两个 `<div ref="chart1">` 和 `<div ref="chart2">`。

```javascript
import * as echarts from 'echarts';

// 假设已经 init 了两个实例
const initLinkage = () => {
  const chart1 = echarts.init(chartRef1.value);
  const chart2 = echarts.init(chartRef2.value);

  // 1. 设置分组 (字符串ID，必须相同)
  chart1.group = 'myDashboard';
  chart2.group = 'myDashboard';

  chart1.setOption(option1);
  chart2.setOption(option2);

  // 2. 建立联动
  echarts.connect('myDashboard');
  // 或者直接传数组：echarts.connect([chart1, chart2]);
};
```

**效果**：动一个，另一个跟着动。不仅 Tooltip 会同步，Zoom（缩放）操作也会同步！

### 三、 动态排序动画（Bar Racing）

这是近年来**最火的视频可视化效果**（动态条形竞赛图）。ECharts 5.0 专门引入了 `realtimeSort` 来原生支持这个功能。

#### 核心原理
1.  **开启排序**：`series.realtimeSort: true`。
2.  **Y轴反转**：`yAxis.inverse: true`（让第一名在最上面）。
3.  **动画时长匹配**：`animationDuration` 必须和 `setInterval` 的更新频率配合好，才能实现丝滑的跑动效果。

#### 实战组件代码 (`BarRace.vue`)

这是一个完整的动态赛跑图 Demo，复制即用。

```vue
<template>
  <div ref="chartRef" style="width: 100%; height: 500px;"></div>
</template>

<script setup>
import { ref, onMounted, onUnmounted } from 'vue';
import * as echarts from 'echarts';

const chartRef = ref(null);
let myChart = null;
let timer = null;

// 模拟初始数据
const data = [];
for (let i = 0; i < 5; i++) {
  data.push(Math.round(Math.random() * 200));
}

const option = {
  xAxis: {
    max: 'dataMax', // 核心：X轴最大值自动根据当前数据最大值调整
  },
  yAxis: {
    type: 'category',
    data: ['A', 'B', 'C', 'D', 'E'],
    inverse: true, // 核心：反转，让第一名在上面
    animationDuration: 300,
    animationDurationUpdate: 300,
    max: 4 // 只显示前5名
  },
  series: [
    {
      realtimeSort: true, // 核心：开启实时排序
      name: '销量',
      type: 'bar',
      data: data,
      label: {
        show: true,
        position: 'right',
        valueAnimation: true // 核心：数字滚动效果
      },
      itemStyle: {
        color: new echarts.graphic.LinearGradient(0, 0, 1, 0, [
          { offset: 0, color: '#2b86ff' },
          { offset: 1, color: '#22e1ff' }
        ])
      }
    }
  ],
  // 核心：设置动画时长
  animationDuration: 0,
  animationDurationUpdate: 3000, // 3秒更新一次动画
  animationEasing: 'linear',
  animationEasingUpdate: 'linear'
};

// 模拟数据动态更新
const runRace = () => {
  timer = setInterval(() => {
    const data = option.series[0].data;
    // 随机增加数值
    for (let i = 0; i < data.length; i++) {
      if (Math.random() > 0.9) {
        data[i] += Math.round(Math.random() * 2000);
      } else {
        data[i] += Math.round(Math.random() * 200);
      }
    }
    
    // 更新数据
    myChart.setOption({
      series: [
        {
          type: 'bar',
          data: data
        }
      ]
    });
  }, 3000); // 这里的 3000 必须和 animationDurationUpdate 一致
};

onMounted(() => {
  myChart = echarts.init(chartRef.value);
  myChart.setOption(option);
  runRace();
});

onUnmounted(() => {
  clearInterval(timer); // 记得销毁定时器
  myChart?.dispose();
});
</script>
```
