欢迎来到第三阶段的最后一课。

在大屏可视化开发（DataV）中，**适配（Adaptation）** 是最让开发者头疼的问题之一。设计稿通常是 1920x1080，但现场的屏幕可能是 4K 电视、超宽 LED 拼接屏（如 3840x1080），或者是老板那台缩放比例设为 125% 的笔记本。

如果图表变形、文字重叠或者留有白边，项目验收就过不了。本节课我们将对比两种主流方案，并给出企业级通用的代码实现。

---

### 一、 终极对决：Rem 方案 vs Scale 方案

#### 1. Rem / VW 方案 (响应式布局)
*   **原理**：将 px 转换为 rem 或 vw。根据屏幕宽度动态调整根字体大小 (`html fontSize`)。
*   **优点**：
    *   **清晰度最高**：文字和矢量图永远是矢量渲染，没有锯齿。
    *   **铺满屏幕**：不会有黑边。
*   **缺点（痛点）**：
    *   **ECharts 难搞**：ECharts 的配置项（如 `fontSize: 12`）接收的是数值（px），它不支持 `rem`。你需要写一个转换函数 `fitSize(12)` 包裹所有的数值。
    *   **开发慢**：每个宽高都需要换算。
*   **适用场景**：后台管理系统（Admin Dashboard）、需要兼容手机端的项目。

#### 2. Scale 方案 (CSS Transform 缩放) —— **大屏推荐**
*   **原理**：开发时完全按照设计稿（如 1920x1080）写死 px。然后通过 CSS 的 `transform: scale(ratio)` 将整个容器像图片一样放大缩小。
*   **优点**：
    *   **开发极快**：设计稿是多少 px，你就写多少 px。
    *   **还原度 100%**：布局永远不会乱，相对位置固定。
*   **缺点**：
    *   **可能失真**：如果放得过大，位图（背景图）可能会模糊（Canvas 绘制的图表一般还好）。
    *   **留白/变形**：如果屏幕比例和设计稿不一样，要么留黑边（保持比例），要么强制拉伸（导致饼图变椭圆）。
*   **适用场景**：**数据大屏**、指挥中心 LED 墙。

### 二、 实战方案 1：Scale 组件封装（最省心的方案）

我们将封装一个 `<ScaleScreen>` 组件。你把它包裹在最外层，里面的所有内容直接写死 1920px 即可。

新建 `src/components/ScaleScreen.vue`:

```vue
<template>
  <!-- 外层容器：占满屏幕，用于居中 -->
  <div class="screen-wrapper">
    <!-- 内层容器：实际开发区域，通过 scale 缩放 -->
    <div class="screen-box" ref="boxRef" :style="styleObj">
      <slot></slot>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted, onUnmounted, reactive } from 'vue';
import { debounce } from 'lodash-es';

const props = defineProps({
  width: { type: Number, default: 1920 },
  height: { type: Number, default: 1080 }
});

const boxRef = ref(null);
const styleObj = reactive({
  width: props.width + 'px',
  height: props.height + 'px',
  transform: 'scale(1) translate(-50%, -50%)', // 默认居中
});

// 核心计算函数
const setScale = () => {
  // 获取当前浏览器可视区域的宽高
  const w = window.innerWidth;
  const h = window.innerHeight;
  
  // 计算宽和高的缩放比例
  const scaleW = w / props.width;
  const scaleH = h / props.height;
  
  // 策略 A：保持比例（会有黑边，但图形不走样）—— 推荐
  const scale = Math.min(scaleW, scaleH);
  
  // 策略 B：强制拉伸（铺满屏幕，但圆形会变椭圆）
  // const scaleX = scaleW; 
  // const scaleY = scaleH; 
  
  // 应用样式
  // translate(-50%, -50%) 配合 absolute left 50% top 50% 实现居中
  styleObj.transform = `scale(${scale}) translate(-50%, -50%)`;
};

// 监听 Resize
const onResize = debounce(() => setScale(), 200);

onMounted(() => {
  setScale();
  window.addEventListener('resize', onResize);
});

onUnmounted(() => {
  window.removeEventListener('resize', onResize);
});
</script>

<style scoped>
.screen-wrapper {
  width: 100vw;
  height: 100vh;
  background: #000; /* 黑边颜色 */
  position: relative;
  overflow: hidden;
}

.screen-box {
  position: absolute;
  top: 50%;
  left: 50%;
  transform-origin: 0 0; /* 缩放基点 */
  transition: 0.3s;
}
</style>
```

**使用方法：**

```vue
<template>
  <ScaleScreen :width="1920" :height="1080">
    <div class="header">我是标题</div>
    <div class="charts">
      <!-- 里面的图表直接写 width: 500px 即可 -->
      <BaseChart ... />
    </div>
  </ScaleScreen>
</template>
```

### 三、 实战方案 2：Rem 适配 ECharts（如果必须用 Rem）

如果你不做大屏，而是做响应式后台，必须用 Rem，那么你需要一个工具函数来转换 ECharts 的字体大小。

**新建 `utils/echarts-size.js`**:

```javascript
// 假设设计稿宽度是 1920
const designWidth = 1920;

export function fitChartSize(size) {
  // 获取当前屏幕宽度
  const clientWidth = window.innerWidth || document.documentElement.clientWidth;
  
  // 简单的线性比例：当前宽度 / 设计稿宽度 * 原始尺寸
  if (!clientWidth) return size;
  let scale = clientWidth / designWidth;
  
  return Number((size * scale).toFixed(3));
}
```

**在 ECharts Option 中使用**:

```javascript
import { fitChartSize } from '@/utils/echarts-size';

const option = {
  title: {
    text: '标题',
    textStyle: {
      fontSize: fitChartSize(20) // 动态计算
    }
  },
  xAxis: {
    axisLabel: {
      fontSize: fitChartSize(12) // 动态计算
    }
  }
  // 每一个涉及到尺寸的地方都要包一层，非常麻烦，所以大屏一般不用这个。
};
```

### 四、 全屏 API 的使用

在大屏演示现场，浏览器顶部的地址栏和书签栏是非常“出戏”的。我们需要提供一个按钮，让网页进入全屏模式（F11 效果）。

**封装全屏工具 `useFullscreen.js`**:

```javascript
import { ref } from 'vue';

export function useFullscreen() {
  const isFullscreen = ref(false);

  const toggleFullscreen = () => {
    // 兼容性写法
    const element = document.documentElement; // 整个页面
    if (!isFullscreen.value) {
      if (element.requestFullscreen) {
        element.requestFullscreen();
      } else if (element.webkitRequestFullScreen) {
        element.webkitRequestFullScreen();
      }
      isFullscreen.value = true;
    } else {
      if (document.exitFullscreen) {
        document.exitFullscreen();
      } else if (document.webkitCancelFullScreen) {
        document.webkitCancelFullScreen();
      }
      isFullscreen.value = false;
    }
  };

  return { isFullscreen, toggleFullscreen };
}
```

**在 Vue 中使用**:

```vue
<template>
  <div class="controls">
    <button @click="toggleFullscreen">
      {{ isFullscreen ? '退出全屏' : '进入全屏' }}
    </button>
  </div>
</template>

<script setup>
import { useFullscreen } from '@/hooks/useFullscreen';
const { isFullscreen, toggleFullscreen } = useFullscreen();
</script>
```
