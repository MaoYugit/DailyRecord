### 一、 地图数据的获取（生死攸关）

ECharts 5 以后，官方包里**不再内置**地图数据（因为地图边界涉及国家测绘法规，经常变动）。

**唯一的解决方案**：
前往 **[阿里云 DataV.GeoAtlas](http://datav.aliyun.com/portal/school/atlas/area_selector)** 工具下载 GeoJSON。

1.  **操作步骤**：
    *   打开链接，左侧选择“中国”。
    *   你也可以一级级点下去，选“浙江省” $\rightarrow$ “杭州市”。
    *   在右侧看到 JSON API，这就是我们要的 **GeoJSON 数据**。

2.  **数据结构理解**：
    GeoJSON 本质是一堆坐标点集合。它告诉 ECharts：“北京的轮廓是由这几百个经纬度点连成的”。

---

### 二、 核心 API：`registerMap`

拿到 JSON 数据后，必须先“注册”，ECharts 才知道怎么画。

```javascript
import * as echarts from 'echarts';
// 假设你把下载的 JSON 存为了 china.json
import chinaJson from './assets/china.json'; 

// 注册地图
// 参数1: 地图名称（自定义，比如 'china', 'zhejiang'）
// 参数2: GeoJSON 数据
echarts.registerMap('china', chinaJson);
```

### 三、 实战：画一个“科技感”中国地图

我们将实现一个**深色主题**的地图，带有**省份热力图**（根据数值深浅着色）。

请新建 `ChinaMap.vue`。

```vue
<template>
  <div ref="chartRef" class="map-chart"></div>
</template>

<script setup>
import { ref, onMounted, onUnmounted } from 'vue';
import * as echarts from 'echarts';

const chartRef = ref(null);
let chartInstance = null;

onMounted(async () => {
  await initMap();
});

const initMap = async () => {
  // 1. 获取地图数据
  // 真实开发中，建议把 GeoJSON 放在 public 目录或者 CDN
  // 这里为了演示，假设你已经 fetch 到了数据
  const response = await fetch('https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json');
  const chinaJson = await response.json();

  // 2. 注册地图 (核心步骤)
  echarts.registerMap('china', chinaJson);

  // 3. 初始化实例
  chartInstance = echarts.init(chartRef.value);

  // 4. 配置 Option
  const option = {
    backgroundColor: '#0E1116', // 大屏常用深色背景
    title: {
      text: '全国业务分布图',
      left: 'center',
      textStyle: { color: '#fff' }
    },
    // 核心组件：Geo 地理坐标系
    geo: {
      map: 'china', // 必须和 registerMap 的名字一致
      roam: true,   // 允许缩放和平移
      zoom: 1.2,    // 初始缩放比例
      label: {
        show: true, // 显示省份名字
        color: '#fff'
      },
      // 地图区域样式（未选中状态）
      itemStyle: {
        areaColor: '#2B3949', // 陆地颜色
        borderColor: '#43D0D6', // 边框颜色
        borderWidth: 1
      },
      // 鼠标悬停高亮样式
      emphasis: {
        itemStyle: {
          areaColor: '#2a333d'
        },
        label: { color: '#fff' }
      }
    },
    // 视觉映射组件 (热力图的核心)
    visualMap: {
      min: 0,
      max: 1000,
      left: 'left',
      bottom: 'bottom',
      text: ['高', '低'],
      textStyle: { color: '#fff' },
      inRange: {
        // 数值从低到高，颜色渐变
        color: ['#A5CC82', '#FFFF00', '#FF0000'] 
      },
      calculable: true
    },
    // 数据系列
    series: [
      {
        name: '业务量',
        type: 'map',
        geoIndex: 0, // 绑定到上面的 geo 配置
        data: [
          // 这里的 name 必须和 GeoJSON 里的 properties.name 完全一致
          { name: '北京市', value: 800 },
          { name: '广东省', value: 1000 },
          { name: '四川省', value: 500 },
          { name: '新疆维吾尔自治区', value: 100 } // 注意全称
        ]
      }
    ]
  };

  chartInstance.setOption(option);
};
</script>

<style scoped>
.map-chart { width: 100%; height: 600px; }
</style>
```

### 四、 进阶：飞线图（物流轨迹）

老板说：“我要看到我们的货车从北京飞到上海的效果！”
这就需要用到 `lines` 系列。

**关键点**：飞线图是画在 `geo` 坐标系上的。数据格式是 `coords: [[起点经纬度], [终点经纬度]]`。

在上面的 `option` 中，增加一个 `series`：

```javascript
series: [
  // ... 上面的 map series 保持不变
  
  // 新增：飞线层
  {
    type: 'lines',
    zlevel: 2, // 放在最上层
    effect: {
      show: true,
      period: 6, // 动画周期
      trailLength: 0.7, // 拖尾长度
      color: '#fff', // 飞线颜色
      symbolSize: 3
    },
    lineStyle: {
      color: '#43D0D6',
      width: 0, // 隐藏原本的线，只显示飞行的光点
      curveness: 0.2 // 曲线弯曲度
    },
    data: [
      {
        coords: [
          [116.405285, 39.904989], // 起点：北京
          [121.472644, 31.231706]  // 终点：上海
        ]
      },
      {
        coords: [
          [113.280637, 23.125178], // 起点：广州
          [116.405285, 39.904989]  // 终点：北京
        ]
      }
    ]
  }
]
```

### 五、 高级交互：省市下钻（Drill-down）

这是大屏最复杂的功能。用户点击“浙江省”，地图变成浙江省地图，且显示杭州、宁波等市。

**逻辑流**：
1.  监听地图点击事件 `chart.on('click')`。
2.  获取点击的省份名称（如 "Zhejiang"）。
3.  **动态请求**该省份的 GeoJSON（要有 ID 映射表）。
4.  `registerMap` 注册新地图。
5.  `setOption` 更新视图。

#### 代码逻辑演示（伪代码）

```javascript
// 省份拼音映射表 (因为 DataV 的文件名是 adcode)
// 实际项目中通常需要一份完整的 adcode 映射表
const adcodeMap = {
  '浙江省': 330000,
  '江苏省': 320000,
  // ...
};

chartInstance.on('click', async (params) => {
  const provinceName = params.name;
  const adcode = adcodeMap[provinceName];
  
  if (!adcode) return; // 如果没有对应数据就不处理

  // 1. 获取子区域数据
  const res = await fetch(`https://geo.datav.aliyun.com/areas_v3/bound/${adcode}_full.json`);
  const provinceJson = await res.json();

  // 2. 注册新地图
  echarts.registerMap(provinceName, provinceJson);

  // 3. 更新 Option，把 map 属性改成新的名字
  chartInstance.setOption({
    geo: {
      map: provinceName, // 变成 '浙江省'
      zoom: 1.0 // 重置缩放
    },
    series: [
      {
        name: '业务量',
        type: 'map', // 记得更新 series 里的 map 关联
        map: provinceName, // 重要：series 也要指明用哪个注册的地图
        data: [] //这里应该加载该省份下的市级数据
      }
    ]
  });
  
  // 4. 记得加一个“返回全国”的按钮逻辑
});
```
