### 一、 三大样式属性：各司其职

ECharts 的样式配置非常遵循直觉，主要分为这三类：

1.  **`itemStyle` (图形样式)**
    *   **管辖范围**：**实体图形**。比如：柱状图的柱子、饼图的扇形、散点图的点、折线图的数据点（拐点）。
    *   **常用属性**：`color` (颜色), `borderColor` (描边), `borderWidth`, `borderRadius` (圆角), `shadowBlur` (阴影)。

2.  **`lineStyle` (线条样式)**
    *   **管辖范围**：**线条**。比如：折线图的线、雷达图的网格线、坐标轴的轴线。
    *   **常用属性**：`width` (线宽), `type` ('solid'/'dashed'/'dotted'), `color`。

3.  **`areaStyle` (区域样式)**
    *   **管辖范围**：**封闭区域**。比如：折线图下方的填充、雷达图内部的填充。
    *   **常用属性**：`color` (填充色), `opacity` (透明度)。

### 二、 颜色配置：从纯色到渐变（核心）

**纯色**很简单，直接写十六进制字符串 `'#ff0000'` 即可。
**渐变色**是让图表具有“科技感”和“立体感”的核心武器。

#### 核心 API：`echarts.graphic.LinearGradient`

在 Vue 中使用时，确保你已经引入了 echarts 对象。

```javascript
// 参数解释：LinearGradient(x, y, x2, y2, colorStops)
// 前四个参数定义渐变方向（范围 0~1）：
// (0, 0, 0, 1) -> 从上到下 (最常用，柱状图)
// (0, 0, 1, 0) -> 从左到右 (横向柱状图)
// (0, 0, 1, 1) -> 对角线

color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
  { offset: 0, color: '#83bff6' }, // 0% 处的颜色（起始）
  { offset: 0.5, color: '#188df0' }, // 50% 处的颜色
  { offset: 1, color: '#188df0' }  // 100% 处的颜色（结束）
])
```

### 三、 格式化函数 `formatter`（面试必问）

`formatter` 存在于 `tooltip`、`axisLabel` (坐标轴文字)、`label` (图形上的文字) 中。
最难、最常用的是 **`tooltip.formatter`**。

#### 1. 为什么需要它？
默认的 Tooltip 只是简单的 `系列名: 数值`。但在实际业务中，我们可能需要：
*   显示单位（如 "1000 **万元**"）。
*   显示环比增长率（需要计算）。
*   自定义 HTML 样式（加个圆点、变个字体）。

#### 2. 参数 `params` 详解
*   **单项触发 (`trigger: 'item'`)**：`params` 是一个**对象**。
*   **轴触发 (`trigger: 'axis'`)**：`params` 是一个**数组**（因为一个 x 轴刻度上可能有多个系列的柱子堆叠）。

#### 3. 实战代码模板（背下来逻辑）

```javascript
formatter: function (params) {
  // 1. 如果是 axis 触发，params 是数组，我们需要遍历它
  let result = `<div style="margin-bottom: 4px;">${params[0].name}</div>`; // 显示 x 轴名称（如 "周一"）
  
  params.forEach(item => {
    // item 包含：color, seriesName, value 等
    // 制造一个小圆点，颜色跟图形一样
    const dot = `<span style="display:inline-block;margin-right:5px;border-radius:10px;width:10px;height:10px;background-color:${item.color};"></span>`;
    
    // 拼接每一行数据
    result += `
      <div style="font-size: 12px; color: #fff">
        ${dot} ${item.seriesName}: <b>${item.value}</b> 单位
      </div>`;
  });
  
  return result;
}
```

### 四、 综合实战：打造“赛博朋克”风格图表

请将以下 `option` 放入你的 `BasicChart.vue`。这个配置展示了如何利用渐变色、阴影和自定义 Tooltip 打造高端 UI。

```javascript
// 记得在 script setup 顶部确认引入了 echarts
// import * as echarts from 'echarts';

const option = {
  backgroundColor: '#080b30', // 深色背景，大屏常用
  tooltip: {
    trigger: 'axis',
    backgroundColor: 'rgba(0,0,0,0.7)', // 半透明黑底
    borderColor: '#00d4c7', // 边框色
    textStyle: { color: '#fff' },
    // 自定义 formatter
    formatter: (params) => {
      let html = `<div style="color:#00d4c7;font-weight:bold">${params[0].name}</div>`;
      params.forEach(p => {
        html += `<div>${p.marker} ${p.seriesName}: <span style="color:#fff;font-size:14px">${p.value}</span> kWh</div>`;
      });
      return html;
    }
  },
  grid: {
    top: '15%', left: '3%', right: '4%', bottom: '3%',
    containLabel: true
  },
  xAxis: {
    type: 'category',
    data: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'],
    axisLine: { lineStyle: { color: '#3d526f' } }, // 轴线颜色
    axisLabel: { color: '#96a4bb' } // 文字颜色
  },
  yAxis: {
    type: 'value',
    splitLine: { 
      lineStyle: { color: '#3d526f', type: 'dashed' } // 网格虚线
    },
    axisLabel: { color: '#96a4bb' }
  },
  series: [
    {
      name: '用电量',
      type: 'bar',
      barWidth: '40%', // 柱子宽度
      itemStyle: {
        // 核心：柱状图渐变色 (从上到下)
        color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
          { offset: 0, color: '#00f2fe' },  // 亮青色
          { offset: 1, color: '#4facfe' }   // 深蓝色
        ]),
        borderRadius: [5, 5, 0, 0] // 顶部圆角
      }
    },
    {
      name: '趋势',
      type: 'line',
      smooth: true,
      // 线条样式
      lineStyle: {
        color: '#ff9a9e',
        width: 3,
        shadowColor: 'rgba(255, 154, 158, 0.5)', // 线条发光效果
        shadowBlur: 10
      },
      // 区域填充样式 (从上到下渐变)
      areaStyle: {
        color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
          { offset: 0, color: 'rgba(255, 154, 158, 0.4)' },
          { offset: 1, color: 'rgba(255, 154, 158, 0)' }
        ])
      },
      data: [120, 132, 101, 134, 90, 230, 210]
    }
  ]
};
```
