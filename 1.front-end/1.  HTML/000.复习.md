在 HTML5 中，**单标签**（也称为“空元素”或“自闭合标签”）是指不需要成对出现（没有闭合标签，如 `</img>` 是错误的）的标签。

以下是 HTML5 中最常用的单标签及其详细使用笔记：

---

### 一、 页面基础与元数据类（Head 常用）

#### 1. `<meta>`：元数据
*   **用途**：定义文档的字符集、关键词、描述、视口设置等。
*   **关键属性**：
    *   `charset="UTF-8"`：定义编码。
    *   `name="viewport"`：移动端适配必用。
    *   `name="description"`：SEO 描述。
*   **笔记**：它是网页的“大脑”，不直接显示在页面上，但决定了浏览器如何渲染和搜索引擎如何抓取。

#### 2. `<link>`：外部资源链接
*   **用途**：最常用于引入 CSS 文件或设置网站图标（Favicon）。
*   **关键属性**：
    *   `rel="stylesheet"`：声明引入的是样式表。
    *   `href`：资源路径。
*   **笔记**：必须放在 `<head>` 内部。

#### 3. `<base>`：基础 URL
*   **用途**：为页面上所有的相对链接规定默认地址或默认目标（target）。
*   **笔记**：一个文档中最多只能有一个 `<base>` 标签。

---

### 二、 排版与换行类

#### 4. `<br>`：强制换行
*   **用途**：在文本中插入一个简单的换行符。
*   **笔记**：不要用多个 `<br>` 来制造段落间距，应该使用 CSS 的 `margin` 或 `padding`。

#### 5. `<hr>`：水平分隔线
*   **用途**：在语义上表示段落级别的转换（通常表现为一条横线）。
*   **笔记**：现代开发中常通过 CSS 去掉默认边框，重新设计样式。

#### 6. `<wbr>`：软换行
*   **用途**：Word Break Opportunity。告诉浏览器：“如果这一行太长需要换行，可以在这里断开”。
*   **笔记**：常用于处理极长的 URL 或不希望被随意截断的长单词。

---

### 三、 图像与多媒体类

#### 7. `<img>`：图像
*   **用途**：向网页中嵌入图片。
*   **关键属性**：
    *   `src`：图片路径（必填）。
    *   `alt`：图片无法显示时的替代文本（对 SEO 和残障人士极重要，必填）。
    *   `loading="lazy"`：图片懒加载，优化性能。

#### 8. `<source>`：媒介资源
*   **用途**：为 `<video>`、`<audio>` 或 `<picture>` 定义多个媒体资源，以便浏览器根据格式支持情况选择其一。
*   **笔记**：需要配合父容器使用。

#### 9. `<track>`：媒体轨道
*   **用途**：为视频或音频添加字幕（WebVTT 格式）、描述等。

---

### 四、 表单与交互类

#### 10. `<input>`：输入控件
*   **用途**：最强大的单标签，根据 `type` 不同，表现完全不同。
*   **常见类型**：
    *   `type="text / password / checkbox / radio"`
    *   `type="submit / button"`
    *   `type="number / email / date"` (HTML5 新增)
*   **笔记**：务必配合 `label` 标签使用以提高可用性。

#### 11. `<param>`：插件参数
*   **用途**：为 `<object>` 标签定义的插件传递参数。

---

### 五、 其他

#### 12. `<embed>`：外部内容引用
*   **用途**：用于嵌入外部应用或交互内容（如 Flash，虽已过时，但也可用于 PDF 预览）。

---

### 💡 核心使用笔记（避坑指南）

1.  **自闭合写法**：
    *   在 HTML5 中，写成 `<br>` 或 `<br />` 都是合法的。
    *   在现代开发（尤其是 React/JSX）中，通常习惯带上斜杠 `<img />` 以符合 XML/组件规范。

2.  **不要在单标签内写内容**：
    *   单标签没有 `</tag>`，所以永远不要尝试在 `<input>这里写字</input>`，浏览器会解析错误。

3.  **属性的重要性**：
    *   对于 `<img>`，**`alt` 属性不是可选的**，它是 Web 无障碍环境（A11y）的要求。
    *   对于 `<meta>`，**`viewport` 属性**是现代响应式网页的基石。

4.  **语义化选择**：
    *   如果是单纯为了视觉上的分割，用 CSS `border-top`；如果是语义上的主题转换，才用 `<hr>`。

### 总结表

| 标签       | 作用     | 核心属性                       |
| :--------- | :------- | :----------------------------- |
| `<meta>`   | 元数据   | `charset`, `name`, `content`   |
| `<link>`   | 外部资源 | `rel`, `href`                  |
| `<img>`    | 图片     | `src`, `alt`, `loading`        |
| `<input>`  | 表单输入 | `type`, `value`, `placeholder` |
| `<br>`     | 换行     | 无                             |
| `<hr>`     | 水平线   | 无                             |
| `<source>` | 多媒体源 | `src`, `type`, `media`         |



双标签（Paired Tags）是 HTML 中最常见的形式，由**起始标签** `<tag>` 和**结束标签** `</tag>` 组成，内容放在两者之间。

这里为你整理了 HTML5 中最常用的双标签及其分类使用笔记：

---

### 一、 页面结构与语义化类（HTML5 核心）

#### 1. `<header>` / `<footer>` / `<nav>`
*   **用途**：分别定义页面的头部、底部和导航栏。
*   **笔记**：在 HTML5 之前都用 `div`，现在使用这些语义化标签能让搜索引擎（SEO）和屏幕阅读器更好地理解页面结构。

#### 2. `<main>` / `<section>` / `<article>` / `<aside>`
*   **用途**：
    *   `<main>`：页面的核心内容（一个页面通常只有一个）。
    *   `<section>`：定义文档中的节（有标题的区块）。
    *   `<article>`：定义独立的、完整的文章或帖子。
    *   `<aside>`：侧边栏（与主内容相关，但可独立）。
*   **笔记**：尽量避免“满屏皆是 div”，合理使用这些标签对 SEO 极有帮助。

---

### 二、 内容与文本格式类

#### 3. `<h1>` - `<h6>`：标题
*   **用途**：定义 1 到 6 级标题。
*   **笔记**：`<h1>` 最为重要，通常一个页面只建议出现一个 `<h1>`，有利于权重提升。

#### 4. `<p>`：段落
*   **用途**：定义文本段落。
*   **笔记**：`<p>` 内部不能包含块级元素（如 `<div>` 或另一个 `<p>`）。

#### 5. `<a>`：超链接
*   **用途**：跳转链接。
*   **关键属性**：
    *   `href`：目标 URL。
    *   `target="_blank"`：在新窗口打开。
*   **笔记**：如果 `href="javascript:void(0);"` 常用于阻止默认跳转。

#### 6. `<span>` 与 `<div>`
*   **用途**：
    *   `<div>`：块级容器，用于布局。
    *   `<span>`：行内容器，用于包裹部分文本。
*   **笔记**：它们没有语义，仅作为 CSS 样式的钩子（Hook）。

#### 7. `<strong>` / `<em>` / `<mark>`
*   **用途**：
    *   `<strong>`：加粗（表示强调、重要）。
    *   `<em>`：斜体（表示语气重音）。
    *   `<mark>`：高亮背景（HTML5 新增）。

---

### 三、 列表类

#### 8. `<ul>` / `<ol>` / `<li>`
*   **用途**：
    *   `<ul>`：无序列表（点状）。
    *   `<ol>`：有序列表（数字）。
    *   `<li>`：列表项。
*   **笔记**：`<li>` 必须嵌套在 `<ul>` 或 `<ol>` 中。

#### 9. `<dl>` / `<dt>` / `<dd>`：定义列表
*   **用途**：用于“名词 - 解释”这种结构。
*   **笔记**：常用于页脚的帮助链接分类或术语解释。

---

### 四、 表单与交互类

#### 10. `<form>`：表单容器
*   **用途**：收集用户输入。
*   **关键属性**：`action`（提交地址）、`method`（get/post）。

#### 11. `<button>`：按钮
*   **用途**：定义可点击的按钮。
*   **笔记**：相比 `<input type="button">`，双标签 `<button>` 内部可以放图片或图标，灵活性更高。

#### 12. `<label>`：标签说明
*   **用途**：为 input 绑定文字。
*   **关键属性**：`for`（对应 input 的 id）。
*   **笔记**：点击 `<label>` 里的文字，光标会自动聚焦到对应的输入框，提升体验。

#### 13. `<select>` / `<option>`：下拉菜单
*   **用途**：提供选项列表。

#### 14. `<textarea>`：多行文本框
*   **用途**：用于长评论、描述输入。
*   **笔记**：可以通过 CSS `resize: none;` 禁用用户手动拉伸。

---

### 五、 多媒体与图形类

#### 15. `<video>` / `<audio>`
*   **用途**：嵌入视频和音频。
*   **关键属性**：`controls`（显示控件）、`autoplay`（自动播放）、`loop`（循环）。

#### 16. `<canvas>`
*   **用途**：通过 JavaScript 绘制 2D/3D 图形。
*   **笔记**：标签中间的内容只有在浏览器不支持 canvas 时才会显示。

#### 17. `<iframe>`：内联框架
*   **用途**：在一个页面里嵌入另一个页面。

---

### 💡 核心使用笔记（避坑指南）

1.  **闭合原则**：
    *   双标签**必须写结束标签**。漏写 `</div>` 会导致整个页面布局塌陷或乱码。

2.  **嵌套规范（非常重要）**：
    *   **块级元素**（如 `div`, `p`, `h1`, `section`）通常可以包含**行内元素**（如 `span`, `a`, `img`）。
    *   但是，**`<p>` 标签不能包裹 `<div>`**，这会导致浏览器解析自动断开。
    *   **`<a>` 标签不能嵌套 `<a>` 标签**。

3.  **语义化优先**：
    *   如果你只是想加粗，虽然 `<b>` 也能用，但推荐用 `<strong>`（更有语义）。
    *   如果你是写导航，虽然 `<div>` 也能做，但推荐用 `<nav>`。

4.  **字符实体**：
    *   如果你要在双标签内显示 `<` 或 `>`，需要使用转义：`&lt;` 和 `&gt;`，否则会被误认为 HTML 标签。

### 常用对比表

| 需求             | 推荐标签        | 理由                  |
| :--------------- | :-------------- | :-------------------- |
| **标题**         | `<h1>` - `<h6>` | 明确权重              |
| **超链接**       | `<a>`           | 页面跳转必备          |
| **强调内容**     | `<strong>`      | 比 `<b>` 更有利于 SEO |
| **通用布局**     | `<div>`         | 无特殊语义时使用      |
| **文字样式**     | `<span>`        | 局部样式调整          |
| **列表**         | `<ul><li>`      | 结构清晰              |
| **容器（语义）** | `<section>`     | 代替部分无意义的 div  |
