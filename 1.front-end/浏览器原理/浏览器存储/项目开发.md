### 📂 一、 项目整体架构与目录设计

我们需要两个独立的文件夹，模拟真实的“前后端分离”开发模式，这样才能触发**跨域（CORS）**和**Cookie 传输**的问题（面试核心考点）。

**目录结构建议：**

```text
Secure-Note-Project/
├── server/                 # 后端 (Node.js + Express)
│   ├── app.js              # 入口文件 (配置 CORS, CookieParser)
│   ├── routes/
│   │   └── auth.js         # 登录接口 (负责下发 Set-Cookie)
│   └── utils/
│       └── mockDB.js       # 简单的内存数据库 (代替 MySQL)
│
└── client/                 # 前端 (Vue 3 + Vite)
    ├── src/
    │   ├── api/
    │   │   └── request.js  # Axios 封装 (重点：withCredentials)
    │   ├── utils/
    │   │   ├── storage.js  # 我们之前写的 Local/Session 封装类
    │   │   └── db.js       # IndexedDB 封装类
    │   ├── stores/         # Pinia 状态管理 (可选，用于同步数据)
    │   └── views/
    │       ├── Login.vue   # 场景：Cookie 登录
    │       ├── Editor.vue  # 场景：LocalStorage 草稿 / SessionStorage 历史
    │       └── Notes.vue   # 场景：IndexedDB 离线列表
    └── vite.config.js      # 代理配置 (可选)
```

### 📅 二、 具体开发流程

#### 第一阶段：环境初始化与后端地基 (解决 CORS)
**目标**：跑通前后端，让前端能请求到后端，并解决跨域问题。

1.  **后端初始化**：
    *   `mkdir server && cd server && npm init -y`
    *   安装依赖：`npm install express cors cookie-parser`
    *   **关键代码 (`server/app.js`)**：
        
        ```javascript
        const express = require('express');
        const cors = require('cors');
        const cookieParser = require('cookie-parser');
        const app = express();
        
        // 核心考点：CORS 配置
        // 必须设置 origin 为前端地址，不能是 '*'，否则浏览器拒绝接收 Cookie
        app.use(cors({
            origin: 'http://localhost:5173', // 假设前端是 Vite 启动的
            credentials: true // 允许携带 Cookie
        }));
        
        app.use(cookieParser());
        app.use(express.json());
        
        app.listen(3000, () => console.log('Server running on port 3000'));
        ```
    
2.  **前端初始化**：
    *   `npm create vite@latest client -- --template vue`
    *   安装依赖：`npm install axios`

---

#### 第二阶段：Cookie 实战 (最核心的 HttpOnly)
**目标**：实现场景 1 —— 登录并下发 HttpOnly Token，以及 CSRF 防御。

1.  **后端接口 (`server/routes/auth.js`)**：
    *   编写 `/login` 接口。
    *   使用 `res.cookie('token', 'xyz...', { httpOnly: true, secure: false, sameSite: 'Lax' })`。
    *   *注意：开发环境非 HTTPS，secure 设为 false，但在面试中要说生产环境设为 true。*
2.  **前端配置 (`client/src/api/request.js`)**：
    *   配置 Axios：`axios.create({ withCredentials: true, baseURL: 'http://localhost:3000' })`。
    *   **验证**：登录后，打开浏览器 DevTools -> Application -> Cookies，看是否有 `token`，且 `HttpOnly` 打勾。尝试用 `document.cookie` 打印，应该是空的（这才是对的）。
3.  **CSRF 挑战**：
    *   后端再设置一个 `csrf_token` 的 Cookie（不设 HttpOnly）。
    *   前端 JS 读取这个 Cookie，并在下一次 POST 请求时放到 Header 里发给后端验证。

---

#### 第三阶段：LocalStorage & SessionStorage 实战
**目标**：实现场景 2 和 3 —— 草稿箱与会话历史。

1.  **工具类移值**：
    *   把你之前写好的 `StorageHandler` 类复制到 `client/src/utils/storage.js`。
2.  **编辑器开发 (`Editor.vue`)**：
    *   **草稿箱**：
        ```javascript
        // 伪代码
        const noteContent = ref('');
        // 监听内容变化，自动存 LocalStorage
        watch(noteContent, (newVal) => {
            myStorage.set('draft_note_1', newVal); // 永久保存
        });
        // 挂载时读取
        onMounted(() => {
            noteContent.value = myStorage.get('draft_note_1') || '';
        });
        ```
    *   **主题切换**：做一个按钮，切换 class 并存 `localStorage`，刷新页面读取配置保持黑暗模式。
3.  **面包屑历史 (`Notes.vue` -> `Editor.vue`)**：
    *   在路由跳转前，将当前路径 push 到 `sessionStorage` 的数组中。
    *   在页面展示“你的浏览路径：首页 > 笔记A > 笔记B”。
    *   关闭标签页再打开，验证是否消失。

---

#### 第四阶段：IndexedDB 终极挑战
**目标**：实现场景 4 —— 离线存储大段文本和图片。

1.  **封装简易 IDB 类 (`client/src/utils/db.js`)**：
    *   不要用第三方库，我们练习原生（或者简单封装）。
    *   我们需要三个方法：`initDB()`, `addNote(note)`, `getAllNotes()`。
2.  **离线列表 (`Notes.vue`)**：
    *   **策略**：
        1.  页面加载 -> 先读取 IndexedDB 显示旧数据（秒开）。
        2.  同时悄悄发 Axios 请求给后端获取最新数据。
        3.  后端数据回来后 -> 更新页面 -> 写入 IndexedDB 覆盖旧数据。
3.  **二进制图片存储**：
    *   做一个 `<input type="file">`。
    *   获取 `File` 对象，直接存入 IndexedDB（不需要 FileReader 转 Base64，体验 IDB 的强大）。
