### 📅 二、 具体开发流程

#### 第一阶段：环境初始化与后端地基 (解决 CORS)
**目标**：跑通前后端，让前端能请求到后端，并解决跨域问题。

1.  **后端初始化**：
    *   `mkdir server && cd server && npm init -y`
    *   安装依赖：`npm install express cors cookie-parser`
    *   **关键代码 (`server/app.js`)**：
        
        ```javascript
        const express = require('express');
        const cors = require('cors');
        const cookieParser = require('cookie-parser');
        const app = express();
        
        // 核心考点：CORS 配置
        // 必须设置 origin 为前端地址，不能是 '*'，否则浏览器拒绝接收 Cookie
        app.use(cors({
            origin: 'http://localhost:5173', // 假设前端是 Vite 启动的
            credentials: true // 允许携带 Cookie
        }));
        
        app.use(cookieParser());
        app.use(express.json());
        
        app.listen(3000, () => console.log('Server running on port 3000'));
        ```
    
2.  **前端初始化**：
    *   `npm create vite@latest client -- --template vue`
    *   安装依赖：`npm install axios`

#### 第二阶段：Cookie 实战 (最核心的 HttpOnly)
**目标**：实现场景 1 —— 登录并下发 HttpOnly Token，以及 CSRF 防御。

1.  **后端接口 (`server/routes/auth.js`)**：

2.  **前端配置 (`client/src/api/request.js`)**：

## **第二阶段：Cookie 鉴权实战**。

这一阶段的目标是：**前端点登录 -> 后端验证 -> 后端种下 HttpOnly Cookie -> 前端自动保存**。

### 1️⃣ 第一步：编写后端登录接口

我们需要在后端创建一个路由来处理登录请求。

1.  在 `server` 目录下创建一个文件夹叫 `routes`。
2.  在 `routes` 文件夹里新建文件 `auth.js`。
3.  **复制以下代码到 `server/routes/auth.js`**：

```javascript
const express = require('express');
const router = express.Router();

// 模拟数据库里的用户
const MOCK_USER = {
    username: 'admin',
    password: '123'
};

// 登录接口 POST /auth/login
router.post('/login', (req, res) => {
    const { username, password } = req.body;

    // 1. 简单的校验逻辑
    if (username === MOCK_USER.username && password === MOCK_USER.password) {
        
        // 2. 核心知识点：设置 HttpOnly Cookie
        // 这里的 'auth_token' 就是我们的 "会员卡"
        res.cookie('auth_token', 'secret_token_xyz_987', {
            httpOnly: true, // 关键：禁止前端 JS 访问 (防 XSS)
            secure: false,  // 开发环境 (HTTP) 设为 false，生产环境 (HTTPS) 必须为 true
            maxAge: 1000 * 60 * 60 * 24, // 24小时后过期
            sameSite: 'Lax' // 允许从前端地址发起的顶层导航请求携带
        });

        // 3. 再设置一个非 HttpOnly 的 Cookie (用于教学对比)
        // 比如记录用户的分组，前端可能需要读取用来做 AB 测试
        res.cookie('user_group', 'A', {
            httpOnly: false, // 允许 JS 读取
            maxAge: 1000 * 60 * 60
        });

        return res.json({ success: true, message: '登录成功' });
    } else {
        return res.status(401).json({ success: false, message: '账号或密码错误' });
    }
});

// 登出接口 POST /auth/logout
router.post('/logout', (req, res) => {
    // 清除 Cookie
    res.clearCookie('auth_token');
    res.clearCookie('user_group');
    res.json({ success: true, message: '已退出登录' });
});

module.exports = router;
```

4.  **修改 `server/app.js`** 把它挂载上去：
    在 `const app = express();` 的下面，`app.listen` 的上面，加入这两行：
    ```javascript
    const authRoutes = require('./routes/auth');
    app.use('/auth', authRoutes); // 挂载路由，访问路径变成 /auth/login
    ```

5.  **重启后端**：在 server 目录的终端按 `Ctrl+C` 停止，然后再次运行 `node app.js`。

这一步我们要实现两个功能，模拟真实的笔记应用体验：

### 🛠️ 第一步：把我们的“神兵利器”封装进去

我们需要把之前手写的 `StorageHandler` 放入项目中，作为通用的工具库。

1.  在 `client/src` 下新建文件夹 `utils`（如果已有则忽略）。
2.  在 `utils` 下新建文件 `storage.js`。
3.  **粘贴之前的封装代码**（为了方便，我再次贴在这里，并做了一点微调适配 ES6 模块导出）：

```javascript
// client/src/utils/storage.js

class StorageHandler {
    constructor(strategy = 'localStorage') {
        this.storage = window[strategy];
    }

    set(key, value, expire) {
        const data = {
            value,
            time: Date.now(),
            expire
        };
        try {
            this.storage.setItem(key, JSON.stringify(data));
        } catch (e) {
            console.error('存储失败:', e);
        }
    }

    get(key) {
        const dataString = this.storage.getItem(key);
        if (!dataString) return null;

        try {
            const data = JSON.parse(dataString);
            // 检查过期
            if (data.expire && Date.now() - data.time > data.expire) {
                this.remove(key);
                return null;
            }
            return data.value;
        } catch (e) {
            return null;
        }
    }

    remove(key) {
        this.storage.removeItem(key);
    }

    clear() {
        this.storage.clear();
    }
}

// 导出两个实例，方便直接使用
export const localStore = new StorageHandler('localStorage');
export const sessionStore = new StorageHandler('sessionStorage');
```

import { localStore } from '../utils/storage'; // 引入封装好的工具

// --- 功能 1: 自动保存草稿 (LocalStorage) ---
const noteContent = ref('');
const lastSavedTime = ref('');

// 1. 初始化时，从 LocalStorage 读取上次没写完的内容
onMounted(() => {
  const savedDraft = localStore.get('draft_note');
  if (savedDraft) {
    noteContent.value = savedDraft;
    lastSavedTime.value = '恢复成功';
  }
  
  // 恢复主题设置
  const savedTheme = localStore.get('theme_setting');
  if (savedTheme === 'dark') {
    isDarkMode.value = true;
  }
});

// 2. 监听输入，实时保存 (防抖优化是进阶点，这里先直接存)
watch(noteContent, (newVal) => {
  localStore.set('draft_note', newVal);
  
  // 更新保存时间显示
  const now = new Date();
  lastSavedTime.value = `${now.getHours()}:${now.getMinutes()}:${now.getSeconds()}`;
});

const clearDraft = () => {
  noteContent.value = '';
  localStore.remove('draft_note');
  lastSavedTime.value = '已清空';
};

// --- 功能 2: 主题切换 (LocalStorage) ---
const isDarkMode = ref(false);

const toggleTheme = () => {
  isDarkMode.value = !isDarkMode.value;
  // 持久化存储主题偏好
  localStore.set('theme_setting', isDarkMode.value ? 'dark' : 'light');
};
</script>

## 📂 第四阶段：IndexedDB 离线数据库实战

太好了，我们终于迎来了最后一个大 Boss——**IndexedDB**。

这是前端存储中**最复杂**但也**最强大**的部分。我们要用原生 JS 封装一个数据库操作类，实现两个普通 LocalStorage 做不到的功能：

1.  **存图片**：直接把图片文件（Blob）存进数据库，不需要上传到服务器。

#### 🛠️ 第一步：封装 IndexedDB 工具类 (`utils/db.js`)

原生 IndexedDB 的 API 是基于事件的（`onsuccess`, `onerror`），写起来像回调地狱。为了在 Vue 里用得舒服，我们用 **Promise** 把它们包起来。

请在 `client/src/utils` 下新建 `db.js`，粘贴以下代码：

```javascript
// client/src/utils/db.js

const DB_NAME = 'SecureNoteDB';
const DB_VERSION = 1;
const STORE_NAME = 'notes';

// 1. 打开/创建数据库
export const openDB = () => {
    return new Promise((resolve, reject) => {
        // 打开数据库 (如果不存在会自动触发 onupgradeneeded 创建)
        const request = indexedDB.open(DB_NAME, DB_VERSION);

        request.onerror = (event) => {
            console.error('数据库打开失败', event);
            reject('DB Open Error');
        };

        request.onsuccess = (event) => {
            console.log('数据库打开成功');
            resolve(event.target.result); // 返回 db 实例
        };

        // 第一次创建或版本升级时触发 (建表都在这里做)
        request.onupgradeneeded = (event) => {
            const db = event.target.result;
            // 创建一个对象仓库 (ObjectStore)，相当于 "表"
            // keyPath: 'id' 意味着每条数据必须有个 id 字段作为主键
            // autoIncrement: true 意味着 id 会自动 +1
            if (!db.objectStoreNames.contains(STORE_NAME)) {
                db.createObjectStore(STORE_NAME, { keyPath: 'id', autoIncrement: true });
            }
        };
    });
};

// 2. 新增一条笔记 (支持存图片 Blob)
export const addNoteToDB = async (note) => {
    const db = await openDB();
    return new Promise((resolve, reject) => {
        // 开启一个读写事务
        const transaction = db.transaction([STORE_NAME], 'readwrite');
        const store = transaction.objectStore(STORE_NAME);
        
        // 添加数据
        const request = store.add(note);

        request.onsuccess = () => {
            resolve(request.result); // 返回新生成的 id
        };
        request.onerror = () => {
            reject('Add Error');
        };
    });
};

// 3. 获取所有笔记
export const getNotesFromDB = async () => {
    const db = await openDB();
    return new Promise((resolve, reject) => {
        const transaction = db.transaction([STORE_NAME], 'readonly');
        const store = transaction.objectStore(STORE_NAME);
        
        // getAll 是获取所有数据的快捷方法
        const request = store.getAll();

        request.onsuccess = () => {
            resolve(request.result); // 返回数组
        };
        request.onerror = () => {
            reject('Get Error');
        };
    });
};
```

这是一个非常高级且实用的问题！**“离线优先（Offline First）”**架构的核心难点就在于**数据同步**。

将 IndexedDB 的数据同步给后端，通常遵循以下 **3 个核心步骤**：

1.  **标记状态**：在本地存储时，给数据打上“未同步”的标签（`synced: false`）。
2.  **监听网络**：监听浏览器的 `online` 事件，一旦联网，自动触发同步。
3.  **发送与更新**：遍历本地“未同步”的数据，构建 `FormData`（因为有图片），发送给后端。发送成功后，将本地状态改为“已同步”。

下面我们分前后端来实现这个功能。

### 🛠️ 第一步：后端准备 (接收图片)

### 🛠️ 第二步：升级 IndexedDB 工具 (`client/src/utils/db.js`)

我们需要给本地数据增加一个 `synced` 字段，并且需要一个方法来**更新**本地数据的状态。

修改 `client/src/utils/db.js`，增加 `updateNoteStatus` 方法：

```javascript
// ...前面的代码保持不变...

// 4. 更新笔记状态 (比如把 synced: false 改为 true)
export const updateNoteStatus = async (id, status) => {
    const db = await openDB();
    return new Promise((resolve, reject) => {
        const transaction = db.transaction([STORE_NAME], 'readwrite');
        const store = transaction.objectStore(STORE_NAME);

        // 先把旧数据拿出来
        const getRequest = store.get(id);

        getRequest.onsuccess = () => {
            const data = getRequest.result;
            if (!data) return resolve();

            // 修改状态
            data.synced = status;

            // 放回去 (put = 更新)
            const putRequest = store.put(data);
            putRequest.onsuccess = () => resolve(true);
        };
        
        getRequest.onerror = () => reject('Update Error');
    });
};
```

### 🛠️ 第三步：实现同步逻辑 (`client/src/components/NoteList.vue`)

这是最关键的一步。我们会修改前端组件，增加“同步”按钮，并监听网络状态。

修改 `NoteList.vue` 的 `<script setup>` 部分：

```javascript
import { ref, onMounted, onUnmounted } from 'vue';
import { addNoteToDB, getNotesFromDB, updateNoteStatus } from '../utils/db'; // 记得导入 updateNoteStatus
import request from '../api/request'; // 导入 axios

const title = ref('');
const selectedFile = ref(null);
const notes = ref([]);
const isSyncing = ref(false); // 同步 loading 状态
const isOnline = ref(navigator.onLine); // 当前网络状态

// --- 核心逻辑 1: 保存时标记为 "未同步" ---
const saveNote = async () => {
  if (!title.value) return;

  const newNote = {
    title: title.value,
    date: Date.now(),
    imageBlob: selectedFile.value,
    synced: false // <--- 新增标记：默认为未同步
  };

  await addNoteToDB(newNote);
  
  // 清理表单
  title.value = '';
  selectedFile.value = null;
  document.querySelector('input[type="file"]').value = '';
  
  await loadList();
  
  // 如果当前有网，尝试立刻同步一次
  if (isOnline.value) {
    syncData();
  }
};

// --- 核心逻辑 2: 执行同步 (Data Sync) ---
const syncData = async () => {
  if (isSyncing.value || !isOnline.value) return;
  
  // 1. 找出所有未同步的笔记
  const allNotes = await getNotesFromDB();
  const unsyncedNotes = allNotes.filter(n => !n.synced);

  if (unsyncedNotes.length === 0) return;

  isSyncing.value = true;
  console.log(`开始同步，共 ${unsyncedNotes.length} 条数据...`);

  try {
    // 2. 循环发送 (实际开发中可能用 Promise.all 并发)
    for (const note of unsyncedNotes) {
      // 【重点】构建 FormData，因为要传文件
      const fd = new FormData();
      fd.append('title', note.title);
      if (note.imageBlob) {
        // Blob, 文件名
        fd.append('image', note.imageBlob, 'note_img.png');
      }

      // 3. 发送给后端
      await request.post('/notes/sync', fd, {
        headers: { 'Content-Type': 'multipart/form-data' }
      });

      // 4. 后端接收成功后，更新本地状态为 "已同步"
      await updateNoteStatus(note.id, true);
    }
    console.log('全部同步完成！');
    // 刷新列表显示最新状态
    await loadList();
  } catch (e) {
    console.error('同步失败:', e);
  } finally {
    isSyncing.value = false;
  }
};

// --- 核心逻辑 3: 监听网络变化 ---
const updateNetworkStatus = () => {
  isOnline.value = navigator.onLine;
  if (isOnline.value) {
    console.log('网络已恢复，尝试自动同步...');
    syncData();
  }
};

onMounted(() => {
  loadList();
  window.addEventListener('online', updateNetworkStatus);
  window.addEventListener('offline', updateNetworkStatus);
});

onUnmounted(() => {
  window.removeEventListener('online', updateNetworkStatus);
  window.removeEventListener('offline', updateNetworkStatus);
});

// ... loadList 和 handleFileSelect 代码保持不变 ...
```
