### 🗺️ 浏览器原理系统学习路线图

#### 核心主线：从输入 URL 到页面展示，到底发生了什么？
这是所有浏览器知识的**骨架**。你需要把后续所有的知识点挂载在这个流程上。

---

### 🟢 第一阶段：网络通信 (The Network)
**目标**：理解资源（HTML/CSS/JS/图片）是如何从服务器跑到浏览器的。

*   **1. HTTP/HTTPS 协议（重灾区）**
    *   **版本进化**：HTTP 1.0 vs 1.1 (长连接) vs 2.0 (多路复用) vs 3.0 (QUIC)。
    *   **HTTPS**：TLS/SSL 握手流程（为什么它是安全的？）。
    *   **状态码**：301 vs 302, 304, 401 vs 403, 500 vs 502。
*   **2. 浏览器缓存机制（Cache）—— 面试必考**
    *   **强缓存**：`Cache-Control`, `Expires`。
    *   **协商缓存**：`ETag`, `Last-Modified`。
    *   *实战*：这部分和我们学的 Storage 不同，这是控制静态资源是否重新请求的。
*   **3. DNS 解析 & TCP 连接**
    *   DNS 查找过程（本地 -> 根 -> 域）。
    *   TCP 三次握手与四次挥手（为什么要三次？）。

> **📚 关联你的知识**：Cookie 就在 HTTP 头里传输；Service Worker 属于网络代理层。

---

### 🔵 第二阶段：渲染机制 (The Rendering)
**目标**：资源拿到了，浏览器怎么把代码变成屏幕上的像素？

*   **1. 关键渲染路径 (CRP)**
    *   HTML -> DOM Tree。
    *   CSS -> CSSOM Tree。
    *   合并 -> Render Tree。
*   **2. 布局与绘制 (Layout & Paint)**
    *   **回流 (Reflow/Layout)**：元素位置大小改变（代价大）。
    *   **重绘 (Repaint)**：颜色背景改变（代价小）。
    *   **合成 (Composite)**：GPU 加速，层（Layer）的概念。
*   **3. 实战优化**
    *   为什么 CSS 要放头部，JS 要放底部？
    *   `defer` 和 `async` 的区别是什么？

---

### 🟡 第三阶段：JavaScript 执行机制 (The Logic)
**目标**：理解 JS 代码是如何在 V8 引擎里跑起来的。

*   **1. 事件循环 (Event Loop) —— 👑 核心之王**
    *   **宏任务 (MacroTask)**：setTimeout, setInterval, script, I/O。
    *   **微任务 (MicroTask)**：Promise.then, MutationObserver, nextTick。
    *   *面试题*：给你一段复杂的代码，让你说出 console.log 的顺序。
*   **2. 作用域与闭包**
    *   词法作用域、执行上下文、调用栈。
    *   闭包的内存泄漏问题。
*   **3. 垃圾回收 (Garbage Collection)**
    *   标记清除法 (Mark-and-Sweep)。
    *   引用计数法。

> **📚 关联你的知识**：Storage 的读写是同步还是异步？IndexedDB 为什么不阻塞主线程？这都和 Event Loop 有关。

---

### 🟠 第四阶段：浏览器安全 (The Security)
**目标**：保护用户数据，防止黑客攻击。

*   **1. 同源策略 (Same-Origin Policy)**
    *   什么是同源？
    *   **跨域解决方案**：CORS (最常用), JSONP (过时), Nginx 代理, WebSocket。
*   **2. 攻击与防御（我们已经学了一半）**
    *   **XSS (跨站脚本)**：HttpOnly Cookie, CSP, 转义。
    *   **CSRF (跨站请求伪造)**：SameSite Cookie, CSRF Token, Referer Check。
    *   **MITM (中间人攻击)**：HTTPS。

> **📚 关联你的知识**：你刚才做的项目里的 CORS 配置、HttpOnly、SameSite 都在这里。

---

### 🔴 第五阶段：性能优化 (The Optimization)
**目标**：把上面四个阶段的知识综合运用，让页面更快。这是面试官最喜欢问的**“综合应用题”**。

*   **网络层优化**：减少 HTTP 请求、使用 HTTP2、CDN、Gzip 压缩、浏览器缓存。
*   **渲染层优化**：减少回流重绘、防抖节流、图片懒加载、虚拟列表。
*   **代码层优化**：Webpack 打包优化、Tree Shaking、Code Splitting。
*   **存储层优化**：利用 LocalStorage 缓存数据（你已经学会了！）、Service Worker 离线缓存。

---

### 🚀 推荐的学习方法

既然你已经有了一个 `Secure-Note` 项目，我建议你**继续基于这个项目**深入学习，不要空看书：

1.  **攻克“事件循环”**：
    *   在你的项目中写几个 `setTimeout` 和 `Promise`，看看执行顺序。
2.  **攻克“渲染机制”**：
    *   使用 Chrome DevTools 的 **Performance** 面板录制你打开“笔记列表”的过程，看看到底哪里发生了 Layout，哪里发生了 Paint。
3.  **攻克“网络与缓存”**：
    *   配置你的 Express 后端，给静态资源（比如图片）加上 `Cache-Control: max-age=3600`，观察 Network 面板状态码变成 304 或 200(from memory cache) 的过程。

### 📚 推荐资源
1.  **《图解 HTTP》**：非常适合新手，画图解释网络。

3.  **"What happens when..."**：GitHub 上著名的开源仓库，详细解释了从 URL 到页面的每一个原子步骤。
