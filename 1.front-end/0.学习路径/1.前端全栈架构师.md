# 🚀 前端全栈架构师修炼之路 (总纲)

## 🟢 第一阶段：JavaScript 核心原理 (The Core)
*这是所有前端技术的基石。不学好这里，Vue/React 源码你根本看不懂。*

*   **Module 01: 内存与作用域 (Memory & Scope)**
    *   堆(Heap) vs 栈(Stack) 内存分配
    *   执行上下文 (Execution Context)
    *   作用域链 (Scope Chain) 与 闭包 (Closure) 的底层原理
    *   垃圾回收机制 (GC) 与 内存泄漏分析
*   **Module 02: 面向对象与原型 (OOP & Prototype)**
    *   原型链 (Prototype Chain) 终极图解
    *   `this` 指向的 4 种规则
    *   `new` 操作符手写实现
    *   继承的 6 种方式 (从 ES5 寄生组合到 ES6 Class)
*   **Module 03: 异步编程 (Asynchronous)**
    *   回调地狱 (Callback Hell)
    *   **Promise 深度剖析** (状态机、链式调用、手写 Promise A+ 规范)
    *   Generator 与迭代器
    *   Async/Await 的实现原理 (自动执行器)
*   **Module 04: 函数式编程 (Functional Programming)**
    *   高阶函数 (HOC)
    *   纯函数与副作用
    *   柯里化 (Currying) 与 偏函数
    *   函数组合 (Compose/Pipe)

## 🔵 第二阶段：浏览器原理与网络 (The Environment)
*你之前学的“浏览器存储”就在这里。这是区分初级和高级的分水岭。*

*   **Module 05: 深入 HTTP 协议 (Network I)**
    *   HTTP 1.0/1.1/2.0/3.0 演进史
    *   HTTPS 握手流程 (RSA/ECDHE 算法概念)
    *   TCP/IP 协议族 (三次握手、四次挥手、拥塞控制)
    *   WebSocket 与实时通信
*   **Module 06: 浏览器运行机制 (Browser Runtime)**
    *   **进程与线程** (GUI 线程、JS 引擎线程、渲染线程)
    *   **事件循环 (Event Loop)** (宏任务 vs 微任务，Node.js vs 浏览器差异)
    *   **渲染流程** (DOM -> CSSOM -> RenderTree -> Layout -> Paint -> Composite)
    *   回流 (Reflow) 与 重绘 (Repaint) 的深度优化
*   **Module 07: 浏览器数据持久化 (Storage)**
    *   **✅ 已完成：** Cookie (HttpOnly, SameSite, Secure)
    *   **✅ 已完成：** Web Storage (Local/Session 封装与配额)
    *   **✅ 已完成：** IndexedDB (异步、事务、二进制存储)
    *   *扩展*：Service Worker 与 Cache API (PWA 离线缓存策略)
*   **Module 08: 前端安全防御 (Security)**
    *   XSS (反射型、存储型、DOM型) 攻击与防御 (CSP, 转义)
    *   CSRF 攻击原理与 Token/Referer 防御
    *   点击劫持 (Clickjacking)
    *   中间人攻击 (MITM)

## 🟡 第三阶段：工程化基础设施 (The Infrastructure)
*学会如何搭建脚手架，理解 Webpack/Vite 到底做了什么。*

*   **Module 09: 模块化演进 (Module System)**
    *   CommonJS (Node) vs ES Modules (Browser) 核心差异
    *   AMD / CMD / UMD 历史包袱
    *   Tree Shaking 原理
*   **Module 10: 构建工具深潜 (Webpack)**
    *   Loader 与 Plugin 的本质区别
    *   手写一个简易 Loader
    *   Webpack 构建流程 (Tapable 事件流)
    *   HMR (热更新) 原理
*   **Module 11: 现代构建工具 (Vite & Rollup)**
    *   ESBuild 为什么快？
    *   Vite 的 No-Bundle 理念
    *   Rollup 的 Scope Hoisting
*   **Module 12: 规范化与自动化 (CI/CD)**
    *   Linting (ESLint, Prettier, Stylelint)
    *   Git Hooks (Husky, Lint-staged)
    *   GitHub Actions / GitLab CI 自动化流水线搭建
    *   NPM 发包流程与 Monorepo (pnpm workspace, TurboRepo)

## 🟠 第四阶段：框架核心与源码 (The Frameworks)
*知其然，知其所以然。不看源码，永远是 API 调用师。*

*   **Module 13: Vue 3 核心原理**
    *   响应式系统 (Proxy vs Object.defineProperty)
    *   依赖收集 (Dep & Watcher / Effect)
    *   Composition API 设计理念
    *   Keep-Alive 与 Teleport 原理
*   **Module 14: React 核心原理**
    *   JSX 的本质 (React.createElement)
    *   Fiber 架构 (时间切片、任务调度)
    *   Hooks 实现原理 (链表结构)
    *   SyntheticEvent (合成事件机制)
*   **Module 15: 虚拟 DOM 与 Diff 算法**
    *   Virtual DOM 的价值与误区
    *   Vue 的双端 Diff 算法 (图解)
    *   React 的单向 Diff 策略
    *   Key 的作用 (为什么不能用 Index 做 Key)
*   **Module 16: 状态管理设计 (State Management)**
    *   Flux 架构思想
    *   Redux 原理 (Reducer, Middleware, Thunk)
    *   Vuex / Pinia 原理
    *   MobX / Recoil 原子化状态管理

## 🔴 第五阶段：Node.js 与全栈开发 (The Fullstack)
*前端不仅仅是浏览器。掌握 Node.js 才能做 BFF、SSR 和工具链。*

*   **Module 17: Node.js 核心**
    *   Node.js 事件循环 (libuv)
    *   Buffer 与 Stream (流式处理大文件)
    *   File System 与 Path 模块
    *   Process 与 Cluster (多进程架构)
*   **Module 18: 后端框架与数据库**
    *   Koa2 洋葱模型 (Compose 原理)
    *   NestJS (IoC 控制反转, AOP 切面编程)
    *   MongoDB (NoSQL) vs MySQL (ORM: TypeORM/Prisma)
    *   Redis 缓存策略
*   **Module 19: 服务端渲染 (SSR)**
    *   CSR vs SSR vs SSG 对比
    *   同构渲染 (Isomorphic Rendering) 的痛点 (注水与脱水)
    *   Next.js / Nuxt.js 核心特性

## 🟣 第六阶段：架构设计与性能优化 (The Architect)
*这是成为 Tech Lead 的必经之路。*
