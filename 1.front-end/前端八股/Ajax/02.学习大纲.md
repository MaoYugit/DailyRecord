### 🚀 Ajax & Axios 进阶学习大纲（Vue 开发者版）

#### 第一阶段：底层原理与核心基础（面试必问）
> **目标**：不依赖库也能手写请求，理解浏览器与服务器如何对话。

1.  **HTTP 协议基础**
    *   **请求报文与响应报文**：理解 Header, Body, Status Code (200, 301, 304, 401, 403, 404, 500)。
    *   **HTTP 方法**：GET vs POST（本质区别是什么？面试常考），PUT, DELETE, PATCH, OPTIONS。
    *   **跨域（CORS）**：什么是同源策略？CORS 预检请求（Preflight request）是什么？`Access-Control-Allow-Origin`。

2.  **JavaScript 异步编程（前置知识）**
    *   **Event Loop**：宏任务与微任务（理解请求回调何时执行）。
    *   **Promise**：手写 Promise（简单版），理解 `.then`, `.catch`, `.finally`。
    *   **Async/Await**：如何用同步的方式写异步代码（Axios 的主流用法）。

3.  **原生 Ajax (XMLHttpRequest)**
    *   *实操*：手写一个原生 `XMLHttpRequest` 请求。
    *   *理解*：`readyState` 的 0-4 个状态分别代表什么。

4.  **Fetch API (现代浏览器的原生替代品)**
    *   *对比*：Fetch 和 Axios 的区别？（Fetch 默认不带 Cookie，不会自动报错 4xx/5xx，需要手动两次 await）。

---

#### 第二阶段：Axios 基础应用
> **目标**：熟练使用 Axios 进行 CRUD 操作。

1.  **Axios 核心特性**
    *   安装与引入。
    *   基本请求语法（GET, POST, PUT, DELETE）。
    *   配置对象：`url`, `method`, `baseURL`, `headers`, `params` (URL参数), `data` (Body参数), `timeout`。

2.  **响应结构**
    *   理解 `response.data`, `response.status`, `response.headers`。

3.  **并发请求**
    *   `axios.all` (旧) vs `Promise.all` (新标准推荐) 处理并发请求。

---

#### 第三阶段：企业级 Axios 二次封装（核心重难点）
> **目标**：像架构师一样思考，编写可维护、可扩展的 API 层。**这是新手和资深开发的在代码层面的最大区别。**

1.  **创建 Axios 实例**
    *   为什么要用 `axios.create()`？（不同服务可能有不同的 baseURL 或超时设置）。

2.  **拦截器（Interceptors）—— 面试与实战核心**
    *   **请求拦截器**：
        *   自动携带 Token（Authorization Header）。
        *   Loading 状态开启。
    *   **响应拦截器**：
        *   **解包数据**：直接返回 `res.data`，少写一层 `.data`。
        *   **统一错误处理**：
            *   根据状态码（401, 403, 500）弹出不同的提示（ElementPlus Message）。
            *   处理 Token 过期（401）自动跳转登录页。
        *   Loading 状态关闭。

3.  **取消请求（CancelToken / AbortController）**
    *   场景：用户频繁点击搜索按钮，如何取消上一次未完成的请求？
    *   场景：路由切换时，取消上一页未完成的请求。

4.  **TypeScript 类型定义（Vue3 必备）**
    *   为 Axios 响应数据定义 Interface，获得代码提示。
    *   封装泛型请求方法 `request<T>(...)`。

---

#### 第四阶段：在 Vue 3 项目中的最佳实践
> **目标**：结合 Vue 生态（Composition API, Pinia, Router）优雅地管理数据。

1.  **API 模块化管理 (Service Layer)**
    *   不要在 `.vue` 文件里直接写 `axios.get`。
    *   **目录结构规范**：
        ```text
        src/
        ├── utils/
        │   └── request.js (axios 封装)
        ├── api/
        │   ├── user.js    (用户相关接口)
        │   └── order.js   (订单相关接口)
        ```
    *   `import { login } from '@/api/user'` 的使用方式。

2.  **结合 Composition API**
    *   `onMounted` 中发起初始请求。
    *   使用 `ref` / `reactive` 绑定响应式数据。
    *   封装 `useRequest` Hook（类似 VueUse 的 `useFetch`，处理 loading, error, data 状态）。

3.  **结合 Pinia (状态管理)**
    *   在 Pinia Actions 中调用 API。
    *   什么时候该把数据存 Pinia，什么时候存组件内部？

4.  **解决跨域问题（开发环境）**
    *   配置 Vite (`vite.config.ts`) 的 `server.proxy` 进行反向代理。

---

#### 第五阶段：高级场景与面试攻坚
> **目标**：解决复杂业务场景，应对高难度面试题。

1.  **无感刷新 Token (双 Token 机制)**
    *   *场景*：Access Token (短效) + Refresh Token (长效)。
    *   *流程*：请求 401 -> 拦截器拦截 -> 暂停队列中的请求 -> 用 Refresh Token 换新 Access Token -> 重试原请求。
    *   *难点*：如何处理并发请求时的 Token 刷新？（防止多次刷新）。

2.  **大文件上传与下载**
    *   利用 `onUploadProgress` 制作进度条。
    *   文件切片上传、断点续传（原理）。
    *   二进制流下载（Blob）与文件名乱码处理。

3.  **防抖与节流在请求中的应用**
    *   输入框搜索（Debounce）。

4.  **安全性**
    *   CSRF 攻击防御（Axios 的 `xsrfCookieName`）。
    *   XSS 攻击（数据转义）。

---

### ✅ 学习路径建议

1.  **第1天**：快速过一遍 HTTP 和 原生 Ajax/Fetch，重点理解“异步”和“跨域”。
2.  **第2-3天**：新建一个 Vue3 项目，安装 Axios，练习基础 CRUD。
3.  **第4-6天（最关键）**：**死磕“第三阶段”**。不要只看文章，要自己手写一个 `request.js` 工具类，涵盖拦截器、Token 处理。
4.  **第7天**：将 API 抽离到 `src/api` 目录，结合 Pinia 跑通一个完整的“登录-获取用户信息-退出登录”流程。
5.  **第8天+**：研究“无感刷新 Token”和“取消请求”，这是大厂面试的加分项。

### 📚 面试模拟题（自测用）

1.  **Ajax、Fetch、Axios 有什么区别？**
2.  **你在项目中是如何封装 Axios 的？做过哪些统一处理？**
3.  **如何处理 Token 过期？（重点考察 401 拦截和刷新 Token）**
4.  **Vue 项目中，如何配置反向代理解决开发环境跨域？**
5.  **如果在组件销毁时，请求还没回来，你会怎么做？**
