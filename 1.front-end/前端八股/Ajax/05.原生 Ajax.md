本节是**“面试过滤器”**。
现在的开发中，99% 的时间我们都在用 Axios 或 Fetch，但面试官问原生 Ajax 并不是为了让你回去写古董代码，而是为了测试：

1.  **你是否理解网络请求的底层生命周期？**
2.  **遇到 Axios 解决不了的古怪 Bug，能不能到底层去调试？**

原生 Ajax 的核心对象是 **`XMLHttpRequest` (XHR)**。Axios 本质上就是在这个对象外面包了一层漂亮的糖衣。

---

### 第一部分：核心概念 `readyState` (生命周期状态机)

XHR 对象里有一个属性叫 `readyState`，它记录了请求目前的进度。
它的值是从 **0 到 4** 的整数。这是面试必问的**死记硬背**知识点。

我们将它比喻为 **“给服务器打电话”** 的过程：

| 状态码 | 状态名               | 含义 (大白话)                                                | 对应代码阶段                                                 |
| :----- | :------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **0**  | **UNSENT**           | **未打开**。电话机拿在手里，还没拨号。                       | `new XMLHttpRequest()` 刚创建实例。                          |
| **1**  | **OPENED**           | **已打开**。拨通了号码，建立了连接。                         | 调用了 `.open()` 方法。                                      |
| **2**  | **HEADERS_RECEIVED** | **接收头部**。对方接通了，说了一句“喂？”（服务器返回了响应头）。 | 调用了 `.send()`，且服务器的 Header 已经回来了。             |
| **3**  | **LOADING**          | **加载中**。对方正在滔滔不绝地说话（服务器正在传输 Body 数据）。 | 响应体（Body）正在下载中，`responseText` 里已经有部分数据了。 |
| **4**  | **DONE**             | **完成**。电话挂断，通话结束。                               | **数据传输全部完成**，可以在客户端使用了。                   |

**面试考点：**
*   我们通常只在 `readyState === 4` 时处理业务逻辑。
*   状态 **1 (OPENED)** 是可以设置请求头（Headers）的唯一时机（在 `open` 之后，`send` 之前）。

### 第二部分：实战 —— 手写原生 Ajax

面试官递给你白板：“写一个 GET 请求，获取 `/user` 接口的数据。”

#### 1. 基础 GET 请求 (标准模板)

请仔细看注释，每一行都是考点。

```javascript
// 1. 创建 XHR 对象
const xhr = new XMLHttpRequest();

// 2. 初始化请求 (配置 Method 和 URL)
// 第三个参数 true 代表“异步”，false 代表“同步”（会卡死页面，永远别用 false）
xhr.open('GET', 'https://api.example.com/user?id=123', true);

// 3. 监听状态变化 (这是一个回调函数，状态每变一次都会触发)
xhr.onreadystatechange = function() {
    // 只有当状态变成 4 (完成) 时，我们才处理
    if (xhr.readyState === 4) {
        // 还要判断 HTTP 状态码 (200-299 算成功)
        if (xhr.status >= 200 && xhr.status < 300) {
            // 成功！
            // ⚠️ 坑点：原生 XHR 返回的是 JSON 字符串，Axios 帮我们自动 JSON.parse 了，这里要手动转
            const res = JSON.parse(xhr.responseText);
            console.log('数据拿到了:', res);
        } else {
            // 失败 (比如 404, 500)
            console.error('请求失败:', xhr.status);
        }
    }
};

// 4. 发送请求
xhr.send();
```

#### 2. 进阶 POST 请求 (发送 JSON 数据)

**区别很大**，这也是面试官喜欢追问的地方：“POST 请求和 GET 在原生代码写法上有什么不同？”

**答：**
1.  `send()` 里要传数据。
2.  **必须手动设置 Content-Type 请求头**（否则后端不知道你传的是 JSON 还是表单）。

```javascript
const xhr = new XMLHttpRequest();

xhr.open('POST', 'https://api.example.com/login', true);

// ⚠️ 关键点：设置请求头 (必须在 open 之后，send 之前)
xhr.setRequestHeader('Content-Type', 'application/json'); 

xhr.onreadystatechange = function() {
    if (xhr.readyState === 4) {
        if (xhr.status === 200) {
            console.log('登录成功:', JSON.parse(xhr.responseText));
        }
    }
};

// 构造数据
const data = {
    username: 'admin',
    password: '123'
};

// ⚠️ 关键点：Body 必须是字符串，不能直接传 JS 对象
xhr.send(JSON.stringify(data));
```

### 第三部分：面试深挖与避坑指南

#### 1. `onload` vs `onreadystatechange`
现在的教程或新代码中，你可能会看到 `xhr.onload`。

*   **onreadystatechange**：老标准。兼容性极好（支持 IE6）。状态 1->2->3->4 都会触发，所以必须加 `if (xhr.readyState === 4)` 判断。
*   **onload**：新标准（XHR Level 2）。**只有在请求成功完成（readyState 变成 4）时才触发**。写起来更简洁，不用判断 readyState。

**现代写法推荐：**
```javascript
xhr.onload = function() {
    if (xhr.status === 200) { ... }
}
```

#### 2. 为什么不用同步 Ajax？
`xhr.open` 的第三个参数如果设为 `false`：
```javascript
xhr.open('GET', '/api', false); // 同步
xhr.send();
console.log('完成');
```
代码会卡在 `send()` 这一行，直到服务器返回数据。在这期间，**整个浏览器页面会“假死”**（点不动、滚不动、动画卡住）。这是极其糟糕的用户体验，所以永远要是用异步。

#### 3. 处理超时 (Timeout)
原生 XHR 怎么做超时处理？（Axios 里的 `timeout: 5000` 底层就是这个）
```javascript
xhr.timeout = 3000; // 设置 3秒超时
xhr.ontimeout = function() {
    console.log('请求超时了！网太烂了！');
};
```

### 🟢 随堂测试 (真题模拟)

假设面试官让你**把上面的原生 Ajax 封装成一个简单的 Promise 函数**（这就是 Axios 的雏形），你会怎么写？

你可以试着在心里构思一下，或者在纸上写写。

**参考答案 (背下来，这是加分项)：**

```javascript
function myAjax(url, method = 'GET', data = null) {
    return new Promise((resolve, reject) => {
        const xhr = new XMLHttpRequest();
        xhr.open(method, url, true);
        
        xhr.onload = function() {
            if (xhr.status >= 200 && xhr.status < 300) {
                // 成功，resolve 出去
                resolve(JSON.parse(xhr.responseText));
            } else {
                // 状态码错误，reject
                reject(new Error(`Status: ${xhr.status}`));
            }
        };
        
        xhr.onerror = function() {
            // 网络层面的错误（断网等）
            reject(new Error('Network Error'));
        };

        if (method === 'POST') {
            xhr.setRequestHeader('Content-Type', 'application/json');
            xhr.send(JSON.stringify(data));
        } else {
            xhr.send();
        }
    });
}

// 用法：
// myAjax('/user').then(res => console.log(res)).catch(err => console.error(err));
```

如果你能写出这个 `myAjax` 函数，这一节就算**精通**了。
