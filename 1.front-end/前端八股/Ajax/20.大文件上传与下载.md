### 第一部分：上传进度条 (`onUploadProgress`)

这是 Axios 原生支持的功能，非常简单，但用户体验提升巨大。

**场景**：用户上传一个 50MB 的 PPT，如果界面没反应，用户会以为卡死了。我们需要一个进度条。

#### 实战代码 (Vue 3)

```vue
<script setup>
import { ref } from 'vue';
import axios from 'axios';

const uploadProgress = ref(0);

const handleUpload = async (event) => {
    const file = event.target.files[0];
    if (!file) return;

    const formData = new FormData();
    formData.append('file', file);

    try {
        await axios.post('/api/upload', formData, {
            headers: {
                'Content-Type': 'multipart/form-data' // 只要是传文件，必须是这个
            },
            // 🔥 核心配置：监听上传进度事件
            onUploadProgress: (progressEvent) => {
                // progressEvent.loaded: 已上传大小
                // progressEvent.total: 总大小
                const percent = Math.round(
                    (progressEvent.loaded * 100) / progressEvent.total
                );
                uploadProgress.value = percent;
            }
        });
        console.log('上传成功');
    } catch (error) {
        console.error('上传失败');
    }
};
</script>

<template>
    <input type="file" @change="handleUpload" />
    <progress :value="uploadProgress" max="100"></progress>
    <span>{{ uploadProgress }}%</span>
</template>
```

### 第二部分：文件切片上传与断点续传 (原理与面试核心)

**面试必考题**：“如果我要上传一个 2GB 的视频，后端限制每次只能传 10MB，或者网络不稳定经常断开，怎么做？”

**核心原理：**
1.  **切片 (Slice)**：利用 `Blob.prototype.slice()` 方法，把一个大文件“切”成无数个小块（Chunk）。
2.  **并发上传**：把这些小块像发普通请求一样发给后端。
3.  **合并 (Merge)**：所有小块传完后，发一个请求告诉后端：“我传完了，请把它们拼起来”。

#### 1. 如何切片？ (代码实现)

```javascript
// 生成文件切片
function createFileChunks(file, size = 10 * 1024 * 1024) { // 默认 10MB 一片
    const chunks = [];
    let cur = 0;
    while (cur < file.size) {
        // file.slice 返回的也是一个 Blob 对象
        chunks.push(file.slice(cur, cur + size));
        cur += size;
    }
    return chunks;
}
```

#### 2. 如何实现“断点续传”？ (逻辑描述)

这是面试官最想听到的逻辑：

1.  **计算 Hash**：前端使用 `spark-md5` 库，根据文件内容计算出一个唯一的 Hash 值（文件指纹）。无论文件名怎么变，只要内容不变，Hash 就不变。
2.  **秒传检查 (Pre-check)**：
    *   上传前，先发个请求问后端：“这个 Hash 的文件你那里有吗？”
    *   **情况 A (秒传)**：后端说“有，完整的”。-> **直接显示上传成功**（其实没传，省流）。
    *   **情况 B (断点续传)**：后端说“有，但我只有切片 1, 2, 5”。-> 前端过滤掉 1, 2, 5，**只上传切片 3, 4 和剩余的**。
    *   **情况 C (新上传)**：后端说“完全没见过”。-> 前端从头开始传所有切片。

#### 3. 简易版并发上传逻辑

```javascript
async function uploadChunks(chunks, hash) {
    const requestList = chunks.map((chunk, index) => {
        const formData = new FormData();
        formData.append('chunk', chunk);
        formData.append('hash', hash); // 文件的唯一标识
        formData.append('filename', `filename-${index}`); // 切片名，后端靠这个排序
        
        // 每一个切片就是一个 Axios 请求
        return axios.post('/api/upload_chunk', formData);
    });

    // 并发上传所有切片
    await Promise.all(requestList);
    
    // 全部成功后，发送合并请求
    await axios.post('/api/merge_chunks', { hash, filename: 'video.mp4' });
}
```

### 第三部分：大文件下载 (二进制流 Blob)

**场景**：后端返回一个 Excel 报表导出，或者 PDF 下载。
**坑点**：如果你直接用 `axios.get`，控制台会打印出一堆乱码字符串，因为浏览器默认把它当文本解析了。

#### 1. 核心配置 `responseType: 'blob'`

```javascript
// src/api/file.js
export function downloadFile() {
    return request({
        url: '/api/export/excel',
        method: 'get',
        // ⚠️ 必填！告诉 Axios 后端返回的是二进制流，不是 JSON
        responseType: 'blob' 
    });
}
```

#### 2. 前端触发下载 (模拟 a 标签点击)

这是浏览器端的标准做法：**Blob -> ObjectURL -> Hidden Link -> Click**。

```javascript
// 组件中调用
const handleDownload = async () => {
    try {
        const res = await downloadFile(); 
        // 注意：如果你做了拦截器解包，这里 res 应该是 Blob 对象
        // 如果拦截器直接返回了 res.data，那这里就是 res.data
        
        // 1. 创建 Blob 对象 (有时候后端没设 Content-Type，需手动指定)
        const blob = new Blob([res], { 
            type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet' 
        });

        // 2. 创建下载链接 (URL.createObjectURL 是浏览器内存里的临时链接)
        const link = document.createElement('a');
        link.href = window.URL.createObjectURL(blob);
        
        // 3. 设置文件名 (暂时写死，后面讲怎么动态获取)
        link.download = '报表.xlsx';
        
        // 4. 模拟点击
        link.style.display = 'none';
        document.body.appendChild(link);
        link.click();
        
        // 5. 清理内存 (重要！否则会导致内存泄漏)
        document.body.removeChild(link);
        window.URL.revokeObjectURL(link.href);
        
    } catch (error) {
        console.error('下载失败', error);
    }
}
```

#### 3. 乱码之谜：如何获取正确的文件名？

很多时候，文件名是后端在响应头 `Content-Disposition` 里返回的。
格式通常是：`attachment; filename=xxxx.xlsx`。

**难点**：如果文件名包含中文，后端通常会进行 URL 编码（比如 `%E6%B5%8B%E8%AF%95`），直接拿下来是乱码。

**解决方案（在响应拦截器或组件中处理）：**

```javascript
// 假设我们在响应拦截器里拿到了完整的 response 对象
const disposition = response.headers['content-disposition'];

if (disposition) {
    // 1. 提取 filename= 后面的字符串
    // 正则匹配：filename="xxx.xlsx" 或 filename=xxx.xlsx
    let fileName = disposition.match(/filename=(.*)/)[1];
    
    // 2. 去掉可能的双引号
    fileName = fileName.replace(/"/g, '');
    
    // 3. 解码 (解决中文乱码)
    fileName = decodeURIComponent(fileName);
    
    return { data: response.data, fileName }; // 返回给组件
}
```

**参考答案：**

1.  **漏写了 `responseType: 'blob'`**。Axios 默认按 UTF-8 字符串解析二进制流，导致二进制数据被破坏，文件损坏。
2.  **`AbortController` (取消请求)**。暂停时，遍历当前正在上传的所有切片请求的 Controller，调用 `.abort()`。续传时，重新检查哪些没传，再发起请求。
