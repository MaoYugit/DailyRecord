这一章是**性能优化**的关键。

场景想象：你正在做一个“数据大屏”或者“个人中心”。你需要同时获取：
1.  用户基本信息 (`/user/info`)
2.  最近的订单列表 (`/user/orders`)
3.  未读消息数量 (`/user/notifications`)

**❌ 菜鸟写法（串行 - 慢）：**
```javascript
// 假设每个请求耗时 1秒，用户要等 3秒 才能看到完整页面
await getUserInfo();
await getOrders();
await getNotifications();
```

**✅ 高手写法（并行 - 快）：**
同时发出三个请求，用户只需要等 **最慢** 的那个请求回来即可（耗时约 1秒）。

### 第一部分：旧时代的 `axios.all` (了解即可)

在 ES6 Promise 普及之前，Axios 必须要自己实现并发功能。你会在很多老项目的代码里看到这个。

*   **语法**：`axios.all([])` 配合 `axios.spread()`。
*   **现状**：**已不推荐使用**。因为现代浏览器原生支持 `Promise.all`，Axios 官方也建议直接用原生的。

```javascript
// ⛔️ 考古代码：在维护 2018年以前的老项目时可能会看到
axios.all([
  axios.get('/user/1'),
  axios.get('/permissions/1')
])
.then(axios.spread((userRes, permsRes) => {
  // axios.spread 帮你把数组拆解成参数
  console.log('用户:', userRes.data);
  console.log('权限:', permsRes.data);
}));
```

### 第二部分：新标准 `Promise.all` (主流推荐)

这是现在的标准写法，**不仅适用于 Axios，适用于所有异步操作。**

#### 1. 基础用法 (结合 async/await)

利用 **数组解构 (Array Destructuring)**，代码非常优雅：

```javascript
const initPage = async () => {
    try {
        // 1. 准备好请求 Promise，但先不 await
        // 注意：这里没有 await！请求已经发出去在跑了！
        const reqUser = axios.get('/user/1');
        const reqPerms = axios.get('/permissions/1');

        // 2. 使用 Promise.all 等待它们全部完成
        const [userRes, permsRes] = await Promise.all([reqUser, reqPerms]);

        // 3. 两个都成功了，才执行这里
        console.log('用户:', userRes.data);
        console.log('权限:', permsRes.data);

    } catch (error) {
        // 4. ⚠️ 只要有一个请求失败，就会立刻跳到这里！
        console.error('页面加载失败，有一个接口挂了:', error);
    }
};
```

#### 2. ⚔️ 面试核心考点：`Promise.all` 的“一挂全挂”特性

**面试官问：** “如果 `/user` 成功了，但 `/permissions` 失败了（比如 404），上面的 `catch` 会捕获到吗？用户能看到用户信息吗？”

**答：** `catch` 会捕获到。**但是！用户看不到用户信息。**
因为 `Promise.all` 是 **“共存亡”** 的。只要有一个 Reject，整个 Promise 链直接炸掉，进入 catch。即便用户信息拿到了，代码逻辑也走不下去。

### 第三部分：高级场景 —— `Promise.allSettled` (容错处理)

**场景升级**：
首页有“核心数据”（必须有）和“广告推荐”（挂了也无所谓）。
如果用 `Promise.all`，广告接口挂了会导致首页打不开，这属于**P0级事故**。

这时要用 ES2020 的新特性：**`Promise.allSettled`**。
它保证：**不管成功失败，我都会等你结束，并且告诉你每个请求的结果。**

```javascript
const loadDashboard = async () => {
    const p1 = axios.get('/core-data'); // 核心数据
    const p2 = axios.get('/ads-banner'); // 广告（经常挂）

    const results = await Promise.allSettled([p1, p2]);

    // results 是一个数组，结构如下：
    // [
    //   { status: 'fulfilled', value: { ...response... } },
    //   { status: 'rejected', reason: { ...error... } }
    // ]

    // 处理核心数据
    if (results[0].status === 'fulfilled') {
        console.log('核心数据:', results[0].value.data);
    } else {
        alert('系统崩溃，请联系管理员');
    }

    // 处理广告（即使失败也不影响上面）
    if (results[1].status === 'fulfilled') {
        console.log('广告:', results[1].value.data);
    } else {
        console.log('广告加载失败，隐藏广告位即可');
    }
};
```

### 🟢 随堂测试 (实战模拟)

**题目**：
你需要在一个 Vue 组件挂载时 (`onMounted`) 并行请求两个接口。
1.  `getUser` (非常重要，失败了要提示错误)
2.  `getWeather` (不重要，失败了就显示“天气未知”)

请补全下面的代码逻辑：

```javascript
import { onMounted, ref } from 'vue';
import axios from 'axios';

const userData = ref(null);
const weatherData = ref(null);

onMounted(async () => {
    // 你的代码写在这里...
    // 提示：你可以用 Promise.allSettled，或者混合使用 try-catch
});
```

---
---

**参考答案 (一种优雅的混合写法)：**

```javascript
onMounted(async () => {
    // 技巧：给不重要的请求单独包一个 catch，让它永远变成“成功”状态（返回 null）
    // 这样我们就可以放心地用 Promise.all 了
    
    const userPromise = axios.get('/user');
    
    // 如果天气挂了，就返回 null，不要报错炸断 Promise.all
    const weatherPromise = axios.get('/weather').catch(() => null); 

    try {
        const [userRes, weatherRes] = await Promise.all([userPromise, weatherPromise]);
        
        // userRes 肯定有值，因为如果它挂了，会直接进下面的 catch
        userData.value = userRes.data;

        // weatherRes 可能是 response 对象，也可能是 null (如果挂了)
        if (weatherRes) {
            weatherData.value = weatherRes.data;
        } else {
            weatherData.value = '天气未知';
        }

    } catch (error) {
        // 这里只捕获 userPromise 的错误
        console.error('核心用户数据获取失败！', error);
    }
});
```
*(注：用 `Promise.allSettled` 也可以，但上面的写法在特定场景下更简洁)*

---

**总结：**
1.  别用 `axios.all` 了。
2.  绝大多数情况用 `Promise.all`（全成功才算成功）。
3.  如果允许部分失败，用 `Promise.allSettled` 或者给单个 Promise 加 `.catch`。
