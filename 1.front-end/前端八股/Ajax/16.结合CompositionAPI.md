这一章我们将见证 **Vue 3 Composition API** 的真正威力。

在 Vue 2 时代，处理 loading、error 状态通常需要你在 `data` 里写一堆变量，还要在 `methods` 里手动写 `loading = true/false`。这叫**样板代码 (Boilerplate)**，写多了非常烦。

在 Vue 3 中，我们可以利用 **Hook (组合式函数)** 将这些逻辑抽离出来。这不仅是开发提效的利器，也是**中高级前端面试的必考题**。

---

### 第一部分：标准写法 (基础版)

在没有封装 Hook 之前，我们通常是这样写一个页面的。这是所有 Vue 3 开发者的基本功。

**场景**：进入页面，加载用户列表，显示 Loading，加载完渲染数据。

```vue
<script setup>
import { ref, onMounted } from 'vue';
import { getUserList } from '@/api/user'; // 上一章封装的 API

// 1. 定义响应式数据
// ⚠️ 最佳实践：后端返回的数据通常是一个对象或数组，用 ref(null) 或 ref([]) 初始化
const tableData = ref([]); 
const loading = ref(false);
const error = ref(null);

// 2. 定义获取数据的函数
const fetchData = async () => {
  loading.value = true;
  error.value = null;
  
  try {
    // 假设 getUserList 返回的是 res.data
    const res = await getUserList();
    tableData.value = res.list;
  } catch (err) {
    error.value = err;
    console.error('获取失败', err);
  } finally {
    // 3. 无论成功失败，都要关闭 loading
    loading.value = false;
  }
};

// 4. 生命周期：挂载时触发
onMounted(() => {
  fetchData();
});
</script>

<template>
  <div v-if="loading">加载中...</div>
  <div v-else-if="error">出错了: {{ error.message }}</div>
  <ul v-else>
    <li v-for="item in tableData" :key="item.id">{{ item.name }}</li>
  </ul>
</template>
```

**痛点：**
如果你有 10 个页面，你就要写 10 次 `loading = true`，10 次 `try...catch...finally`。
**这不符合“DRY (Don't Repeat Yourself)”原则。**

### 第二部分：封装 `useRequest` Hook (进阶版)

我们要封装一个通用的 Hook，类似 React 的 `useRequest` (ahooks) 或 VueUse 的 `useFetch`。
它的目标是：**把状态管理（loading/data/error）自动化。**

在 `src/hooks/` 目录下新建 `useRequest.js` (或 .ts)。

#### 1. 核心代码实现

这是一个**面试级**的 Hook 实现，包含了自动执行和手动执行的逻辑。

```javascript
import { ref } from 'vue';

/**
 * @description 通用请求 Hook
 * @param {Function} apiFn - 返回 Promise 的 API 函数
 * @param {Object} options - 配置项 { immediate: boolean, initialData: any }
 */
export function useRequest(apiFn, options = {}) {
  const { immediate = true, initialData = null } = options;

  // 1. 定义状态
  const data = ref(initialData);
  const loading = ref(false);
  const error = ref(null);

  // 2. 定义执行函数
  const run = async (...args) => {
    loading.value = true;
    error.value = null;

    try {
      // 执行传入的 API 函数
      const res = await apiFn(...args);
      data.value = res;
      return res; // 返回数据供外部继续处理
    } catch (err) {
      error.value = err;
      throw err; // 继续抛出，以便外部也能捕获
    } finally {
      loading.value = false;
    }
  };

  // 3. 是否立即执行
  // 如果是获取列表，通常需要立即执行
  // 如果是提交表单，通常不需要立即执行，而是等待用户点击
  if (immediate) {
    run();
  }

  // 4. 返回状态和方法
  return {
    data,
    loading,
    error,
    run // 暴露给外部手动调用（比如点击刷新按钮）
  };
}
```

### 第三部分：使用 Hook 重构组件

看看现在的组件代码变得多简洁：

```vue
<script setup>
import { getUserList } from '@/api/user';
import { useRequest } from '@/hooks/useRequest';

// 🔥 一行代码搞定所有状态管理
// immediate: true 代表组件加载时自动触发 run()
const { data: tableData, loading, error, run: reload } = useRequest(getUserList, {
  immediate: true,
  initialData: []
});

// 如果你想在某个按钮点击时重新加载
// <button @click="reload">刷新</button>
</script>

<template>
  <div v-if="loading">Loading...</div>
  <div v-else-if="error">Error!</div>
  <!-- 注意：如果 getUserList 返回结构不同，这里可能要写 tableData.list -->
  <ul v-else>
    <li v-for="item in tableData" :key="item.id">{{ item.name }}</li>
  </ul>
</template>
```

**优势对比：**
*   **代码量**：减少了 60%。
*   **可读性**：逻辑一目了然，不再关注 try-catch 细节。
*   **复用性**：任何接口都可以套用这个 Hook。

### 第四部分：`ref` vs `reactive` 在 API 数据中的选择

这是面试常考题：**“接收接口数据时，应该用 `ref` 还是 `reactive`？”**

**推荐答案：使用 `ref`。**

**理由：**
1.  **数据替换方便**：
    *   接口返回通常是一个全新的对象或数组。
    *   用 `ref`：`data.value = res.data` (简单，触发响应式)。
    *   用 `reactive`：`data = res.data` **会丢失响应式！**
        *   你必须写成 `Object.assign(data, res.data)` 或者把 reactive 定义为一个包含 list 的对象 `const state = reactive({ list: [] })` 然后 `state.list = res.data`。这很麻烦。
2.  **解构丢失问题**：
    *   Hook 返回 `reactive` 对象时，如果用户在组件里解构 `const { loading } = useRequest(...)`，`loading` 会失去响应式（除非用 `toRefs`）。
    *   Hook 返回 `ref` 对象，怎么解构都没事。

### 🟢 随堂测试

**题目**：
你需要实现一个“搜索”功能。用户输入关键词，点击按钮后调用 API。
请使用刚才封装的 `useRequest` 来实现。

**要求**：
1.  默认不发起请求。
2.  点击按钮时传入输入框的值。

```vue
<script setup>
import { ref } from 'vue';
import { searchUser } from '@/api/user';
import { useRequest } from '@/hooks/useRequest';

const keyword = ref('');

// 请填空：如何配置 useRequest？
const { ________, ________ } = useRequest(searchUser, { 
    ________: ________ // 默认不执行
});

const handleSearch = () => {
    // 请填空：如何触发请求并传参？
    ________(keyword.value);
}
</script>
```

---
---

**参考答案：**

```javascript
// 1. 解构 data 和 run 方法
const { data: searchResult, run } = useRequest(searchUser, { 
    immediate: false // 默认不执行，等用户点
});

const handleSearch = () => {
    // 2. 调用 run 方法，传入参数
    run(keyword.value);
}
```
