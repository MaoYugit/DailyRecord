终于到了实战环节！
从这一刻起，我们不再手写 `XMLHttpRequest`，也不再纠结 Fetch 的两次 await。我们要开始使用 **Axios** —— 这个前端开发的瑞士军刀。

这一章的目标是：**让你闭着眼睛都能写出正确的请求代码，并且彻底搞懂 `params` 和 `data` 的区别（这是初学者最大的坑）。**

---

### 第一部分：安装与引入

在 Vue 3 项目中（通常是 Vite 或 CLI 创建的），我们需要先安装它。

**1. 安装**
打开终端，在项目根目录下执行：
```bash
npm install axios
# 或者
yarn add axios
# 或者
pnpm add axios
```

**2. 引入**
在任何 `.vue` 文件或 `.js/.ts` 文件中：
```javascript
import axios from 'axios';
```

### 第二部分：基本请求语法 (CRUD 快捷方式)

Axios 为常见的 HTTP 方法提供了别名（快捷方法）。
**核心口诀：** **“查参数用 params，改数据用 data”**。

#### 1. GET 请求 (查)
通常用于获取数据。
*   **参数位置**：URL 后面（Query String）。
*   **写法**：
    ```javascript
    // 写法 A：直接拼在 URL 里 (不推荐，参数多了很难看)
    axios.get('/user?ID=12345');
    
    // 写法 B：使用 params 配置 (推荐！企业级写法)
    axios.get('/user', {
        params: {
            ID: 12345,
            status: 'active'
        }
    });
    // Axios 会自动把对象转换成：/user?ID=12345&status=active
    ```

#### 2. POST 请求 (增)
通常用于提交表单、新建数据。
*   **参数位置**：Request Body（请求体）。
*   **写法**：
    ```javascript
    const newUser = { firstName: 'Fred', lastName: 'Flintstone' };
    
    // 注意：第二个参数直接就是数据对象，不是配置对象！
    axios.post('/user', newUser);
    ```

#### 3. PUT 请求 (改 - 全量)
用法和 POST 几乎一样。
```javascript
axios.put('/user/123', { firstName: 'Barney' });
```

#### 4. DELETE 请求 (删)
**⚠️ 注意坑点**：DELETE 的参数传递方式很特殊。
通常删除只需要传 ID 在 URL 里。如果非要传 Body，需要包在 `data` 里。
```javascript
// 情况 1：ID 在 URL (最常见)
axios.delete('/user/123');

// 情况 2：需要传 Body (比如批量删除 ID 列表)
// 注意：第二个参数是 config，数据要放在 config.data 里
axios.delete('/user', {
    data: { ids: [1, 2, 3] }
});
```

### 第三部分：配置对象 (Config Object) —— 核心中的核心

虽然上面的快捷方式很好用，但在封装企业级 `request.js` 时，我们更多使用的是 **通用配置写法**。

这种写法将所有请求细节收敛到一个对象中，非常清晰。

```javascript
axios({
    // 1. url: 接口地址
    url: '/user/123',

    // 2. method: 请求方法 (默认是 get，不区分大小写)
    method: 'post', 

    // 3. baseURL: 基础 URL (非常重要)
    // 自动拼接到 url 前面。比如 baseURL 是 'https://api.com'，那最终请求就是 'https://api.com/user/123'
    baseURL: 'https://api.example.com', 

    // 4. headers: 请求头
    headers: {
        'X-Requested-With': 'XMLHttpRequest',
        'Authorization': 'Bearer token_xyz' 
    },

    // 5. params: URL 参数 (Query String) -> 对应 GET
    // 最终变成 ?ID=12345
    params: {
        ID: 12345
    },

    // 6. data: 请求体 (Body) -> 对应 POST/PUT
    // 只有 put, post, delete, patch 才有这个参数
    data: {
        firstName: 'Fred'
    },

    // 7. timeout: 超时时间 (毫秒)
    // 如果超过这个时间（比如 5秒）后端还没回，请求直接断开并报错
    // 默认是 0 (永不超时)，企业级开发必须设置，通常 5000 或 10000
    timeout: 5000, 
    
    // 8. responseType: 预期服务器返回的数据类型
    // 默认 'json'。如果要下载文件，这里要改成 'blob' (后面大文件下载会讲)
    responseType: 'json' 
});
```

### ⚔️ 面试重难点：`params` vs `data`

这是初级 Vue 开发者最容易搞混，也是面试官最爱问的细节。

| 属性名     | 全称        | 对应 HTTP 位置         | 典型场景                 | Axios 转换结果            |
| :--------- | :---------- | :--------------------- | :----------------------- | :------------------------ |
| **params** | Parameters  | **URL** (Query String) | GET 搜索、分页、筛选     | `/api?id=1&page=2`        |
| **data**   | Data (Body) | **Request Body**       | POST 提交表单、上传 JSON | JSON 字符串 `{ "id": 1 }` |

**面试官问：** “我在 POST 请求里能不能用 params？”
**答：** “能，但很少见。如果你用了 `params`，数据会拼在 URL 后面（`POST /login?user=admin`）；如果你用了 `data`，数据在 Body 里。通常 POST 都是用 `data`。”

### 🟢 随堂测试 (找 Bug 环节)

下面这两段代码是新手常犯的错误，请指出**哪里写错了**或者**会有什么后果**。

**代码 A (GET 请求):**
```javascript
// 想查询 ID 为 1 的用户
axios.get('/user', { id: 1 }); 
```

**代码 B (POST 请求):**
```javascript
// 想提交用户信息
axios.post('/user', {
    params: {
        name: 'Vue',
        age: 3
    }
});
```

---
---

**答案解析：**

1.  **代码 A 错误**：`axios.get` 的第二个参数必须是**配置对象**，不能直接传数据。
    *   *修正*：`axios.get('/user', { params: { id: 1 } })`。
    *   *后果*：Axios 会把 `{ id: 1 }` 当作配置对象去解析，发现里面没有 `params` 也没 `headers`，结果发出去的是一个不带任何参数的 `/user` 请求。

2.  **代码 B 错误**：`axios.post` 的第二个参数是 **Data (Body)**。
    *   *后果*：你实际发送给后端的 Body 数据是：`{ "params": { "name": "Vue", "age": 3 } }`。多嵌套了一层 `params` 属性。
    *   *修正*：直接传对象 `axios.post('/user', { name: 'Vue', age: 3 })`。
