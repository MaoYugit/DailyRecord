在前端面试中，“手写代码”（Coding）环节主要考察你对 **JavaScript 语言底层机制的理解**、**编程思维**以及**代码健壮性**的掌握。

面试官让你手写的通常不是复杂的 LeetCode 算法题（虽然大厂也会考），而是**常用 API 的 Polyfill（垫片）实现**、**实用工具函数**或者**设计模式**。

以下是按考察频率和重要性分类的“必考”清单：

---

### 第一梯队：高频必考（必须滚瓜烂熟）

这部分是基础中的基础，如果写不出来或写得漏洞百出，通常会直接挂掉。

1.  **防抖 (Debounce) & 节流 (Throttle)**
    *   **考察点**：闭包、`setTimeout`、`this` 指向、高阶函数。
    *   **场景**：输入框搜索（防抖）、滚动条监听（节流）。
    *   **加分项**：能否实现“立即执行”的版本？能否支持取消？

2.  **深拷贝 (Deep Clone)**
    *   **考察点**：递归、数据类型判断、**循环引用**（这也是最大的坑，需要用 `WeakMap` 解决）。
    *   **场景**：Redux 状态更新、复杂对象处理。

3.  **手写 Call / Apply / Bind**
    *   **考察点**：`this` 的显式绑定、`Symbol`（防止属性名冲突）、参数处理。
    *   **核心逻辑**：将函数设为对象的属性执行，执行完删除。

4.  **手写 Promise 系列**
    *   **`Promise.all`**：考察并发、结果顺序保证、错误处理。
    *   **`Promise.race`**：考察竞态机制。
    *   **简易版 `Promise` 类**：考察状态机（Pending/Fulfilled/Rejected）、发布订阅模式（`.then` 的链式调用）。

5.  **发布订阅模式 (EventEmitter)**
    *   **考察点**：设计模式。需要实现 `on` (订阅), `emit` (发布), `off` (取消), `once` (只执行一次)。
    *   **场景**：Vue Bus、Node.js Events。

---

### 第二梯队：语言底层与工具函数

考察你对 JavaScript 数组、对象及原型链的熟悉程度。

6.  **数组去重 (Unique)**
    *   **方法**：`Set` 一行代码、`Map`、`filter` + `indexOf`。
    *   **陷阱**：如何处理对象数组去重？`NaN` 去重？

7.  **数组扁平化 (Flat)**
    *   **考察点**：递归、`reduce`、扩展运算符。
    *   **要求**：实现 `flat(arr, depth)`，指定层级扁平化。

8.  **柯里化 (Currying)**
    *   **考察点**：闭包、递归、函数参数长度 (`Function.length`)。
    *   **典型题**：实现 `add(1)(2)(3)` 输出 6。

9.  **手写 `new` 操作符**
    *   **考察点**：原型链继承、构造函数执行、返回值判断（如果构造函数返回对象，则忽略 `this`）。

10. **手写 `instanceof`**
    *   **考察点**：原型链查找 (`__proto__` 循环向上查找直到 `prototype` 匹配)。

11. **对象继承 (寄生组合式继承)**
    *   **考察点**：ES5 时代的继承写法，`Object.create` 的使用。

---

### 第三梯队：异步与并发控制（进阶）

这部分在字节跳动、阿里等大厂面试中非常常见。

12. **并发限制的调度器 (Scheduler)**
    *   **题目**：实现一个带并发限制的异步调度器，保证同时运行的任务最多有 N 个。
    *   **考察点**：队列（Queue）、递归/循环调用、Promise。

13. **手写 AJAX (XMLHttpRequest)**
    *   **考察点**：基础 API、`onreadystatechange`、状态码判断。虽然现在都用 Axios/Fetch，但老代码需要懂。

14. **Sleep / Delay 函数**
    *   **题目**：实现一个函数，等待 N 秒后执行。
    *   **解法**：返回一个 `Promise`，配合 `setTimeout`。

---

### 第四梯队：框架原理与场景题

结合 Vue/React 或实际 DOM 操作。

15. **解析 URL 参数**
    *   **题目**：将 `?a=1&b=2&c=3` 解析为对象。
    *   **考察点**：正则、`split`、解码 (`decodeURIComponent`)。

16. **模板引擎 / 字符串插值**
    *   **题目**：实现 `render(template, data)`，将 `{{ name }}` 替换为 data 中的值。
    *   **考察点**：正则替换、递归获取属性（如 `data.user.name`）。

17. **简易版 Vue 响应式原理**
    *   **考察点**：`Object.defineProperty` (Vue2) 或 `Proxy` (Vue3)。你需要写出 getter (依赖收集) 和 setter (触发更新) 的基本结构。

18. **虚拟 DOM 转真实 DOM**
    *   **题目**：给定一个 vnode 对象（tag, props, children），写一个函数生成真实的 DOM 节点。
    *   **考察点**：`document.createElement`、递归渲染子节点。

19. **图片懒加载 (Lazy Load)**
    *   **考察点**：`IntersectionObserver` API 或 滚动监听 + `getBoundingClientRect`。

---

### 面试官看重什么？（避坑指南）

当你手写这些代码时，面试官不仅看结果，更看重以下几点：

1.  **边界条件处理**：
    *   如果参数传错了怎么办？（如 `deepClone` 传入 `null` 或函数）。
    *   如果数组是空的怎么办？
2.  **代码规范与命名**：变量名是否语义化，代码缩进是否规范。
3.  **沟通能力**：
    *   **动手前先沟通**：不要闷头写，先告诉面试官你的思路（例如：“我打算用 Map 来解决循环引用的问题”）。
    *   **时间不够**：如果你知道思路但代码太长，可以申请写伪代码或核心逻辑。
4.  **ES6+ 新特性**：能用 `const/let`、箭头函数、解构赋值、`Proxy`、`Reflect` 等新特性通常比写 ES3/ES5 老语法更加分。
