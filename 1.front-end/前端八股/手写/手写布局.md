**CSS 布局**和**界面实现**是前端面试中“手写”环节的另一大重头戏。

不同于 JS 考察逻辑，CSS 考察的是你的**页面还原能力**、**对盒模型的理解**以及**解决兼容性问题的经验**。

以下是面试中 CSS 布局类手写题的“必考清单”，按出现频率排序：

---

### 第一梯队：居中与对齐（由浅入深）

这是最基础的，但面试官会不断加限制条件来考察你的深度。

1.  **水平垂直居中 (Center Everything)**
    *   **题目**：实现一个宽高不定的子元素在父元素中水平垂直居中。
    *   **必会解法**：
        1.  **Flexbox** (最推荐): `display: flex; justify-content: center; align-items: center;`
        2.  **Absolute + Transform**: `position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);` (适用于不定宽高)
        3.  **Grid**: `display: grid; place-items: center;`
    *   **老式解法**（可能问到）：
        *   `margin: auto; position: absolute; top: 0; left: 0; right: 0; bottom: 0;` (需要定宽高)

2.  **两端对齐**
    *   **题目**：列表最后一个元素靠右，其他元素靠左；或者常见的导航栏布局。
    *   **解法**：Flexbox 的 `justify-content: space-between` 或者 `margin-left: auto` 技巧。

---

### 第二梯队：经典分栏布局

这部分主要考察文档流、浮动（Float）、BFC 以及 Flex 的应用。

3.  **两栏布局（左定宽，右自适应）**
    *   **题目**：左边侧边栏宽度固定 200px，右边内容区占满剩余空间。
    *   **解法**：
        *   **Flex**: 父 `display: flex`，右侧 `flex: 1`。
        *   **Float**: 左浮动，右边 `margin-left: 200px` (或触发 BFC)。
        *   **Grid**: `grid-template-columns: 200px 1fr;`

4.  **三栏布局（圣杯布局 / 双飞翼布局）**
    *   **背景**：虽然 Flex 甚至 Grid 已经秒杀这个问题，但很多面试官为了考察你对 **Float、负 Margin、清除浮动** 的理解，依然会考这两个经典老题。
    *   **题目**：左右两栏固定宽度，中间栏自适应，且**中间栏优先渲染**（HTML 结构中在前面）。
    *   **核心难点**：如何利用 `float`, `margin-left: -100%`, 以及 `position: relative` (圣杯) 或 内部 `div` (双飞翼) 把左右两块拉到正确的位置。

---

### 第三梯队：实际 UI 场景复现

考察解决实际业务痛点的能力。

5.  **Sticky Footer（紧贴底部的页脚）**
    *   **题目**：当页面内容很少时，Footer 必须固定在视口底部；当内容很多超过一屏时，Footer 被顶下去，跟在内容后面。
    *   **解法**：
        *   **Flex**: `body { min-height: 100vh; display: flex; flex-direction: column; }` 内容区 `flex: 1`。
        *   **Grid**: `grid-template-rows: auto 1fr auto;`

6.  **画几何图形（CSS Shapes）**
    *   **三角形**：非常高频。
        *   原理：宽高为 0，利用 `border`。如 `border-width: 50px; border-color: transparent transparent red transparent;`
    *   **扇形**：在三角形基础上加 `border-radius`。

7.  **单行/多行文本溢出省略 (...)**
    *   **单行**：`white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`
    *   **多行**：需要用到 Webkit 私有属性 `-webkit-line-clamp: 3; -webkit-box-orient: vertical; display: -webkit-box;`。

8.  **九宫格 / 瀑布流**
    *   **九宫格**：Flex `flex-wrap: wrap` 或 Grid 布局。
    *   **瀑布流**（Masonry）：
        *   纯 CSS 方案（`column-count` 多列布局，但顺序是竖向的）。
        *   JS + CSS 绝对定位计算方案。

---

### 第四梯队：移动端与高保真还原

9.  **0.5px 边框 (Retina 屏 1px 问题)**
    *   **题目**：在高清屏上，CSS 写 `1px` 看起来太粗，设计要更细的线。
    *   **解法**：伪元素 + `transform: scale(0.5)` + `transform-origin: 0 0`。

10. **等比例矩形**
    *   **题目**：实现一个 `div`，宽度为屏幕的一半，**高度始终等于宽度**（即正方形），随屏幕缩放。
    *   **解法**：利用 `padding-top` 百分比是相对于**父元素宽度**计算的特性。`width: 50%; padding-top: 50%; height: 0;`

---

### 面试官考察布局时的心理活动

当你手写布局代码时，面试官会关注：

1.  **是否拥抱现代标准**：
    *   能用 Flex/Grid 解决的，尽量别用 Float/Position，除非面试官明确要求兼容 IE 或者考旧知识。
    *   使用 Flex 是“常规操作”，使用 Grid 是“加分项”，还在盲目用 Float 可能是“知识陈旧”。

2.  **HTML 语义化**：
    *   布局是不是全用 `div`？有没有考虑 `<header>`, `<footer>`, `<nav>`, `<main>`？
    *   类名命名是否规范（BEM 或语义化命名，如 `.container` 而不是 `.box1`）。

3.  **盒模型理解**：
    *   会不会主动设置 `box-sizing: border-box`？（这是老手和新手的典型区别，不写这个在处理 Padding 和 Border 时很容易布局错乱）。

### 总结：应该怎么练？

不用背长代码，建议你打开 **CodePen** 或 **JSBin**，把下面这三个练熟即可覆盖 80% 的面试：

1.  **三行代码搞定居中**（Flex版）。
2.  **左侧固定右侧自适应**（Flex版 + Grid版）。
3.  **画一个三角形**。

其他的题目，知道了原理，现场都能推导出来。
