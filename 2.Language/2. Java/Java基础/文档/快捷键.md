好的，这里是一些 IntelliJ IDEA 中非常常用且能极大提高开发效率的快捷键。请注意，Windows/Linux 和 macOS 的快捷键有所不同，下面将分别列出。

### 一、通用/全局快捷键 (General)

| 功能                    | Windows / Linux                | macOS                          |
| :---------------------- | :----------------------------- | :----------------------------- |
| **查找一切** (万能搜索) | `Double Shift` (连按两次Shift) | `Double Shift` (连按两次Shift) |
| 查找操作 (Find Action)  | `Ctrl + Shift + A`             | `Cmd + Shift + A`              |
| 显示项目视图            | `Alt + 1`                      | `Cmd + 1`                      |
| 显示/隐藏所有工具窗口   | `Ctrl + Shift + F12`           | `Cmd + Shift + F12`            |
| 打开设置                | `Ctrl + Alt + S`               | `Cmd + ,`                      |

### 二、编辑代码 (Editing)

| 功能                                   | Windows / Linux          | macOS                      |
| :------------------------------------- | :----------------------- | :------------------------- |
| **代码补全**                           | `Ctrl + Space`           | `Ctrl + Space`             |
| 智能代码补全                           | `Ctrl + Shift + Space`   | `Ctrl + Shift + Space`     |
| **生成代码** (构造器, Getter/Setter等) | `Alt + Insert`           | `Cmd + N` / `Ctrl + Enter` |
| 快速修复/显示意图操作                  | `Alt + Enter`            | `Option + Enter`           |
| **格式化代码**                         | `Ctrl + Alt + L`         | `Cmd + Option + L`         |
| 优化导入                               | `Ctrl + Alt + O`         | `Ctrl + Option + O`        |
| 复制当前行                             | `Ctrl + D`               | `Cmd + D`                  |
| 删除当前行                             | `Ctrl + Y`               | `Cmd + Backspace`          |
| 上/下移动行                            | `Ctrl + Shift + Up/Down` | `Cmd + Shift + Up/Down`    |
| 包裹代码 (if, for, try/catch...)       | `Ctrl + Alt + T`         | `Cmd + Option + T`         |
| 注释/取消注释当前行                    | `Ctrl + /`               | `Cmd + /`                  |
| 注释/取消注释代码块                    | `Ctrl + Shift + /`       | `Cmd + Option + /`         |
| 重命名                                 | `Shift + F6`             | `Shift + F6`               |
| 提取变量                               | `Ctrl + Alt + V`         | `Cmd + Option + V`         |
| 提取方法                               | `Ctrl + Alt + M`         | `Cmd + Option + M`         |

### 三、查找与替换 (Search & Replace)

| 功能             | Windows / Linux    | macOS             |
| :--------------- | :----------------- | :---------------- |
| **当前文件查找** | `Ctrl + F`         | `Cmd + F`         |
| 当前文件替换     | `Ctrl + R`         | `Cmd + R`         |
| **全局查找**     | `Ctrl + Shift + F` | `Cmd + Shift + F` |
| 全局替换         | `Ctrl + Shift + R` | `Cmd + Shift + R` |
| 查找类           | `Ctrl + N`         | `Cmd + O`         |
| 查找文件         | `Ctrl + Shift + N` | `Cmd + Shift + O` |

### 四、导航 (Navigation)

| 功能                       | Windows / Linux                 | macOS                         |
| :------------------------- | :------------------------------ | :---------------------------- |
| **查看声明/定义**          | `Ctrl + B` 或 `Ctrl + 左键单击` | `Cmd + B` 或 `Cmd + 左键单击` |
| 查看实现                   | `Ctrl + Alt + B`                | `Cmd + Option + B`            |
| **查看用法** (Find Usages) | `Alt + F7`                      | `Option + F7`                 |
| 返回上次编辑位置           | `Ctrl + Alt + Left/Right`       | `Cmd + Option + Left/Right`   |
| 在打开的文件间切换         | `Alt + Left/Right`              | `Ctrl + Left/Right`           |
| 显示最近文件               | `Ctrl + E`                      | `Cmd + E`                     |
| 跳转到指定行               | `Ctrl + G`                      | `Cmd + L`                     |
| 查看类/方法/变量的文档     | `Ctrl + Q`                      | `Ctrl + J` / `F1`             |
| 查看类层级结构             | `Ctrl + H`                      | `Ctrl + H`                    |
| 查看方法层级结构           | `Ctrl + Shift + H`              | `Cmd + Shift + H`             |

### 五、运行与调试 (Run & Debug)

| 功能                 | Windows / Linux | macOS              |
| :------------------- | :-------------- | :----------------- |
| **运行程序**         | `Shift + F10`   | `Ctrl + R`         |
| 调试程序             | `Shift + F9`    | `Ctrl + D`         |
| 停止运行/调试        | `Ctrl + F2`     | `Cmd + F2`         |
| **下一步 (逐行)**    | `F8`            | `F8`               |
| **进入方法**         | `F7`            | `F7`               |
| 跳出方法             | `Shift + F8`    | `Shift + F8`       |
| 继续运行到下一个断点 | `F9`            | `Cmd + Option + R` |
| 设置/取消断点        | `Ctrl + F8`     | `Cmd + F8`         |

**一些高效使用的建议:**

*   **从 `Alt + Enter` (快速修复) 开始**: 这是 IDEA 的“神键”。当你看到任何波浪线或者有想法时，都可以按一下它，IDEA 会给你很多有用的建议。
*   **善用 `Double Shift`**: 当你忘记某个快捷键，或者想找某个类、文件、设置时，连按两下 Shift 搜索即可。
*   **记住重构相关的快捷键**: 像重命名 (`Shift + F6`)、提取变量/方法 (`Ctrl + Alt + V/M`) 这类快捷键可以极大地提升代码的可维护性。
*   **自定义快捷键**: 如果你从其他编辑器（如 Eclipse 或 VS Code）转过来，可以在 `Settings/Preferences -> Keymap` 中选择你习惯的快捷键方案，或者自定义你觉得不顺手的快捷键。
